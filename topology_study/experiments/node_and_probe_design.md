# 配电网拓扑辨识与调度式 Probe 的论文实验设计

论文检验两项贡献。第一项是在当前树的分叉点用 Node MIQP（节点混合整数二次规划）联合选择共享上游线路的子树、重估全树阻抗，再由 Tree MIQP 重新选树。第二项是对仍有竞争解释的接法，利用预测电压响应选择下一小时需求响应的用户、方向和电量，再用执行后的量测更新采购。正文先比较**完整方法的效果**，再用中间输出和单因素消融解释收益来源。

## 2. 正文实验一：相同被动历史上的整树辨识

已有支路开合 MIQP 和逆变器扰动下的候选母线连线识别可用于讨论先例。若另作这类定量比较，应设置共同的母线图、可用量测和可控设备，并在结果表注明这些先验。[Tian 等](https://doi.org/10.1109/TPWRS.2015.2394454) · [Taheri 等全文](https://engineering.purdue.edu/~kekatos/papers/PowerTech2019.pdf)

每种方法在同一截止时刻交付一棵树。主表使用相同端表的有功 P、无功 Q、电压 V 和首端电压。另列具备 PCC 功率时的完整部署结果，并在同批算例增加“所提法有/无 PCC 功率”配对，量出这项额外信息带来的影响。各方法都采用其实际支持的量测，表头注明所用通道。真值拓扑、内部母线的潮流状态和受控评价日的量测仅供模拟或事后评分。

| 方法 | 实施口径与比较目的 |
| --- | --- |
| RG（递归分组）、NJ（邻接法）、RNJ（有根邻接法） | 报告三个独立的构树输出。现有三个实现共用从历史量测估计的共享路径电阻矩阵 `R̂` 及由它算出的路径距离，适合比较同一距离上不同构树规则。论文主基线给各方法使用开发馈线上预定的容差和多叉处理的机会，列明根的处理和短边合并规则。项目内零容差/数值容差等原始版本另存为实际热启动。 |
| Park 等的端表辨识法 | 增加一条从 V/P/Q 原始序列独立估计电阻距离、再递归分组的配电网文献方法。按原文估计矩实现，先在隐藏中间节点度数至少为三、跨节点注入不相关且表内 P/Q 激励足够的参考算例校验，再上相同主表。记录相关负荷和近固定功率因数时的病态或失败。 |
| 所提主辨识流程（Proposed ID） | 报最终表计分组树。初始树、锚定后树和 Node 搜索后树用于归因。线路翻转评分只对所提法另作正确判定/错误判定/未决评价。 |

现有 NJ 以 PCC 作为根的参考点，使用标准 Q 准则。RG 在噪声下会回退到距离差分散程度最小的一对。RNJ 用共享路径、中位数更新和零分支容差。稿件采用原文名称 *Rooted Neighbor Joining*，描述项目实现时注明这些选择。Park 基线使用自己的矩估计前端。文献依据为 RG、RNJ、Park 作者全文的方法部分及 NJ 原论文。[实际构树代码](../ptid/method/builders.py) · [Choi 等，RG](https://www.jmlr.org/papers/volume12/choi11b/choi11b.pdf) · [Saitou 与 Nei，NJ](https://doi.org/10.1093/oxfordjournals.molbev.a040454) · [Ni 与 Tatikonda，RNJ](https://arxiv.org/pdf/0809.0158) · [Park 等，配电网端表法](https://arxiv.org/pdf/1710.10727)

**整树指标按下游表计分组计算。** 去掉单表服务线和包含所有表计的公共段，统一合并等价投影。有隐藏负荷时，各法仍在同一表计集合上评分。逐馈线报告正确、误增、漏辨的分组数，精确率、召回率、F1、整树完全命中及含预处理的总耗时。主分析沿用 3 mΩ 短线合并规则，另对全部物理分组复算。真值与估计均为空时单列整树命中，注明 F1 约定。以馈线等权汇总，附分组总数。超时、病态或无输出均计入完成率的分母，标明有解及共同有效的配对数。九棵初始树仅按历史拟合评分择优。[现有评分口径](../PROTOCOL.md)

## 3. 正文实验二：完整辨识加调度式 Probe

主比较为**同一初始辨识结果的全天被动更新与全天主动更新**。二者都有新一天的量测。差别是是否采购、采购怎样改变运行点。再用两个主动对照拆开目标选择和反馈重排的价值。每条馈线复用历史、日初树、基础负荷、初始设备荷电状态和按表计/小时预先配对的噪声。每种政策在自己的执行轨迹上逐时更新。

| 政策 | 如何行动 | 与所提法的配对含义 |
| --- | --- | --- |
| P0　主辨识＋被动更新 | 不采购，全日采数、重新辨识 | 一天自然负荷变化本身已解决多少歧义 |
| P1　主辨识＋整树分歧滚动调度 | 将旧版强贪心的整树打分接入相同的候选、设备、预算与辨识器 | 采购瞄准具体未决分组的增益 |
| P2　主辨识＋日初固定计划 | 用相同局部目标、日初竞争树及可获得的逐时预测制定计划，预扣预算、推算荷电状态。逐时执行同一安全及停买检查，失效动作跳过，后续不重排 | 获得最新量测后重排调度的增益 |
| P3　主辨识＋所提滚动 Probe | 用当时的竞争接法预测购买与零购买下的电压分离程度，按辨识收益及价格选择下一小时的用户、方向和电量 | 完整主张 |

同时保留主辨识在**执行前**的结果，形成“日初辨识、日终被动、日终主动”三列。跨算法的日终整树比较统一在 P0 的相同观测序列做。如要回答“同样的主动数据能否帮助其他算法”，可把同一条 P3 已执行轨迹交给 RG、NJ、RNJ、Park 和 Proposed ID 重新估计，标明为固定轨迹回放。政策效果以 P0–P3 各自真实执行的轨迹评价。

在第 h 小时初仅使用截至第 h−1 小时的量测，为第 h+1 小时下单，当小时兑现此前承诺。沿用每小时 20 元、每日 100 元、上/下调 1.2/4 元每千瓦时、单表计单方向四档幅度和相同可行性检查。提前停买后继续被动观测至共同终点。48 小时版需接入第二日逐 15 分钟底层数据、按当地时钟处理设备可用性、跨午夜衔接电池状态及订单、按交付日计每日预算。初始目标固定，累计历史、识别状态和噪声连续。若比较相同总投入下的时长价值，另设相同两日总上限。[当前只执行第九天的实现](../ptid/cases/world.py) · [下单与重辨识逻辑](../ptid/method/probe.py)

主指标是同一批日初可评价的未决表计分组中，**正确判清、错误判定、仍未判定**各有几个。确认存在和排除不存在均计入。另报已判定中的误判率、最终全树 F1、实际支出、调节电量、动作数、正确判定出现与持续的时间。零目标日保留在总天数和费用统计，单列比例。隐藏负荷位置 `place` 尚无真值匹配，单列状态及相关采购。每 15 分钟用 AC 仿真记录实际母线电压和变压器有功与视在功率，按交付小时记录资源荷电状态。与同一时点被动轨迹比较新增越限。预算相同仍须报告实际花费，用费用重叠区间比较成本效率。[现行评价入口](../ptid/runs/probe_cases.py)

## 4. 贡献归因：从启发式热启动到锚定后的最终解

“热启动的 Tree MIQP 与固定 block 后的完整 MIQP”在论文中宜写为**“初始候选池的 Tree MIQP，与保留本轮锚定分组、经过候选扩充和整树重选的最终辨识结果比较”**。锚点是本轮要求保留的下游表计分组，下一轮可重新判定。锚点内部还能细化。每个锚和根的直接单元都至多 9 个时，枚举覆盖保留这些锚的所有候选分组。出现宽节点时，Tree MIQP 的界属于当轮实际候选域，Node MIQP 的界属于当前树、当前节点的一次加线。证明最优还需相应求解界闭合。这里的分组与 Probe 采购的一小时功率块是两类对象。[锚点及其单元](../ptid/method/anchors.py) · [完整执行顺序与求解界](../ptid/method/identify.py)

**同一次运行保存以下输出。** 对每一步报告分组 TP/FP/FN、F1、同一历史上的目标值 H、累计耗时，求解步骤另报候选域、有效上下界差和超时。单列“沿用初值并收紧界”“发现更优树”“改善拟合但拓扑变差”的例数。

| 阶段 | 要保存的结果 |
| --- | --- |
| S0 | 九棵构造树中按历史 H 选出的最佳树 |
| S1 | 在初始池完成多起点局部搜索后、实际传给首次 Tree MIQP 的树 |
| S2 | 首次 Tree MIQP 步骤输出。求解器返回的可行树和后续局部搜索树分开记录，以区分各自增益 |
| S3 | 在 S2 上确定本轮锚点、构造锚定候选域，重求 Tree MIQP，保存本轮节点搜索前的树 |
| S4 | 节点搜索提出新线路后的可行树、扩池重求后的树，以及按真实停止规则返回的最终树 |

S2 与最终树直接回答整套细化比首次选树多找回几条线路。宽节点 MIQP 的独立作用另用三组嵌套消融。A 保留锚定流程，仅做 Tree MIQP。B 在 A 上加入至多九棵子树的节点枚举，跳过的宽节点标记为未检验。C 在 B 上加入宽节点 MIQP。三组固定初始池、热启动、首次树、阈值、`K=9`、每步及整例时限。记录“原池自然遗漏→节点搜索前仍遗漏且在宽节点可达→宽节点首次提出→整树重选保留”的真实分组数，以及同流程误增数。C−B 衡量宽节点搜索，B−A 衡量窄节点枚举。改变 `K` 会同时改变锚定候选域，应独立开关宽节点搜索。四个长期算例的生成拓扑最大直接子树数为 3–4。独立报告估计树中实际出现的具有 10 棵及以上子树的分叉点及触发 MIQP 的次数。若评估“固定分组后完整求解”的收益，可在可枚举的小馈线上固定同一批锚，显式生成全部兼容候选再求 Tree MIQP，给出同一锚定域的参照值，并列明时间和界差。这行与实际 S4 分开。

补两个很小的机制实验。其一，对 8、10、11 棵子树的固定节点各自穷举 246、1,012、2,035 种合法组合，和 Node MIQP 采用相同约束，每种组合独立重估全树阻抗，比较最佳分数、界、超时及总时间。并列解按目标值判断，留存可行解、有效下界，穷举完成才作精确参考。沿用归一化分数 `crit` 上 `1e−7` 的加线容差。其二，在同一个十子树分叉处做两例配对 AC 仿真，一例有共享段且从候选、热启动中移除其全部等价表示，另一例无该段，比较找回与误增。当前十一表计小试的四组配对中，三组树相同，一组误增使物理 F1 从 1 降到 2/3。受控找回和自然找回应分列。[现有节点结果](node_pairs/README.md) · [四表计全枚举核验](pool_audit/README.md)

## 6. 实施与论文结果表

1. 先用现存四个长期算例完成接入和零动作校验，锁定样本、历史截点、基线容差、噪声种子、计量通道、运行设备与时限。各法容差在独立开发数据上选择。若只有这四网，就先采用预先固定的设置并逐网报告。先验证文献算法在满足其假设的参考算例上能工作，再解释主表。
2. 四个算例各跑 RG、NJ、RNJ、Park 和完整被动辨识，形成**主表一**。沿途保存 S0–S4，复用完整组 C，只新增 A/B 得到节点消融。**归因表**列拟合变化、真线路找回、误增、总时间和界。
3. 复用同一份日初辨识，每个算例在预选的一天跑 P0–P3，共 16 个政策日，形成**主表二**。配一张事先选定的馈线日轨迹图，画实际采购和交付时刻、两种接法的电压响应、实测变化及最后判定。再加单因素敏感性和两日对照，避免全因子铺开。
4. 四个已用开发网逐例列结果、样本数和失败。论文若报告跨馈线平均提升，冻结流程后另取未参与校准的完整馈线，按物理馈线配对估计差值及不确定区间。确认集规模取决于预设的最小有意义提升与开发集逐馈线差值的变异。同网窗口、噪声重复和四种隐负荷位置均不充当新增独立馈线。

本文件是实验方案。四网适配、独立的 Park 基线、仅窄节点枚举模式、采购策略对照和跨日调度均列为待实施工作。

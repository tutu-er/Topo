# Node MIQP 与调度式 Probe 的实验设计

本文列出拟做的对照和判据。首轮用小规模配对实验决定两项贡献各能写到什么程度。

| 论文主张 | 最有区分力的证据 |
| --- | --- |
| 在当前树的一个分叉点，Node MIQP（节点混合整数二次规划）直接选择共享一段上游线路的子树，同时重估新旧线路阻抗。由此生成的候选线路可交回 Tree MIQP 重新选树。 | 同一节点上能否找到与穷举等价的解、花多少时间。在完整辨识中找回几条原先遗漏的真实分组，又误增了几条。 |
| 对仍有两种合理接法的分组，利用两棵树对用电调节的不同电压响应，决定下一小时向哪户购买多少上调或下调，再用实际量测更新后续采购。 | 同一馈线、同一天，相比继续被动观测、按整树分歧采购、按日初计划采购，每花多少费用能多判对几个分组。 |

这里的“线路分组”指一段线路下游的表计集合。已有方法用混合整数规划估计已有支路的开合，或从母线之间的候选连接恢复拓扑。逆变器有功激励及用电压响应辨识拓扑也有先例。本文把可检验的区别落在**分叉点的子树组合**与**针对具体拓扑歧义、提前一小时采购并逐时更新的需求响应调度**。该文献对照依据作者全文的方法部分。[Tian 等](https://doi.org/10.1109/TPWRS.2015.2394454) · [Taheri 等，§II–III](https://engineering.purdue.edu/~kekatos/papers/PowerTech2019.pdf) · [Cavraro 与 Kekatos，§III–IV](https://engineering.purdue.edu/~kekatos/papers/L-CSS-2018.pdf)

## 1. Node MIQP

**N1　固定分叉点，与穷举逐例核对。** 预设 8、10、11 个子树各一个节点，分别有 246、1,012、2,035 种合法组合。固定当前树、量测、权重、阻抗边界与加线惩罚。穷举对每种组合独立做有界最小二乘，重估全树阻抗。Node MIQP 求同一问题，对它返回的组合也独立重拟合。每例记录两者的最佳目标值、相对原树的改善、是否应加线、含建模和重拟合的总耗时，以及 MIQP 的可行解、有效下界和终止状态。并列最优按分数核对。沿用代码在归一化目标 `crit` 上的绝对改善容差 `1e-7`，同时列实际差值与界差。超时仍保留可行解和有效界，穷举未完成的行不充当精确基准。历史两个 11 子树输入来自同一馈线，作为复核线索单列。[固定节点模型](../ptid/method/search.py) · [历史比较](../RESULTS.md)

**N2　相同起点，分开窄节点枚举和宽节点 MIQP。** 下列三组共享九种构树法的输出、初始候选池、热启动、第一次 Tree MIQP 的树、评分及求解预算。从这棵树起运行各自的后续步骤。可同步保存热启动中按训练评分选出的最佳树，作为完整流程的低成本基线。

| 组别 | 第一次选树之后的处理 | 配对比较 |
| --- | --- | --- |
| A | 保留原锚点流程和 Tree MIQP，关闭节点加线搜索 | 候选池选树的基线 |
| B | A 加入至多 9 个子树的节点枚举，跳过宽节点搜索，并将其记作未检验 | B−A 衡量窄节点枚举 |
| C | B 加入超过 9 个子树的 Node MIQP，沿用同一规则重新选树 | C−B 衡量宽节点搜索的增量，C−A 衡量完整节点细化的增量 |

所有组固定 `K=9`、锚点规则、参数选取、轮数、每次求解及整例时限。当前 `node_refinement=False` 同时关闭两种搜索，实施时只需增加 B 的实验开关。改变 `K` 也会改变锚点允许的初始搜索范围，会混入另一个因素。[辨识入口](../ptid/method/identify.py) · [锚点候选构造](../ptid/method/anchors.py)

主表对**全部预选馈线**逐例报告正确、多加、漏掉的分组数，精确率、召回率、F1 和辨识总耗时。另列一张计数表，追踪真实分组从“初始池未包含”到“节点搜索前仍缺失且能由当前宽节点的完整子树组成”，再到“宽节点首次提出”和“整树重选后保留”。同时列新增假分组和最终翻转评分。这样能分清候选构造、节点搜索和整树重选各贡献了什么。真值只在输出后用于自然样本的计数。

若需与外部被动方法比较，优先选 Park 等利用端表电压、有功和无功估计电阻距离再递归分组的方法。在无额外隐负荷、隐藏中间节点度数至少为三、跨节点注入不相关的共同设定下，向两法提供相同端表序列，比较分组 F1 和总耗时。该对照回答完整方法相对已有方法的表现，C−B 仍用于识别 Node MIQP 本身的作用。[Park 等，§II–III，作者全文](https://arxiv.org/pdf/1710.10727)

**N3　给模型一次明确的找回机会，并配一个容易误加的对照。** 构造两个配对的交流潮流算例，候选树都从同一个 10 子树分叉点开始。第一例中预设两棵子树共用一段超过 3 mΩ 的线路，在送入节点搜索的候选和热启动中删去它及同表计投影的表示。第二例中这两棵子树直接接在分叉点。复用负荷、噪声及其他支路设置，向估计器提供同样类型的电表量测。比较 B/C 能否找回真段、无真段时是否误加，并报告最终树是否保留该段。这两例单列为受控机制实验。自然样本若无遗漏可找，直接报告机会数为零。

现有单馈线四组配对中，三组返回相同树，一组加了假线路，物理分组 F1 从 1 降至 2/3，该分组的翻转标签仍为 `open`。原池已包含唯一真分组。N1 支撑求解正确性与计算效率，N3 支撑受控遗漏的找回能力；要写“提高实际辨识效果”，依据应来自 N2 中的真实找回、误增和总耗时。[现有配对原始结果](node_pairs/README.md)

## 2. 调度式 Probe

**同一个第九天比较四种政策。** 先用相同的八天历史、同一 Node 设置得到日初树、候选和有竞争解释的目标。每种政策各自从相同设备荷电状态开始，使用同一组逐小时基础负荷、表计偏差和噪声抽样。调度只看到已结束小时的读数和下单时可知的预测、报价及可用容量。各组采用同一辨识器和评价时钟。

| 政策 | 如何选择要买的需求响应 | 与完整法比较时回答的问题 |
| --- | --- | --- |
| P0 被动全天 | 全日买零，照常获取当天量测并逐时更新辨识 | 单纯多观察一天，已能判清多少？ |
| P1 整树分歧滚动调度 | 移植工程旧版强贪心的整树候选评分，和完整法共用当前可获得的候选及其拟合、可执行动作、合同与辨识器 | 把采购对准具体未决分组，比按整棵树的分歧采购多解决多少？ |
| P2 日初固定计划 | 冻结日初的局部目标、竞争树和分差，用当时的逐时预测顺次制定当日意向计划，逐笔扣减预计预算、更新预计荷电状态。实际下单时检查与 P3 相同的运行约束及停止条件，失效的块跳过，余下时点不重排 | 已知相同歧义并能主动调度时，用最新量测重排是否值得？ |
| P3 局部目标滚动调度 | 采用现行 T0。每小时更新树和日初目标的状态，比较本小时下单与不下单对下一个小时区分这些接法的增益，足以支付价格时才买 | 论文方法 |

各组使用单表计、单方向、四档幅度的相同动作规则。沿用上调/下调 1.2/4 元每千瓦时、每小时 20 元、每日 100 元，以及相同预测电压带、变压器和设备可用容量检查。第 h 小时开始时只能用到第 h−1 小时的读数，可为第 h+1 小时下单；第 h 小时执行已承诺的动作。某组提前停买时仍履行已有承诺，继续被动采到第 24 小时，再统一评价，同时记录实际停买时间。日初没有目标的日子保留在部署统计里。[策略与提前下单时序](../ptid/method/probe.py) · [第九天交流仿真](../ptid/cases/world.py)

**主指标是同一批初始歧义中，到日终正确判清了几个。** 锁定各组共有的日初 T0 可评价表计分组，判为存在且真有，或判为不存在且真无，均计正确。对固定分母同时报告正确判定、错误判定、仍未判定三项数量；另报已判定中的错误比例、最终整树 F1、实付元数、调节电量和动作数。零目标日另报天数及支出，不计算日内比例。隐藏负荷位置 `place` 目前缺少真值匹配，保留其调度及花费，单列状态。以合并短于 3 mΩ 线路后的分组为主，另列对全部物理分组的结果。[现行评价入口](../ptid/runs/probe_cases.py) · [真值与参数约定](../PROTOCOL.md)

**成本和运行约束与辨识效果一起看。** 每个馈线日画出实付费用和正确判定数，标出误判数。共有预算上限下比较政策效果，实际花费接近的点比较同成本效果。若四组花费相差很大，在相同馈线上为主动政策补一个预定的较低日上限（50 元），只比较费用范围有重叠的结果。保留每 15 分钟交流潮流的实际电压、变压器有功与视在功率，以及资源荷电状态。并排报告原有越限和相对同日被动运行新增的越限，注明阈值及单位。信息价值系数 `ψ=5` 目前是预设值；若要调参，另用开发馈线，评价日前冻结。

旧版整树策略在 532 个自然歧义运行中，确认真树的比例为 43%，被动为 32%。人为移除真树后，确认错误树的比例为 64%，被动为 60%。这使 P1 成为有意义的强对照，也给出一项低成本压力测试。可在一个预定馈线日共同删去关键竞争解释，对被动和 P3 各跑一次，记录新量测能否纠错或会否加深误判。旧版统计口径是整树确认，本轮四种政策统一按上述分组评价。[旧版开发记录](https://github.com/tutu-er/Topo/blob/f91dcf993a8e72c90f85426e971d8ab3ef7afe8d/rnj_wzzt_dr/experiments/hourly_probing_20261118/DEVELOPMENT_RUNS.md)

若论文还要主张**按价格选动作能省钱**，补一个直接消融。在预先指定的两个馈线日保留 P3 的滚动更新、硬预算和设备约束，只把动作排名从“预期辨识收益折价后减采购费”改为“预期辨识收益”，最大收益为正则买。与已有 P3 输出配对，报告相同正确判定数所需的实付金额及误判数。只赢过被动观测不足以支持这一项经济性主张。

## 3. 最小规模、实施顺序与结果判读

1. **冻结样本和参数。** 首轮预选 4 条不同开发馈线，每条取一个互不重叠的评价日，先定 ID、时段、噪声种子、求解器版本、线程和时限。每条需有八天历史及可执行的第九天仿真。历史输入若不可用，可用 4 个预定种子生成不同的交流馈线，明确标为模拟开发结果。保留无宽节点、无目标及超时的行。全部用固定翻转门槛 `m=4.6` 和同一 `p_s` 选择规则；按馈线列配对差，多个分组或随机种子不充当独立馈线。
2. **先做 N1、N3，再做自然样本 N2。** 三个节点双方法核验，两个正反算例各跑 B/C，然后 4 条自然馈线各跑 A/B/C（12 次辨识）。记录共用起点哈希、每轮新增及其来源、求解时间和超时界。若只有 N1/N3 成立，主张就落在精确搜索与受控找回上。
3. **复用 N2 的 C 组日初结果跑 Probe。** 4 个馈线日各比较 P0–P3（16 次日内仿真），输出逐日正确/错误/未决数、费用和实际越限。P3 优于 P0 支撑主动调度的总体收益；优于 P2 才支撑反馈重排的额外价值；优于 P1 才支撑针对局部分组设计动作的额外价值。以误判和费用同时判断得失。四条开发馈线足以发现归因问题，论文中的跨馈线平均提升需用预先封存的新馈线复验。
4. **篇幅优先给两张表和一张图。** 节点表放穷举差值、时间、自然找回和误增；调度表放四种政策的正确/错误/未决三项和实付；图选一个事先指定的馈线日，画出某一分组两种接法的电压预测、实测响应、下单及执行时刻和累计支出。这样可以看到究竟是哪一次调度改变了判定。

实施的新增工作集中在实验入口：节点增加 B 组及逐轮记录，Probe 拆出可替换的采购策略，在停买后补齐全天评价并存储交流潮流实测轨迹。首轮复用 Tree MIQP、Node MIQP、线路翻转评分和现有设备模型。

# 大规模馈线上的宽节点消融

给定相同的街坊分组和锚定树，启用宽节点 MIQP 后，24 表和 36 表两个受控算例都找回了根侧共享线段，最终各恢复 13/13 个真实分组。24 表在每次求解 4 秒时已经恢复，36 表在 4 秒时停于 7/13，放宽到 60 秒后恢复。仅搜索窄节点的分支在两档限时下分别保持 8/13、7/13。两种尺寸上的常规 NJ、RNJ 都已找到该共享段，这两例检验的是给定不完整初始树后 Node MIQP 的修复能力。

## 四个交流算例

物理网络由 12 个街坊组成，编号 0 至 11。24 表每坊 2 表，36 表每坊 3 表。PCC 母线 0 经公共主干连接母线 1。两个共享段版本另设 **母线 1→2**，将街坊 **0、2、4、6、8、10、11** 接在母线 2 下。它覆盖 14/24 或 21/36 个表计，符合既定的“下游表计严格超过半数”根侧口径。在物理图中它是离 PCC 的第二条边，在可评价的非平凡分组中位于第一层。无共享段版本直接把全部街坊接在母线 1 上。全表公共主干和单表入户线均不计入分组 F1。

每个街坊母线编号为 100 加街坊号，表计母线编号从 1000 连续排列。24 表目标覆盖 1000–1001、1004–1005、1008–1009、1012–1013、1016–1017、1020–1023；36 表目标覆盖 1000–1002、1006–1008、1012–1014、1018–1020、1024–1026、1030–1035。共享段版本的最宽物理节点有 7 个直接子节点，收缩该段后根侧接点有 12 个。估计树漏线时，树中的接点可以比物理接点更宽。

| 线路 | 电阻 / 电抗，Ω |
| --- | --- |
| 全表公共主干 | 0.016 / 0.008 |
| 根侧共享段 | 0.036 / 0.014 |
| 街坊支线 | 0.040 / 0.016 |
| 入户线 | 0.020 / 0.008 |

基准为 0.4 kV、0.2 MVA。按宽度固定种子 20261129 与表数，生成八天的 768 个 15 分钟负荷点，运行径向交流潮流。先按小时平均，再施加冻结的表计增益与读数噪声，得到 192 行端表有功、无功、平方电压差及 PCC 平方电压。每对算例使用相同负荷、P/Q 与根电压读数及电表误差抽样。标定阈值、噪声水平、目标街坊和求解预算在运行前固定。

## 兼容相同锚定块的 B/C 比较

正常流程使用原有九种构树、局部搜索至收敛及首次 Tree MIQP。受控流程由实验者给出全部 12 个街坊内的表计归属，每个街坊作为一个初始分组，初始候选中只有这些组。这个人工输入用于构造“已知街坊、未知街坊间接法”的压力测试。两个流程各自只计算一次共同的初始评分、锚定块与锚定 Tree MIQP，并在 B/C 间按输入摘要复用。B 枚举最多 9 个直接子树的节点，C 在更宽节点上另做 Node MIQP。每次 Tree、Node 及翻转求解限时 4 秒，单线程，锚定一轮，最多增补两条线；阶段总墙钟限时 180 秒。逐次证据含每棵估计树各接点的直接子树数、真实前两层的分组命中数、受限域界与停止原因。[逐阶段证据](results.json)

| 受控输入 | B 命中 / 真实，误增 | C 命中 / 真实，误增 | C 实际求解的接点宽度 | 结果解释 |
| --- | --- | --- | --- | --- |
| 24 表，有共享段 | 8/13，0 | 13/13，0 | 16、15 | 第二次宽节点求解找回线路 1→2 |
| 24 表，无共享段 | 12/12，0 | 12/12，0 | 12 | 两组均保留 12 路根侧接法 |
| 36 表，有共享段 | 7/13，0 | 7/13，0 | 22 | 节点求解限时，无改善可行解 |
| 36 表，无共享段 | 12/12，0 | 12/12，0 | 12 | 两组均保留 12 路根侧接法 |

24 表共享段例中，锚定 Tree MIQP 先保留 8 个真实街坊分组，目标为 5.249591。第一次 Node MIQP 在有 16 个子树的估计接点限时返回一条错误的 23 表分组，其重拟合目标为 5.069803，节点下界为 0.964576。第二次在临时树的 15 子树接点返回正确的 14 表根侧分组，该节点单条增线路径的可行值和下界都为 1.182925。两条候选进入重求解域后，局部热启动已丢弃错误的 23 表分组、保留正确根侧线段，随后的 Tree MIQP 保留该树。最终目标降至 1.018985。真实根侧段的提出可归因于 Node MIQP，全部街坊分组的恢复是后续联合重拟合的结果。

36 表共享段例中，22 个直接子树的节点限时返回一条两表候选。该候选的重拟合目标为 4.790893，高于当前树的 4.788902；节点下界为 0.925523。算法因此保留原树，节点界也未排除其他有收益的增线。四个算例都附有独立显式电压设计的有界最小二乘复核。

## 在同一宽节点放宽求解时间

取上述两个共享段算例，将每次 Tree、Node 和线路翻转的上限从 4 秒调到 60 秒，单线程、每阶段最多 1,800 秒。两个算例各有三个阶段，依次重算四秒档中第一次遇到的宽节点、运行窄节点分支 B、运行宽节点分支 C。六个阶段都完成。下表比较同一接点最佳单条增线的可行上界与求解器下界，使用与辨识相同的归一化评分，越小越好。24 表和 36 表两档的量测、受控街坊初始树、该接点的输入树和直接子树都逐项相同。[六个阶段及独立复核结果](time_limits.json)

| 表数 / 首接点宽度 | 4 秒首次增线与 [下界, 可行上界] | 60 秒首次增线与 [下界, 可行上界] | 60 秒档固定节点实际耗时 | 4 秒 → 60 秒 B 最终命中 | 4 秒 → 60 秒 C 最终命中 |
| --- | --- | --- | ---: | --- | --- |
| 24 / 16 | 错误的 23 表组，[0.964576, 5.069803] | 正确的 14 表根侧组，[1.180115, 1.180115] | 7.38 秒 | 8/13 → 8/13 | 13/13 → 13/13 |
| 36 / 22 | 两表候选，高于原树，[0.925523, 4.790893] | 正确的 21 表根侧组，[1.190110, 1.190110] | 39.34 秒 | 7/13 → 7/13 | 7/13 → 13/13 |

两档的四棵共享段 C 最终树均无误增。24 表在 4 秒档要到第二次宽节点求解才提出真线，60 秒档在同一初始树的第一次求解即选中它。36 表的第一次宽节点求解在 4 秒档没有找到可改善原树的并集，60 秒档直接选中 21 表目标。随后对扩展候选域重求，恢复全部街坊分组，最终评分为 1.006693。该流程后来遇到的一个 16 子树节点仍达到 60 秒限时，其可行上界为 1.156866、下界为 1.117748。上表中两次闭合的界各对应固定接点的一次增线。

60 秒档先单独计算固定接点，C 遇到同一输入树、接点、种子和限时时复用该结果。24、36 表的 C 阶段本身墙钟分别为 9.95、88.63 秒，均另有表中的固定节点计算。若合计 C 阶段墙钟与首次节点实算，用时分别为 17.32、127.97 秒，仍不含已在 B 中计算的共同前缀。包含进程启动的独立固定节点阶段墙钟分别为 9.05、42.05 秒。各阶段及缓存复用时间均保存在记录中。

## 执行与导出

在 `topology_study` 下运行。生成输入时只做交流潮流和表计模拟。每例目录的 `observations.npz` 含四个输入数组，`circuit.json` 单独记录物理接线、标签、计量参数、种子及逐数组 SHA-256。求解器使用前者的四个数组，真实接线只用于模拟和事后评价。

```powershell
python -B experiments/run.py wide-feeders --export-inputs ../outputs/topology_study/wide_feeders_inputs
python -B experiments/run.py wide-feeders --out ../outputs/topology_study/wide_feeders.json
python -B experiments/run.py wide-feeders --check experiments/wide_feeders/results.json
python -B experiments/run.py wide-feeders --check experiments/wide_feeders/time_limits.json
python -B experiments/run.py wide-feeders --sizes 36 24 --workers 1 --phase-seconds 1800 --time-sensitivity experiments/wide_feeders/results.json --solver-seconds 60
```

两条 `--check` 命令只重建量测、核对保存的结果，并按显式电压设计独立拟合有界线路系数。对自行重跑的延时结果，可用 `--reference <四秒档文件>` 指定配对来源。

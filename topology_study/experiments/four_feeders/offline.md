## 改善发生在哪里

各网选择训练目标最低的九构树初值，其 F1 按表中顺序为 0.727、0.706、0.600、0.778。多起点局部搜索实际交给首次 Tree MIQP 的热启动均已恢复完整树。首次 Tree MIQP 均沿用该热启动，四次首次与四次锚定 C 组求解均在各自候选域内达到求解容差。Pengwah18 锚定求解的可行 H 为 1728.138（完整数值见个例），下界约为 1727.979，落在配置的相对容差之内。各组的首次树、候选和热启动已逐例核对完全一致。A/B 栏把复用的首次求解耗时加回，C 总耗时范围为 3.25–23.19 秒。

节点搜索前可由宽节点找回的真实遗漏分组共 0 个，宽节点 MIQP 实际调用 0 次，A/B/C 后续均未增加线路。此批收益发生在初始构树到局部搜索之间。完整组最终翻转评分对 23 个组给出 decided，另有 5 个 open 替代，分别分布为 1、1、2、1。[全部 32 项汇总及独立复核](offline_audit.json)

## 复核和重跑

四个网络均按源清单 SHA-256 读取原始归档。九日窗口每网 864 个 15 分钟点的零动作交流潮流重放，所有母线与端表电压最大绝对误差均为 0，首端 P 与 Q 的最大误差分别为 5.0e−15 和 4.1e−15 pu。16 项所提法及消融结果在独立构造的显式电压设计上使用 SciPy 有界最小二乘重拟合，最大绝对目标差为 1.23e−11 H。原有 14 项候选定价、受限界和评分界检查通过。

采用 1 轮锚定、每轮最多增加 2 条线路、单线程、Tree/Node/翻转每次 4 秒、局部搜索每初值首遍 1 秒。计时包含建模及方法本身的预处理，独立事后评分和文件读写另计。并行执行不同馈线会影响墙钟计时。Soumalas11 首次导出报表时将评分设置传错，保存的原生识别结果有效，修正报表后使用相同 C 缓存及输入重建记录。[读取和零动作复核](../../ptid/runs/four_feeders.py) · [运行器](../../ptid/runs/four_offline.py)

在 topology_study 目录下运行以下命令，PTID_FOUR_DATA 可指向包含历史源文件的 data 目录。

~~~powershell
python -m ptid.runs.four_offline
python -m ptid.runs.four_offline --audit
python -m unittest ptid.tests.test_pool_pricing ptid.tests.test_score_bounds -q
~~~

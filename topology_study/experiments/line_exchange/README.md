# 单步线路替换消融

在同一棵估计树上检验两个问题。第一，允许撤销一条未锚定线路并同时换入一条新线路，能否改善辨识？第二，在两种方法都允许这样换线时，宽节点整数优化比贪心搜索多找回了哪些真实分组，付出了多少计算时间？

## 比较协议

- 输入为 21 张通过原始 SHA-256 校验的随机开发网。每网使用同一份八天端表有功、无功、电压量测和首端电压。起点取 [30 秒档记录](../four_feeders/random_time_limits.json)中第一次锚定 Tree MIQP 的输出，即首次节点搜索前的树。硬锚点从该次整树求解的实际约束恢复。
- 对照保留原有的单条加线。两个替换分支均可保留原树、使用同一原加线结果，或撤销一条未锚定的现有分组，在其原父接点选择至少两个、至多全部减一的直接子树重新组成一条线路。两步作为一个动作评分，避免因单独删除时评分变差而提前截断。每个方案均重拟合全树阻抗，选择惩罚评分 H 最低的可行树。
- 替换位置由当前估计树给定，两个替换分支逐一检查同一批位置。一个分支采用贪心搜索，另一个分支在至多 9 个子树时穷举，在更宽的接点上调用 Node MIQP。记录单步后的树、正确和错误分组数、F1、目标值、耗时及可用界。单节点界只覆盖该位置的替换。原始已验证方案始终作为可行备选。
- 首先复核 `dev_large_003_middle`、`dev_huge_003_middle`、`dev_huge_004_end`、`dev_huge_005_none`。此前查看过这些网的真值，它们用于诊断。另 17 网沿用同一规则。21 网均为开发网。盲搜阶段仅接收量测模型、估计树和锚点，真值仅用于输出后的计分。
- 单独核对 `dev_huge_004_end` 的指定收缩位置。位置来自先前的事后诊断；该位置的 10 个直接子树有 1,012 个合法并集。完整枚举与 Node MIQP 分别求解同一问题，候选按 H 排名，然后再对照物理真值。整网实验仍需从所有可撤销位置中自行选择。

从 `topology_study` 目录运行 `python -B experiments/run.py line-exchange --help` 查看整网实验参数，`python -B experiments/run.py exchange-reference --help` 查看固定节点复核参数。

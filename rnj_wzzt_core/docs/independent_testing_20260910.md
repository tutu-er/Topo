测试不是算法每一步输出的快照复制。MILP参照独立于生产的特征矩阵、约束构造和层状判断，但 `linprog` 与生产 SciPy `milp` 的底层都使用 HiGHS，不能声称独立求解器交叉验证。大批参数化测试表示跨条件数值覆盖，不表示相同数量的独立科学发现。

发现并修复两处构树函数共用的输入风险：隐藏节点编号可能与负数终端/根标签重合；重复终端和根/终端重叠未拒绝；RNJ还未拒绝NaN/无穷容差。修复见 [rooted_neighbor_joining.py](../rnj_wzzt/graph/rooted_neighbor_joining.py) 与 [rooted_hierarchy.py](../rnj_wzzt/graph/rooted_hierarchy.py)。正常正标签仍从原来的 -1 分配隐藏节点，数值递归和生产默认设置保持原语义。

## 三层压力研究

入口：[run_advantage_stress.py](../experiments/run_advantage_stress.py)。生成器和统计：[stress_support.py](../experiments/stress_support.py)。图表再生：[analyze_advantage_stress.py](../experiments/analyze_advantage_stress.py)。

| 层次 | 固定设计 | 条件数 | 每条件方法数 |
|---|---|---:|---:|
| 理想/受扰动矩阵 | 5种形状 × 8/16/32/64终端 × 10随机树重复 × 7压力条件 | 1400 | 7 |
| 合成P/Q/平方压降 | 平衡/深链/随机树 × 8终端 × 3重复 × 8压力条件 | 72 | 12 |
| 非线性AC | 4个现有reference馈线 × 3独立重复 × 3压力条件 | 36 | 12 |

矩阵层压力为精确、内部边倍率0.03、两档对称噪声、X高噪声、R高噪声、仅对角扰动。它用于分离重构机制，不能代替表计数据的端到端结论。比较R-RNJ、X-RNJ、RX75-RNJ、RX50-RNJ、零容差RX75-RNJ、已知根锚定的经典NJ两档边收缩。零容差和固定边收缩是事先声明的诊断对照，没有读取真树调参。

合成观测层压力为参考、低样本、高响应噪声、Q=0.6P、终端强相关、3%大响应异常、弱内部边、公共响应误差。树真值在数据生成前随机确定，独立于生产灵敏度构造。其噪声相对于总体平方压降信号RMS；不能把这里的5%或30%解释为电压表相对误差。此层来自线性模型，适合因果机制隔离；AC层验证非线性失配和P/Q表误差。

AC层使用原reference物理网、96点完整日轨迹和真实根标签。P/Q相对量测噪声0.5%，终端电压噪声为0.02%或高噪声0.1%，根表噪声0.02%，背景根电压过程标准差参数0.003 p.u.。低样本从完整日抽取8点；参考/高噪声抽取32点，测试日保留96点。

## 信息与计算公平性

每个条件三场景；训练、验证、最终测试使用独立随机重复，所有方法共享数组。常规条件有96个训练快照加96个验证快照；低样本为24加24；测试均288快照。调参总数据预算应同时计训练和验证。验证复用训练截距，测试不参与阈值、候选或模型选择。R/X分解秩亏不必然意味着拓扑不可识别，应单独查看K=R+κX。

观测层比较R/X/RX75 RNJ、固定RNJ树L1、相同根信息的经典NJ（0/.04/.08/.16阈值只按验证MAE选择）、RNJ池wzzT、同池原生MILP、one-edit池、全子集原生MILP、稳定块冻结、稳定块收缩、验证选择RNJ或RNJ池wzzT。固定树原端L1重拟合对所有结构法一致。主拓扑得分按返回结构族，零权重仍保留在原始族时不自动当作实际正阻抗线路；这与真实物理边估计应区别。

每个结构搜索预算4秒、单次求解最多1.5秒；预算控制是现有实验适配器，固定支持LP可能略超墙钟总预算。有限池逐步枚举每个可用支持并精确解固定族LP，全子集使用原生MILP；同RNJ池原生MILP对照用来区分候选缩减和求解器实现的贡献。每步证书不等于完整路径全局证书。超时的可用回退仍计分，并同时报告不完整状态；缺失结果保留在分母。

本研究默认20次bootstrap，生产默认100次；收缩对照在原端重新拟合参数并使用冻结训练截距验证。这些是明确的组件消融，不应写成生产默认流程在所有条件的原样性能。两工作进程共享机器，墙钟限时会受调度影响；种子保证数据与协议复现，不保证限时搜索路径逐比特复现。

## 统计与复现

主指标为非平凡有根clade F1，排除整树公共根茎与无观测二度节点细分；同时保存根分区、末端clade、R/X误差、独立测试MAE、耗时、候选真clade覆盖及搜索状态。真值只用于这些诊断，不能用于选模型或先验获取。

同一job精确配对；95%区间按独立随机树或AC重复整群重采样，跨压力档重复使用的树不能当成更多独立树。区间是当前固定算例库上的描述性不确定性；没有预设现实馈线抽样分布，没有多重比较校正，不能将事后挑出的正区间宣称为普遍显著优势。合成观测每个压力档只有9个树/重复，AC只有12个网络/重复，外推应保守。

在安装项目依赖的Python环境、从本核心目录运行：

```powershell
python -m pytest tests -q
python experiments/run_advantage_stress.py --output outputs/my_new_stress_run --workers 2
python experiments/analyze_advantage_stress.py outputs/my_new_stress_run
```

输出目录必须新建，防止覆盖旧实验。`protocol.json` 在求解前保存完整任务表、种子、预算、环境和源码SHA-256；每个观测条件保存输入npz、真值和设置、候选选择、每种方法与求解路径；`rows.jsonl` 增量保存结果，完成后生成CSV和配对区间。矩阵条件从任务表精确再生。当前机器未全局安装依赖，本轮实际使用Python3.12及工作区现有 `.codex-rnj-deps`；没有安装或升级依赖。

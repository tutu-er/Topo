# 公共模态与双 ridge 对比实验

日期：2026-09-07。主线默认回归未切换；新增实验入口为 `experiments/run_common_mode_comparison.py`。

## 结论

在本次四案例、五次独立重复和两类根量测条件下，三种方法的 RX75-RNJ 均精确恢复所有测试拓扑。
自由公共模态降低了使用电压残差回算公共项后的拟合误差，但 R/X 及距离估计明显变差；
双 ridge 能限制这种自由度，在有根量测噪声时改善条件拟合与矩阵误差，独立预测改善较小。
这些实验不能说明公共模态在更强噪声、其他馈线或根不可观测时没有价值。

## 三组模型

采用相同的多场景有序约束，令 Θ=[R;X]，A=[P,Q]，c 为每个时刻所有终端共享的标量：

\[
\min_{R,X,c}\frac12\|Y-A\Theta-c\mathbf1^\top\|_F^2
+\frac{\alpha}{2}(\|R\|_F^2+\|X\|_F^2)
+\frac{n\gamma}{2}\|c\|_2^2.
\]

- 当前版本：c=0、α=0。
- 自由公共模态：γ=0、α=0。
- 公共模态 + 双 ridge：α>0、γ>0，分别惩罚 R/X 和公共模态。

这里 c 是已观测根电压校正后的残余公共项，而不是再次把真实根电压当作已知量相减。
两种噪声条件下真实根电压都保持 `1.02 + N(0, 0.0008²)` 的日内波动。

公共模态可以解析消去。设 E=Y−AΘ、J=11ᵀ/n，

\[
c^*=\frac{E\mathbf1}{n(1+\gamma)},\qquad
L_\gamma=(I-J)+\sqrt{\frac{\gamma}{1+\gamma}}J.
\]

由此复用原 QP 优化 `||(Y−AΘ)Lγ||² + α||Θ||²`，不改变 R/X 的物理参数化与约束。
底层仅新增可选 `output_transform`；默认 None 保持旧计算路径。

## 公平比较与数据划分

- 案例：paper15、soumalas11、flynn16、pengwah18。
- 每案例五次重复；每次训练、调参、测试各自含 3×96 个样本，使用不同随机种子。
- 第 k 次重复采用训练 replicate=3k、调参=3k+1、测试=3k+2。
- P/Q 量测噪声为瞬时幅值的 0.5%；终端电压量测噪声为瞬时幅值的 0.02%。
- 条件一沿用当前实现，根量测准确；条件二额外给根表计加瞬时幅值 0.02% 的独立高斯噪声。
- 同一案例/重复的两种根条件复用相同物理数据；同一条件的三方法共享全部观测。
- 三组使用相同的对称、非负、ordered 约束，以及由当前 OLS 初始化确定的固定裕量。
- α=a||A_centered||F²/(2n)，a网格为 {1e−8,1e−6,1e−4,1e−2,1}；γ网格为 {0.001,0.03,1,30,1000,1000000}。
- 每个案例/重复/噪声条件分别用调参集的**无公共项校正预测 RMSE**选择 a、γ；未用真值矩阵、真拓扑或测试集挑参数。
- 截距仅由训练数据均值恢复，再按同一场景定义槽位迁移到调参/测试集；没有用测试均值重估截距。
- 本次直接评价 RNJ，未运行 bootstrap 或下游 L1-MILP，以隔离回归改变的效果。

共 40 个配对条件、120 个最终模型、1200 个 ridge 网格候选；没有求解失败。
表中是每种根条件的 20 个案例/重复结果等权平均，非按终端数量加权。

## 误差口径

表中三个 RMSE 均以 **10⁻⁴ p.u.²** 为单位。R、X 误差分别为 `||M_hat−M_true||F/||M_true||F`。

- 训练拟合：允许训练公共模态进入拟合值。
- 测试条件拟合：使用测试电压残差回算 c，再计算误差；这是条件拟合，**不是预测**。
- 测试预测：只使用已拟合 R/X、训练截距和测试 P/Q，令未知测试 c=0；测试 Y 仅用于评分。

自由公共模态使 R→R+a11ᵀ、X→X+b11ᵀ 两条平移不可识别。
为给出可复现代表，自由组在求解后分别减去 R/X 的最小元素，固定为非负可行域内沿这两条方向的最小 Frobenius 代表。
这相当于选择零公共根边的基准，不使用真值。其矩阵误差、无公共项预测与 RNJ 是**该规范约定下**的结果，不能认为自由模型唯一识别了它们。
原始求解矩阵、平移量、规范前后 RNJ 和不受平移影响的距离矩阵误差均已保存。
自由组的距离误差也更大：d_R 约 16.32%、d_X 约 66.62%；准确根条件下基线分别为 6.52%、23.38%。
因此退化并不只是上述公共平移造成。规范前后条件拟合误差差异小于 1e-16、距离变化小于 1.4e-15。

## ridge 系数的选择结果

- 根电压准确时，20 次中有 14 次选 γ=10⁶（公共项几乎为 0），5 次选 30，1 次选 1。
- 根表计有噪声时，20 次中有 17 次选 γ=1，其余分别为 30、1000、10⁶。
- 选中的 a 均为 10⁻⁸、10⁻⁶ 或 10⁻⁴；本次无需很强的 R/X ridge。
- 这些系数由各自调参集选择，不能当作其他网络的固定最优参数。
- 联合 ridge 的改善不能全部归因于公共模态；R/X 正则本身也可能贡献改善。

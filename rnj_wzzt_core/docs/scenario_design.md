# 算例设置：参考条件、根波动与压力测试

场景研究记录：2026-09-07；接口说明更新：2026-09-28。普通 `run.py` 默认使用 `reference`，原结果所属场景配置保留为显式 `legacy`。正式回归/RNJ/MILP 现已采用已观测根、原始 P/Q/Y 的零偏置模型；本文保留的历史研究数值不代表该新模型的重跑结果。

## 0.08% 的根波动是否过小

不能只看绝对幅度。旧根电压标准差参数为 0.0008 p.u.，即额定电压的 0.08%；旧线路阻抗又被放大，因而该公共扰动相对压降信号偏弱。
此前“四案例全部 5 倍”的说法不精确，实际为 paper15=5.0、soumalas11=5.2、flynn16=4.8、pengwah18=4.5。本次已把实际倍率纳入配置和记录。

保持同一套 P/Q 和标准化根随机数，对旧 iid 根过程作 48 组 AC 对照（四网络、原倍率/1倍/5倍、根 sigma=0/0.0008/0.003/0.006）：

| 根 sigma 参数 | 根平方电压波动 / 动态线压降，旧倍率 | 同比，线路倍率1 |
|---:|---:|---:|
| 0.0008 | 0.127–0.315 | 0.665–1.678 |
| 0.003 | 0.475–1.181 | 2.496–6.294 |
| 0.006 | 0.951–2.364 | 4.993–12.593 |

这里用逐日去均值后的 RMS/标准差比较动态振幅。旧根波动只约为旧压降动态的 13%–31%，但取消阻抗放大后，它已与压降动态同量级。因此既不能把旧设置当强公共模态试验，也不应仅凭 0.08% 就断言它不合理。

阻抗放大还使压降动态/根与端表计共同误差的振幅比从倍率1的约 1.8–4.5，提高到旧倍率的约 9.6–24.6，显著改善回归信号条件。
旧设置 flynn16 的最低端电压约0.9287 p.u.；这些历史场景即使潮流收敛，也不能一概标为正常运行条件。原倍率仅保留用于重放和高压降压力对照。

## 五套明确设置

`rnj_wzzt/scenario/settings.py` 是统一配置入口。四网络的拓扑和资源类别继续保留；reference 不再通过几倍阻抗增强信号。

| 套件 | 用途 | 线路倍率 | 根背景 sigma | 根时序 | 负荷/天气 |
|---|---|---:|---:|---|---|
| legacy | 原结果逐值重放 | 各案例原4.5–5.2 | 0.0008 | 原独立高斯 | default 的三个种子 |
| weak_root | 弱根波动对照 | 1 | 0.0008 | 日周期+相关随机项 | 三种不同工况 |
| reference | 新研究参考条件 | 1 | 0.003 | 日周期+相关随机项 | 三种不同工况 |
| strong_root | 强根波动压力 | 1 | 0.006 | 同 reference，仅改幅度 | 三种不同工况 |
| tap_step | 调压事件压力 | 1 | 0.003 | reference 背景+0.00625阶跃 | 三种不同工况 |

三种不同工况为 `default`、`cloudy_variable_pv`、`evening_peak_high_load`；种子为42/7/21，独立重复改变种子。它们代表不同的光伏/负荷运行条件，但仍是人工生成曲线，并非三个实测地区。

0.0008/0.003/0.006 是有意分开的控制实验档位，不是现场统计标定，也不应宣称 0.003 是所有配网的典型标准差。
weak_root/reference/strong_root 的其他设置完全一致，可直接隔离根波动幅度；legacy 与 reference 同时改变阻抗、天气和时间相关性，二者差异不能全部归因于某一个因素。

## 根电压时序的数学定义

新的三个波动档位均采用15分钟物理网格、24小时周期。令 f=0.65，tau=1小时，dt=0.25小时：

\[
U_0(t)=1.02+\sqrt{2}f\sigma\sin(2\pi t/24+\phi)+w_t+s_t,
\]
\[
w_t=\rho w_{t-1}+\eta_t,\quad \rho=e^{-dt/\tau},\quad
w_0\sim\mathcal N(0,(1-f^2)\sigma^2),
\]
\[
\eta_t\sim\mathcal N(0,(1-\rho^2)(1-f^2)\sigma^2).
\]

相位 phi 每天随机生成。sigma 表示背景过程的总体波动尺度；有限单条相关日曲线的经验标准差不必等于它。本实现不按样本方差重新归一化，不裁剪电压来掩盖越限。

除tap_step外，s_t=0；tap_step在12–18小时增加0.00625 p.u.并减去全天均值，所以入段上升、出段下降各为该幅度。它模拟外生调压事件，不是带死区/延时/负荷反馈的调压器闭环模型。
选择该阶跃量级参考了NREL关于线路调压器与LTC离散档位约0.625%的说明，而非把所有变压器档位都假定相同。[NREL报告](https://docs.nrel.gov/docs/fy18osti/70517.pdf)

## 研究对照中的三种根观测

物理根电压先进入AC潮流；观测模式之后才决定拟合目标。切换观测模式不会重新选择物理负荷、端表噪声或实际根轨迹。

| 模式 | 提供给算法的根观测 | 拟合目标 |
|---|---|---|
| exact | 真实根电压的理想量测 | U0_true²−Vi_measured² |
| noisy | U0_true+根表计误差 | U0_observed²−Vi_measured² |
| unobserved | None；固定参考 Uref=1.02 | Uref²−Vi_measured² |

unobserved 的真实根轨迹仅存放在独立诊断字段，不能用于构造目标。该目标中的潜在公共项为 Uref²−U0(t)²。
准确量测时，直接公共根项已经被消除；把真实根波动放大并不能证明“已观测根电压仍缺一个未建模自由度”。

当前默认回归没有逐时公共项。因此 benchmark 的 unobserved + 当前回归是失配对照；它不是声称现有回归已正确处理缺失根量测。
核心场景生成器、pipeline 和 CLI 均只接受 exact/noisy 根观测，拒绝 unobserved。
unobserved 的目标变换保存在父仓库 `research_experiments/rnj/scenario_observation.py`，仅用于独立失配研究；
它不符合正式模型“根电压已观测”的前提。上表是研究对照的观测模式全集。

## 量测误差与物理波动分开配置

参考运行沿用 P/Q 相对随机误差标准差0.5%、端电压0.02%、根电压0.02%。legacy 原始默认根量测准确；仅显式选择 noisy 时添加根表误差。
误差标准差按瞬时幅值计算，P/Q 接近零时误差也接近零。这一测量模型仍偏理想，不能当作额定量程误差、系统偏置或缺失数据模型。

建议按独立轴增加电压随机噪声标准差0.02%/0.1%/0.2%，同时分别改变根表与端表误差；不应通过扩大真实根波动来代替较差量测精度。
这些是随机噪声分档。GB/T12325的供电电压偏差限值，以及仪器最大允许误差，均不能直接转换成高斯噪声标准差或根电压波动sigma。[国家标准状态](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=75EBBCF838AA40D281EDA854B8F63AD7)；[政府网站公布的标准正文](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web3087/site/attach/0/bd0771dd739a4b4493e219e6ede43738.pdf)

## 数据量和实验顺序

新套件始终先生成96点完整物理日、运行AC、添加量测误差，再抽取8/16/32/96点。这样改变数据量不会同时改变风电AR过程或负荷平滑的物理时间尺度。其他4以上且整除96的点数也可使用。
数据量分别为三场景×N点；这是整日稀疏采样，连续短窗口和随机丢包需要另设对照，不能混为同一种“小数据量”。

按三个阶段安排，避免先运行巨大的全因子组合：

1. **物理与数据核验**：四网络、五套件、三根观测模式，检查AC收敛、端电压范围、实际root标准差与相关性、动态信噪比、跨模式配对和legacy重放。
2. **回归对照**：先在reference条件比较当前、仅R/X ridge、自由公共模态、双ridge；按N逐级减少数据。再单独扫根波动或量测误差。调参集也计入数据预算，测试集不参与模型选择。
3. **拓扑修正与速度**：对不稳定的候选先做固定树LP/QP，再测试小候选池MILP或等价单步LP枚举；分别设置总时间预算和单次时限，保存证书、停止原因与回退结果。不能将有限池单步最优写成整棵树全局最优。

仍未覆盖的关键外推维度包括：实测线路阻抗尤其小X线路、非零隐藏注入、三相不平衡、根与负荷的闭环相关、系统性计量偏差、跨工况分布变化和更大网络。新reference仍是透明的合成参考，不是现场验证的替代。

## 运行与兼容

在独立核心目录执行：

```powershell
# 新研究参考主线；time-limit仍是单次MILP的上限
python run.py --scenario-suite reference --output outputs/reference --time-limit 30

# 使用旧场景与旧随机路径，回归仍采用当前零偏置模型
python run.py --scenario-suite legacy --output outputs/legacy_replay

# 重放独立的历史去均值/训练截距研究协议，不运行bootstrap或MILP
python experiments/run_scenario_benchmark.py --repeats 3 --output outputs/scenario_benchmark

# 单独提高量测误差，保留同一物理参考场景
python experiments/run_scenario_benchmark.py --suites reference --voltage-noise-rel 0.001 --root-meter-noise-rel 0.001 --output outputs/meter_noise_0p1pct

# 固定根电压的单因素对照
python experiments/run_scenario_benchmark.py --suites reference --root-sigma 0 --output outputs/constant_root
```

`pipeline.run`、普通 CLI 及历史高级 CLI 默认均为 reference、完整 RNJ＋MILP，输出 outputs/reference。只有低层 `_simulate_pool` 原六位置参数接口保留 legacy 数据生成默认；历史 outputs/mainline 不会自动被覆盖。
旧公共模态比较脚本继续调用legacy数据源，其结果不因本次新默认而被悄悄改变。已有结果源指纹改变时必须使用新输出目录，实际运行源码和旧数据均保留。

`run_scenario_benchmark.py` 保留独立的历史去均值/训练截距研究协议，不代表 2026-09-28 起正式流程的零偏置模型。它使用独立训练/测试重复（train=2k、test=2k+1），测试固定为3×96点；研究协议中的场景截距仅从所选训练点计算，测试电压只用于评分。
输出包括物理/观测数组、实际R/X真值、拟合矩阵、逐点残差、RNJ树、全部参数和源码SHA256。数据/算法失败单独记录，不把未完成模型算作成功。

## 历史研究协议的验证结果

已完成四网络×五套件×三次独立重复×三种根观测，共180组条件。每组分别使用每场景8/16/32/96点拟合，合计720次，均完成；每个模型在独立的3×96点测试集评分。这里比较的是现有回归和直接RX75-RNJ，没有运行MILP，也没有重新拟合自由公共模态或双ridge。

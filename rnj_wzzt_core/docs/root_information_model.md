# 根信息、公共项与 R/X 识别

日期：2026-09-08。本文审查根信息进入回归的方式，并报告一个有独立调参/测试集的小型配对实验。推导基于本仓库的平方电压 LinDistFlow 近似；公式是本文直接推导，不以实验结果代替可辨识性证明。

生产默认回归没有改变。新增入口为 [`../experiments/run_root_information_study.py`](../experiments/run_root_information_study.py)，复用已有 QP 的 `output_transform`。

## 1. “知道根”至少包括四种不同的信息

| 可用信息 | 能提供的约束 | 不能据此自动得到的内容 |
|---|---|---|
| 根节点标签、物理位置/参考点 | 指定树的方向和路径起点；排除把别的节点当根 | 不等于知道每时刻根电压，也不等于已知共同干线阻抗 |
| 准确根电压 U0(t) | 用 U0(t)²−Vi(t)²消除物理根电压变化；模型中公共根项可硬锚定 | P/Q欠激励或共线、AC近似误差及端表计误差仍存在 |
| 有噪根电压量测 | 提供有置信权重的公共项锚定；根表误差在所有终端间相关 | 不能把同一个根表误差当作 n 个独立误差重复计权 |
| 已知根支路归属、根分支参数或根侧 P/Q | 前两者可提供零共享路径/指定 clade/公共边权等结构约束；根侧 P/Q可检查功率总和和损耗 | 根侧 P/Q总量本身不自动产生 n 个独立终端电压方程，也不能单独确定逐时根电压 |

在本仓库隐藏节点零注入的模型下，根侧 P/Q在忽略损耗时主要是终端净 P/Q之和；含损耗时需加支路损耗。总量表计可用于聚合一致性、损耗诊断或改善噪声终端功率的估计，但还需额外测量/模型才能锚定电压公共项。如果某个上游支路的阻抗已知、上下游电压或参考电压关系已知，才可以进一步把该支路压降转成公共阻抗约束。

已知根直接连向哪些终端群也不同于只知道根标签。例如，若确认终端 i、j 位于根的两个不同直接分支，其路径只在根相交，则当前纯路径模型有 R_ij=X_ij=0。若已知一条边位于全部观测终端上游，则其贡献分别为 r0·11ᵀ、x0·11ᵀ（平方电压约定下系数含 2）。这些信息应作为明确的结构或参数约束进入问题。本实验没有模拟根 P/Q表计或注入此类已知支路先验。

## 2. 统一的根量测锚定模型

设每场景有 T 个时刻、n 个终端，A=[P,Q]，Θ=[R;X]。代码中 P/Q正值表示净负荷，负值表示净 DER 注入；R、X各为 n×n。平方电压模型使用真实路径阻抗的两倍，见 `models/lin_distflow.py::build_reduced_sensitivity_matrices(..., voltage_model="squared-voltage")`。

令固定参考电压 Uref=1.02，并定义

\[
Z_{ti}=U_{\rm ref}^2-\widetilde V_{ti}^{2},\qquad
c_t=U_{\rm ref}^2-U_0(t)^2.
\]

则近似观测方程为

\[
Z=A\Theta+\mathbf1_Tb_s^\top+c\mathbf1_n^\top+E.
\]

这里 b_s 是场景各终端截距。它可以吸收常量偏差，不能代替变化的 c_t。根量测提供

\[
a_t=U_{\rm ref}^2-\widetilde U_0(t)^2=c_t+\nu_t.
\]

一种明确使用根信息的加权模型为

\[
\min_{R,X,c,b_s}
\frac12\sum_t(e_t-c_t\mathbf1)^\top W_t(e_t-c_t\mathbf1)
+\frac12\sum_t w_{0,t}(c_t-a_t)^2
+\frac{\lambda_c}{2}\sum_t c_t^2
+\frac{\alpha_R}{2}\|R\|_F^2+\frac{\alpha_X}{2}\|X\|_F^2,
\]

其中 e_t=Z_t−A_tΘ−b_s，W_t表征终端平方电压残差权重，w0,t表征根量测权重。可叠加原有对称、非负、ordered约束。公共项有解析解：

\[
c_t^*=\frac{\mathbf1^\top W_te_t+w_{0,t}a_t}
{\mathbf1^\top W_t\mathbf1+w_{0,t}+\lambda_c}.
\]

- **准确根量测**：硬设 c_t=a_t，再估计 R/X。
- **噪根量测**：有限 w0,t，使公共项围绕实际根读数调整；不能自由漂移。
- **无根量测**：不构造 a_t，也不读取根真值。可以给 c 设置明确的统计先验或动态模型，但这是新增假设。

本次实现的简化版令 αR=αX=α；α与公共项的 γ分别设置。它没有实现三个各自独立的 αR、αX、λc，也没有实现逐时异方差 W_t或 OU平滑正则。本文一般式说明这些扩展的位置，不把它们记作已经完成的实验算法。

## 3. 噪根的 GLS 权重，以及系数中不可遗漏的 n

若根可观测，先构造 Y=Z−a1ᵀ=U0_measured²−V_measured²。此时回归的公共项 δ=c−a 是根表误差留下的**残余公共项**。无根量测时则直接使用 Y=Z，公共项仍是物理根变化 c。

在终端平方电压噪声方差同为 σv²、根平方电压噪声方差为 σ0²且两者独立的简化假设下，已减根量测目标的每行误差协方差为

\[
\Sigma=\sigma_v^2I+\sigma_0^2\mathbf1\mathbf1^\top.
\]

最小化 GLS 损失等价于

\[
\min_{\Theta,\delta}\frac12\|Y-A\Theta-b-\delta\mathbf1^\top\|_F^2
+\frac{\sigma_v^2}{2\sigma_0^2}\|\delta\|_2^2
+\frac\alpha2\|\Theta\|_F^2.
\]

已有实验 QP 的记号是公共项惩罚 **nγ||δ||²/2**，因此

\[
\boxed{\gamma_{\rm meter}=\frac{\sigma_v^2}{n\sigma_0^2}}.
\]

同相对精度且电压接近时，未乘 n 的惩罚系数 nγ约为 1，**γ约为 1/n**。两种写法不能混用。准确根 σ0=0 时 γ→∞，公共项为零；再令 α=0，严格回到当前目标。

令 J=11ᵀ/n，消去公共项得到

\[
\delta^*=\frac{(Y-A\Theta-b)\mathbf1}{n(1+\gamma)},\qquad
L_\gamma=(I-J)+\sqrt{\frac\gamma{1+\gamma}}J.
\]

随后优化 `||(Y−AΘ−b)Lγ||F² + α||Θ||F²`。该右变换正是现有 `constrained_least_squares.py::solve_symmetric_least_squares(..., output_transform=...)` 的接口。R/X参数、约束和 ridge 没有被右变换。γ=0仅保留跨终端对比，γ→∞保留所有输出方向。

本实验根表计锚定方法根据已知的模拟表计相对标准差、**训练量测值**估计权重。对乘性高斯幅值误差 η=σrel·V·ξ，直接展开有

\[
\operatorname{Var}[(V+\eta)^2-V^2]
=V^4(4\sigma_{\rm rel}^2+2\sigma_{\rm rel}^4).
\]

用训练终端和根读数的四次方均值代替未知 V⁴，得到一个常方差近似；没有用 root_voltage_true、真实 R/X或拓扑调权。噪根 γ实际范围为 0.05357–0.08898，与 n=11/15/16/18相符。该近似没有完整建模 P/Q误差、AC模型残差、异方差和平方噪声均值偏差，因而不能称为经过校准的最优统计估计或置信度。

## 4. 11ᵀ规范不辨识到底说明什么

对任何标量 u、v，若约束仍可行，变换

\[
R'=R+u\mathbf1\mathbf1^\top,\quad
X'=X+v\mathbf1\mathbf1^\top,\quad
c'_t=c_t-u\sum_jP_{tj}-v\sum_jQ_{tj}
\]

保持所有端电压拟合值不变。对称性和 ordered的对角差不变；非负性只限制负向移动的幅度，不能消除正向自由度。因此，无锚定、无公共项/RX正则的自由 c 模型不能从这些方程唯一识别共同干线的绝对 R/X贡献。RX ridge可以选出一个代表，但“正则选出的代表”不等于量测识别了该共同阻抗。

另一方面，终端两两距离

\[
d_{ij}(M)=M_{ii}+M_{jj}-2M_{ij}
\]

在 M→M+u11ᵀ下不变。这条规范方向**不证明缺根电压时所有相对拓扑或非平凡 clade必然无法恢复**。在充分激励、合适树模型和根位置/结构知识下，仍可讨论相对距离及拓扑恢复。当前 RNJ同时使用共享路径和根深度，其表现还依赖根位置知识、矩阵估计误差、噪声、弱激励、模型近似及容差规则。实验中 F1下降不能替代一般的不可能性证明。

准确根锚定可以限制上述变换，但也不是 R/X唯一识别的充分条件：若总 P/Q没有变化或互相共线，相关阻抗方向仍可能缺少激励。反之，已知根分支零共享项或已知共同支路参数也可提供规范锚点，作用不同于根电压表计。

自由组为可复现展示分别从 R、X减去最小元素，选择非负可行域内沿统一平移方向的最小 Frobenius代表，并保存原始解及平移量。它不是从真值学习到的根阻抗。除绝对矩阵误差外，结果同时报告：

- `r/x_uniform_shift_invariant_relative_error`：从估计误差中去掉统一 11ᵀ平移分量。
- `d_r/d_x_relative_error`：终端距离矩阵误差，对该平移严格不变。

自由 c 组的距离误差也变差，说明本批数据的退化不只是展示规范的选择造成。

## 5. 实验协议与额外预算

- 仅用 `reference`：三种不同日曲线，阻抗倍率 1，相关根背景 σ=0.003 pu；不重跑全 suite审查。
- 四案例，每场景 N=16/32，三次重复；P/Q量测标准差保持瞬时幅值的 0.5%。
- 终端幅值噪声取 0.02%和 0.1%；噪根条件根幅值噪声使用同一档相对标准差；准确根不加根表噪声，无根量测不给拟合器根值。
- 同一 case/repeat/noise 的 exact/noisy/unobserved共享完整物理曲线和终端表计读数，只改变可用根信息。不同 N从同一完整96点测量网格嵌套抽取。
- 每 repeat k使用 train replicate=3k、tune=3k+1、test=3k+2。训练和调参分别为 3N行，测试为独立3×96行。
- 因而每条件 N16使用48训练+48额外调参+288测试；N32使用96训练+96额外调参+288测试。不同根条件/N复用配对数据，不能把它们当作独立物理重复。
- 当前组 c=0、α=0；自由组 γ=α=0。
- 双 ridge组固定搜索 a∈{1e−6,1e−3,0.1}、γ∈{0.001,0.1,10000}，α=a||A_centered||F²/(2n)。α和γ是不同系数。
- 根表计锚定组固定 γ为上述表计方差公式（准确根为∞），只用相同 a网格选择 RX ridge；无根量测没有此组。
- **全部参数只根据独立调参集的未消公共项预测 RMSE选择**。未用测试数据、真实 R/X、真实 clade或F1选择参数。截距只由训练均值恢复，并按场景槽位迁移。
- 每根信息条件内，全部方法共用当前组 OLS确定的固定 ordered裕量。不同根条件的默认数据导出裕量可能有微小差异。
- 当前 RNJ规则保持不变，τ=0.16·median(root_depths)，同时保留 R-only、X-only、RX75及固定基线τ的诊断。

共144个根信息/噪声/N条件、528个最终模型、1872次QP，零模型/候选失败。24个工作单元累计171.4 worker-seconds，使用2个worker。另有独立 smoke：39次QP、11个模型，用于实现检查和估时；不纳入正式统计。没有bootstrap或MILP。网格和条件在正式结果之前固定，没有根据F1增删条件。

## 6. 预测与条件拟合必须分别评价

**测试预测 RMSE**：测试时只使用测试 P/Q、已经拟合的 R/X及训练截距，未知残余公共项设为0；已观测根条件的目标按实际根读数形成。无根时相当于采用固定Uref预测绝对电压，无法凭训练数据知道新的逐时根波动。这不是一个根电压时间序列预测器。

**测试 profile RMSE**：允许用当时测试电压残差重新估计公共项，按选定γ收缩后计算残差。它使用了当时 V，属于条件拟合/辨识诊断，不是未来电压预测。

**测试 contrast RMSE**：各模型都统一将测试残差减去每行终端均值，相当于只评价跨终端对比。它不依赖各模型选择的γ，适合比较共同模态之外的拟合，但仍不能宣传成绝对未来电压预测。

## 8. 实施建议和复现

1. 根电压准确：保留直接根差目标；是否加入RX ridge由独立观测验证选择，不需要为已知根再加入自由公共项。
2. 根电压有噪：优先考虑有表计方差解释的公共项锚定/GLS；需要更精细统计模型时，再实现异方差和P/Q误差建模。
3. 没有根电压：允许有明确正则/动态假设的公共项，并优先检查contrast、距离和可辨识方向；需要共同干线绝对参数时增加真实根/支路信息，不能把自由c当作替代测量。
4. 已知根位置、支路归属或参数：把这些单独建模为结构/参数约束；不要把它们与“根电压可观测”混成一个开关。


默认输出位于父项目 `artifacts/root_information_study_20260908/root_model/`：

- `config.json`、`source_manifest.json`：固定协议和源码SHA-256；不同配置/源码拒绝复用缓存目录。
- `metrics.csv`：528行模型明细，含预测、profile、contrast、绝对/规范不变R/X、距离和RNJ结果。
- `aggregate.csv`：按噪声、根条件、N、方法汇总均值、样本标准差和数量。
- `paired_changes.csv`：逐配对条件相对当前模型的变化；`run_summary.json`：工作量与失败计数。
- 每case/repeat/noise的 `observations.npz`：三个独立数据划分、根量测条件、真值诊断及真实R/X。真值仅用于事后评分。
- 每N/根条件的 `*_tuning.json`：所有候选、观测调参指标与失败记录；`*.npz`：估计矩阵、训练截距、每划分残差/公共项/contrast、RNJ边和自由组原始规范。

未修改生产估计器、默认方法或其他人的实验文件。

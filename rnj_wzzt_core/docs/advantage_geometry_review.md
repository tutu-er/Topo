# 几何层独立审阅：默认 RX75-RNJ 的优势边界

本文件仅分析正式运行 `outputs/advantage_stress_20260910` 已完整写出的 geometry 层。读取时完整性为 **1,400 个计划任务、9,800 条方法结果、7 种方法各 1,400 条、零失败、零重复 job/method**。没有使用仍在运行的 synthetic/AC 结果形成结论。数据源：[protocol.json](../outputs/advantage_stress_20260910/protocol.json)、[rows.jsonl](../outputs/advantage_stress_20260910/rows.jsonl)。

**当前证据不支持“默认 RX75-RNJ 在一般噪声下普遍优于 NJ”。相对零阈值 NJ，最清楚的优势来自星形、多分叉树中防止噪声产生虚假细分；面对 NJ0.16，这部分优势大多消失。非零阈值的代价是在二叉树、深链形树及短内部边上误合并真实分支。** 对相同的零阈值 NJ 比较，噪声层总体均值可以为正，但二叉树三个家族内部的均值全部转为负值。这是必须分层报告的结果。

## 试验口径

五个树族为 balanced、caterpillar、random、multifurcating、star；终端数为 8、16、32、64，每个 shape/n 有 10 个独立种子，七种压力复用同一基础树。每个 stress 有 200 个配对任务，每个 shape/stress 有 40 个。结果是任务级非平凡 rooted-clade F1 的等权均值；没有把不同规模的全部 clade 合并为一个 F1。

默认 `rnj_RX75` 使用 `tau = 0.16 * median(root_depths)`；`rnj_RX75_zero_tau` 仅把分组阈值设为零。`classical_nj_zero` 使用相同 RX75 距离和观测根锚点，只有数值零内部边收缩；`classical_nj_016` 使用同一数值比例作**重建后内部边收缩**。RNJ 分组与 NJ 后收缩是不同操作，不能把“比例同为 0.16”当作统计校准相同。

geometry 直接扰动已知 R/X 矩阵，没有回归、候选池或 L1 搜索。noise_02/noise_10 的 0.02/0.10 是相对真实矩阵对角中位数的高斯扰动系数，不是电表相对误差；对称化使非对角扰动标准差再除以 sqrt(2)。weak_internal 把内部边缩为原来的 0.03，且不加矩阵噪声。见[生成器](../experiments/stress_support.py:75)。

## 七种压力的总体配对结果

以下每格均基于 200 个任务。正负差值方向为默认 RX75-RNJ 减去 NJ0。

|---|---:|---:|---:|---:|---:|
| exact | 0.880230 | 1.000000 | 1.000000 | 0.777525 | -0.119770 |
| weak_internal | 0.248811 | 1.000000 | 1.000000 | 0.200000 | -0.751189 |
| noise_02 | 0.879836 | 0.748816 | 0.748252 | 0.776689 | +0.131584 |
| noise_10 | 0.751972 | 0.700582 | 0.696478 | 0.757102 | +0.055493 |
| x_noisy | 0.875742 | 0.728888 | 0.726787 | 0.784882 | +0.148955 |
| r_noisy | 0.590965 | 0.611714 | 0.609520 | 0.584375 | -0.018555 |
| diagonal_only | 0.849362 | 0.930843 | 0.999430 | 0.777430 | -0.150068 |

全部 1,400 个任务的默认 RX75 均值为 0.725273859，NJ0 为 0.825781135。默认−NJ0 为 **-0.100507276，275 胜 / 461 平 / 664 负**。相对 NJ0.16，默认差值为 +0.059844860，517 胜 / 763 平 / 120 负。因此，仅选择 NJ0.16 作为对照会得到明显不同的印象。

这些总体均值依赖给五个树族与七种压力各多少权重。星形树真值没有非平凡 clade：预测无额外 clade 的 F1 为 1，一旦产生额外 clade 即为 0。这一计分约定合理但特殊，不能与二叉树的误差幅度不加说明地混合解释。

## 用两组配对剥离阈值效应

必须同时报告“0.16 对 0.16”和“0 对 0”，而不能只让有阈值 RNJ 比较无阈值 NJ。两组差值方向均为 RNJ 减去 NJ：

| 压力 | RNJ0.16−NJ0.16 | RNJ0−NJ0 |
|---|---:|---:|
| exact | +0.102704990 | 0.000000000 |
| weak_internal | +0.048810898 | 0.000000000 |
| noise_02 | +0.103146364 | +0.000564516 |
| noise_10 | -0.005129722 | +0.004103462 |
| x_noisy | +0.090859986 | +0.002100390 |
| r_noisy | +0.006590141 | +0.002193426 |
| diagonal_only | +0.071931364 | -0.068587478 |

零阈值两算法总体差值仅为 -0.008517955，**82 胜 / 1,194 平 / 124 负**；只看四种同时含非对角噪声的压力（noise_02/noise_10/x_noisy/r_noisy，800 对），均值差为 +0.002240448。两算法在 exact 与 weak_internal 的全部 400 对均完全正确。由此，本库中大多数大的差距与阈值、分组/收缩准则以及非物理矩阵修复有关，不能全部归于 RNJ 的排序统计优越性。

以 noise_02 的 multifurcating 为例，RNJ0.16 相对 NJ0 有 +0.251079629 的均值收益，但相对 NJ0.16 只剩 **+0.000974026，3 胜 / 37 平 / 0 负**；star 的相应差值从 +1 降为 **0，40 对全平**。因此，“RNJ 善于抑制多分叉中的虚假细分”在这里首先是**有阈值与无阈值的区别**，不能宣称经典 NJ 加适当收缩后不具备这一效果。

同为 0.16 时，明显收益反而集中在深二叉树：noise_02 的 caterpillar 中 RNJ0.16 为 0.612319，NJ0.16 为 0.254394，差值 **+0.357924982，31 胜 / 9 平 / 0 负**。然而 RNJ0 和 NJ0 在同组分别为 0.995161 与 0.992339。这不是默认 RNJ 已准确辨识深树，而是它在这个数值比例下比 NJ 后收缩少丢掉一些真实结构。exact 的 caterpillar 同样为 0.606980 对 0.247727，而零阈值两算法均为 1。

“参数同为 0.16”不代表有效复杂度惩罚相等：RNJ 在递归时根据共享深度差一次归并若干活动节点；NJ 先二叉重建，再把每一条短内部边分别收缩。后者可以把很多相邻短边连续收掉，前者的多节点分组与后续共享深度更新不等价。geometry 的固定四种结果共同暴露这个差别；正式 measurement 层另有只用 validation MAE 选择 NJ 阈值的对照，必须等完整后联合解释。

## 优势主要来自多分叉，而非二叉树

这里将 balanced/caterpillar/random 合称二叉三族。胜/平/负均逐任务配对默认 RX75 与 NJ0。

| 压力 | 二叉三族差值，120例 | 二叉胜/平/负 | 多分叉差值，40例 | 多分叉胜/平/负 | 星形差值，40例 |
|---|---:|---|---:|---|---:|
| noise_02 | -0.197720 | 0 / 44 / 76 | +0.251080 | 40 / 0 / 0 | +1.000000 |
| noise_10 | -0.137562 | 1 / 28 / 91 | +0.215152 | 40 / 0 / 0 | +0.475000 |
| x_noisy | -0.165749 | 0 / 40 / 80 | +0.242021 | 40 / 0 / 0 | +1.000000 |
| r_noisy | -0.094373 | 14 / 17 / 89 | +0.140343 | 39 / 0 / 1 | +0.050000 |
| diagonal_only | -0.249570 | 0 / 36 / 84 | -0.001632 | 0 / 36 / 4 | 0.000000 |

noise_02 的 multifurcating 40 例中，默认 RX75 **40/40 精确恢复**；NJ0 与 RNJ tau=0 均保留全部 690 个真 clade，却各添加 **430 个假 clade**。这是明确的防细分收益，不是找回被 NJ 遗漏的真实分支。

这种收益也不是 RNJ 独占。noise_10 的 40 个 star 例，默认 RX75 精确恢复 19/40，而 NJ0.16 为 35/40。按 n=8/16/32/64，默认的成功数是 **10/7/2/0**，NJ0.16 为 **10/9/10/6**。固定 RNJ 阈值在更大规模下仍可能不足以抵御噪声极值产生的假分支。

## 无噪声下的规模反例

下表是 exact 压力、每格十个种子的 F1 均值。NJ0 与 RNJ tau=0 在所有格均为 1。

| 树族 | n=8 | n=16 | n=32 | n=64 |
|---|---:|---:|---:|---:|
| balanced，默认 RX75 | 1.000000 | 1.000000 | 0.944973 | 0.801681 |
| caterpillar，默认 RX75 | 0.990909 | 0.666667 | 0.480769 | 0.289574 |
| random，默认 RX75 | 1.000000 | 0.944358 | 0.795691 | 0.689979 |
| multifurcating，默认 RX75 | 1.000000 | 1.000000 | 1.000000 | 1.000000 |
| star，默认 RX75 | 1.000000 | 1.000000 | 1.000000 | 1.000000 |

默认 exact 总体只有 121/200 精确恢复；总计漏掉 **1,433/4,050 个真实 clade，额外 clade 为零**。64 终端 caterpillar 每例有 62 个真 clade，默认平均漏掉 51.5 个，F1 均值 0.289573820。数据完全精确，因此不能用测量噪声或 P/Q 可识别性解释这些损失。

原因可直接映射到当前实现：[入口](../experiments/run_advantage_stress.py:67)把阈值设为根深度中位数的固定比例；[RNJ 合并](../rnj_wzzt/graph/rooted_neighbor_joining.py:155)在相邻共享深度差不超过阈值时归为同一个父节点。caterpillar 随 n 增长时，根路径不断增长，而单条内部边仍处于固定权重区间，故阈值会跨过越来越多真实分支间隔。它不是一个与规模无关的最小边分离阈值。

weak_internal 中，默认只保留 162/4,050 个真实 clade，漏掉 3,888 个且没有额外 clade。balanced 与 multifurcating 的默认 F1 均为零；NJ0 与 RNJ tau=0 **200/200 精确恢复**。因此“真实内部边足够长，超过所用阈值”是默认方法的实际适用条件。

## R/X 权重不能提供无条件优势

| 压力 | R-only | X-only | RX50 | 默认 RX75 |
|---|---:|---:|---:|---:|
| noise_10：两通道相同扰动系数 | 0.674480 | 0.672359 | 0.805167 | 0.751972 |
| x_noisy：R系数0.01，X系数0.20 | 0.873837 | 0.522086 | 0.688982 | 0.875742 |
| r_noisy：R系数0.20，X系数0.01 | 0.499054 | 0.876540 | 0.672980 | 0.590965 |

RX75 相对 X-only 在 x_noisy 有 +0.353655457 的均值差，在 r_noisy 则有 **-0.285575058** 的差值。相同通道噪声系数下 RX50 比 RX75 高 0.053195417。不能把某个通道在当前回归案例更可靠，推广为所有数据源下恒定的最优权重。

“权重依据通道误差变化”是值得后续验证的方向，但本实验没有给出可部署的权重估计器；从本表按真值选最佳通道属于事后 oracle，不应当计为算法结果。除误差方差，混合权重还会改变真实分支间隔和阈值，因此单纯最小化混合噪声方差也不自动最优。

## 对角扰动揭示另一种边界

diagonal_only 只改变原始 R/X 对角，原始共享路径非对角不变。NJ0 的总体 F1 为 **0.999430108，194/200 精确恢复**；RNJ tau=0 为 0.930842630，默认为 0.849361758。64 终端 caterpillar 的均值分别为 **0.991935484、0.324939620、0.127856025**。

这个压力可能产生与正支路模型不一致的矩阵，不能解释为真实电表误差百分比。但它能明确定位机制：[sensitivity_geometry](../rnj_wzzt/graph/sensitivity_geometry.py:112)把共享路径裁剪到两个端点深度以内；对角变小会因此改变 RNJ 实际使用的共享路径，即使原始非对角数据完全没有噪声。同时默认阈值也依赖对角深度。NJ 的原始距离更接近吸收为末端长度变化，直到异常导致负末端长度/收缩等边界。这说明“直接用非对角因此天然不受对角误差影响”不符合当前实现。

## 目前可以支持的条件性判断

在本预声明测试库中，相对不使用非零阈值归并的对照，默认 RX75-RNJ 的结构收益集中在：真树具有多分叉、需要避免把同一分叉细分成多个潜节点；真实内部共享深度间隔足够大；R 通道确实较稳定；分组阈值能覆盖噪声形成的同父节点差异，又不跨过真实内部边。

作为下一步分析的局部尺度关系：若共享路径误差有统一界 epsilon，同父分组的差值误差可达 2 epsilon；若真实最小内部间隔为 m，不同父节点的观察间隔可降至 m−2 epsilon。希望阈值同时满足 2 epsilon <= tau < m−2 epsilon，需要 m > 4 epsilon。这解释了阈值必须同时适应误差与分支间隔；这里只给出局部分组的分离条件，未声称完成整个递归算法在任意误差模型下的全局证明。

这些判断尚未包括 R/X 回归误差、L1 候选池、冻结或收缩、计算预算与测量数据失配。正式 synthetic/AC 结果应作为独立证据层完成后再解释。每个 shape/n/stress 只有十个独立种子，不能把单格结果当作跨所有树分布的概率保证。

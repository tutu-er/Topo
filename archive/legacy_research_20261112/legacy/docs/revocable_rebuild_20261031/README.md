# 可撤销局部重构完整矩阵测试

## 结论和建议

退出机制能够修复部分旧连接造成的限制，但本轮不支持用这版逐区域扫描整体替换上轮五块联合加搜索惩罚。主面板的冻结配置由原RNJ加WZZT的F1 0.7545、完整恢复44/108，提高到0.7719、47/108；相对上轮最佳0.7813、51/108，仍低0.00942和4例。压力面板则为0.6649、4/12，优于上轮最佳的0.6531、3/12。压力样本较少，保留为本矩阵观察。

单独清理零连接的同参数逐步对照，F1从0.7524升至0.7588，完整恢复仍是44/108。这说明解除零权连接的结构限制有用，但不足以纠正有非零响应的错误分组。加上局部重构后，主面板自身路径F1为0.7683，比原RNJ加WZZT路径0.7299更高；收益不仅来自公共RNJ库回退。不过最终81/108仍选择公共RNJ库，不能把这些输出算成重构成功。

与上轮最佳相比，本轮最终小块FP为178对159，小块FN为110对108；大块FP为14对16，大块FN为8对9。大块略有改善，更多的小块误检抵消了收益。最终相容多余细分为133对117，交叉错误分组为59对58，差距主要表现为过度细分。惩罚强度由开发预测规则选为0.003；无惩罚重构的F1更高0.7789，但完整恢复更少45/108，没有一个本轮配置同时取得两项最优。

搜索过程确实发生了结构纠错：主面板路径上被错误集合阻断的真连接次数从124降至81，交叉假集合从137降至74。但终点仍有16个交叉假集合不被本次声明的frontier打开。当前一次改一个区域，反复联合拟合全网权重；旧方法在固定粗骨架下同时优化多个区域，两者邻域不构成简单包含关系。在120个正式输入中，冻结重构配置78个用尽软预算，39个邻域扫描仍有未排除改善，只有3个记录了声明局部域的界门槛退出。其1224次实际局部MILP中640次触时，不能把这次效果评价解释为精确局部最优树的比较。

目标偏差和搜索不足同时存在：主面板22个错误终点的含惩罚目标，明显优于真实支撑重新拟合后的最佳目标；另外51个错误终点仍差于真实支撑最佳目标。前者需要关注目标与数据模型的偏差，后者存在尚未利用的搜索空间。180次接受的局部变化中，有24次降低了支撑F1，直接说明J下降不能作为拓扑正确性的判据。

建议保留可撤销建模和零连接退出能力，继续以已有较强的多区域联合方法作为对照主线。下一轮优先在开发集验证怎样减少逐区域重复求解、覆盖大分叉内的错误边，并控制小块误检；不依据本轮正式F1重选lambda，也不通过任意提高生效阻抗下界制造恢复收益。生产默认未修改。

## 范围与公平性

新运行的逐步固定与逐步清零对照均lambda=0.003，唯一策略差别是清理零响应临时集合。可撤销方法使用五块完整子树frontier，也允许在大分叉中按训练RNJ几何选择至多五个兄弟子树。每个frontier候选并集完整枚举，保留外部权重联合重拟合。未增加正阻抗下界。
每条搜索20秒软预算，RNJ重构预选最多5秒，每次MILP最多2秒，四个单线程工作进程。模型构造和LP可能使软预算小幅超出，实际耗时保留。历史三基线复用上一轮同输入结果，计时不同批，不作为同次速度比较。
修正版正式批次前段与保留的初版诊断批次重叠，最多8个单线程工作进程，机器可见32个逻辑处理器；其后仅修正版4进程。execution_notes.json保留实际执行范围，耗时不作严格受控加速结论。
开发bundle0与1的外层观测用于参数选择；正式bundle2至4的测试观测和真拓扑不参与本次选参。这是此前已分析过的既有矩阵复测，不称为新盲测。最终候选均采用相同公共RNJ库、验证MAE、0.16收缩、0至2权重界；另列仅路径和未收缩终点。路径库也包含未修改初值，实际重构纠错另以逐事件变化统计，避免把RNJ回退或保留初值当作搜索修复。
局部候选至多25个，但20秒只覆盖有限邻域。触时与未排除改进的状态保留为unresolved，未报告全局或全邻域收敛。原始训练MAE与含线路代价的J分别核验，J下降允许MAE上升。
与旧五块联合的搜索域不构成简单包含关系：旧方法在固定粗骨架下同时优化多个区域；当前方法一次优化一个区域，能够释放部分较大边界，但需要多次全局系数重拟合。大分叉辅助邻域仅选择兄弟子树，没有枚举其所有进一步打开方式；stage_coverage.csv另报哪些交叉假块能被本次声明的frontier打开，不能把未覆盖写成所有五块邻域都无效。
全局零清理可能在局部MILP结束后删除其原本固定的外部零支撑。MILP下界只针对清理前的固定结构域；核验时把这些被删外部支撑以零权重恢复，并加回其固定线路数代价，形成同域可行上界。清理后更大的结构域不沿用该局部最优性证书。

## 目标偏好与搜索不足分开

离线把真实支撑集合固定，以相同0至2权重界独立求解训练L1 LP，再加相同线路数代价。真拓扑只在冻结后的诊断中使用，不参与任何搜索或选参。比较门槛沿用1e-10加0.001倍终点MAE。错误终点的J低于真实结构最佳J，表明当前量测与目标确实更偏好该错误结构；错误终点J仍高于真实结构最佳J，则存在未利用的搜索改善空间。两者均不作总体可辨识性结论。

# wzzT 改进评估：联合层次结构选择、Benders 与可辨识性

日期：2026-09-22。范围：当前 `rnj_wzzt_core/rnj_wzzt` 的主算法。本文是源码审查、数学推导与研究方案；不是已经完成的生产算法升级或运行时间优势证明。原核心、历史实验和校准链不作修改。

## 1. 判断

**可以用 Benders，但首先应改清楚优化对象。** 对现有每次新增一个支撑集的 MILP 作 Benders，只改变单步求解方法，不消除整条前向路径的贪心性。更值得做的第一版是：固定一个数据生成的候选支撑池，同时选择所有互相兼容的支撑集，并共同拟合 R/X；先实现直接联合 MILP 作基准，再比较其 Benders 版本。

研究优先级：

1. 将“每步最优”推进为“固定候选池内联合最优”，或至少增加可删除/交换的局部修正。
2. 保持同一联合数学模型，比较直接 MILP、Benders 和小规模穷举 oracle。
3. 优先融合可解释噪声尺度、线路 X/R 范围及真正新增的探测/电流信息。
4. 针对输入量测误差和根电压误差建立统计模型，再讨论拓扑恢复条件。
5. 后续用候选扩展/定价处理候选遗漏；Benders 本身不会补全候选池。

## 2. 当前实现实际上做了什么

以下行号是本次读取时的位置。

| 事实 | 源码位置 |

| 只删除在重估后零权重且不损害目标的非冻结支撑 | 同文件 `1387-1423` |

| 主流程生成 RNJ/局部编辑池并传入初始支撑 | `rnj_wzzt_core/rnj_wzzt/pipeline.py:549-574` |

设 s 为场景，t 为时间，i 为终端，S_k 为支撑集，z_k 为其 0/1 指示向量。当前模型可写为

\[
R=\sum_k r_kz_kz_k^\top,\qquad X=\sum_k x_kz_kz_k^\top,
\quad r_k,x_k\ge0,
\]

\[
\widehat D_{sti}=b_{si}+\sum_{k:i\in S_k}
\left(r_k\sum_{j\in S_k}P_{stj}+x_k\sum_{j\in S_k}Q_{stj}\right).
\]

这里的 r/x 是实现中的灵敏度原子系数，不能未检查平方电压与标幺约定就直接当作欧姆值。当前目标是全部标量观测的平均绝对误差；没有显式的支撑数惩罚或 X/R 物理区间。

几个重要区分：

- **R/X 共享支撑已经存在。** 再提“共享拓扑”不是新改进。
- **R/X 半正定已经自动成立。** 对任意 v，有 vᵀRv=Σ r_k(z_kᵀv)²≥0。再次给这一阶段添加 PSD 约束没有收紧作用。
- **联合重估权重已经存在。** 缺少的是对仍为正权重的错误支撑主动删除、交换或联合重选。
- **候选池限制是可选的。** 不能把核心无池接口说成只能有限池搜索；但无池的单步全域最优仍不等于全树最优。
- **1-SE 是预测与复杂度选择规则。** 它不保证所有真实弱分支都被保留。

## 3. 更适合 Benders 的联合模型

### 3.1 固定候选池的原子选择

令 C 是训练数据产生的支撑池，A_c=z_cz_cᵀ 已知；二元变量 a_c 表示允许启用候选 c。令 E_cross 为所有发生交叉的候选对，即非空相交且互不包含。

\[
\begin{aligned}
\min_{a,r,x,b,e}\quad &\frac1N\sum_\ell e_\ell+\lambda\sum_{c\in C_{\rm optional}}\omega_ca_c\\
\text{s.t.}\quad&-e\le d-F_Pr-F_Qx-Bb\le e,\quad e\ge0,\\
&0\le r_c\le M_c^Ra_c,\quad0\le x_c\le M_c^Xa_c,\\
&a_c+a_d\le1,\quad(c,d)\in E_{\rm cross},\\
&a_c\in\{0,1\}.
\end{aligned}
\]

N 为标量观测数；B 是场景/终端截距设计矩阵；F_P 第 c 列是 vec((Pz_c)z_cᵀ)，F_Q 同理。根参考及符号沿用现有预处理。必要的叶单点可固定启用，是否允许全终端公共支撑应与根端测量及物理模型一致。非必要 RNJ clade 宜作候选或软代价，不宜直接锁死。

候选两两满足不交或包含恰好保证所选集合族层次相容。加叶单点及必要的虚根/零长度连接后可解释为约化层次树；此处不保证未知物理二度节点数或每条原始线路可辨识。若有最大复杂度需求可加 Σa≤K；理论上非空不同支撑的 laminar 族最多 2n−1 个。

**这不是现有逐步算法的等价重写，而是更大的联合搜索。** 联合可行域包含同池、同边界和同冻结约束下的每一个前向路径模型。因此对同一个训练目标，联合最优值不劣于这些路径模型；这不保证测试误差或拓扑 F1 更好。λ 的选择必须使用独立调参数据。

优点：无需对每个候选再引入未知 z_i z_j；可同时撤销错误支撑、添加正确支撑；不必预先枚举完整树。代价：候选数与交叉图仍可能很大，组合搜索没有消失。若 C 来自单棵树且已全部 laminar，交叉约束为空，结构纠错能力也受限。

### 3.2 Benders 主问题与子问题

保留 a 与 θ 于主问题：

\[
\min_{a\in\mathcal A,\theta\ge0}\lambda\omega^\top a+\theta.
\]

固定 a 后，求解上述连续 L1 LP，记最优值 Q(a)。在未加入额外硬物理可行性条件时，令 r=x=b=0、e=|d| 即可行，故具有完全追索，通常只需最优性割。

子问题的一个对偶写法是

\[
\begin{aligned}
Q(a)=\max_{\pi,\mu^R,\mu^X}\quad&
d^\top\pi-\sum_c a_c(M_c^R\mu_c^R+M_c^X\mu_c^X)\\
\text{s.t.}\quad&|\pi_\ell|\le 1/N,\qquad B^\top\pi=0,\\
&F_P^\top\pi\le\mu^R,\quad F_Q^\top\pi\le\mu^X,\\
&\mu^R,\mu^X\ge0.
\end{aligned}
\]

对任意对偶可行点，下面的割对所有 a 有效；若对偶在当前 a 的子问题上最优，割在该处相切：

\[
\boxed{\theta\ge d^\top\pi^{(j)}-
\sum_ca_c(M_c^R\mu_c^{R,(j)}+M_c^X\mu_c^{X,(j)})}.
\]

有效性直接来自弱对偶，相切来自 LP 强对偶；不是依赖某一次固定拓扑的局部外推。主问题下界与已求得可行模型上界之差给出**固定池、固定边界、固定目标**下的最优性 gap。这一结构使用经典 [Benders 分解](https://link.springer.com/article/10.1007/BF01386316)；上面的 wzzT 专用对偶是本文推导。

固定有限二元域、有效有界目标、精确子问题和正确主问题求解下，可以获得有限终止的精确方法；它仍可能需要指数数量的组合。完整算法必须明确记录全局上下界与总时间预算。

### 3.3 直接分解现有未知支撑 MILP 也可行

现有实现已作线性提升：y_ij=z_iz_j，u^R_ij=r_new y_ij。把整数 z/关系选择留在主问题，连续 y/u/权重/残差放入统一 LP 后，可写为 Wv≥h−Ta，其中 W 不依赖主问题。也可把 y 留主问题，将乘积包络的 y 项放右端。

但不要在每次固定 z 后仅形成维数/系数随 z 改变的回归矩阵，然后未经证明复用该 LP 的对偶作为通用线性割。可行的对偶域随拓扑改变时，某拓扑下有效的乘子未必对其他拓扑有效。必须使用共同提升形式、正确的广义分解或逻辑割。

保留现有外层前向算法时，即使每个 Benders 子程序都认证最优，也只认证单原子扩展，不认证全树。

### 3.4 场景分解不能丢掉共享线路参数

原问题中的 r/x 跨场景共享，通常有

\[
\min_{r,x}\sum_s L_s(r,x)\ \ge\ \sum_s\min_{r_s,x_s}L_s(r_s,x_s).
\]

右端允许每个场景拥有不同线路参数，至多作为松弛下界，不能作为原问题的精确 recourse。正确的可选实现是：

- 把所有场景放在一个联合 LP 中；或
- 把共享 r/x 放主问题，场景 LP 只处理本地截距、残差和明确允许变化的噪声变量；或
- 用带一致性约束的分解，并证明上下界关系。

时间块也一样：同场景共用的截距、平滑项等若跨块耦合，不能默默复制为自由的块独立参数。

### 3.5 何时有望提速

| 情形 | 优先方法 |
|---|---|
| 固定一棵树，仅估计边权 | 一次 LP/QP |
| 现有单步扩展且候选很少 | 枚举候选 LP，可并行并复用矩阵 |
| 中等候选池的联合结构选择 | 先直接联合 MILP |
| 离散结构规模适中，但样本/场景很多、LP 子问题很大 | 测试 Benders / 多割 |
| 没有候选池，主要困难是终端子集组合搜索 | Benders 未必解决主要瓶颈 |

本地旧报告 `rnj_wzzt_core/docs/root_voltage_low_sample_milp.md:84-94` 记录：2026-09-07 的两个小池单步例子中，枚举 LP 分别约快 5.0/5.7 倍。这是旧设置、两次单步试验，不能当作当前联合模型或 Benders 的加速结论。

L1 子问题可能对偶退化；普通割弱时迭代会很多。可研究 [Magnanti–Wong 的 Pareto 割](https://pubsonline.informs.org/doi/10.1287/opre.29.3.464)、主问题稳定化、初始割、连续松弛处割及嵌入同一分支树。应先测原型瓶颈，再增加这些技术。

上界 M 特别重要：当前 `estimate_atom_upper_bounds` 使用 OLS 尺度估算，外层可触界扩张。这对“当前有界域”的求解有效，但未自动证明覆盖所有真实参数。收紧 M 可以加速，但必须保留依据；扩界后旧割原则上应丢弃或按新对偶域重新验证，不能直接沿用更小域的结论。

## 4. 可以加入哪些项，哪些不值得重复加入

| 项/约束 | 解决的问题 | 对求解形式与辨识的影响 |
|---|---|---|
| 加权绝对残差和，权重由独立噪声尺度给定 | 电表精度、场景噪声不均匀 | 仍为 MILP/LP；固定权重不能用测试残差倒推 |
| λΣa_c 或复杂度约束 | 将复杂度控制放进联合搜索，减少冗余分支 | 仍为 MILP；过强会删真实弱边，不是拓扑正确保证 |
| 下界/上界比值：κ_min r_c≤x_c≤κ_max r_c | P/Q 相关时约束不合理的 R/X 交换 | 仍为 MILP；需要可信线路物理范围，应允许松弛并检验偏差 |
| X/R 偏差的绝对值惩罚：λκΣ abs(x_c−κ_c r_c) | 不确定的 X/R 先验作软约束 | 仍为 MILP；κ 不应由隐藏真值调出 |
| λ₂Σ(r_c²+x_c²) 或适当加权 ridge | 固定拓扑的病态参数估计 | 联合成 MIQP，固定结构成 QP；改变经典 LP Benders 子问题，但可用凸分解 |
| Huber 电压损失 | 兼顾小噪声效率和大异常鲁棒性 | 通常 QP/凸二次锥表达；不要仍称原 L1-MILP |
| 受约束公共根误差 g_st + TV/二次先验 | 根不可测、噪声或漂移 | 固定权重 TV 可保 MILP；自由 g 会吞掉共同上游结构信息 |
| 独立主动探测 ΔP/ΔQ→ΔD 项 | 增加可区分结构的激励 | 在已知激励下保持线性；更可能改善可辨识性 |
| 支路电流相量/KCL、编码信号匹配 | 提供电压拟合以外的结构证据 | 已知线性观测映射时仍可为 MILP；电流幅值不能直接当有符号 KCL |
| 多日/多相共享支撑，适度参数漂移惩罚 | 积累证据、允许温度/运行差异 | 限定共树条件；三相互耦不能硬套单相标量模型 |
| EIV / TLS / 工具变量 | P/Q 自身带噪引起的回归偏差 | 完整 EIV 通常引入乘积与非凸性，宜先在固定结构或独立估计层实现 |
| 线损/未计量负荷通道 | 物理模型失配与区域筛查 | 需独立测量/时序结构限制；自由隐藏负荷会拟合掉拓扑错误 |

上表的残差绝对值采用文字记号以避免表格竖线冲突。

具体建议是先选前三类，另设主动探测/额外测量的独立研究轴；不宜一次把所有误差源和隐变量放进同一联合模型。

### 4.1 根项存在一条明确的辨识边界

若方程包含自由逐时公共项 g_t 1，而全终端原子 z=1 的贡献为

\[
\mathbf1\left(r_0\mathbf1^\top p_t+x_0\mathbf1^\top q_t\right),
\]

则任意系数变化 δr/δx 都可由

\[
g'_t=g_t-\delta r\,\mathbf1^\top p_t-\delta x\,\mathbf1^\top q_t
\]

抵消。只要参数仍在可行域内，上游全终端共同阻抗不可与自由根项区分。惩罚只能施加先验偏好，不能把不存在的数据信息变出来。准确根量测已用于构造电压降时，也不应再无依据添加同一个根波动项。

### 4.2 P/Q 共线与 EIV 是不同问题

若所有观测满足 q_t=κp_t，则只看到 H=R+κX。对各原子，r'_c=r_c+κδ_c、x'_c=x_c−δ_c 给出相同预测（在可行范围内）。更强优化器无法辨识 R/X 的拆分。不过若 H 的边权正且激励与量测足够，H 的约化树仍可能可识别，不能把参数不唯一直接说成拓扑不唯一。

EIV 则是观测输入也含误差。若引入潜在真 P*=P−δP，则 P*R 出现未知量乘积；即使固定支撑，联合优化测量修正与边权也通常不再是 LP。已有 [Bayesian EIV 电网辨识研究](https://arxiv.org/abs/2107.04480) 处理电压/电流双侧误差；其观测与模型并不等同于当前末端 P/Q/平方电压方案，不能直接移植恢复保证。

### 4.3 避免与树结构相冲突的通用正则

因为 R≥0 且 R⪰0，

\[
\|R\|_{\text{entrywise }1}=\sum_cr_c|S_c|^2,
\qquad \|R\|_* =\operatorname{tr}(R)=\sum_cr_c|S_c|.
\]

因此对 R 作元素 L1 或核范数，并非“对树边数稀疏化”：它额外按下游终端数惩罚共同上游分支。正叶边存在时 R 可以满秩，不能因为它由秩一原子相加就假定整体低秩。若希望减少结构复杂度，用 a_c 的计数更直接；若希望稳定参数，用有单位/尺度解释的 ridge 或先验。

## 5. 可以进一步证明什么

以下是本报告推导的条件化命题，不是当前实现已具备的完整恢复定理。

### 5.1 优化误差、噪声与结构间隔的联合条件

设有限候选拓扑族为 T，每个拓扑的可行无噪预测集合为 F_T。真实信号 f*∈F_T*，观测 d=f*+ε，定义归一化 L1 范数 ||v||_N=||v||₁/N，且 ||ε||_N≤η。定义

\[
\Delta_T=\inf_{f\in\mathcal F_T}\|f-f^*\|_N.
\]

算法对损失+λK 取得绝对优化误差不超过 g（上界减全局下界≤g，且与平均 L1+λK 同单位，不能使用相对 gap 或单步扩展 gap 代替），则排除错误 T 的充分条件是

\[
\boxed{\Delta_T+\lambda(K_T-K_{T^*})>2\eta+g.}
\]

证明：错误模型目标≥Δ_T−η+λK_T；真实可行模型目标≤η+λK_T*；若两者差超过 g，g-最优算法不可能选择该错误模型。λ=0 时简化为 Δ_min>2η+g。

意义：改进数据、激励及模型减小 η 或增大 Δ；更充分的优化减小 g。求解器只能处理 g。这里 η 包含本模型下的输入误差传播和线性化失配，不能只填电压传感器标准差。该确定性条件保守；不是直接的样本复杂度定理。

**关键前提：**真模型在池内且满足边权边界；候选预测集必须真的可分。如果允许零权重任意精化、不可辨识二度节点、任意小边或自由隐藏负荷，可能 Δ=0。应按正边阈值定义约化树/等价类，或加入有物理依据的最小可检测边长。不能省略此条件宣称精确恢复。

### 5.2 条件参数估计的有效维数

给定 k 个活跃支撑，主要线路参数只有 2k，而非两张一般稠密矩阵的 O(n²) 自由度。将截距从设计中消去后，需要 [F_P,F_Q] 在相关参数方向上满足足够的秩/最小奇异值或适用 L1 的受限条件。

这给出“少样本下结构模型可能更稳”的解释，但不能仅凭参数计数证明优越性。选错支撑、P/Q 共线、短时间窗及共同负荷变化可使这个较小设计矩阵仍退化。若要得到有限样本恢复率，还需规定设计分布、时间依赖、噪声、最弱边和候选构造的数据使用方式。

末端隐节点恢复已有 [Learning with End-Users](https://arxiv.org/abs/1803.04812) 等理论；主动探测下全网观测与仅探测点观测分别对应不同恢复对象，见 [Graph Algorithms for Topology Identification using Power Grid Probing](https://arxiv.org/abs/1803.04506)。本文不将这些模型的定理直接称为当前 wzzT 定理。

### 5.3 候选扩展应有自己的证书

联合池优化只解决池内搜索。较长期可建立：受限候选主问题 → 对偶残差信息驱动新原子搜索 → 新候选与已有候选共同重选。

若先去掉 laminar 整数限制并改用连续原子权重惩罚，可得到一个凸松弛的列生成框架。某 R 原子的对偶得分形式为

\[
f_P(S)^\top\pi=\sum_t\sum_{i,j\in S}\pi_{ti}P_{tj}
=z^\top H_Pz.
\]

一般是二元二次定价，不能未经额外结构证明就宣称低复杂度。凸松弛的完整定价证书给出松弛最优性；加上整数层次结构仍需要分支/割或新的理论。仅在当前 laminar 家族内找不到可加原子，也不排除“先删除一个、再加入两个”的改进。

一个可交付的中间改进是删除/交换局部搜索：接受前重新解全部权重 LP，对同一惩罚目标要求严格下降并保存已访问结构。有限池中可有限终止于所选邻域的局部最优；不能冒充全局最优。

## 6. 应当如何验证下一版

### 6.1 第一阶段：固定同一个数学问题

比较三者：小 n 穷举全部可行候选子族；直接联合 MILP；Benders。保持相同候选、M、λ、输入和允许冻结支撑。逐实例检查目标、可行性、全局 gap；每条割应在小 oracle 全域有效且在生成点相切。遇到多解比较目标和等价类，不强求支撑逐位一致。

### 6.2 第二阶段：区分两种收益

- **算法形式收益：**原前向法 vs 可回退联合选择，比较结构错误、弱边遗漏与预测误差。
- **求解技术收益：**同一联合模型的直接 MILP vs Benders，比较总墙钟、内存、LP 次数、主问题节点、割数和最终上下界。

不能把更换目标/候选/边界后的加速归因于 Benders。保留超时和无可行解，统一整模型墙钟预算；当前核心每次 LP/MILP 的 time_limit 不是整模型预算。

### 6.3 第三阶段：独立消融

分别增加噪声加权、X/R 范围、额外主动探测、EIV、公共根误差。覆盖：弱内部边、候选遗漏、错误冻结、P/Q 共线、同步误差、根慢漂移、重尾异常、隐藏非零注入。训练/调参/最终测试分离；额外测量和探测须计入信息预算。

目标指标同时报告：约化拓扑/clade F1、整树恢复、参数误差、独立预测损失和失败率。bootstrap 频率是稳定性指标；优化 gap 是模型内证书；两者均不是当前物理拓扑正确概率。

## 7. 本轮交付与证据边界

本轮完成源码对应、联合模型和 Benders 对偶推导，并作独立条件审查。数值核验因执行环境阻塞未完成；本报告不交付已验证的 Benders 实现或加速数据。

尚未完成：生产版 Benders 求解器、实际馈线速度评测、全规模鲁棒性实验、当前 wzzT 的完整统计恢复定理。本文的建议不是以上工作的完成声明。

建议下一次只做一个明确升级：**候选池内联合 laminar 选择 + 可审计全局 gap**；之后在相同问题上决定是否采用 Benders。这样能先解决当前结构搜索范围的缺陷，再评估分解是否值得。

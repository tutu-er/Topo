# 追加时机对照：在原退出之前进行单块重启

首轮24输入、96分支完成并审计后，诊断发现：原退出后的13个被选大块中11个为真块，2个错误块也不交叉真结构；在旧退出前的训练前缀终点，同一固定规则在18输入找到大块，其中11块错误、共交叉14个真连接。为检验用户提出的退出时机，本追加试验只改变起点。

仍使用全部相同24输入，不能挑出错误的11例来运行。仍是最大的保留proper集合、>5终端、字典序破同分，不使用真拓扑选块。四分支continue/drop_refit/drop_resume/mask_resume、lambda、收缩、14,400秒总账、单MIP3,600秒、LP300秒、MIPGap=.0001及验证规则完全相同。直接复用首轮冻结的数值worker和依赖源，核验逐字节相同；不重新初始化RNJ、不新增策略参数。

起点改为保存的trajectory.point，即原末端联合结束或前向停滞、尚未进入旧全候选退出。训练提议只运行一次恢复WZZT/末端流程，不再接第二个退出。验证保护仍可返回完整旧主线最终树，因此累计时间继续计入完整旧主线成本，不把本试验冒充替换旧退出后的独立端到端速度比较。

本对照在看过首轮结果后追加，结果性质为探索性时机消融，不是初始预注册主比较。保留首轮协议和96条输出哈希，真拓扑/test仍仅用于事后评分；同样保留无大块输入、失败、超时及总分母。输出独立目录，不覆盖首轮或主线。

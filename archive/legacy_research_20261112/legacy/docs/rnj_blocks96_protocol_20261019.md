# 原96点数据：RNJ块筛选与WZZT配置对照

本轮按2026-10-19用户指示，内部子簇频率上限从10%改为15%，取消至少三终端条件，允许二终端块；恢复最初一天96点及原电压精度。NJ、RNJ不重新拟合，经原数据和产物核验后复用。

## 数据与信息

- 原始数据：`outputs/source_ac96_20261018`，paper15、soumalas11、flynn16、pengwah18四网络；无源、常值源、间歇源、平滑源四条件，共16组。
- 每组原96点全部拟合，不划验证集或测试集。电压及根电压相对噪声0.0002（0.02%），P/Q噪声0.005；源平均规模为原生成协议的馈线标称P的5%，不改用后续25%压力源。
- 有源算法可见精确P/Q时序，接入位置未知。拟合进程只接收observed和source白名单文件；物理网络仅由控制器在模型完成后评分。
- 本轮用已有数据诊断配置，不将同一批数据上的优胜解释为独立泛化或普遍优势。

## 固定的筛选规则

保留RX75（R占75%、X占25%）、粗阈值系数0.16、细阈值为粗阈值一半、移动块bootstrap100次、块长4、稳定度至少75%、最多2个互不相交块。要求完整直接末端同胞组，至少2端；子簇出现频率≤15%；全数据细阈值树中存在内部细分仍否决。有源时保留原Source投影可识别秩检查。bootstrap按相同索引同步重采样测量和源时序。

分母遵循既有方法：同胞频率除全部100次，内部细分频率除有效可识别次数；无效次数不隐藏。保存完整粗/细树、普通clade频率、同胞频率、每次重采样索引及每候选淘汰原因。普通clade频率仅作诊断，不替换atomic筛选。空选择原样保留。

## 新计算的64项

每组数据固定比较4种配置；不依据真实拓扑为各组另选参数。

| 配置 | 初始支持 | 共用binary的不可分块 |
|---|---|---|
| WZZT | 全部原终端singleton | 无 |
| RNJ+WZZT | singleton + 选中的稳定块 | 选中的稳定块 |
| RNJ+WZZT_ungrouped | 与上一行完全相同 | 无 |
| RNJ+WZZT_tree_init | singleton + 全数据RNJ全部非平凡clade + 选中块 | 选中的稳定块 |

主方法为前两种（32项），后两种为配置对照（32项）。另复用原32项NJ/RNJ基线，合表分母96。全部既有结果保持不变。

普通初始支持会固定laminar兼容关系，但其线路权重可归零。共用binary实现为同组选中变量相等，未选终端各自单独成组。三终端及更大分组还禁止内部细分，故开/关分组对照同时反映搜索域变化与编码规模变化；不把时间差全部归因于压缩。两配置path0为相同固定支持问题，可独立核验原始目标与约束。

## 历史求解流程和下界

使用已冻结的72af Source/terminal_groups完整贪婪流程，不改生产主线代码。不提供验证集，保存最后认证路径点；保留原全部终止条件、零权重剪枝、无显著改善证据、系数上界2及触界自动扩界（倍增、最多4次）、严格status/gap检查。

沿用已验证RX75线路下界适配器：由同组观测预树R/X固定尺度，tau=0.16×RX75根深度中位数。非singleton旧边权重允许为零，否则必须达到tau；新增内部边达到tau并含至少两个原终端；终端leaf不套内部边下界。Source完整h路径、全部原终端残差及源幅值只计一次均保留。

每solve上限6000秒（沿用此前扩大100倍的预算），每方法总墙钟30000秒。4个新worker并发、各solver/BLAS单线程。另有旧288点批次可能同时运行，时间为非独占机器环境的实测墙钟，不作精确硬件速度排名。

## 验证与留存

运行前冻结协议、实际代码依赖闭包、runtime、输入哈希及环境；worker实际执行冻结副本。被动observer记录每次原始COO、边界、整数域、原始终端家族、分区、目标/界/gap、耗时，独立重算数值可行性及目标。checkpoint原子保存认证模型对；超时与进程失败保留最后认证模型并标记incomplete/failed。

汇总family、active和RX75 resolution三种拓扑F1，以及相对Frobenius R/X响应矩阵误差、时间、状态、扩界数、选择块、求解次数及超时。主F1为resolution，真实拓扑始终完整保留；原始family/active分数同时给出。NJ/RNJ新增resolution仅在保存模型上后处理，原F1、R/X及计算时间保留，并单列后处理时间。没有模型的失败项保留空指标，不从分母删除。

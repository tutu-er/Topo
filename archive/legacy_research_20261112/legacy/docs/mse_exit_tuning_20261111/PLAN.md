# 最终E的MSE相对改善门槛校准

2026-11-11。用户要求使用类似现有形式的MSE相对改善退出指标，并优化参数。本轮仅替换最终E提议的接受门槛；保留当前MIQP+T版本作原始对照，原生求解、前向/T、计数罚alpha=.003、及时清零、.24输出收缩及严格MAE选模均保持原规则。

## 判据

记Mold、Mraw为E前点与已有E原始可行提议的训练MSE，K=f01/f02。新判据为

\[
M_{\rm old}-M_{\rm raw}>10^{-10}/K+\tau M_{\rm old}.
\]

原判据等价于

\[
M_{\rm old}-M_{\rm raw}+.003 f_{02}(k_{\rm old}-k_{\rm raw})
>10^{-10}/K+.001M_{\rm old}.
\]

新判据去掉接收门槛中的计数补偿，但MIQP仍优化带计数罚的平方目标，所生成的提议不变。保持先判断raw提议、接受后QP重拟合的顺序，不添加允许MSE上升的删块例外；原有数值零块释放规则另行保留。

固定tau网格为0、.0001、.001、.003、.01。它们分别表示只要求越过数值容差、.01%、.1%、.3%、1%的相对改善。不是绝对误差阈值，不用F1或真实拓扑选择tau。

## 精确回放

只用刚完成48个T003原生记录。最终E在前向结束后仅执行一次，所以改变其接收门槛不影响前面的MIQP提议；本轮不重跑结构求解。

由保存路径去掉旧E接收点和最终零清理点恢复前向路径，必须逐项复核before_score。新门槛拒绝旧接受时移除对应尾点；新接受旧拒绝时，才对该缺失家族补做QP、清零及.24收缩重拟合。旧已有拟合系数直接复用。不能把未经闭合的raw权重当作最终输出。

原J对照必须逐参数、分数、索引和路径长度重放原生结果。新旧门槛均使用相同raw提议和同一输入；48条重用结构求解、6个视图/输入，共288视图，不是288次新MIQP。

## 校准与评价

主校准分数是E后单个端点经.24收缩/QP后的验证MSE，除以同输入E前端点经相同处理后的验证MSE，48输入等权。它不取整条候选库中的最小验证误差，以免把“接受更多候选必然使库内最小误差不增”的集合包含关系当作调参收益。最终部署输出仍按完整自身路径的严格验证MAE选择。

按四个共享seed_index分组，四折留一组：在其余36输入上选tau，对留出的12输入评分。三档噪声和四个网络的同一seed整组移动。数值同分容差1e-12，固定优先顺序为.001、.003、.0001、.01、0；保留原相对尺度作为首选，不宣称同一评分平台内某个tau是唯一最优值。

所有全样本和分组参数选择须先写入独占selection.json，随后才读取真值和测试数据，报告F1、完整恢复、测试预测误差、端点/最终输出差异及触发次数。已知48输入的结果此前已公开，因此本轮称历史校准和分组敏感性，不称全新独立验证。若最终输出确实改变，再冻结参数并考虑新seed测试；若全部输出相同，不为相同候选提议重复运行MIQP。

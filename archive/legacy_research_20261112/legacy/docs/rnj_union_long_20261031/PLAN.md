# 长时限候选并集重构与纯WZZT：结果前方案

用户明确授权：候选块联合优化，增加纯WZZT，大幅延长求解，保留当前方案，在同一120输入比较F1、完整恢复和总耗时，并检查策略复杂度。旧四方法与整树组合只读保留；不按新F1调参。

## 最小描述与模型

策略可概括为：**从训练观测生成有限候选集合，做一次带相容约束的稀疏L1回归，最后按固定尺度收缩并独立验证。**

对候选C预计算z_C z_CᵀP、z_C z_CᵀQ。内部集合选择a_C∈{0,1}，0≤r_C,x_C≤2a_C；交叉集合a_C＋a_D≤1，加层级计数／团约束。单点和全集是连续响应基，其他集合全部可撤销。最小化原终端量测MAE＋λΣa_C。没有未知成员乘积，也不强制二叉完全细分。

主模型λ=0.003 f0，f0是同输入原始完整RNJ训练MAE，沿用既有尺度。另固定λ=0消融，判断计数惩罚的作用，不是再调一组最优参数。所有权重仍在原终端残差上共同拟合；没有新增阻抗正下界。

## 四个新对照

| 方法 | 候选与步骤 |
|---|---|
| union_count | 训练生成的原始RNJ候选库、完整RNJ修正版和稀疏原始WZZT的全部训练路径／退出集合、原始NJ集合取并集；一次计数正则MILP。 |
| union_plain | 完全相同候选池，一次无计数惩罚MILP。 |
| simple_count | 原始训练P/Q/Y重新拟合一次R/X，仅生成单个RX75-0.16 RNJ和NJ树，候选并集做一次计数正则MILP。不运行WZZT生成器、末端枚举或额外退出。 |
| pure_wzzt | 仅单点和全集连续基初始化，每步自由选择一个相容集合、重拟合全部权重；不使用NJ/RNJ集合、候选池或热启动，不运行联合末端／退出，不回退公共RNJ库。 |

联合池构造不读取validation choices。原方案验证后选择的集合只检查是否已在该训练池中，不能用它们补池。新联合模型无原树硬保留约束、无多区域扫描、无再次按验证接受／拒绝的新回路。简化消融用于判断旧WZZT候选生成器是否确有必要；核心描述变简单，不代表完整生成流程已变简单。

新联合方法只输出一次联合最优可行解及既定收缩结果；不加入旧整树择优回退。纯WZZT保持只在自身路径与单点回退中进行严格验证选择，另报其终点。共同0.24主响应阈值，0.16敏感性；未收缩终点也单列。测试观测与真拓扑不进入优化、调参或选择。

## 明确的总预算与计时

每个方法、每个输入总账上限**14,400秒（4小时）**，比上一轮单条300秒显著延长。纯WZZT单次MILP最多**3,600秒（1小时）**；联合MILP使用扣除生成器和预留时间后的剩余结构预算。相对MIP gap为0.0001，提前达到gap即可返回，不强迫耗满。

每个固定家族LP最多300秒，并受剩余总额约束。预留600秒给连续闭合、固定收缩和验证。若仍耗尽总额或LP未闭合，记录未完成／错误和已保存可行路径，不丢分母，不标成最优。

复用联合候选的计费为：共同前端记录耗时＋完整RNJ流程耗时＋稀疏WZZT流程耗时＋NJ记录的边际生成耗时，计一次；再加本轮建模、求解、重拟合、验证。记录**本轮新增墙钟耗时**和**累计记录总耗时**两列；后者是复用流程的累计成本，不冒充全新端到端重跑。纯WZZT和简单模型的前端、结构、后处理全部本轮实测。旧方法仍保留原300秒、双路径组合600秒名义预算，比较时明确预算差异。

共120×4＝480条新方法作业，8个单线程worker；总上限是逐方法逐输入上限，不是整批4小时。旧候选生成器由已核验记录复用，没有再次重跑。所有源文件、协议、观测、候选和父结果哈希冻结，所有失败／超时保留。

## 过拟合能判断到什么

这轮可检验：更多候选是否只改善训练损失；固定线路数惩罚是否帮助拓扑；简单RNJ＋NJ候选是否可替代复杂生成器；长时限是否改变求解状态。不能用同一120输入上反复设计方案后的最佳F1证明泛化。保留独立验证／测试和原24／其余84划分，但这些都是已多次研究的固定算例，未增加新的盲测数据。

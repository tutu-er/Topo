# Root and pseudo-aggregation diagnostics

## Test matrix

The large sweep uses all four paper-style feeders, scenario counts 1/3/5, 48/96/288 samples per scenario, raw and daily-demeaned fitting, and both NJ and RG. This gives 144 topology runs. Every time series is generated by radial AC power flow with 0.5% relative P/Q meter noise and 0.02% relative voltage-magnitude noise.

## Root result

NJ and RG reconstruct an unrooted latent tree. A root is not returned by either algorithm. For diagnosis, the diagonal sensitivity terms are retained as estimated root-to-terminal depths and the least-squares root point is located on the reconstructed weighted tree.

- Exact additive R/X distances: root terminal partition success is 100%.
- Noisy estimated R/X distances: root terminal partition success is 22.2% over 144 runs.
- The physical root can be a branching hidden node or a degree-2 point inside a latent edge. Flynn16 has a degree-2 root and reaches 88.9% root-partition success; the other three cases are 0% under the strict multiway root-partition metric.

Therefore the current NJ/RG output must not be described as correctly rooted. Rooting needs to be an explicit constrained stage that uses sensitivity diagonals; terminal-terminal distances alone cancel the root depth.

## Hidden topology and terminal region

| method | split precision | split recall | split F1 | sibling precision | sibling recall | sibling F1 | median terminal-limb relative error |
|---|---:|---:|---:|---:|---:|---:|---:|
| NJ | 0.434 | 0.936 | 0.592 | 0.972 | 0.304 | 0.459 | 0.261 |
| RG | 0.552 | 0.823 | 0.652 | 0.930 | 0.582 | 0.698 | 0.296 |

The apparent contradiction is important. Predicted terminal sibling relations have high precision, so high-confidence local relations are usually correct. Recall is low because noisy NJ/RG often split a true multifurcating terminal group with short artificial hidden edges. NJ is especially affected because its native output is binary. Thus individual terminals remain pendant leaves, but exact parent attachment and service-edge impedance are not generally recovered.

This is stricter than the earlier terminal-equivalent MST metric. A correct MST neighbor does not prove that two terminals share the same physical hidden parent. Under the hidden-tree metric, 86.1% of runs have a larger sibling-recall loss than internal-split-recall loss, although many of these errors are local short-edge over-resolutions rather than remote wrong attachments.

## Pseudo P/Q/V result

The proxy test uses every true downstream branch containing 2--5 terminals, giving 180 cluster tests.

| case | mean-V2 RMSE | drop-corrected V2 RMSE | mean dynamic error / parent std | corrected dynamic error / parent std | P aggregation relative RMSE | Q aggregation relative RMSE |
|---|---:|---:|---:|---:|---:|---:|
| paper15 | 0.01696 | 0.00030 | 0.2257 | 0.0195 | 0.0344 | 0.0610 |
| soumalas11 | 0.00857 | 0.00023 | 0.2237 | 0.0448 | 0.0198 | 0.0368 |
| flynn16 | 0.00595 | 0.00020 | 0.0829 | 0.0178 | 0.0165 | 0.0289 |
| pengwah18 | 0.01014 | 0.00022 | 0.2413 | 0.0345 | 0.0204 | 0.0361 |

Mean terminal squared voltage is systematically below the true boundary-node voltage squared. Its mean bias ranges from -0.00588 to -0.01681 p.u.-squared, and its dynamic error is 8%--24% of the true parent-voltage variation. This is much larger than the 0.02% voltage meter noise. Using the true subtree structure and a LinDistFlow drop correction reduces voltage-squared RMSE by 30--56 times.

P/Q summation is less problematic but is not exact: branch flow includes line losses, producing 1.7%--3.4% active-power and 2.9%--6.1% reactive-power relative RMSE after measurement noise.

The current aggregation decline is therefore mainly caused by an inconsistent pseudo voltage, followed by neglected branch losses and occasional wrong/stably over-resolved clusters. The next aggregation implementation should reconstruct boundary voltage with estimated subtree drops and should reject or contract short NJ/RG edges using uncertainty-aware thresholds.

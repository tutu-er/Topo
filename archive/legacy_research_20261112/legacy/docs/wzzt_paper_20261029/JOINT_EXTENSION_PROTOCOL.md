# 两步联合修正的十数据组补充对照

本扩展在主估计结果与原单bundle两步消融可用后提出，补足组件的独立重复；属于次要扩展，不替换原方案或追加主假设检验。代码、输入选择和求解预算在本扩展输出前冻结于 `joint_extension_freeze_receipt.json`。

固定四旧网络，全部十个独立数据bundle，电压噪声标准差0.05%/0.1%，N48/288，共160个匹配输入。原主批每个输入的扩池收缩前候选库、校准量和预选家族保持相同，独立比较：

1. `joint_control25`：原扩池上追加25秒单步修正。
2. `joint_width5`：25秒两步联合提案，宽度5。
3. `joint_width5_delete`：两步结果之后追加15秒、一轮验证保护后向删簇。

单步与两步使用各自新建的固定家族LP，无跨政策候选缓存或求解器基共享；原LP最优性和15秒上限、系数界[0,2]、3%验证简洁规则、最终0.16过滤均保留。不改算法、不调阈值，不用真实拓扑选输出。四工作进程，每个求解器一线程；单输入进程上限360秒。原基线库的训练预计算成本属于复用成本，补充记录不作端到端独立计时。

保留全部160个输入分母、失败、原生LP状态、路径和输出模型。结构F1、验证及独立测试误差在计算结束后复算。报告相对原ridge_union、相同追加预算单步控制和删除前模型的配对差值；置信区间按十个bundle均值重采样，作为次要描述性区间。该扩展与原主面板复用数据，不能当作全新确认数据。

# 四方法完整对照：冻结方案

用户授权完整测算四种方法；沿用上一轮四网络、108主＋12压力输入、300秒结构预算。独立目录保存，不改写旧结果和生产默认。

| 方法 | 本轮明确口径 |
|---|---|
| ordinary：普通RNJ＋WZZT | 沿用此前明确指定的近期全面实验完整RNJ初值；单候选逐步扩展、无预联合、无末端联合、无结构退出、保持原无线路数惩罚。不是生产默认bootstrap最多两个边界块配置。 |
| full_rnj_exit：完整RNJ＋联合修正＋退出 | 完整RNJ初值；预联合修正；必要时逐步WZZT；≤5块末端联合；compact退出；0.003 f0线路数惩罚。 |
| small3_coarse_exit：少量RNJ小块＋大块优先WZZT＋退出 | 至多两个互不相交、各≤3终端的训练筛选种子；最大直属区域优先，先要求覆盖半数直属块；末端联合；扩展退出池。 |
| small3_original_exit：少量RNJ小块＋原始WZZT步骤＋退出 | 相同small3种子；调用既有rnj_count.original_step，取消半数块和强制整块并限制；相同末端联合和扩展退出。 |

共同预算：总结构300秒、单次基础MILP30秒、固定家族LP30秒；三个扩展方法前缀180秒、剩余时间交退出，完整RNJ预修正最多60秒。普通方法没有退出，全部300秒可供原逐步搜索。共同前端和最终验证另计，worker硬限900秒。扩展方法使用已有RNJ／前缀最优可行解热启动。

共同观测、训练／验证／测试划分与前端；相同R/X响应权重[0,2]；不增加硬阻抗下界；不重新调参。small3、0.003惩罚、0.24主收缩及0.16敏感性沿用已冻结选择。普通方法保留原不加计数惩罚的定义，因此对照评估完整方法包，不能把差异只归因于联合步骤。

最终均使用同一个公共RNJ候选库＋各自路径＋单点回退，经相同收缩和训练LP重拟合，再按严格验证MAE选择。另报自身路径、退出前路径与未收缩终点；分别列出选模来源、基础WZZT参与率、末端／退出参与率、耗时和求解状态。重点指标为内部集合F1和完整恢复率，并报告各网络、噪声、N、大小块FP/FN以及逐输入配对胜负。

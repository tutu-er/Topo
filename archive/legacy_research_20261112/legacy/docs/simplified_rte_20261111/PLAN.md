# 简化RTE：实现与最小对照协议

用户同意减少超参数、使用简化的R/T/E结构。本任务新增隔离研究入口，保留原主线与生产默认；不覆盖旧结果，不重新生成观测。

检验两个问题：实现是否符合统一正则目标与可撤销层级约束；精简规则后的四网络固定小样本是否出现明显恢复退化。这个小样本不用于重新调alpha，也不证明全面性能优于旧版。

## 冻结设计

结构层沿用alpha=.003，所有阶段共用。bmax=5限制末端枚举计算规模。R只提供原RNJ和已提供暖启动族的连接，不做两个/三个终端小种子预选；W保持原始未知支持域；T枚举全部不超过五块的当前完整子树切面，汇总候选并统一重构；E使用R/路径/T候选和全部终端对，一次释放所有临时内部连接。T/E共用同一选择模型。

每个结构先QP闭合、允许范围内清理数值零块，再检查共同正则目标是否超过固定数值容差下降。取消相对改善门槛和输出.24收缩；没有新增正阻抗下界、ridge或RNJ整树最终备用。保留原验证MAE，另记录同库MSE；不把这次结构简化混入验证指标替换。

RNJ几何及参考误差继承历史冻结预处理，其参数仍披露。移除输出收缩是独立设计变化，并非计数正则与后收缩数学等价。有限T/E连接域没有全网络最优或唯一可识别性保证。

先用合成n3/n4示例、独立SciPy有界最小二乘与同域完整laminar族穷举，核对E最优值、错误交叉块替换、纯删块的拟合/正则权衡、硬先验/基底保护和大终端块的五直属块开层。核对全部有界切面、旧解可恢复及统一目标下降。

再对历史连续一天96点面板的四网络paper15、soumalas11、flynn16、pengwah18运行seed_index=0、voltage_sigma=.0005四输入。训练96、独立验证288，测试和真拓扑只由事后分析读取。alpha与数据域在新结果产生前固定，不按F1调参。

对照为同四输入已核验旧MIQP/T003记录；旧版与新版同时改变R初值、T邻域/控制、E候选规则、验收与输出映射，属于整体精简比较，不将差异归因单一模块。保留失败、超时及未证明最优状态。不得把四输入推广为48或120输入全面结论。

每输入总上限14400秒，扣除一次历史公共预处理成本，QP上限300秒，W单次MIQP上限3600秒，输出保留600秒；剩余结构预算半数供W/T，其余供E。T/E单次可用本阶段全部剩余时间。最多四单线程工作进程，名义总上限16方法小时，实际并行日历时间另报。

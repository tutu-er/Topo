# 联合方法退化原因与 LP 枚举优化：本轮结论

**问题同时来自搜索域、路径选择和统计目标。已修复全集响应项遗漏，完成合法层级 LP 枚举；目前没有找到获得留出支持的正下界数值。** 开发集选中的弱下界 0.04 在新留出上仍比无下界对照差，较强的量测投影下界在开发阶段就损害预测。当前建议保留零下界，将精确小邻域枚举作为补充，不把“系数更大”当成连接更可信。

数学解释见 [METHOD.md](METHOD.md)，全部表格、参数网格和图见 [RESULTS.md](RESULTS.md)，逐例核验及冻结代码见 [records.zip](records.zip)。本轮是四参考网络、两个新留出 bundle 的 16 个合成 AC 输入，不能覆盖或替代上一轮 108 输入的结论。

## 为什么联合方法会更差

1. **四块联合不是逐步换边域的超集。** 它只能组合完整块，逐步候选可能切开某个块或改动外围。旧 108 例中有 18 例联合终点的训练损失也更高。固定 16 个旧终点完整扫描后，有 3 个过门槛单步落在全部四块邻域外。
2. **其中有实际实现缺口。** 两个漏掉的单步是全集响应。旧实现排除全集候选，又在零权重时把它清掉，后续无法重新引入。修正后每个局部问题都保留可为零的全集响应系数，外围所有权重仍共同重拟合。全集不计入非平凡支撑 F1；这项修复保证域的完整性，不保证噪声下 F1 上升。
3. **局部 MILP gap 与接收门槛太接近。** 二者都是 0.1%，状态正常的近优解可能漏掉刚过门槛的改善。四块全部 26 个层级的 LP 枚举能消除该邻域的整数求解余量，但仍是局部搜索。
4. **更小训练残差不等于真拓扑。** 同一局部区域释放多个组合后，弱假连接也参与拟合。旧终点新增的 296 个假连接中，181 个低于归一化深度 0.16；新增真连接 62 个中，也有 11 个低于该值。强度有区分信息，但没有一个由这些样本推出的无误差分界线。

## 已实现并测试的方案

固定家族中，所有 R/X 权重仍由原始量测 L1 拟合。四块枚举 26 个合法层级，虚拟区域的整体连接可有可无时至多 52 个；每个区域一次扩充响应列矩阵，缓存固定家族 LP。已用独立同域 MILP 验证小例最优值一致。

| 方案 | 本轮设置 | 作用与边界 |
|---|---|---|
| 归一化有效深度下界 | 0、0.04、0.08、0.16 | 约束选中边的 `(a*r+b*x)/d`；最终重拟合也保留下界 |
| 实际响应投影下界 | 初始训练 MAE 的 0.5/1 倍 | 真正下界该项中心化响应 RMS；不保证它相对其他边不可替代 |
| 连接数惩罚 | 初始 MAE 的 0.1%/0.5% 每条内部连接 | 改变训练目标，显式权衡残差与连接数 |
| 先逐步后联合 | 共用 20 秒总预算 | 先找较好起点，再重构，保留两个阶段路径 |

没有对 R、X 分别随意设置正下界。Q=0 的反例已通过测试：模型可以增加不影响预测的 X 满足普通深度下界。若已知导线电抗电阻比上界，可以增加线性比值约束来阻止这种逃逸；本轮未使用真网络反推此先验。

## 参数选择与新留出结果

16 个开发输入上比较 11 个设置，共 176 次修正模型运行，全部返回。仅根据开发验证 MAE，按冻结规则选中：

- 联合法：深度下界 **0.04**、无连接数惩罚。它不是验证损失严格最小值；无下界的验证损失稍小，0.04 在预定 0.1% 容差内因连接数略少而被选中。
- 混合法：深度下界 **0.08**、连接数惩罚 **0.001×初始MAE**。
- 投影下界 0.5/1 明显损害开发验证预测，没有作为推荐设置进入留出测试。它们的幅值保证成立，当前阈值却过强。

随后在未参与此前局部法开发/测试的 bundle 5/6 上运行 112 个工作进程，全部返回。下表均使用同一个 RNJ 候选库加各自路径，收缩 0.16、收缩后训练重拟合、0% 验证带宽；参数没有按留出 F1 改选。

| 方法 | 留出平均 F1 | 完整恢复 | 搜索时间中位数 |
|---|---:|---:|---:|
| 池内逐步修正 | 0.7282 | 8/16 | 0.92 s |
| 原始逐步 MILP，完整池暖启动 | 0.7152 | 8/16 | 20.06 s |
| 旧局部联合 MILP | 0.7605 | 8/16 | 5.66 s |
| 修正域局部 MILP | 0.7512 | 8/16 | 5.14 s |
| **修正域 LP 枚举，无下界** | **0.7628** | 8/16 | 4.11 s |
| 开发选中下界 0.04 | 0.7452 | 8/16 | 6.08 s |
| 开发选中混合策略 | 0.7375 | 8/16 | 3.32 s |

无下界 LP 枚举相对同域修正 MILP 的中位搜索时间约少 20%，相对旧联合 MILP 的 F1 仅多 0.0024，逐例为 **1 胜、14 平、1 负**。本轮的逐步基线平均较低，与上一轮 108 例方向不同；只有两个 bundle，不能据此反转为“联合普遍更好”。时间为并发单线程搜索计时，不含前端和最终选模；完整成本估算另列。

## 下界为何反而丢掉了较好的结果

0.04 下界相对无下界为 **0 胜、15 平、1 负**，平均差来自一个 pengwah18 高噪声输入。该例 F1 从 **0.4000** 降到 **0.1176**，匹配真连接从 3 个降到 1 个，预测内部集合从 8 个增到 10 个。

事后交叉重拟合得到关键证据：无下界方法找到的较好家族，在施加 0.04 下界后，仍达到相同训练 MAE **0.002361624**、验证 MAE **0.002452139**；下界方法最终从公共库选中的家族为 **0.002440273 / 0.002493159**。因此这个退化主要表现为**较好家族没有进入最后的验证候选库**，而非它被 0.04 下界从整个参数域排除。

这说明硬下界会改变逐次局部最优和接收路径，不能只理解为“把弱假边删掉”。保留无下界基准路径、或保留多个训练近优局部家族，可能比继续抬高下界更有针对性。候选库扩充只能保证相同规则下的最小验证损失不劣，F1 仍须另验；两条搜索路径的成本也必须合并计算。本轮没有将此事后建议包装成已经获得新留出验证的方案。

连接数惩罚的混合方法将未收缩终点的平均内部集合数从无下界枚举的 10.69 减到 8.31，原始 F1 从 0.581 升到 0.619；最终选模 F1 却较低。因而只看原始终点或只看边数，都会遗漏最终结构恢复的取舍。

## 当前建议与验证边界

**优先采用搜索域修复和固定列/家族缓存；四块 LP 枚举可作为精确邻域求解器。下界默认保持 0，不把 0.04 推入正式默认流程。** 正下界应来自可信线路域先验，或获得更大独立留出支持；本轮未找到后者。若已知最小线路长度、导线参数及基准量，可换算成响应系数硬下界；没有这些条件，严格正物理下界无法由“阻抗应为正”推出。

模型机制与求解器相关测试 **75 passed**；32 个已冻结输出家族用 HiGHS 独立重解，保留相同下界，全部通过。原量纲目标、层状性、下界保持、搜索目标下降、原生界及源代码/参数/输入哈希核查均通过，详细计数保存在 verification.json。未修正根项前的 176 次完整开发结果另行保留，修正后在新目录重新冻结和校准，没有覆盖或按测试 F1 筛选结果。

# GTLS topology posterior: model, implementation, and results

## Scope

This experiment evaluates GTLS under the same measurement contract as the
current topology-identification pipeline:

- terminal P/Q/V measurements are always noisy;
- voltage and branch-flow states are generated by radial AC power flow;
- the root voltage varies and is used to form the measured squared-voltage drop;
- P/Q relative noise is 0.25%, 0.5%, or 1.0%;
- V relative noise is 0.01%, 0.02%, or 0.05%;
- candidate topology quality is measured by rooted hidden-clade F1.

The implementation is in
`terminal_case33/estimation/gtls.py` and
`terminal_case33/pipeline/gtls_topology_posterior.py`.

## 1. Separable GTLS point estimate

After removing one mean from every operating scenario, stack

\[
Y = [\Delta v_1,\ldots,\Delta v_n], \qquad
Z = [P,Q], \qquad Y \simeq ZB,
\]

where \(B=[R^\top,X^\top]^\top\). Let \(S_Z\) and \(S_Y\) be diagonal
column-noise scales. The separable GTLS approximation whitens the augmented
matrix

\[
W = [ZS_Z^{-1},\;YS_Y^{-1}].
\]

If the last \(n\) right singular vectors of \(W\) are partitioned as

\[
V_2 = \begin{bmatrix}V_{Z2}\\V_{Y2}\end{bmatrix},
\]

the multiresponse TLS solution is

\[
\widehat B_w=-V_{Z2}V_{Y2}^{\dagger},\qquad
\widehat B=S_Z^{-1}\widehat B_wS_Y.
\]

This SVD solution is global for the separable, column-homoscedastic GTLS
approximation. It is not the exact solution for sample-dependent relative
meter variance, AC-model mismatch, or constrained additive trees.

Pure SVD-GTLS is unstable in the present feeders: P/Q noise is small, while
the linear-model error and correlated excitation are large enough to rotate
the estimated response noise subspace. A regularized estimate is therefore
used for candidate generation,

\[
\widehat B_{\lambda}
=(1-\lambda)\widehat B_{\rm GTLS}+\lambda\widehat B_{\rm OLS},
\]

with \(\lambda=0.99\) in the reported sweep. This value is intentionally
conservative: the global GTLS matrix is used only to diversify RNJ candidates,
not as the final branch-parameter estimate.

## 2. Candidate-tree structured GTLS

For a fixed rooted candidate tree \(T\), let \(A_T\in\{0,1\}^{n\times m}\)
be the terminal-to-edge path-incidence matrix. Exact tree additivity and
nonnegative branch impedances are imposed directly:

\[
R_T=A_T\operatorname{diag}(r)A_T^\top,\qquad
X_T=A_T\operatorname{diag}(x)A_T^\top,\qquad r,x\ge 0.
\]

For terminal \(i\) at time \(t\), the EIV residual variance is approximated by

\[
s_{ti}^2 = \sigma_{v^2,ti}^2
+\sum_j R_{T,ij}^2\sigma_{P,tj}^2
+\sum_j X_{T,ij}^2\sigma_{Q,tj}^2
+\sigma_{\rm model,i}^2.
\]

The model floor \(\sigma_{\rm model,i}^2\) is estimated once from the ordered
OLS fit after subtracting propagated meter variance. For each candidate, the
code alternates between:

1. computing \(s_{ti}^2\) from the current tree matrices;
2. solving a nonnegative weighted least-squares problem for \((r,x)\);
3. damping the update and repeating until convergence.

For fixed weights, step 2 is a convex NNLS problem. The complete
sample-dependent likelihood is not globally convex because the variance also
depends on \((r,x)\); the implementation is therefore a structured-GTLS IRLS
approximation with an auditable convex subproblem at every iteration.

## 3. Finite topology posterior

RNJ candidates are generated from both ordered OLS and regularized GTLS R/X
matrices and deduplicated by rooted clades. Each candidate is fit on training
scenarios and scored on held-out scenarios by

\[
\ell_T = \frac{1}{2N}\sum_{t,i}
\left[\log s_{ti}^2+\frac{e_{ti}^2}{s_{ti}^2}\right]
+\frac{w_k k_T\log N_{\rm eff}}{2N_{\rm eff}}
+w_M\varepsilon_T^2.
\]

The reported configuration uses \(w_k=0.25\), \(w_M=0\), and counts one
effective independent block per 12 samples. The finite-candidate generalized
posterior is

\[
\pi(T\mid\mathcal D)=
\frac{\exp[-N_{\rm eff}(\ell_T-\ell_{\min})/\tau]}
{\sum_{T'}\exp[-N_{\rm eff}(\ell_{T'}-\ell_{\min})/\tau]},
\qquad \tau=1.
\]

This is a tempered generalized posterior over the generated candidate set,
not a fully calibrated Bayesian posterior over all latent trees. The code also
reports clade marginals

\[
\pi(C\mid\mathcal D)=\sum_T\pi(T\mid\mathcal D)\mathbf 1\{C\in T\}
\]

and a laminar 0.5-threshold consensus. The MAP tree remains the default output.

## 4. Combined results

The combined report contains 44 unique noisy AC conditions: all four feeders,
two random trials for the main sparse/medium tests, three noise levels for
sparse and medium data, and nominal rich-data tests.

| method | mean F1 | minimum F1 | exact rate |
|---|---:|---:|---:|
| structured GTLS posterior, OLS+GTLS candidates | 0.9967 | 0.9231 | 95.45% |
| structured EIV posterior, OLS candidates only | 0.9950 | 0.9231 | 93.18% |
| AC + quartet validation | 0.9947 | 0.8571 | 95.45% |
| AC+BIC candidate reranking | 0.9904 | 0.8000 | 90.91% |
| fixed OLS-RNJ | 0.9678 | 0.5455 | 84.09% |
| fixed regularized-GTLS RNJ | 0.9288 | 0.0000 | 77.27% |

Per feeder, the structured GTLS posterior obtained mean F1 values of 0.9930
for paper15, 1.0000 for soumalas11, 1.0000 for flynn16, and 0.9939 for
pengwah18.

The gain over the fixed OLS-RNJ setting is concentrated in sparse data. Under
sparse nominal conditions, mean F1 increased from 0.9057 to 1.0000. Under
sparse high noise, it increased from 0.9183 to 0.9641.

## 5. What GTLS actually contributed

The ablation does not support the claim that an unconstrained global GTLS R/X
matrix is superior:

- pure SVD-GTLS generated very poor fixed RNJ trees in the four medium nominal
  cases, while the structured candidate posterior still recovered all four by
  retaining OLS candidates;
- with 0.99 shrinkage, the fixed GTLS and fixed OLS candidates are usually the
  same;
- among the 44 conditions, only
  `paper15__sparse__nominal__trial1` required a GTLS-only candidate to change
  the result from F1 0.9231 to exact recovery;
- in all other improvements, the important component was candidate-tree
  structured EIV fitting and held-out posterior ranking, not the dense GTLS
  point estimate.

Two sparse high-noise trial-1 conditions did not contain the exact tree in
either the OLS or GTLS RNJ candidate set. Their MAP F1 values were 0.9231 and
0.9333. AC+quartet contraction recovered both exactly. The 0.5 clade-marginal
consensus did not repair them and reduced paper15 to F1 0.8571, so posterior
consensus is retained as a diagnostic rather than the recommended topology.

## 6. Recommended use

Use the structured GTLS posterior as a finite-candidate uncertainty and
reranking layer. Keep AC+quartet validation as a complementary repair step
when candidate coverage is weak. Do not replace the ordered OLS estimator by
pure dense GTLS under the current 0.25%-1% P/Q noise range.

Run a sweep:

```powershell
python -m experiments.run_gtls_topology_posterior_sweep `
  --data-regimes sparse medium rich `
  --noise-regimes low nominal high `
  --trials 2
```

Combine completed runs without resimulation:

```powershell
python -m experiments.summarize_gtls_topology_posterior `
  --inputs outputs/run_a outputs/run_b `
  --output outputs/gtls_structured_combined
```

The main tables are `metrics.csv`, `candidate_posterior.csv`,
`summary_by_method.csv`, `summary_by_case.csv`, and `summary_by_regime.csv`.

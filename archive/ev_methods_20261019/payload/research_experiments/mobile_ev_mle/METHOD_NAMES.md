# EV方法统一名称

2026-10-17。名称区分规划目标、动作权限和最终推断。旧文件、旧键和旧结果保持原样；本表给出显示名称，避免继续用A/B或G11混指不同环节。

| 显示名 | 中文名 | 规划目标/含义 | 旧名称或键 |
|---|---|---|---|
| OBS | 同长度被动观测 | EV功率为零；只匹配观测预算，不承担充电任务 | none/noEV |
| CC | 恒充 | 在预定初始接入点完成电池任务 | constant |
| HL | 预设高低充电 | 前半高功率、后半零功率；任务与CC相同 | highlow |
| P-LIN | 精度线性MILP | 最大化方差倒数加权净功率；保留为历史对照 | quality/linear precision |
| P-SQ | 精度平方MILP | 最大化归一化电压方差倒数加权功率平方；强基线 | square/SQMD |
| G-SQ | 拓扑加权平方MILP | 最大化各候选对最小的、灵敏度差异与计量精度加权功率平方 | 本轮新增 g_square |
| G-AQ | 拓扑仿射距离MILP | 同G-SQ，但保留背景差异、线性项和各候选对常数 | 本轮新增 g_affine |
| AC-GRAD | 固定线路AC梯度MILP | 固定训练线路，竞争源可调，以完整AC距离梯度提案 | gradac |
| JP-GRAD | 联合拟合优势梯度MILP | 竞争者共享线路解释历史和假想未来，以联合优势价格提案 | joint_margin/部分旧B |
| B-RISK | 贝叶斯预测风险MILP | 以声明预测分布的风险代理规划；模型校准单列 | BC/BCMD |

动作权限后缀：F+固定点纯充电，F±固定点双向，M+允许移动纯充电，M±允许移动双向。允许移动不要求一定移动。

推断后缀与规划独立：FIX固定历史训练R/X、估计当期源；JNT历史与新增计量共享一组R/X并联合拟合逐时源P/Q。例：`G-SQ/M± + JNT`。

“平方”“距离”“风险”“联合拟合”不互换。拟合值是局部取得值；规划分数及似然差不作为拓扑正确概率。

# 竞争重拟合的交叉项诊断

日期：2026-10-14。本项是在首个开发结果出现后增加的事后诊断。读取已保存的9个986101条件、每条件3条曲线×2个有向候选对，共54行；这些行共享基础历史，不是54个独立统计样本。不增加拟合、优化或选曲线。

## 分解的含义

令m(theta,w)是竞争拓扑的白化AC计量均值。theta包括全部线路R/X，w包括逐时真实总P/Q和同一接口的源P/Q。theta0、w0是保存代理的展开点；theta1、w1是已经保存的完整AC联合重拟合见证。未来w0中已包含原展开曲线3kW，未重复加入EV。

定义四角m00=m(theta0,w0)、m10=m(theta1,w0)、m01=m(theta0,w1)、m11=m(theta1,w1)，并使用保存的展开点导数Jtheta、Jw。严格恒等式为

    R = m11-m00-Jtheta*(theta1-theta0)-Jw*(w1-w0)
      = Rtheta + Rstate + Rcross,
    Rtheta = m10-m00-Jtheta*(theta1-theta0),
    Rstate = m01-m00-Jw*(w1-w0),
    Rcross = m11-m10-m01+m00.

前三项分别反映单独改变线路、单独改变逐时状态、二者同时变化的影响。各项是向量，可能互相抵消，不能把其范数当成可加的百分比贡献。历史与未来分别分解。m与残差均除以对应计量标准差，因此所列范数无量纲。

额外独立核对整个目标：r_AC=r_linear+[R_history, source_forward_error-R_future]。同一非线性见证处的线性成本与完整AC成本的差，反映目标近似误差；比较两个不同优化点的成本则会混入优化误差。

profile MILP曲线中，固定源侧参数的响应近似误差仅占激励响应范数的0.347%（中位数），但同一竞争AC见证处的线性成本中位数611.613、完整AC成本中位数269.565。恒充相应数值92.641与92.832接近。这定位到一个具体问题：大幅改变EV功率时，竞争线路重新调整的影响没有被冻结导数充分表达。

首条件R=0.0003、拟合floor=1e-6，方向clade12→clade02，profile曲线约(0,6,6,0)kW：实际竞争AC成本25.443，同一见证的线性成本390.699，而已保存有界线性QP最优成本376.641。该见证本身符合原参数边界。四角未来交叉项范数19.089，纯线路余项0.0199，纯状态余项3.9753。因而仅进一步求准这个冻结QP或MILP，无法消除此例的竞争解释差异。

## 对下一步的含义

应优先保留竞争线路与功率变化的乘积，或在动作变化后重新计算竞争线路响应，再检查上下界所属的代理。LinDistFlow形式V≈RP+XQ也含有deltaR*deltaP和deltaX*deltaQ，电压对固定参数P/Q近似线性并不足以保证联合重拟合准确。该诊断支持这一机制在当前保存例子中实际出现；它还没有验证新的曲线策略，也没有完成独立校准。

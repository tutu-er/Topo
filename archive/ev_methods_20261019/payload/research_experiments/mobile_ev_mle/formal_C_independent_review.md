# 冻结 C 评价独立审查

**结论：C 的保存证据、冻结门限与后处理计数内部一致。refit MILP 相对 constant 的唯一正确保留增加 9/256，但这种增益全部集中于 strong cherry；star 与 weak cherry 基本没有被唯一识别。现有模型距离代理对实际 signed margin 的关联较弱，不能据此宣称普遍可识别、全局 MLE 或拓扑正确概率。**

本审查只读既有 C 数据与源码，以独立标准库计算复核计数、门限、区间及成分误差；未调用优化器、仿真器或项目后处理程序，未改变策略、阈值、collector、empirical 或正式源码。所述频率和区间均针对冻结模拟总体与固定数值策略，不是单次历史的拓扑正确概率。输入根目录为 `C:\Users\23761\.codex\worktrees\36a1\Topo\research_experiments\mobile_ev_mle\outputs\adaptive_milp`。数字与输入哈希保存在同目录交付文件 `formal_C_independent_numbers.json`。

- 评价为 256 条独立生成器历史，7 方法、1 轮、4 候选；1,792 个方法记录和 7,168 个候选拟合。方法与候选都是同一历史上的配对观测，不能作为 1,792 或 7,168 个独立样本。
- 校准 128 历史和评价 256 历史 ID 无重叠；校准 manifest 的 257 条配置/JSON/NPZ 哈希、评价 manifest 的 513 条均匹配。15 个冻结核心源码哈希与 3 个后处理源码哈希均匹配当前文件。独立重算所有 1,792 个联合拒绝 mask，与保存门限记录无差异。
- AC 重放 status 为 **verified 7,168，unavailable/mismatch/not_requested 均 0**。最大 loss 重放差为 1.819×10⁻¹²，loglik 差为 9.095×10⁻¹³；最大 AC 方程残差 7.537×10⁻¹⁵，功率平衡残差 3.770×10⁻¹⁵。
- 优化器 success 为 7,166 true、2 false：均在历史 730180 的 random_action，候选 clade_01 与 clade_02。其保存状态仍可通过 AC 重放。**重放验证目标评价，不验证优化收敛或最优性；7,168 个全局最优证书均为 false。**因此 random_action 有 1 个历史级拟合失败，不能把失败候选从分母删除。

## 3. 整体误拒与冻结校准

每条校准历史的 score 是 **7 方法/所有声明轮次的真候选 relative gap 最大值和 absolute loss 最大值**。两个门限分别使用 α=0.05；128 个样本的第 123 个顺序统计量为 relative=8.610311359932325、absolute=75.77255697515467。独立重算精确一致。一个校准计算失败以 +∞ 留在两组 score 中；完整校准历史为 127、总分母仍是 128。

统计对象应为 `该历史至少一个冻结方法误拒真候选`，不能逐方法重复当作独立历史。该 **all-methods union false rejection=14/256=5.46875%**，95% CP 区间 [3.02172%, 9.00548%]。冻结 nominal total=0.1；顺序统计量尾界合计为 12/129=0.0930233。观察值及区间与该口径相容。这个评价结果不是对每一历史或任意参数的保证。顺序统计量尾界同时对校准样本随机性和新历史取边际，不能理解为给定这套已观察校准样本后的条件保证。

校准有效范围是事先固定策略、同一声明模拟总体、独立/可交换历史下的边际门限，覆盖七方法联合事件。校准集外参数、改动后的策略、现场误差分布、按历史条件化或连续参数域统一保证均未由 C 证明。该边际门限控制与比较七方法效率的多重检验是不同问题。

## 4. 分层与配对结论

独立分层计数为 **star=65、weak cherry=102、strong cherry=89**。唯一正确保留如下：

| 方法 | star | weak cherry | strong cherry |
|---|---:|---:|---:|
| none | 0/65 | 0/102 | 19/89 |
| constant_fixed | 0/65 | 0/102 | 62/89 |
| fixed_pulse | 0/65 | 0/102 | 61/89 |
| random_action | 0/65 | 1/102 | 69/89 |
| legacy_library_proxy | 0/65 | 0/102 | 81/89 |
| fixed_mle_milp | 0/65 | 0/102 | 68/89 |
| refit_milp | 0/65 | 0/102 | 71/89 |

refit 对 star、weak 均为 0 次唯一正确保留；未决分别 62/65 与 100/102。random_action 在 weak 的唯一一次保留发生于 730121（真候选 clade_12）：真 loss=74.98535、三个错误候选约 78.185，absolute 门限 75.77256 恰好区分，relative gap 约 3.2 低于 8.61031，因此 relative gate 仍全保留。这是该冻结样本中的绝对门限边界事件，不能据 1/102 宣称弱支路稳定分离。这是本次外推的主要限制。不能用 strong 层的结果代表弱内部分支可识别。分层为描述性；原冻结总体的边际风险预算没有自动变成每层风险预算。

refit 对 constant 的唯一正确保留配对表为：两者均成功 62、refit 单独成功 9、constant 单独成功 0、两者均未成功 185。效果差 **9/256=3.515625 个百分点**；配对标准误为 1.15335 个百分点。按两个 discordance 概率各自的 97.5% CP 区间作 Bonferroni 差分，得到保守配对 95% 区间 **[−0.26212, 7.04877] 个百分点**。该区间包含 0。

双侧 exact McNemar p=0.00390625，依据的是 9 个 discordance 全部同向。它检验两方向 discordance 概率相等；保守差分区间较宽，因此 p 值较小与该区间跨 0 并不矛盾。不得把这个 p 值写成算法正确的概率。若唯一终点的比较族是预先指定 constant 的其余 6 方法，简单 Bonferroni 调整为 0.0234375；若事后比较七方法所有 21 对则为 0.08203125。更多终点、分层和挑选胜出方法会扩大比较族；现有报告未提供覆盖这些选择的统一比较结论。

**字段语义修正：collector 的 `improved` 永远表示事件 0→1，`worsened` 表示 1→0。** 对唯一正确保留，0→1 是收益；对 false_rejection、unresolved、fit_failure，0→1 是坏事件增加。refit 对 constant 的 false_rejection `improved=2,worsened=0` 实际是 **新增 2 次误拒、消除 0 次误拒**，不是误拒改善。误拒频率差 +0.78125 个百分点，保守配对区间 [−1.63178, 3.13505] 个百分点，McNemar p=0.5；既无改善证据，也不能据此断言真实增加。

## 5. 代理距离与实际辨别裕量

实际 signed margin 定义为 `最小错误候选的拟合 full-AC loss − 真候选的拟合 full-AC loss`；正值表示真候选严格优于错误候选。signed half-loglik margin 是它的一半。这里都是保存的局部数值拟合，不是全局 MLE 距离。

refit 的原始共同 refit-QP 代理与实际 margin 的 Spearman ρ=0.12801，历史 bootstrap 95% 区间 [0.00839, 0.25264]。相对 constant 的代理增益与 margin 增益 ρ=0.14712，[0.00526, 0.26416]；相对 none 为 0.27231，[0.14828, 0.38647]。每历史跨方法增益排序的平均相关分别为 0.14964（constant 基准）与 0.12232（none 基准）。这些是保存数据的描述性相关，不是因果效应或未来预测验证。

refit 对 constant 的实际 margin 增益中位数 0.24750，均值 227.33218；代理增益中位数 1.49672，均值 105.08837。均值与中位数差距很大，混合层和长尾主导平均值。refit 自身实际 margin 中位数为 −0.02241，即该方法的典型历史尚无正的真/错排序裕量。

refit active rollback witness 的未来项占总 witness cost 的中位数仅 **3.134405×10⁻⁷**，可用 254/256 历史，bootstrap 中位数区间 [2.18639×10⁻⁷,5.27940×10⁻⁷]；均值 0.10659。说明该活动见证在典型历史中主要由历史代价占据，不能把整个代理目标叫作新增未来信息。该比例只针对记录的活动 pair/见证；未覆盖全部 pair 的非线性下确界，实际 rollback 代价只给相应非线性下确界的可行上界。固定 MLE 自己的判据另有口径，不能直接混作共同 refit 代理增益。

## 8. 可成立的最终判断

C 支持“冻结总体中 refit 相对 constant 的 strong-cherry 唯一正确保留有配对收益，同时总体联合误拒与冻结风险口径相容”。它不支持“refit 普遍优于全部方法”“弱内部分支已可识别”“代理距离增益等于未来辨别收益”“保存拟合为全局 MLE”或“给出单次拓扑正确概率”。本审查不据评价结果反馈策略或重新校准门限。

## 1. 中心化实际诊断：支持什么，哪些数字需要改写

诊断包含两条独立历史、每条 24 个冻结竞争 pair、七个已保存动作。共同常数分别为 13.3138308146 和 15.6493838038；记录的原目标恢复防护范围分别约 ±1.76362e−4 和 ±1.68835e−4。14 条记录的报告误差都在这些范围内，恢复区间都与原区间相交，未发现与共同常数推导冲突的数字。

**不能写“所有 pointwise upper 身份误差约 1e−13”。** JSON 中的最大报告误差为 9.19687e−7；具体非机器精度级记录如下。

这些数值是优化所得上界的比较，并不自动等于“同一 u、同一 z 的两次残差代入”。JSON 未保存用于该字段的共同 z 及两份残差；因此单看本文件不能独立核实该字段是逐点代数恒等误差，还是不同 QP 可行见证的数值差。后一种解释与现有数字一致，但仍是推断。

这些宽度由固定动作 min-pair 分数的上下界相减得到；JSON 未逐 pair 保存对偶见证，不能把它们逐个解释成某一个指定 QP 的 gap。
共同中心化仍有原始判据相同的实数推导；本诊断显示部分内层下界更紧，部分基本不变。下界变紧应解释为数值求解/最优性核验精度改善，不是新信息、EV 辨识能力增加或判据改进。中心化还要把约 1.7e−4 防护加回原界；不能只显示非常小的 centered gap 而隐藏恢复误差。
原 `original_order` 只是 primal 上界排序。多组分差小于原 QP gap 和恢复防护，不足以证明严格动作优劣；无需据此说共同中心化“改变了真实排序”。

pairwise 消融的数值更小、排序不同，正符合其减去各 pair 不同历史成本、改变判据的含义。它不能作为与原策略等价的实现优化。本 JSON 的 flags 声明实际 AC likelihood 未中心化，但没有保存逐候选实际 AC 损失的双重对照；本复核仅确认冻结范数诊断，不额外声称非线性成本或新计量信息已被独立验证。

## 2. 未来预测模型：实质缺口与修订

原文 Gaussian 异协方差 KL 公式、同接口源导数、EV 加一次以及 proper EIG 定义均正确。需要以下实质补充。

1. 总 P/Q 计量不能逐时分别估计 base load 与 EV tracking：p_total=l+(u+ν)/S，在域允许的范围内 l'=l+δ/S、ν'=ν−δ 产生完全相同的 AC 均值。H 未执行 EV 时，固定其他参数的历史似然对共享增益 g 没有直接信息；Ω_g/Ω_e 需设备测量/校准、明确先验或经独立验证的背景预测约束，不能称 H 已识别 tracking。
2. 原 Γ 只传播未来状态和追踪误差，对一个固定 β 展开点成立。若用于 full predictive uncertainty，还须包括历史/未来共享 β、预测参数不确定性及交叉协方差。修订使用明确的堆叠 U(u)g 和 K=[J_β,L,D U(u),D]，并说明其局部 Gaussian 近似条件。
3. 常数基线本身不足以推出任意时段置换对称；需 root、协方差和解释域也满足同一置换，旧历史保持原顺序。常数效率本身不必打破对称，SOC/移动/时变约束才可能如此。
4. 4H 的有限 fixed-atom 拒绝属于该参数/过程先验表示的诊断，不是零 Gaussian 观测密度或正确拓扑已知。MC EIG 的正确性还依赖完整 proper 模型及积分精度；很低的 posterior entropy 可能是错误表示造成的饱和。

修订文本同时明确：这套随机预测尚未实施；现场只靠总计量不能直接验证 base/source/tracking 分解误差。

## 3. 控制梯度：证明基本正确，需收紧一个公式的范围

固定有限盒下 q=min_z ||d+Eu+Dz||² 等于闭凸集的平方距离，即使 z 非唯一，最优 Dz 和残差唯一，q 全域可微且梯度 2Eᵀr*，原证明成立。
活动面上的 Π_f 公式仅在面及其自由解在邻域保持时成立。原零残差后的二次等式必须显式继承这一条件，否则在活动面切换点不成立：q(u)=dist²(−u,[−1,1]) 在 u=1 梯度为零，但左右两侧分别为 0 与 (u−1)²，不能用一个局部固定 Π 描述整个邻域。
两时段共享 z 例子的 q=(u₀−u₁)²/2、脉冲分数 18 正确；若改为逐时独立 z_t，在该标量例子中 q 全零。这不是完整同点 AC 源能抵消全部计量通道的定理。
MLE 参数坐标不可直接比较、全方向最小奇异值过强和 min-pair 目标的解释正确；修订补出并列活动 pair 的方向导数为 min_{k active} ∇q_kᵀv，避免把一对的梯度称为全目标梯度。

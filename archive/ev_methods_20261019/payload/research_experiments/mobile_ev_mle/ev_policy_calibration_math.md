# 完整 EV 策略的独立校准与评价

日期：2026-10-15。实现为 `ev_policy_calibration.py`。本文件规定统计层，不运行AC拟合、MILP或新策略。当前验证是39项单元测试及一条旧保存trial的接口检查；新策略尚无已完成的36H校准结果。

## 1. 要控制什么

一次独立试验包括一段历史、策略根据历史安排的动作、新增计量以及全部竞争拟合。这个完整历史试验是一个统计单位。同一历史下重复未来噪声、比较多条曲线或多个方法，仍属于同一个单位。

- \(C\)：预声明的有限候选集合；当前为star及三种cherry。
- \(a\in C\)：正在检验的候选；\(a_*\)表示仅用于离线校准/评价的真候选。
- \(m\)：在校准前确定的方法；单策略时只有一个\(m\)。
- \(J_m(a)\)：该策略实际执行动作后，历史与新增计量共同拟合得到的白化误差平方和，使用完整SSE，不除以2。
- \(s\)：预声明的模拟条件层，例如`declared_asset_reference`；其含义属于模拟生成协议。
- \(\alpha\in(0,1)\)：目标误拒水平。

候选的拒绝统计量为

\[
 T_m(a)=J_m(a)-\min_{b\in C}J_m(b)\ge0,
 \qquad K_m=\{a:T_m(a)\le\tau_m(a)\}.
 \tag{1}
\]

直觉是：一个候选的最佳取得误差比当前最小误差大多少。阈值按“被检验候选\(a\)”确定；应用时对每个\(a\)分别使用其阈值，不查新试验的真拓扑。等号保留。

这里的\(J\)允许由固定预算的局部AC拟合取得。统计校准覆盖的是这套完整算法的重复运行，包括其优化误差；因此无需Wilks近似，也不宣称这些值为全局MLE。若使用半SSE，全部分数和阈值须同时除以2。

## 2. 失败分支与完整分母

操作、物理或必要拟合失败时，实际决策保留全部预声明候选\(C\)。对应的**决策分数**定义为0：

\[
 T_m^{\rm safe}(a)=
 \begin{cases}T_m(a),&\text{完整计算有效},\\0,&\text{失败且输出 }K_m=C.\end{cases}
 \tag{2}
\]

原始损失和失败原因继续保存，式(2)只编码保留规则。对非负阈值，逐个试验都有

\[
 \mathbf1\{a_*\notin K_m\}
 =\mathbf1\{T_m^{\rm safe}(a_*)>\tau_m(a_*)\},\quad a_*\in C.
 \tag{3}
\]

有效计算时直接由式(1)成立；失败时两边都为0。这解释了为何失败可以保留在校准分母中，同时必须报告未决率和失败率。设计失败后成功执行恒充回退，且全部联合拟合有效，则按回退的实际\(J\)计算，不记零。

候选漏真与计算失败分开。真结构不在\(C\)内时，“保留全部\(C\)”仍没有覆盖真结构。实现发现校准覆盖问题或未声明的模拟层时，关闭拒绝并标记全局未决；评价单列候选漏真和域外历史，不能沿用下面的条件覆盖结论。

## 3. 候选零假设下的有限样本阈值

固定候选\(a\)、条件层\(s\)及方法\(m\)。从声明模拟分布中生成\(n\)个真候选为\(a\)的独立校准历史，得到分数\(S_1,\ldots,S_n\)。策略、候选规则、拟合预算、失败与回退规则在这些数据之前冻结。假设这些分数与下一条同层、同真候选的分数\(S_{n+1}\)可交换。独立同分布足以满足该条件。

排序为\(S_{(1)}\le\cdots\le S_{(n)}\)。定义

\[
 k=\left\lceil(n+1)(1-\alpha)\right\rceil,\qquad
 \boxed{\tau_{s,m}(a)=
 \begin{cases}S_{(k)},&k\le n,\\+\infty,&k=n+1.\end{cases}}
 \tag{4}
\]

实现用十进制有理数计算\(k\)，避免`.1`的浮点误差改变整数排序；不对相邻分数插值。

**推导。** 对相同分数附加独立连续随机数，只用来分析并列名次。可交换性使新分数在\(n+1\)个分数中的随机名次均匀。新分数严格超过前\(n\)项的第\(k\)个排序值时，其随机名次必大于\(k\)。因此

\[
 \Pr\{S_{n+1}>\tau_{s,m}(a)\}
 \le {n+1-k\over n+1}\le\alpha.
 \tag{5}
\]

并列值采用“严格大于才拒绝”，只会减少拒绝。\(k=n+1\)时阈值为无穷，对该候选不拒绝，式(5)也成立。

当前协议计划每真候选9个历史、\(\alpha=.1\)，于是\(k=9\)，阈值是这9个分数的最大值。每候选仅0至8个已完成历史时，其阈值为无穷。未执行的计划历史不计作0分，不增加\(n\)。9个分数中有计算失败时，该失败仍是已经执行的历史，按实际保留决策计0分。

式(5)的概率同时平均了随机校准数据和下一条历史。它不是“这一次固定阈值的条件风险以95%概率小于.1”。例如连续分布且阈值取9个分数的最大值，固定阈值的真实尾概率超过.1的校准集概率可达\(.9^9\approx.3874\)。若另需95%置信的90%内容容忍界，最大值方案至少要\(\lceil\log(.05)/\log(.9)\rceil=29\)个同层同候选历史；该目标未混入本模块。

## 4. 多条件层与多方法

若运行时的条件层无法从公开条件确认，使用

\[
 \tau_m(a)=\max_{s\in\mathcal S}\tau_{s,m}(a).
 \tag{6}
\]

在任意已声明层\(s\)，超过式(6)的事件包含在超过本层阈值的事件中，故式(5)仍给出上界。缺少一个必要单元时，其阈值为无穷，这一保守结果保留。只有明确声明层在决策前可观测，才允许使用本层阈值；不能用真实线路或未来噪声选择更低阈值。

单策略模式分别校准\(T_m^{\rm safe}(a_*)\)。若要控制预声明多个方法中“至少一个误拒”，先对同一历史取

\[
 S=\max_{m\in\mathcal M}T_m^{\rm safe}(a_*),
 \tag{7}
\]

再按式(4)校准共同阈值。式(3)变为“至少一个方法误拒”的指示量等于\(\mathbf1\{S>\tau\}\)。这里不要求多个方法独立。`familywise=False`时只提供逐方法保证；输出中的“任一方法误拒”只是实测计数，不自动享有同一\(\alpha\)保证。

## 5. 实现接口与冻结身份

```python
spec = spec_from_freeze(
    freeze, reference_id='declared_asset_reference_v1',
    candidates=('star', 'clade_01', 'clade_02', 'clade_12'),
    methods=('refined_v2g_mobile',), alpha=.1, familywise=False)
cal_records = [adapt_saved_trial(t, freeze, spec) for t in saved_calibration_trials]
calibration = calibrate(cal_records, spec,
    expected_history_ids=completed_calibration_ids,
    planned_history_ids=range(989301, 989337))
result = evaluate(saved_evaluation_records, calibration,
    expected_history_ids=completed_evaluation_ids)
```

新策略的`policy_config`应保存完整字典：`config,prediction,master_form,domain,source_sha256`。内部与外部源码hash必须一致；若重复保存config或模式，其内容也须一致。模块核验这个完整字典的policy ID，明确支持紧凑JSON编码及当前driver的`json.dumps(sort_keys=True)`编码。配置hash另外覆盖四个非源码字段。旧记录只有config+source时按旧格式读取，不将其当新策略证据。

v2收集器另报告两主策略`refined_v2g_mobile,capped_v2g_mobile`的式(7)共同阈值；单方法阈值与这项多方法控制分别保存。11方法的逐方法结果也分别保留，不把其“任一误拒”计数套用两主策略的保证。

`CalibrationSpec`固定方法、候选、模拟域、层规则、\(\alpha\)及是否多方法最大值。它与阈值一起进入`calibration_id`。实际运行前需保存该声明；函数无法仅从事后字典证明其冻结时点。校准完成后改目标cap、预测情景、求解时间、初值、回退或失败判断，均须重新校准相应策略。

`history_id`与`independent_unit_id`均检查重复和校准/评价交集；同一历史下的多个方法保存在一个record中。`expected_history_ids`检查实际完成文件是否齐全；`planned_history_ids`只报告待完成数量。声明分布内的可交换性和独立性由生成协议保证，ID检查是必要的数据完整性检查。

## 6. 新策略证据的独立复算清单

1. **完整AC。** 复用保存的逐候选线路、P/Q与源，重新前推AC并白化P/Q/V/root通道；重算全部SSE、半SSE、对数似然、排序和真实裕量。只重放保存状态，不重优化。历史与未来逐边R/X相同、源接口相同、EV只进入总P一次。
2. **操作。** 用保存的完整路径变量检查每条网络流、接入窗口、旅行/接线、充放电互斥、功率、SOC、效率、驾驶消耗、throughput及终端能量；`capped_v2g_mobile`采用同一v2g移动物理域。不能只看控制功率或求解器success。
3. **继承。** 对所有实际可行继承计划，用同一H-only预测规则复算选择分数。大域最终选择分数应不小于其被保留的可行子域计划。该比较用于预测选择，不代替未来真实排错结果。
4. **预测。** 每个互斥未来情景单独与同一历史共同拟合，保存每个情景的全部状态并复算分数。情景平均、解释平均与任务cap的先后顺序按冻结定义核查，不能把不同未来情景堆成同时观测。
5. **QP及MILP。** 从冻结源码、H和保存解释重建矩阵后，重算原绝对参数盒、QP残差、可行上界及切平面下界；对每条保留见证核查全动作合法性。完整操作证明同槽零乘积；共移动见证满足\(T=S\)才使用共享平方压缩。无法重建的项记为未覆盖，不由少量点检查替代全域证明。
6. **统计分母。** 单列已执行H、候选漏真、域外、操作失败、必要历史/联合拟合失败、保留全部、唯一正确与误拒。用开发数据选择方法后，36H校准和12H评价分别使用新的不重合历史。

## 7. 共享平方与cap的只读代码核查

在当前D开发文件上检查`ev_shared_square_milp.py`及`ev_original_domain_milp.py`，没有发现改变上下界方向的错误：

- 功率链接和二进制互斥由实际操作矩阵验证；若不能证明零乘积，回到保留全部乘积的通用模型。跨时Gram非零也触发回退。
- 共移动见证残差为\(a+Cu\)。合法零乘积消去交叉项后，每个平方系数\(\|C_{:,k}\|^2\ge0\)，因此共享平方上弦仍是见证成本上界。MILP incumbent不充当原域QP下界。
- cap作用于扣除历史基准后的任务分数：\(v_k=\min\{\frac12(q_k-h_k),c_k\}\)。由于`min(x,c)`单调，QP下界和上界同样经过cap仍有效。主问题对每个任务的score变量另加上界cap，原始逐任务分数继续保存。
- 负目标用正数scale归一，最小化后端的dual lower乘负号变成最大化upper；cap均值、最差分数和达到的QP下界沿同一方向处理。

数值保护基于通常浮点舍入模型，完整AC误差另行检查。初始化LP证明、见证形成与模型编译耗时计入整体墙钟；它们不属于后端`TimeLimit`的MILP求解部分。

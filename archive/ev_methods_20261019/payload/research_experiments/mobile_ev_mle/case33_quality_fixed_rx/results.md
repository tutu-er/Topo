# case33：P/Q校正与潮流近似的质量分数比较

本轮固定case33原始拓扑和逐边R/X，隔离计量误差与潮流近似的影响。
结论：DF-I²在两个PV状态下接近完整AC，在原始满载状态下仍有明显分数偏差。
允许P/Q校正还可能吸收潮流模型误差，因此需要同时检查自身分数与完整AC回代分数。

## 实验与数学口径

保留33母线、32条原始闭合线路及全部32个非根计量节点。根电压已知1 pu，
仪表偏差与未计量源固定零。已计量PV包含在所在节点净P中，PV无功为零。
新增PV装机2229 kW（总额定有功的60%），位于18/25/33母线，比例35%/30%/35%。
这些是预先声明的单时段数值状态，未冒充现场时序或原case33的PV配置。

|状态|净P kW|净Q kvar|根P kW|电压最小/最大 pu|
|---|---:|---:|---:|---|
|原始满载、PV关闭|3715.00|2300.00|3917.68|0.91309 / 0.99703|
|白天PV|631.55|1610.00|673.25|0.98053 / 0.99913|
|PV反送电|−743.00|1150.00|−690.27|0.99772 / 1.02976|

设z=(P,Q)，y=(32个电压幅值、根总表P/Q)，每个模型M使用同一目标：

\[
 F_M(z)=\tfrac12\|(z-z^{obs})/\sigma_z\|^2+
        \tfrac12\|(h_M(z)-y^{obs})/\sigma_y\|^2.
\]

FIX固定z=z_obs，无剩余未知量；EIV拟合当期64个P/Q状态。全部方法不估计R/X。
同一FIX任务以AC-FIX为参照，同一EIV任务以高精度局部AC-EIV为参照。
真实P/Q处的噪声残差另记，不能把它当最优分数。

3状态×2噪声水平×8种子=48份含噪观测，另有3份无噪数值核查，共306方法槽。
两个噪声水平共享标准噪声，实际24组标准噪声向量；不是48份独立历史。
P/Q标准差为额定通道尺度的0.2%或1%，电压标准差0.05%额定值，
根表标准差为对应额定总量的0.1%。Q尺度含0.2P_nom及1 kvar下限；
标准差不按瞬时净功率缩小，也不等同仪表等级最大误差。

## 用完整AC回代分清两种误差

对模型M拟合出的z_M，记录自身分数J_self=F_M(z_M)，
统一物理分数J_back=F_AC(z_M)，以及同任务AC参照J_ref：

\[
 J_{self}-J_{ref}=(J_{self}-J_{back})+(J_{back}-J_{ref}).
\]

前一项为模型评分偏差，后一项为状态拟合损失。

|P/Q标准差|状态|DF-I²自身分数|同状态AC回代|AC-EIV参照|
|---|---|---:|---:|---:|
|0.2%|满载|55.62|31.18|12.89|
|0.2%|白天PV|18.48|18.16|18.09|
|0.2%|PV反送|15.54|15.29|15.20|
|1%|满载|19.67|71.01|13.38|
|1%|白天PV|18.31|18.37|18.13|
|1%|PV反送|14.86|15.13|14.83|

满载1%行最能说明问题：自身分数下降了，但完整AC回代分数变差，
说明P/Q修正在补偿近似模型误差。分数看起来接近，状态仍可能明显不同。
满载DF-I²在其拟合状态低估根有功约26.5—26.8 kW，而根P标准差只有3.715 kW。
其电压最大偏差约0.00042 pu（0.042%），单看电压误差会漏掉总表评分问题。

P/Q误差对完整AC本身也有影响：

|P/Q标准差|AC固定P/Q：满载/白天/反送|AC校正P/Q：满载/白天/反送|
|---|---|---|
|0.2%|13.09 / 18.71 / 15.84|12.89 / 18.09 / 15.20|
|1%|23.01 / 32.38 / 26.04|13.38 / 18.13 / 14.83|

## 验证、费用与适用范围

306/306槽返回，51/51个AC参照达到预定梯度及多初值一致性要求。
5项测试通过。另按原物理线路独立重建LD、DF-I²和AC，重算全部306端点：
自身分数最大差2.55e-11，AC回代分数最大差3.46e-11；
153个EIV点独立差分梯度最大8.19e-7，AC参照最大7.42e-7。
典型方向导数检查最大相对误差2.38e-9。

单时段主要拟合时间中位数在本共享机器运行中为：LD约3—18毫秒，
DF-I²约4—18毫秒，AC约9—45毫秒。模型构造和数值审计另计；
完整独立审计约205秒，主要来自约2万次独立差分回算。
AC-FIX后的物理缓存可在EIV初点复用；现有AC接口还计算多余R/X导数。
最佳审计状态的分数与primary单次计时分别记录，不能当严格同冷启动速度对照。
本轮不据此预测未知R/X或96/288时点的总耗时。

第一次pytest从无关D主干目录收集时导入了同名旧包；显式设定研究目录和导入源后
5/5通过。该调用失败单独保留，不作为科学拟合失败或被删除的样本。
规范C源码独立重跑全部306槽，状态、分数和梯度与首轮逐项相同。

本轮只回答已知线路条件下的评分近似质量，不涉及新拓扑恢复、EV规划增益或R/X精度。
AC-EIV是通过多初值及严格梯度核验的局部参照，没有全局最优证书。

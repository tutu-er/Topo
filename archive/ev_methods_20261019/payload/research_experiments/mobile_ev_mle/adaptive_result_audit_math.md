# 自适应 EV 的独立结果核查

`adaptive_result_audit.py` 只读取已执行策略的结果，不重新选择 EV 动作，不读取真值来改变候选、参数初值或功率曲线。真值只用于离线统计错误事件。

## 统计单位与检验规则

令 $i=1,\ldots,n$ 表示独立生成的历史路径，$m$ 表示冻结的比较方法，$r$ 表示轮次，$h$ 表示候选拓扑。保存的 $L_{imrh}$ 是该候选完整 AC 联合拟合达到的白化残差平方和；它不自动等于全局最小值。每个历史路径的校准分数为

\[
S_i=\max_{m,r}\{L_{imr,h_i}-\min_h L_{imrh}\},\qquad
A_i=\max_{m,r}L_{imr,h_i}.
\]

其中 $h_i$ 是离线评价已知的真实拓扑。任何必须完成的拟合失败、或真实拓扑缺失，都将该历史路径的两项分数设为 $+\infty$。这些路径仍计入校准样本数。漏真同时单独统计，因为任何阈值都不能保留一个不存在的候选。

分别给相对、绝对规则风险预算 \(\alpha_S=\alpha_A=\alpha/2\)，使用次序

\[
k_j=\lceil(n+1)(1-\alpha_j)\rceil,\qquad
b_j=X^{(j)}_{(k_j)};
\]

若 \(k_j>n\) 或相应次序统计量为无穷，则 \(b_j=+\infty\)。新历史的候选 \(h\) 仅在严格超过阈值时被拒绝：

\[
L_{mrh}-\min_gL_{mrg}>b_S
\quad\text{或}\quad L_{mrh}>b_A.
\]

若当前方法某轮有任何必要拟合失败，保留该轮全部候选，并记录计算失败。阈值不会控制模拟中的候选删减或下一轮动作；这里评价的是预先冻结、保留完整候选库的影子策略。多轮误拒绝事件定义为任一轮拒绝真候选，最终保留数量则单独报告。

若校准历史与新历史在**固定策略及声明的模拟总体下可交换**，新分数在 \(n+1\) 个位置中的秩给出

\[
\Pr(X_{n+1}>b_j)\le\frac{n+1-k_j}{n+1}\le\alpha_j.
\]

严格不等式使并列值不会增加拒绝概率。因为 \(S_i,A_i\) 已取全部方法和轮次的最大值，联合界控制完整策略内的相对或绝对误拒绝事件；并集界再给两类规则的总风险上界 \(\alpha\)。这是模拟总体的边际结论，不是每个历史条件下、每组连续线路参数下的统一保证。有限次局部求解已包括在冻结的数值策略中；该校准不证明全局 MLE。

校准、评价的策略 ID、总体 ID、源码哈希表和方法集合必须相同，历史 ID 必须互不重叠。推断性汇总要求预先声明的批次完整完成，避免把因耗时或失败而只完成的部分结果当成固定样本。偏差、源漂移及候选缺失压力测试必须显式声明为总体之外的描述性报告，不能继承上述秩保证。

## 排错、未决和失败

每个事件先压缩为每条独立历史一个布尔值，然后计算精确二项区间。报告真候选误拒绝、漏真、最终仅保留真候选、错误单候选、多个候选未决、空集合、选择失败、拟合失败、实际电压失败。选择失败后的恒充回退属于冻结策略的一部分，其最终表现与“优化器本身成功”分别统计。

错误候选排除比例在每条历史内计算，再汇总历史均值；不能把同一历史中的三个错误候选当成三个独立样本。同一历史的同噪声方法比较使用配对事件和精确 McNemar 检验。连续误差、耗时、似然差的配对均值与标准误只作描述性汇总；缺失对数与完整历史分母同时保留，不从成功子集推断总体改进。

star 按一个层单独汇总；其没有弱内部枝，因此不能把生成器给它的 `case='weak'` 标签当成弱枝案例。三个 cherry 各按 strong/weak 分层，层内数据用于失败分析，不将层内频率解释为拓扑正确概率。

## 数值与物理审计

每个内层 QP 逐项核查 \(q_{\rm lower}\le q_{\rm upper}\)，主问题核查冻结代理的收益下界不超过上界，以及最大化 MILP 的 incumbent 不超过 best-bound。方向下界 MILP 的 best-bound 只约束有限方向主问题；平方弦上界 MILP 的 best-bound 才可给对应冻结代理的上界。重新线性化后必须使用新代理的界，不能沿用旧界。

保存的完整 AC 回代损失与仿射损失并列输出；AC 可行解释给非线性最小距离的上界，不是设计收益下界。较大的 Taylor 残差或明显的回代代价变化说明代理近似需要审查，即使 AC 方程残差很小。

若 NPZ 保存了拟合的端点总 P/Q、同一物理点源 P/Q、逐边 R/X，收集器独立调用 AC 方程并计算

\[
L=\sum_{t,c}\left(\frac{\mu_{tc}+b_c-y_{tc}}{\sigma_c}\right)^2,
\qquad
\ell=-\tfrac12L-\tfrac12\sum_{t,c}\log(2\pi\sigma_c^2).
\]

EV 已包含于端点总 P/Q，不再相加。此核查只验证保存的目标值计算；没有重新优化，不构成全局最优性证明。旧 pilot 若没有保存潜状态，就明确报告 `unavailable`，不声称其目标值已独立回算。

## 运行

```
python -m research_experiments.mobile_ev_mle.adaptive_result_audit --pilot <pilot_folder> --out <audit_folder>
python -m research_experiments.mobile_ev_mle.adaptive_result_audit --calibration <cal_folder> --evaluation <eval_folder> --out <audit_folder>
```

输出 `fits.csv`、`actions.csv`、`numerical_bounds.csv`，推断性报告还包括逐历史候选保留记录及汇总 JSON。所有输入 JSON 保存 SHA-256；原始记录不被修改。

## 浮点交叉的审计约定

collector 继续保存每一个原始负 gap。QP 和 MILP incumbent/best-bound 使用相对 1e-7 核验；整体代理上下界使用冻结 core 已声明的相对 1e-6 一致性容差。容差内交叉仍输出 raw_bound_crossings，不截成零、不称严格有序界或最优证书。大于合同容差则中止核验并保留原始批次。普通浮点防护不是区间算术严格舍入证明。collector 的容差只用于审计既有冻结程序，不改变优化策略或校准分数。

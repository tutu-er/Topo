# 共同未来噪声下的线性拟合差：数学审查

`audit.json` 绑定本次核查的数学、代码和两份已存 toy 证据。审核通过；没有运行新样本、AC、拟合、优化或策略，也没有读取实际评价值。

固定历史 H、动作及一个预测情景后，最小二乘残差投影为 `P=I−A A†`；秩亏不改变该结论。两个模型必须解释同一份未来噪声。展开完整 SSE 差后，均值为 `d0+tr G`，方差为 `4||h||²+2 tr(G²)`；线性项和中心化二次项的协方差因高斯三阶矩为零而消失。历史行不注入新噪声，故修正量针对未来噪声吸收，不能简单按总参数个数代替。

`G=0`、`h≠0` 时差值正态，所给尾式方向正确；`G=h=0` 时差值恒为 `d0`。单侧矩界也正确：记 `X=Δ−μ`、`a=μ−τ>0`，对任意 `s≥0`，

```text
P(X<=-a) <= E[(X-s)^2]/(a+s)^2 = (v+s^2)/(a+s)^2.
```

取 `s=v/a` 即得 `P(Δ>τ) >= a²/(v+a²)`。该界只涉及声明的随机模型，不是拓扑正确概率。

盒边界反例给 `Δ=−e² 1{e≥0}`，均值 `−1/2`、方差 `5/4`；无约束模型则为 `−1`、`2`。若再将模型 a 固定为 `γ>0`，在 b 的活动面 `e≤0` 上有 `Δ=2γe−γ²`，条件均值 `−γ²−2γ√(2/π)`。这直接展示了按噪声选面后，条件噪声已被截断，标准高斯矩不能照搬。

还核查了先拟合再取期望与先取期望再选参数的区别、SSE 与半 SSE 的尺度、截断任务价值的 Jensen 不等式。9 个已有 toy 是数值检查，8 个估计标准误差仅作核查容差；复用噪声的多个小例不增加独立电网历史数。本补充没有接入冻结的 MILP 策略。

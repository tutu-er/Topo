# 时变普通负荷 EV 开发结果：成对分析 v2

这是保存结果的只读分析。输入为 `dynamic_dev_v2`（统一精度）和 `dynamic_alternating_dev_v2`（交替精度），每组4条开发历史，种子991101–991104依次对应star、clade01、clade02、clade12。两组共享同4个资产、背景、训练数据、参数和预测，因此是**4个独立历史、8个成对设置**。本批没有独立评价或统计校准结论；下文的分母4及改善次数均为开发描述。

**主要结果：** 同服务下，固定点的高幅度纯充和双向方案明显增加本批AC裕量，恒充并非最强对照。判别优化相对同域质量MILP的额外改善主要集中在一个star历史；其余固定点方案大多继承质量曲线。移动没有显示稳定的平均优势。交替精度下的强择时收益主要依靠预先给定的精度时钟；统一精度下，反序对照没有平均择时收益。未来预测与训练参数误差仍会使规划分数提高、实际裕量降低。

## 口径与输入一致性

对候选k，J_k为“验证4点＋未来6点”的条件P/Q完整AC输出残差平方和，R/X保持训练96点得到的一组值，只调整同一接口的逐时源。定义
$$
M=\min_{b\ne a}J_b-J_a,
$$
其中a为仅用于离线评价的真候选。M为正表示保存的局部拟合值更支持a；它不是已校准的排错概率。规划目标则是12个有向任务的平均半SSE距离，两者单位和聚合口径不同。

两组4/4历史的背景、训练观测及预测逐项一致，训练R/X最大逐值差为0。未来使用相同标准化噪声。统一精度的电压重复计量次数为[5,5,5,5,5,5]，交替精度为[1,9,1,9,1,9]，总次数均30；其余通道未来标准差均除以√5。线路来自公开电缆系数及合成长度，负荷与源为声明的普通AR过程，未使用新能源或现场时序。

## 能量、移动与人员成本

均值单位为kWh；移动为4历史的合计次数。每次移动占驾驶1槽、接线1槽，耗电0.2 kWh和人员30分钟；固定末端电池任务均为24→26.85 kWh。人员目前按时间预算约束，未设置货币成本目标。

|---|---:|---:|---:|---:|
| 判别：固定纯充 | 3.000 / 3.000 | 0 | 3.000 / 3.000 | 0 |
| 判别：固定双向 | 3.231 / 7.500 | 0 | 3.231 / 7.500 | 0 |

固定双向相对固定纯充，净取电增加约7.69%，吞吐增加150%。大幅M提升伴随更多输入资源；现有对照尚未量化其中多少来自放电方向、多少来自增加吞吐。用“相对无EV的平均M增量/吞吐”作描述性比较，统一精度固定纯充/双向约为38.27/37.61 SSE·kWh⁻¹，交替精度约76.17/45.58；该比值不替代同吞吐下重新优化的公平对照。

效率关系解释了质量基线的一个行为。设C/D为网侧充/放电量、E_drive为驾驶耗电，则
$$
E_{\rm net}=C-D
=\frac{E_{\rm end}-E_{\rm start}}{\eta_c}
+D\left(\frac1{\eta_c\eta_d}-1\right)
+\frac{E_{\rm drive}}{\eta_c}.
$$
统一精度时，线性质量目标正比净取电；循环损耗和驾驶能耗都可能增加该目标。观察到质量移动双向4/4选择移动，净取电3.315 kWh，而固定双向3.231 kWh；判别移动双向只2/4移动，另2/4继承固定双向。这批对比混合了选址、避免出行和可用吞吐的变化，不能全部归为新的空间激励。

## MILP的实际自由度、来源与求解程度

主策略联合优化6槽×3节点的18个连续净功率、充放状态、到达节点及至多一次移动；固定点域只有6个有效功率坐标。竞争QP每对保留12个逐时源坐标，训练R/X不参与未来调整。没有预枚举完整路线或功率曲线库。

初始四段分段下，固定点/移动域分别使用24/72个共享平方二进制，操作二进制分别48/132。自适应细分使本批固定点平方变量达到48、移动域达到288，不能把初始72写成全程上限。

# 固定训练参数的标量AC profile：定向近似检查

本例选择已知存在AC门问题的rich32开发990102，属于定向诊断，不是独立评价。计算入口只收到training_only_inputs.json.gz中的训练观测、训练拟合、候选和公开future计量精度；validation、未来真实负荷/源、真实线路和未来噪声均未传入数值计算。输入raw哈希与白名单哈希分别保存。

固定每个拓扑的训练R/X，源按时段在同一接口独立拟合，则各有向任务的完整未来距离按时段相加。单EV每槽最多一点后，可写为各时段、接入点、连续功率的标量函数之和。54个函数节点是2种公开计量精度×3点×9功率，其中5点是预声明插值端点、4点是留出中点。它们不满足完整SOC/人员服务，也没有被当作可执行计划或动作库。没有运行新的动作优化。

全部12有向任务保留：节点任务完成648/648，中点误差项完成288/288，失败在records中逐项保留。原一次线性模型的QP和完整AC局部源profile分别计算。距离单位均为半个白化SSE。

插值更小的中点任务为0/288，更大为288/288。逐任务和平均任务排序的翻转、并列和分母见summary.json。中点仅检验这些预声明位置，不代表整区间误差上限。

两个预声明非执行曲线核对了按槽求和与原六槽evaluate_fixed_action：全部通过=True，最大半SSE差5.12443e-11。单槽矩阵与原六槽对应行列一致=True；全部保存拟合的独立物理/目标回放通过=True。每次非线性源拟合仍是局部取得值，该一致性不证明全局极小。

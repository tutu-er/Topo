# 局部信息与平均检验功效的严格联系

范围：A、B、动作u预先固定，线性Gaussian计量Y=Aζ+Bν+e，e~N(0,I)，自由目标/补偿空间，信息秩r>0。实际AC的历史依赖策略继续使用独立历史校准。下面是自行推导，与information_power_link_checks.py的21项数值核验对应。

令Q=I−BB⁺，I=AᵀQA。对score S=AᵀQY，有E[S]=Iζ、Cov(S)=I。将I正特征方向标准化后，T=SᵀI⁺S是r个独立标准Gaussian偏移的平方和：T~χ²_r(λ)，λ=ζᵀIζ。

设c是中心χ²_r的alpha上分位，p_d=Pr(χ²_d>c)。非中心卡方矩母函数为(1−2z)^(-r/2)exp[λz/(1−2z)]，z<1/2。
将指数写为exp(−λ/2)exp[λ/(2(1−2z))]再展开，得到Poisson(λ/2)混合χ²_{r+2k}。因此功效

power(λ)=exp(−λ/2)Σ_{k>=0}(λ/2)^k/k!*p_{r+2k}
        =alpha + .5(p_{r+2}−alpha)λ + R(λ).

p_d随d递增，因为χ²_{d+2}可写成χ²_d加独立χ²_2。Poisson混合微分两次得
power''(λ)=.25 E[p_{r+2(K+2)}−2p_{r+2(K+1)}+p_{r+2K}]。
两个相邻增长量非负且总和<=1，所以第二差分绝对值<=1。由Taylor积分余项，所有λ>=0满足|R(λ)|<=λ²/8。

令Ξ为预声明有限正R/X任务方向，Ω=E[ΞΞᵀ]，ζ=γΞ，γ->0。于是

E[power]=alpha + .5(p_{r+2}−alpha)γ² trace(IΩ) + R_avg,
|R_avg|<=γ⁴ E[(ΞᵀIΞ)²]/8。

所以L=.5trace(IΩ)决定小信号平均功效的首项。在两个同秩/同alpha动作之间：

E[power(u)−power(0)] = (p_{r+2}−alpha)γ²[L(u)−L(0)] + O(γ⁴)。

有限任务可按固定历史权重平均；各任务秩不同时应使用各自的功效系数。多个历史点的min只覆盖保存的这些点。非线性AC与H依赖选择改变固定线性条件，不由此确定实际门限。

有限信号的平均λ不足以决定平均power。固定r=2、alpha=.1时，所有任务λ=5的功效为.6283499503；半数λ=0、半数λ=10，同样平均λ=5，平均功效为.4936606461。可用同一个I=I_2及不同方向分布实现这两例；二者方向第二矩都可取diag(5,0)。因此信息矩阵及第二矩并不确定有限信号平均功效。

数值审计以Poisson部分和作为下界、加剩余Poisson质量作为上界，独立与SciPy非中心卡方尾概率比较：rank1/2/3，λ=0/.0001/1/10/100，最大差8.11e-15；另验证局部导数、严格余项和同均值反例。这里没有选择EV、校准AC或估计拓扑概率。

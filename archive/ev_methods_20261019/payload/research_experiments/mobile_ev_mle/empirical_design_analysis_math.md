# 冻结设计分数与实际排错：独立的评价协议

本模块只读取完整的、预先声明的实验批次，不拟合参数、不生成动作、不估计拒绝阈值。`pilot_v3` 的六个历史用于检查保存格式和指标，不用于调整冻结策略。正在运行的正式评价批次不会被本模块接受。评价结果可用于提出下一版策略的研究假设，但下一版必须重新冻结，并使用新的独立历史校准和评价。

## 1. 统计单位与实际 AC 指标

以 (i=1,\ldots,n\) 表示独立历史及其预先生成的未来仿真路径。对同一 (i\)，全部方法共享历史与实验生成机制；不同方法、候选和滚动轮次不是额外的独立历史。令 (m\) 表示方法，(g_i\) 表示仅供评价器使用的真候选，(\mathcal G_i\) 表示保留的候选集合。

令 (L_{im}(h)\) 为历史与新增数据在候选 (h\) 下的完整 AC 白化平方残差，通过共享线路参数及允许的状态变量进行联合局部拟合得到。它是保存的可行局部拟合值，不能被称作经过全局证明的最小值。对同一数据和固定已知协方差，

\[
\ell_{im}(h)=C_{im}-\tfrac12 L_{im}(h).
\]

当真候选在集合内且所有必要候选拟合成功时，定义带符号的实际拟合间隔

\[
M_{im}=\min_{h\in\mathcal G_i\setminus\{g_i\}}L_{im}(h)-L_{im}(g_i).
\]

于是

\[
\ell_{im}(g_i)-\max_{h\ne g_i}\ell_{im}(h)=\tfrac12 M_{im}.
\]

正值表示保存的真候选拟合优于所有保存的错误候选；负值表示至少一个错误候选拟合更好。以前的非负 `true_gap` 等于 (\max(0,-M_{im})\)，它把所有正间隔压成零，无法度量改善幅度。即使 (M_{im}>0\)，也不直接推出显著排错或拓扑正确概率：候选集合可能不完整，拟合未获全局证明，且需要独立的统计阈值。

同一历史内对参考方法 (b\in\{\text{none},\text{constant\_fixed}\}\) 定义

\[
\Delta M_{im,b}=M_{im}-M_{ib}.
\]

none 与其他方法是同长度观测对照；充电方法之间另按相同电网电量任务比较。移动耗电和效率会改变最终电池能量，因此“相同电网电量”不等于“相同最终 SOC”。逐历史 CSV 保留动作电网电量、最大功率与已保存的路线移动能量。

均值和中位数只在两边都可计算的配对历史上描述；另报全体历史数量、缺失配对数量及胜/负/平数量。使用 (10^{-8}\) 白化损失单位作为数值平局容差。胜率的分母始终为全部预声明历史，缺失配对不会被计作胜利。拟合失败、选择失败后执行回退动作、物理失败和漏真各自保留标记。成功回退动作产生的数值间隔可以描述，但不会被计作原算法成功执行后的严格真候选胜利。

## 2. 只比较同一冻结代理下的动作值

对给定历史冻结的开放竞争解释代理，令

\[
\Phi_i(u)=\min_k q_{ik}(u),\qquad
q_{ik}(u)=\min_{z\in Z_{ik}}
\|c_{ik}+B_{ik}u+A_{ik}z\|^2+\|F_{ik}z\|^2.
\]

保存的 QP 原始可行值和对偶下界给出所选动作的区间

\[
\underline\Phi_i(u)\le\Phi_i(u)\le\overline\Phi_i(u).
\]

MILP 顶层的 `proxy_upper` 是所有可执行动作上最优代理分数的上界，通常不等于所选动作的上界。本模块从实际动作匹配的 QP 记录或同动作 AC 回代记录中的 QP 区间提取动作值。动作计量中的 P 是标幺值，使用保存的 `base_kva` 恢复 kW 一次；匹配容差为 (2\times10^{-6}\) kW，并明确记录它只是数值匹配。

在同一组开放竞争矩阵内，动作增益具有有效区间

\[
\underline\Phi_i(u_m)-\overline\Phi_i(u_b)
\le \Phi_i(u_m)-\Phi_i(u_b)
\le \overline\Phi_i(u_m)-\underline\Phi_i(u_b).
\]

相关性使用区间中点作为数值近似，并保留区间上下界及下界为正的计数。固定 MLE 方法冻结线路及源变量，其自有代理与开放竞争代理不同；自有分数单列，不能与开放竞争分数直接相减。若其动作未在保存的开放竞争矩阵内评价，则共享代理分数报告缺失。原 11 动作库中的 `criterion` 必须明确表示使用同一冻结开放竞争代理，才能用于 constant/pulse/random 等匹配动作的分数。

保存浮点计算的原始 (\overline\Phi-\underline\Phi\)，不将负数截为零。全设计代理按冻结核心的相对 (10^{-6}\) 数值容差标记交叉；动作 QP 使用相对 (10^{-7}\) 容差。容差内交叉仍是方向冲突，不能当作严格有序上下界或严格 gap 证书。若动作 QP 端点交叉，该动作增益只保留描述性中点和冲突标记，其增益上下界设为未定，不计作正增益下界。

滚动方法的完整规划分数不能当作已执行首段的分数；本模块拒绝这种转用，只保留真实新增数据的最终 AC 间隔和全路径失败标记。

## 3. 距离为何可能相关，也为何不必相关

先看一个参数已知、无历史拟合的高斯例子。真实观测为

\[
Y=\mu_g+\varepsilon,\quad\varepsilon\sim N(0,\Sigma),\quad
d=\Sigma^{-1/2}(\mu_g-\mu_h).
\]

候选 (h\) 和 (g\) 的白化损失差严格满足

\[
L(h;Y)-L(g;Y)=\|d\|^2+2(\Sigma^{-1/2}\varepsilon)^\top d.
\]

因此均值为 (\|d\|^2\)，方差为 (4\|d\|^2\)。这是距离与似然差联系的简单来源。竞争模型重新拟合时，最小化和取期望不能任意交换；当前代理又包含两个历史解释的残差、局部区域和固定预测。上述简单公式并不能证明当前 (\Phi_i\) 等于期望实际排错收益，更不能把它变成拓扑概率。

当前代理在某些历史中主要由不可再降低的历史残差决定。对代理最活跃的候选对，保存的实际 AC 回代满足

\[
C_{ik}^{\mathrm{witness}}
=C_{H,g}^{\mathrm{witness}}+C_{H,h}^{\mathrm{witness}}
+D_{N,gh}^{\mathrm{witness}}.
\]

本模块报告未来份额 (D_N^{\mathrm{witness}}/C_{ik}^{\mathrm{witness}}\)，活跃对名称、活跃对是否包含真候选，以及活跃与最差 Taylor 残差。真候选只在事后评价中使用。回代竞争解释是一个可行点，其成本是实际非线性内层最小成本的上界；未来份额是解释诊断，不是信息收益下界。某个难区分的错误—错误候选对可以支配 max-min 分数，未必改善真—错误间隔。

## 4. 成对统计与相关性

逐方法、逐层（star、弱 cherry、强 cherry）报告：完整 AC 间隔、相对 none/constant 的配对间隔增益、胜/负/平/缺失计数、原始代理分数与间隔的 Spearman 相关、代理增益与实际增益的 Spearman 相关。

对一次历史内的多个冻结方法，还计算方法之间的 Spearman 排序相关 (\rho_i\)，然后报告独立历史上的 (\rho_i\) 均值和中位数。它评价“这一历史内代理是否把方法排对”，不会把 (n\times\#\text{methods}\) 行误当成独立样本。少于三个可用配对、任一轴为常数或 bootstrap 退化时，相关报告未定义并给出数量。

所有 percentile bootstrap 都有放回抽取整个独立历史索引。配对效应先在同一历史内相减，再抽样；每次抽取保留该历史对应的全部缺失状态。95% bootstrap 区间仅作此已冻结模拟总体下的描述；没有据此调参数、选择显著子组、宣称条件覆盖或进行多重比较显著性检验。

若传入独立 collector 目录，本模块核对其 evaluation config 和每个 trial 的 SHA-256，再读取其已校准 gates。这里不会从评价批次反推门槛。门槛事件的分母同样是全部独立历史。

此时还报告共享代理分数与校准排错比例、算法唯一正确保留事件的描述性相关，以及同一历史内代理增益与排错比例增益的相关。排错比例以该历史的错误候选数量为分母，它是一个历史级指标；各错误候选仍不会被当成独立样本。

## 5. 耗时与 AC 调用数

`ac_calls` 包含完整联合拟合失败过程中实际发生的调用；`returned_fit_ac_calls` 只包含返回拟合的调用，不能当作总数。一次历史的仪表化调用数为全局 selector 调用数加全部方法联合拟合调用数。全局 selector 调用数已经包含各方法选择调用，不可再重复相加。未在该计数器内执行的真值仿真不属于这个总数，因此字段名明确为 `instrumented_selector_and_joint_calls`。

MILP 时间上限状态、缺失上界、QP 数量、最大模型变量数和最终代理 gap 是否满足分别保留。未达到代理 gap 不等于没有可执行动作；选择失败与代理预算停止是不同事件。

## 6. 运行命令

待正式 evaluation_v3 和独立 collector 完成后，root 可运行：

```powershell
python -m research_experiments.mobile_ev_mle.empirical_design_analysis `
  --input research_experiments/mobile_ev_mle/outputs/adaptive_milp/evaluation_v3 `
  --collector research_experiments/mobile_ev_mle/outputs/adaptive_milp/evaluation_v3_audit `
  --out research_experiments/mobile_ev_mle/outputs/adaptive_milp/evaluation_v3_metrics `
  --bootstrap-draws 1000 --seed 881001
```

结果为 `empirical_design_summary.json`、逐历史逐方法 CSV 和逐历史复杂度 CSV。模块与所有输入记录均有哈希绑定；原始实验记录不被覆盖。

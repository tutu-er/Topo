# 来源、保留内容与重构差异

本目录从同一项目中对话涉及的RNJ、NJ及WZZT研究代码整理而来。算法运行代码重新集中为少量本地模块；没有通过修改`sys.path`寻找原项目、动态安装旧补丁或读取旧缓存来执行算法。

## 数学与实现来源

| 本地模块 | 原项目中对应的实现来源 | 整理方式 |
|---|---|---|
| trees.py / RNJ | rnj_wzzt_core/rnj_wzzt/graph/rooted_neighbor_joining.py | 保留递归及相容层级含义，改为索引支持族接口 |
| trees.py / NJ | research_experiments/rnj/rooted_study_baselines.py | 保留经典Q准则和观测根锚点，去掉项目内部导入 |
| trees.py / 灵敏度 | rnj_wzzt_core/rnj_wzzt/estimation/multiscenario.py | 自包含的对称、非负、有序约束QP；NumPy/SciPy |
| optimization.py / W | 原laminar_l1_milp提升约束及平方误差后端 | 用清晰的z、z外积和响应乘积重新写成凸MIQP |
| algorithm.py / T、E | research_experiments/simplified_rte_20261111/engine.py | 同一选择模型，区别只在候选域与必选骨架 |
| data/、cases/ | 连续一天96点历史面板 | 复制48组观测和四物理网络，记录全部本地SHA |
| data.py / 新AC生成器 | 径向网络后向/前向扫掠的电路方程 | 本地NumPy实现，与独立Ybus功率平衡求解核对 |

这些路径只用于说明来源，不是运行时依赖。来源代码是本项目的本地实现；NJ基线不宣称复现某篇文献的完整辨识流程。网络名也不等同于论文原始数据声明。

## 与旧实验保持一致的部分

- 原始量测目标：平方电压降，预测为共同R/X响应。
- 层级相容支持、非负有界响应系数、原始WZZT未知支持域。
- R引导、可选T、小区域候选并、一次可撤销E、严格验证选模的结构。
- 内置48组历史观测的实际字节、终端顺序和物理网络。

## 为可读性显式改变的部分

1. 不复制旧实验的253个以上源文件与多层运行时补丁；固定族拟合直接用SciPy有界最小二乘，结构搜索直接建立Gurobi凸MIQP。
2. 直接使用MSE/Mref+alpha*k，去掉仅为旧L1单位兼容引入的K与f01。数值改善容差和绝对MIP gap按新归一化单位解释。
3. R从15组原始RNJ生成族合并候选，保留其完整支持。旧实验曾先用L1拟合、剪去零权重，再只导出剪后的热启动支持；本目录不再从这些缓存反推候选。因此候选覆盖及最终结果可以变化。
4. RNJ/NJ输出各自的固定族QP重拟合/数值清零结果；W类输出验证择优自身路径及单点保护模型。
5. 不把旧小种子、相对门槛、.24后收缩、屏蔽分支、整树组合等重新加入当前引擎。旧方案的地位在ALGORITHMS.md中单独列出。

因此，“历史数据字节一致”“前端递归一致”“整个算法历史成绩复现”是三个不同结论。本目录验证前两项及新引擎自身的数学/运行一致性；不把旧分数直接用作新引擎结果。

## 第三方运行环境

NumPy、SciPy和Gurobi通过requirements安装，不分发第三方库源码或许可文件。RNJ/NJ不要求Gurobi；执行W/T/E MIQP需要用户环境中的有效Gurobi许可。无需原仓库环境变量或外部数据服务。

历史结果快照只作追溯，不参与拟合、参数选择、候选生成或验证择优。新实验的计划、原始输出和数据/代码哈希独立保存。

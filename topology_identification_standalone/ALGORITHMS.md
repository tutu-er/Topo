# 方法目录与对话中算法的对应关系

本目录统一为一套平方误差响应模型、一套固定族QP，以及一个带R/T/E开关的搜索引擎。它整理了对话中的主要方法；历史探索方案以谱系说明保留，不继续堆进默认运行路径。数学和参数见 [MODEL.md](MODEL.md)。

## 1. 可以直接运行的十种方法

三位编号依次表示R、T、E。W始终存在；初始结构始终为单点/全集基底。

| ID或别名 | 结构 | 用途 |
|---|---|---|
| rnj | 固定RX75/0.16 RNJ族，QP重拟合及验证 | RNJ基线 |
| nj | 同一RX75几何、观测根锚点的经典NJ，0.16边收缩后QP重拟合及验证 | NJ对照 |
| 000 / pure_wzzt | 原始未知支持W，无R/T/E | 纯WZZT |
| 100 / rnj_wzzt | RNJ候选与热启动＋W | 简化RNJ＋WZZT（MIQP） |
| 010 | W＋末端T | 单独检验T |
| 001 | W＋最终E | 单独检验E |
| 110 | R＋W＋T | 去掉最终E |
| 101 | R＋W＋E | 去掉末端T |
| 011 | W＋T＋E | 去掉RNJ结构引导 |
| 111 / rte | R＋W＋T＋E | 完整简化RTE |

R仅提供候选和可行热启动，不固定小种子。T把末端逐步扩展替换为一次有界子树切面联合重构。E在一次有限池联合选择中释放全部临时内部连接。T/E共用选择模型，W保留原始未知支持域。

“纯WZZT”表示结构搜索不用RNJ支持或热启动；八格仍共用训练数据得到的RNJ参考误差，使计数正则强度相同。因此它是匹配尺度的纯WZZT结构基线，不是完全不计算RNJ前处理的端到端计时定义。

RNJ/NJ只输出各自固定族的QP重拟合与数值清零结果，验证分数用于记录，不与单点模型择优。其名称不等于未经重拟合的裸几何树，更不代表外部论文完整方法的逐字复现。

## 2. 统一执行规则

结构目标为$J=\mathrm{MSE}_{\rm train}/M_{\rm ref}+\alpha k$，默认$\alpha=0.003$。每个提议先进行固定族QP和允许范围内数值清零，再按J下降超过数值容差接收。

W/T/E均使用凸MIQP；固定族使用SciPy有界最小二乘QP。枚举T候选连接后仍有二元层级选择变量，不是逐棵完整树求LP。

本版没有两个小种子的数量/大小筛选、独立相对改善门槛、近邻修复窗、最终0.24收缩或独立完整RNJ树备用。RNJ候选生成的15组固定设置仍公开保留。

## 3. 完整消融怎么读

完整消融应在同一输入上运行八格，并同时比较F1、完整恢复、耗时、失败/超预算和原生求解状态。不能只选择有利的四格串成一条结论。

设$g_{rte}$为某项已冻结的评价指标。模块边际效应取决于已有模块，例如

$$
\Delta_T(R=1,E=0)=g_{110}-g_{100},\qquad
\Delta_T(R=1,E=1)=g_{111}-g_{101}.
$$

它们可以异号；不应把训练J改善等同于拓扑F1改善。二阶交互可从条件边际的差得到，例如

$$
I_{RT\mid E=0}=g_{110}-g_{100}-g_{010}+g_{000}.
$$

三阶交互为

$$
I_{RTE}=g_{111}-g_{110}-g_{101}-g_{011}
+g_{100}+g_{010}+g_{001}-g_{000}.
$$

六种加入顺序RTE、RET、TRE、TER、ERT、ETR，是同一八格表的六种解读顺序。实际算法执行仍按R引导、W、T、E；没有另外运行“E后再T”等六条时间流程。Shapley平均用这些上下文边际分配总差异，不建立模块普遍有效或因果机制的证明。

命令行会保存逐格结果、条件边际、加入顺序、Shapley汇总及interactions.csv中的二/三阶交互。失败、超预算与未完成格保留分母，缺少有效格时相应成对效应为空。

## 4. 历史谱系：哪些保留为记录

| 对话阶段 | 主要内容 | 在本目录的地位 |
|---|---|---|
| 早期RNJ/NJ与原始WZZT | RNJ/NJ从灵敏度几何建树；WZZT用L1-MILP逐步加相容集合 | 图算法和逐步域思想保留；当前搜索统一为MSE-MIQP |
| 普通RNJ＋WZZT | 按当时配置预选RNJ集合，再单连接扩展；当时验证与整树备用口径因实验而异 | 历史基线；不能把其分数直接标成新100 |
| 少量RNJ小块＋原始WZZT＋退出 | 至多两个不相交、各含≤3终端的小种子；即时释放零块；≤5末端联合；一次E；最终收缩/重拟合 | 曾选研究主线，历史实现与成绩保留，不作为本目录另一套默认代码 |
| 完整RNJ初值修正版 | 完整RNJ层级先作联合修正，再视大区域运行W、末端T和E | 历史对照 |
| 大块优先变体 | 对新增集合覆盖比例、整块并等作额外限制 | 历史探索，不进入简化引擎 |
| 整树组合与候选并集 | 一类只验证择优完整树；另一类把连接并集后联合选择 | 两者不同；本目录不设整树备用组合，仅保留明确的R/T/E连接池 |
| 完整R/T/E消融 | 旧协议下的八格组合、边际与模块顺序分析 | 分析结构保留，当前需用新实现重新运行 |
| 平方误差MIQP对照 | 将整条训练链由L1替换为MSE，旧小种子/输出收缩等仍保留 | 提供当前平方目标来源，不是新版本成绩 |
| E的纯MSE相对改善门槛 | 曾检验$\tau=0.001$等，只改变E接收，选结构仍有计数惩罚 | 历史研究；本版用统一J接收，不保留该分支 |
| 首轮简化RTE | 删除小种子、相对门槛和后收缩；依赖旧缓存的初始族/热启动支持 | 当前结构的前身；本目录重新生成并保存原始RNJ族支持 |

上述历史中的“原始WZZT步骤”描述的是未知支持逐步扩展域；不自动表示没有计数正则。历史“退出E”指删块/换块结构重构；求解器TimeLimit和gap停止是另一件事。

历史数值依赖各自的数据、候选生成、损失、收缩、验证、预算和备用口径。旧120输入或48输入F1、完整恢复、耗时不能直接贴到本目录的方法编号上。本目录只将已核实数据作为输入携带，不把旧结果冒充新运行结果。

## 5. 本目录与历史实现的明确差异

- 单个权威实现取代历史模块之间的导入链；代码和算例均在本目录内。
- 直接使用归一化MSE，无旧K和S数值缩放适配层；数值门槛按本目录目标解释。
- 固定族QP改用SciPy BVLS，结构MIQP仍用Gurobi；求解后保留目标、下界和状态。
- RNJ生成的15个原始支持族完整保留，不先用旧L1/QP零权重缓存剪裁。
- 不继承更广旧公共池的demean/NJ/ridge几何搜索；R池来源在trees.py中明示。
- 主要模型对照和消融共用数据与规则，独立测试与真值只用于事后评价。

保留原始支持减少一个候选丢失来源，但不保证有限池包含真树。首次简化实验中的负例已说明：候选不足与权重目标、验证选择是不同问题；单调J和原生gap不能替代拓扑恢复检验。

## 6. 最短运行入口

进入本目录，在已安装requirements.txt依赖且结构搜索具有Gurobi许可的环境下运行：

    python run.py demo
    python run.py ablation --dataset toy
    python run.py benchmark --jobs pilot
    python run.py ablation --dataset bundled --jobs pilot

默认demo是可快速验证的六终端线性响应例，不是paper15物理算例。bundled的pilot为四网络各一组固定输入，all为全部48组历史观测。外部新轨迹生成与历史观测回放分开，细节见 [DATA.md](DATA.md)。

更多设置与结果文件见 [README.md](README.md)。完整八格只是有声明范围的有限搜索实验，不提供全网络最优或拓扑唯一性保证。

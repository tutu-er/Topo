# 历史结果快照

本目录仅保存对话中既有结果表，帮助追溯算法谱系。它们不参与当前算法，不是新独立代码的运行成绩，也不是新入口执行后应逐字匹配的验收标准。

| 子目录 | 历史口径 |
|---|---|
| four_methods_120 | 原四方案在120输入上的比较，含完整RNJ、少量小块及大块优先等探索 |
| own_mainline_four_120 | NJ匹配基线、纯WZZT、普通RNJ+WZZT、无RNJ整树备用的自身主线展示 |
| factorial_RTE_120 | 当时L1/小种子/后收缩协议下的完整八格R/T/E消融及交互 |
| MIQP_loss_48 | 同48个一天96点输入上，L1与MSE、无T与有T的历史配对对照 |
| MSE_exit_48 | 固定旧MIQP提议上的E接收门槛回放与参数选择 |
| first_simplified_RTE_4 | 首轮简化RTE四输入pilot，保留F1下降与候选覆盖缺口 |

`manifest.json`记录每个表的原相对来源、长度和SHA。所有表都已复制到当前目录，读取它们不需要访问原路径。完整历史实现和大归档仍属于原仓库的冻结研究记录；当前独立目录不加载或解压它们。

各历史表的数据域、损失、种子、RNJ候选来源、输出收缩、验证规则及预算不同。请按原表方法ID理解；例如旧`ordinary`不等于本目录的`100`，旧`small3_original_exit`也不等于本目录的`111`。完整对应关系见上级`ALGORITHMS.md`。

本次新代码的运行检查单独保存在上级`validation/`。若要形成新48输入完整比较，应使用当前独立CLI重新运行，并保留失败、超预算及未完成分母。

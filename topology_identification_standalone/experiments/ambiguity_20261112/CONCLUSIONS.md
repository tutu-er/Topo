# 按MSE分离程度决定返回一个还是两个拓扑

## 当前规则

输出先保持实际留出MSE主选，再寻找活动内部族不同的最佳冻结备选。令M1为主选留出MSE，M2为该备选MSE，只在

\[
M_2-M_1\le\kappa_{\rm amb}M_2,
\quad\text{即}\quad M_1\ge M_2-\kappa_{\rm amb}M_2
\]

时返回两个，否则只返回一个。它判断第一名相对第二名的改善是否足够明显，分母明确取第二名。用现有归一化数值并列容差保护浮点边界。默认ambiguity_kappa=.003为公开工程设置，尚未统计校准。

例如M1=.995、M2=1时分离度为.5%；κ=.003只返回第一名，κ=.01返回两者。增大κ会扩大双候选范围，但不改变第一名、搜索路径、系数或响应界。它与训练正则J的relative_gain分开：前者决定输出/DR候选，后者决定是否接收结构更新，当前后者默认0。

没有不同族时输出一个，状态为single_no_saved_alternative；存在明显更差的不同族时为single_separated；接近时为two_near_tied。secondary_index只指实际返回的第二拓扑，models长度为1或2，dr_candidate_indices只有条件成立才包含两个索引。best_distinct_index保留诊断指针，不能当成DR已接收候选。

两者MSE均零按并列输出两个；第一名为零、第二名明显非零时分离度为1，只输出第一名。零辅助支持和同族不同系数不会伪造第二拓扑。稀疏并列规则导致主选MSE略高的数值情形也按并列处理。

## DR衔接与数据预算

建议后续在预先约定DR费用和误差容忍范围后设置κ；允许更多保守的DR复核时，可放大同一个输出κ，而不放大训练搜索门槛。先比较同一库的分离度和干预代价，不为了凑出两个拓扑按真树成绩调阈值。

本次实现只产生DR候选对，不执行DR或生成干预数据。未来新DR测量必须单独记录采样/干预预算，不能算成本轮原有96点。该规则是候选筛选阈值，不是统计拒绝检验或拓扑正确率。

## 验证与复现

55项回归通过，覆盖门槛等号、零MSE、数值稀疏并列、无备选、非法参数、放宽单调性、主选不变及审计工具对旧/新schema的兼容。独立回放核验10个有效边界、7个非法边界和60次实际判别，均与真实helper一致。原run、grade、selection seal和旧ZIP均未修改。

审阅中补充了正反两个精确数值并列探针：1与1+10^-12相减可能超过容差一个浮点单位，故守卫与最终判别均采用与排序一致的加法比较。初版脚本/CSV/receipt保存在initial_replay及其manifest；修复后实际60行CSV字节不变，当前receipt记录更新源码和10个有效边界。

通用运行可用`python run.py demo --ambiguity-kappa .01`。只重评估同一冻结库时调用`competition(result, selection_observations, kappa=.01)`，不需要搜索或重拟合。独立标量回放：

```powershell
python -I -B tools/replay_ambiguity.py --source outputs/strict96_20261112_002 --output outputs/ambiguity_new
```

如从便携目录重建该历史回放，需先把上轮strict96的records.zip解压到独立目录根下，恢复其中相对路径outputs/strict96_20261112_002。整包仍带可重新运行的本地数据和代码，嵌套原始ZIP另行提供。replay.csv和receipt.json记录所有输入记录SHA、脚本与判别源码SHA。

# 配网灵活性服务：分析与扩大试验

三轮开发后，800日总体面板与1408日困难条件重复面板均已完成并独立核验。绝对恢复约束减少采购，在部分困难条件提高恢复；冻结参数模型仍有严重的条件失配。用户要求继续迭代，下一轮针对均值偏差和动作方向展开，规则重新锁定并使用新随机路径。

## 目标应当是最终辨识，而非固定增长量

这一修改合理。旧要求只保证声明模型中的平均区分证据比零采购增加，历史错误很深时仍可能判错；本来就能判对时也会采购。绝对要求直接问“加入新日后是否足以正确选择”，允许零采购，并要求历史非赢家在它正确的情况下也能胜出。

但由“某个冻结H正确”得到的结论，与“某种拓扑结构正确、它的参数估计存在偏差”不同。当前真实网络生成实际电压，冻结H只是历史估计，结构正确也可能有预测偏差。这是本轮最重要的模型差别。

## 约束是否只是右端改变

对同一候选对，令h为历史对数赔率，J(u)=||(H_i−H_j)P(u)||²/(2sigma²)。若两方分别作为可能真模型、误差为同方差独立正态，每对分配相同错误额度，则绝对条件等价于

`J(u) >= 0.5 * [ z + sqrt(z² + 2(|h|+delta)) ]²`。

旧要求是`J(u) >= J(0)+gamma`。在这个条件下，二次距离式确实相同，只改右端；不应把它包装成新的非凸结构。

完整实现还改变了需要保护的候选范围、历史赢家的地位、零采购验收和比较错误额度。加入历史均值偏差时，左端也加入新的二次项。单方向且历史优势为正时，绝对条件可能有两个可行区间，当前辅助变量形式保留了这两段。

## 为什么理论上的增加在实际中会缩水

实际新日平均电压响应记为f(P)。对固定真拓扑参数估计H_i和竞争者H_j，实际平均对数赔率等于

`历史优势 + J(u) + <f(P(u))−H_i P(u), (H_i−H_j)P(u)> / sigma²`。

最后一项是冻结参数及物理近似偏差沿比较方向的影响。采购改变功率后，它也改变；增加J不保证它不下降。

第一轮正确但优势弱的18日中，旧方案实际J平均增加1.541，偏差项平均减少0.922，净无表计噪声证据只增加0.618；3日下降。双向历史保护能限制已拟合均值中的坏方向，仍没有覆盖真实新日全部方向。

第二轮唯一新增恢复的原始参数比较中，实际J增加5.447、偏差抵消1.242、量测变化贡献1.565，最终评分优势增加5.770，由−0.765变为5.005。这同时包含实际区分增强和该条路径的随机量测作用，不能把后者也算成确定收益。

## AC与表计误差的核查

主评价始终使用原真实网络的AC潮流。线性对照使用同一真实线路、P/Q、响应和量测随机流，替换为物理LinDistFlow，不以目标候选生成电压。该对照只去除新日AC非线性，保留原AC历史拟合形成的参数偏差。

旧32日对照中，单独去除新日AC非线性使恢复20→19；本轮R2的AC和物理线性结果相同。因此现有证据不支持把问题主要归于AC。

另一个已核实差别是根节点表计误差共享给所有平方电压差，实际噪声不是逐节点独立。开发诊断中，预定候选比较的实际电压噪声方差与声明独立模型之比，中位约.65、最大约1.51；它是模型简化，但本批通常没有低估该比较的电压噪声方差。

同时将量测和预测减去每时刻节点均值，可以消去共同根表计误差。开发R1恢复数不变；R2无采购40→41，与原对称保护41次持平；原历史中则有1例改对、1例改错。已锁定为大批次附加评分对照，不能将评分改善算作采购收益，也不替换主要终点。

## 初值、资源不足与求解精度各有什么影响

对同一问题的8个输入做了初始化对照。1例零动作足够；6例各初始化均判定当前QCQP不可行，其中5例另有放宽功率域的独立上界证明；剩余1例仅公共初值找到可行方案。

该例3/12/60秒的可行费用为19.33/16.41/14.05元，有效下界为1.19/1.19/1.25元。3秒只保留初值，12和60秒改善了初值，但最优性间隙仍很大。换初值或增加时间确实有用，不能解决已经证明不满足当前约束的输入。

均匀错误额度只是联合概率要求的一种充分实现，当前QCQP不可行不等于真实联合辨识问题无解。第三轮提前按零动作难度分配错误额度，减少了部分采购和失败，但未增加恢复数。

资源容量试验使用同一双安装物理背景，采购一组或两组，控制域严格嵌套。标准合同200个可行方案在扩大合同中全部仍可行、同动作同费用。扩大资源改善部分可行报价和费用，两个合同的全部方法仍为41/64恢复。容量与有限时间解质量须分开；少数扩大域报价更高，不能解释为真实最优成本增加。

## 能否对任意候选质量都可靠

固定库中选优存在三个直接限制：没有真结构时不能输出缺失的结构；两个候选在可用资源方向上没有预测差别时，扩大同一方向无效；正确结构的冻结参数很差时，错误结构可能拥有更低的实际MSE。改变采购右端不能统一消除这些问题。

本批400个历史库中150个含真拓扑、250个不含。全部保留；恢复、错误输出和拒绝输出分别统计。固定拒绝参考只能识别绝对拟合很差的候选，无法识别所有“预测接近但结构错误”的候选。

当前规划保护代表参数库，主要评价使用完整原始参数库。主面板方向保护678/678、非均匀额度729/729可行方案，以及补充1021/1021、1105/1105，均通过完整原始参数库的条件概率补验。未发现遗漏参数点破坏本批模型证书；声明均值与真实均值的差异仍在。

## 扩大试验的解释方式

总体面板为400历史×2新日=800日，另列221个未参与本轮开发的历史条件。追加面板为全部28个历史困难条件与16个固定对照，每条件32日，共1408日。合计2208个独立新日，AC与线性重复评价不增加独立样本数。

主要终点保留原完整参数库的严格MSE恢复。每组列无采购、旧增量、对称保护、非均匀额度及同费轮换；保留每次新增恢复、丢失恢复、失败回退和费用。追加组刻意多测困难条件，不能直接并入800日总体率。每条件32次从相同历史重新开始，不累计成32日历史。

已经完成三轮开发：除第二轮对称保护新增1次恢复外，其余变化主要影响权重、可行性或报价。R2首次集成的128次模块导入异常单独保留，修复后换新随机流重跑。下面是两批完整结果。

## 正例与严重反例并列

Pengwah18的留出历史main/input129，原负荷形态、电压噪声0.02%，无采购18/32，方向保护27/32，轮换24/32，旧增量23/32，非均匀额度20/32。方向保护平均结算12.54元/日，真权重均值0.545→0.836。9次新增恢复集中于该历史；这是面板完成后的例子展示，未重新挑选总体分母，费用未证明最优。

Soumalas11的留出历史pressure/input042，R/X比例为原值0.5倍、电压噪声0.05%，无采购15/32，方向保护14/32，旧增量13/32，非均匀额度15/32。方向保护唯一丢失路径中J增加0.868，参数偏差变化−1.070、AC修正−0.030、表计影响−0.717，实测净优势下降0.948。

更严重的是pressure/input043，R/X比例为原值2倍。两种绝对方法32条均判断零采购足够，直接重算模型下界98.5529%—99.9958%，真目标在所保留的2个目标中，实际仅3/32恢复。没有采购，也没有失败回退。

该例平均历史对数赔率0.235，预测J为18.141，真实功率下J为17.554，但冻结真候选残差沿竞争方向的贡献为−28.271。无表计噪声的实际优势已为−10.482，表计平均仅贡献+0.238。去掉AC非线性仍3/32。主要失配来自正确结构的冻结参数，而非5%预测误差或新日AC非线性。

补充面板中，方向保护在真目标被保留且模型下界≥90%的799条里失败78条，非均匀额度在879条里失败88条。接近10%的平均失败率掩盖了上述固定条件的29/32失败。因此逐历史结果必须与总体平均并列，模型内概率不能直接作为实际AC可靠度。

## 大批次归因与附加评分

补充旧方案4次丢失恢复的平均J增量1.785，被参数偏差−1.687及表计−1.264抵消，AC平均修正仅−0.049。方向保护轮换的7次新增恢复反而平均J减少0.054、偏差改善6.421。完整恢复与J增长须分别报告。

历史P/Q高度相关。方向诊断中，历史偏离节点Q≈κP的能量约0.072%—0.087%，一条丢失恢复行动达到8.621%。这支持“行动进入历史很少覆盖的方向、冻结参数外推失准”的解释，尚非逐条预测收益的规则。

事前锁定的去共同电压分量附加评分：主面板无采购284→286、方向保护285→288；补充无采购948→940、方向保护959→955。它有取舍，未替换原主要评分。实际电压比较方差与独立假设之比主面板中位0.673、最大4.761；少数方向低估方差，均值偏差仍是上述反例主因。详见METER_MODEL_AUDIT.md和NATIVE_FAILURE_ANALYSIS.md。

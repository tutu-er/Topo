# 相对电压评分：附加分析锁定

在主800日、追加1408日仍运行时锁定本对照。设计依据仅为已完成R1/R2-fixed，尚未按大批次的辨识效果选择此指标。原始主要终点、采购策略、候选参数及全部已锁定协议保持不变。

每个时刻同时对量测和预测减去节点均值，使用Pi=I−11ᵀ/N，比较原始完整参数库的历史验证残差及新日残差：

`S_i_relative = ||(Y_history−P_history H_iᵀ) Pi||² + ||(Y_new−P_new H_iᵀ) Pi||²`。

根电压表同一误差进入所有节点，减去节点均值可精确消去该项。对称响应矩阵满足Pi ΔR=0时，ΔR只能是c11ᵀ；这一代数性质不自动保证有限、低激励P/Q观测下的全部拓扑信息都被保留。因此本对照同时记录改对和改错。

开发证据：R1全部方案40/64保持不变；R2-fixed除原对称保护外，其余方案40/64变为41/64，对称保护保持41/64。原历史32个条件的正确数18/32保持不变，但有1例改对和1例改错。它是评分变化带来的收益，不能算作灵活性采购收益。

只对两个锁定批次的相同观测作附加重评分。所有原始候选参数保持冻结，不重新辨识、不重新优化、不选择性删例；同一观测先后评分不增加独立样本数。只评价完整恢复、错误、配对改对／改错，不给未经重新校准的相对电压后验概率。两个指标分别给出各自无采购基线，以避免把评分作用归入采购作用。

精确允许路径、时间、开发证据哈希见`outputs/absolute_projection_secondary_lock_20261114.json`。本对照作为附加分析，不替换主确认结果，也不根据其结果重新调阈值。

# 根表计共享误差与相对电压评分核查

## 结论

实际量测确实含有同一时刻各节点共享的根电压表计误差，所以“每个电压响应格点的误差独立且等方差”与当前模拟器不完全一致。不过，在已完成开发组预先确定的历史赢家—第二名比较中，真实电压表计方差/当前独立误差模型方差的中位数约0.65，最大约1.51。这个缺口存在，但本组证据不支持把它作为整体效果弱的主要原因。

把每个时刻的电压响应减去节点平均值，可以精确消掉根表计误差，且不需要估计完整协方差矩阵。开发数据曾出现一个改善例：R2无服务由40/64变为41/64，与原对称加保护方法持平。但随后按事前锁定的次要指标检查完整批次，主800条无服务净增加2次恢复，44个历史条件的1408条重复路径净减少8次恢复。它改变了不同条件间的取舍，当前不支持用完全投影统一替代原评分。完整结果见第7节。

## 1. 当前量测实际怎样产生

实际代码为`unified_posterior_dr_20261112/physical.py::measured_channels`。用r表示一个时刻的真实根电压，v_n表示第n个真实节点电压，s表示电压表计的相对标准差，则

\[
r_m=r(1+sZ_0),\qquad v_{m,n}=v_n(1+sZ_n),\qquad
Y_n=r_m^2-v_{m,n}^2.
\]

同一时刻全部节点使用同一个Z_0；各Z_n与Z_0独立，不同时刻也独立。根电压物理变化与根表计误差是两件事：前者已经进入真实r与v，后者是这里的Z_0。

平方后有

\[
\mathbb E[Y_n]=(1+s^2)(r^2-v_n^2).
\]

定义去均值的标量表计误差A=2sZ+s²(Z²−1)，则E[A]=0，Var(A)=4s²+2s⁴。因此

\[
Y_n-\mathbb E[Y_n]=r^2A_0-v_n^2A_n.
\]

这一步同时说明两点：共享根误差带来相关性；平方也带来很小的均值偏移和非正态项。不能只把其中一个归入冻结参数偏差。

## 2. 对数赔率的精确电压表计方差

固定实测功率P与两个冻结候选，记d_t=(H_i−H_j)P_t。共同评分方差记为σ_s²，避免与电压表计幅值s混淆。两候选对数赔率中的随机电压项为sum(d_tn Y_tn)/σ_s²。给定真实物理状态与实测功率，其电压表计方差精确为

\[
V_{ij}=\frac{4s^2+2s^4}{\sigma_s^4}
\sum_t\left[
r_t^4\left(\sum_n d_{tn}\right)^2+
\sum_n v_{tn}^4d_{tn}^2
\right].
\]

第一项是根表计，第二项是各用户表计。这里σ_s⁴表示(σ_s²)²；Y和d均为标幺电压平方，σ_s²为其残差平方的尺度，所以V是无量纲对数赔率的方差。各比较共享噪声并不妨碍使用各自失败概率的联合上界。

现有名义模型采用V_iid=||d||²/σ_s²。若所有电压接近1，且σ_s²≈8s²，则

\[
\frac{V_{ij}}{V_{iid}}\approx
\frac12\left[1+\frac{\sum_t(\sum_n d_{tn})^2}{\sum_{t,n}d_{tn}^2}\right]
\in\left[\frac12,\frac{N+1}{2}\right].
\]

共同根误差是否放大比较方差，取决于候选预测差在不同节点上是否同向累积；相关性存在不等于所有比较的方差都被低估。当前σ_s²又是从历史残差估出的，可能已包含参数误差与功率量测误差，更不能直接使用最大放大倍数代替实际诊断。

这个方差是精确二阶矩，正态概率仍是一阶电压误差近似，因为A含Z²。若要求仅依赖均值与方差的严格概率界，可以把正态分位数换成单边方差不等式系数sqrt((1−α)/α)，通常会明显更保守。

## 3. 不引入完整协方差矩阵也能保持QCQP

规划时若使用预先给定的电压上界v_max，同时覆盖根与各用户电压，则可用

\[
\overline V_{ij}(u)=
\frac{(4s^2+2s^4)v_{max}^4}{\sigma_s^4}
\left[\sum_t\left(\sum_n d_{tn}(u)\right)^2+\|d(u)\|^2\right].
\]

因为d(u)对采购控制u是线性的，右侧仍是二次函数。用辅助变量a≥0写成V_bar(u)≤a²以及mu(u)≥z a，即保留当前二次约束形式。这个处理修正表计方差，不修正预测负荷误差、冻结参数均值偏差或实际交付偏差。当前批次没有实现或使用这一新约束。

## 4. 相对电压为何能消掉根表计误差

令Π=I−11ᵀ/N，即把每个时刻的节点平均值减去。由于1ᵀΠ=0，

\[
Y\Pi=-v_m^2\Pi.
\]

这对实际平方量测精确成立，不需要小噪声近似。预测也采用P HᵀΠ，相当于把H的每一列在输出节点方向减去平均值，即H改为ΠH，仍可使用现有N行矩阵接口。

相对预测差d_c=dΠ的节点和为零，其电压表计方差只剩

\[
V_c=\frac{4s^2+2s^4}{\sigma_c^4}\sum_{t,n}v_{tn}^4d_{c,tn}^2.
\]

若节点电压近似相等，在N−1个正交相对电压方向上可使用统一方差约4s²。保留N列的中心化数组时，列之间仍相关且秩为N−1；应按这个有效维度估尺度，不能把N列称为相互独立。当前诊断只比较完整恢复，没有计算新的投影后验或拒绝概率。

这个操作也会丢掉一部分信号。若两个响应矩阵的有功块R均对称，且Π(R_i−R_j)=0，则每列为常数，再由对称性可得R_i−R_j=c11ᵀ；无功块X同理。在正权树模型、完整响应矩阵可辨识的条件下，这对应全部用户共同经过的上游干线差别，用户之间的树距离不受影响。由此推到隐藏节点结构仍需要明确的正权、非退化树与充分P/Q激励；有限或共线的功率输入可能产生更多无法区分的情况。

还存在一个保留共同信息的理论备选。近1 p.u.且各表计同精度时，一阶正态模型在每个时刻给出的残差损失，除公共尺度外为

\[
\|r-\bar r\mathbf1\|^2+\frac{N}{N+1}\bar r^2.
\]

原因是相对方向的误差方差约4s²，而单位长度的公共方向方差约4s²(N+1)。这相当于把原来N·r_bar²的公共分量权重降至1/(N+1)，而完全投影将该权重置零。它仍是一个固定线性变换后的平方损失，保持QCQP接口；没有需要调的额外权重。但电压差异、参数偏差与P/Q误差仍须另行检查。

这个新指标在本次分析中提出，随后仅对原R1/R2开发观测做了重评分，没有加入已锁定的确认指标。脚本`common_mode_diagnostic.py`强制拒绝非development批次。结果与完全投影的逐例正确/错误分类一致：R1各法40/64；R2各法41/64；历史仍18/32，相对原评分1次救回、1次丢失。开发组没有显示它优于完全投影，但其保留公共信号的理论取舍明确。记录为`outputs/absolute_common_mode_r1_20261114_v1`及`..._r2_20261114_v1`；尚未测试对应的重新规划。

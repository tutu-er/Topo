# 线性DR与真实AC总体测试

本轮严格采用：真实新日功率→加预测误差→规划→真实网络AC→表计误差→完整历史加新日后验。候选和R/X冻结，评价电压只来自原AC网络。旧的`Y=HtP+e`抽样不参与本轮效果评价。

使用当前较简洁主线101的400份冻结库：RNJ引导、WZZT逐步加线、结束前联合重选；111另加末端局部重选，不混入本次DR总体分母。没有重新拟合辨识器。

## 设备和指标

只用确定性线性响应：`deltaP=历史节点功率峰值*x_hour`、`deltaQ=.35*deltaP`。x为可正可负的归一化小时请求。去掉全部设备功率、时窗、SOC、充放电方向、能量、截止和截断约束，不再交给旧设备执行器修复。二次费用为`mean(x²)`，是声明的合成计价，不是实证货币。实际调节幅度、净注入、AC失败和电压越限完整记录。

规划目标仍为最小费用，使预先确定的竞争者期望对数赔率增量至少达到`log(2),2,4`三档之一。目标取历史MAP；竞争者取历史后验至少1%的其他候选，并始终保留最强竞争者。最终评价使用完整原候选库。历史只计原32点验证，64点训练只用于已冻结的拟合。

设`D=Ht-Hj`，背景预测为Phat，线性功率变化为Bu，规划增强量为

\[
G_j(u)=[\|D(\widehat P+Bu)\|^2-\|D\widehat P\|^2]/(2\sigma^2).
\]

预测从真实新日P/Q分别添加独立5%乘性高斯误差得到，噪声流与0.5%P/Q表计误差独立；电压表计噪声和物理网络版本保持原输入设定。规划只读取预测、历史尺度、冻结候选和sigma²；不读取真实负荷、真实线路、AC电压或真拓扑。

## 简化求解，不使用ADMM

单竞争者问题是`min ||x||², x'Qx+2a'x>=gamma`。固定乘子lambda且`I-lambda Q`正定时，拉格朗日函数是严格凸二次式，极小点为`x=lambda*(I-lambda Q)^-1*a`。用一个标量方程令增强量等于gamma，即得原问题的可行点和对偶下界。最高特征方向的边界情形也单独处理。节点矩阵最多18维，小时结构重复，无需大矩阵逆或ADMM。

多竞争者先分别解上述问题。各单对最小费用的最大值是联合问题下界；若某份方案满足全部比较且上下界闭合，就完成相应精度的全局核验。否则从可核验的定向初值启动原生联合非凸QCQP，单计划总预算0.15秒。保留初值成本、求解器实际改进、停止原因和原问题界；有可行点不等于全局最优。

原生求解只用由可行费用推出的计算边界：任何更便宜解均在该球及其外包盒内。它不恢复任何设备能力限制，也不删除更好的原域解。

## 锁定范围

- 16个历史概率分层输入作求解和AC接口试运行，各1个新日。
- 主体：全部400个101库，四网络各100输入；每输入4个新日；无DR及三档优化DR、三档同费轮换，共11200个策略日记录。
- 主体完成后，按gamma=4的配对真后验变化，每网络锁2个改善最强输入及1个最弱对照；12输入各64个独立新日。全部三档强度保留，选例收益与总体效果分开。
- 求解失败执行明确的零动作兜底并计失败；AC失败保留缺失后验，恢复率分母包含失败。均不更换种子或删除难例。
- 所有原始P/Q/V、真实状态、预测、拟合矩阵和行动轨迹留私有输出；公开统计、合成费用、源哈希与可复核边界。

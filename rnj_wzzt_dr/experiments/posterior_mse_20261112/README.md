# 简单共同尺度的后验权重验证

按已确定的方案：`sigma²=min(validation MSE)`，`s=2 sigma²/N`，`w=softmax(-MSE/s)`。候选参数冻结，按独立、零均值、同方差高斯残差处理，均匀拓扑先验；本次没有调尺度、改辨识器或增加协方差模型。

## 本次结论

100/100 个已完成候选库成功计算，11 项解析／接口检查通过。前两组是同一 48 历史输入的两种方法，补充组是四个已完成严格96点输入；不是100个独立新输入。

| 来源 | 完整恢复 | 最高权重≥90%：正确／入选 | 高权重但错误 |
|---|---:|---:|---:|
| 原48输入，101（R＋W＋E） | 39/48 | 38/46 | 8 |
| 原48输入，111（R＋W＋T＋E） | 38/48 | 37/46 | 9 |
| 严格总96点，固定101／relative_gain=0 | 4/4 | 4/4 | 0 |

MAP在100/100中与原MSE首选拓扑一致。历史主组平均最高权重98.52%，完整恢复率80.21%；92次权重≥90%的方法／输入比较中，75次正确、17次错误，实际正确比例81.52%。17次错误全部来自候选库缺完整真拓扑；本批库含真的77次全部选对。两个方法复用观测，以上计数不能当作92次独立试验。

这支持把公式作为**给定候选库内的相对证据**。本批没有“库含真但MAP选错”的案例，尚不足以检验该条件下高权重选错的频率。直接把库内权重当作完整物理拓扑的无条件正确概率，会漏掉候选覆盖不足。

## 难区分候选

沿用现有`.003`相对MSE门槛，得到11次方法／输入比较，来自7个不同历史输入。9次库含真且MAP正确；另外2次来自同一个缺真拓扑的输入在两种方法下的结果。

- pengwah18，b1001，电压噪声`.0002`：101和111的最高权重均为 **57.44%**，都选对，体现两候选证据较弱。
- pengwah18，b1002，电压噪声`.0002`：两种方法最高权重均为 **98.90%**，都选对。
- flynn16，b1001，电压噪声`.0010`：两种方法最高权重均为 **79.19%**，都选错；原库缺完整真拓扑。

逐项概率见 [results/near_pairs.csv](results/near_pairs.csv)，完整统计见 [results/REPORT.md](results/REPORT.md)。

## 如何算与如何核验

同一活动拓扑若有多个冻结参数点，先按训练MSE最小、原序号择一，再赋均匀拓扑先验；没有根据验证结果重拟合或挑参数。所有原点仍保存在私有审计中。未新增阻抗阈值、删弱线或剔除不利候选。

原48输入使用训练96＋验证288；补充组使用同一天前64训练、后32验证。N均为实际节点数×验证时槽数。历史参数、原始MSE及方差、完整点表、输入路径／哈希和源快照保存在忽略的 `outputs/posterior_mse_validation_20261112_v1/`。公开表只含概率、候选数量和拓扑恢复指标。

先锁协议／源码／输入，再计算和封存全部权重，之后读取真拓扑评价。原始观测test文件未打开；正在运行的large96批次未纳入。此次是历史数据回溯，不是独立概率校准，也没有新DR或AC执行。

独立核验逐支持重建P/Q预测、用高斯似然重算概率；最大概率差约`1.20e-13`。原覆盖台账96/96对照一致；模型参数、来源和权重封存哈希均核验通过。完整恢复沿用原指标：非单点、非全集的活动内部支持与真族一致。

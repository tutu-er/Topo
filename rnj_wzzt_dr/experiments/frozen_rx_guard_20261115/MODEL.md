# 本轮增加了什么

评分矩阵 `H=[R X]`、历史损失和评分方差 `sigma_s^2` 全部冻结。三种原概率约束及原方向保护均保留。本轮只比较两种调度预算，各自单独追加；没有改变候选、设备、执行器或价格。

## 1. P/Q 偏离预算

在每个节点的训练数据上计算仿射关系 `q=a+k p`，以其残差 RMS `s` 表示原来的偏离幅度。调度增量不含截距：

\[
 B_{PQ}(u)=\frac1{T_hN}\sum_{h=1}^{T_h}\sum_{n=1}^N
 \left(\frac{\Delta q_{n,h}-k_n\Delta p_{n,h}}{s_n}\right)^2\le 4^2.
\]

这里 `T_h=24` 是小时数，`N` 是量测节点数；P/Q 及 `s` 使用相容的功率单位。它限制偏离历史 P/Q 变化方向的程度，不要求 P/Q 严格成比例。采用逐节点标准化，再汇总预算；预算仍可在节点和时段之间分配，不能解读成每个节点各有一个独立的上界。调度仍须满足所有原设备约束。

## 2. 响应不确定性预算

固定每个历史代表候选的支路支持，把其 R/X 系数排列为 `theta`。历史线性设计满足 `y=F theta+e`。根据原电压量测误差法则，先计算一次

\[
 C=(F^TF)^{-1}\left(\sum_tF_t^T\Sigma_eF_t\right)(F^TF)^{-1}.
\]

`C` 表示固定支持、无约束线性估计近似下，哪些参数组合容易受到量测噪声影响。所有系数方向都保留，包括拟合为零的系数；矩阵秩亏直接记录失败。代码用列标准化后的分解计算上述同一矩阵，不重新拟合 R/X。

令 `Phi_delta(u)` 是调度增量对应的设计矩阵，要求每个代表候选满足

\[
 W(u)=\frac{\operatorname{tr}[\Phi_\Delta(u)C\Phi_\Delta(u)^T]}
 {T_{new}N\sigma_s^2}\le 0.25^2.
\]

它限制调度所产生响应的估计方差：允许的平均响应不确定性 RMS 为评分残差尺度的四分之一。这是预先声明的工程预算。固定支持选择、P/Q 输入误差、参数系统偏差及校准均值的误差不在这个方差式中，实际响应误差仍须单独核验。

两种新增限制都是 `u^T Q u <= b`、`Q` 半正定。原辨识约束保留非凸二次项，整体仍为 QCQP。求解器使用原非凸分支搜索和同一初值池；新增预算通过后才接受初值或新解。

## 3. 为什么限制后仍可能出现负例

把 P/Q 合记为 `x`，两个候选的评分差为 `D=H_i-H_j`，规划使用的冻结校准均值为 `Kx`，真实无噪声电压变换为 `f(x)`。定义 `b(x)=f(x)-Kx`。两候选对数评分优势的真实值与预测值之差恰好为

\[
 L_{clean}(x)-L_K(x)=\frac{\langle b(x),Dx\rangle}{\sigma_s^2}.
\]

令 `x=x0+delta x`、`b=b0+delta b`，采购增益的预测误差就是

\[
 \Delta L_{clean}-\Delta L_K=
 \frac{\langle b_0,D\Delta x\rangle+
 \langle\Delta b,D(x_0+\Delta x)\rangle}{\sigma_s^2}.
\]

因此，即使调度没有显著增加电压预测误差，原有偏差也可能因为候选差的方向改变而更支持错误候选。P/Q 预算限制偏离原运行方向，W 预算限制历史数据难以估准的参数方向；二者都不能直接消除这两项系统偏差。

上述恒等式使用相同实际功率输入。预测功率与实际交付的差异、量测噪声另列。实验分别报告实际 H 增量误差、实际 K 增量误差、预测和实际证据增量，以及全候选选模结果。

## 4. 结果口径

主恢复指标沿用原内部拓扑分组；包含单节点和公共项的全部响应支持完全一致另列。报价失败后的零采购保留在执行分母中，单独标记，不能计作找到了满足新增预算和概率门槛的方案。费用同时保留调用费目标及预约加调用的实际结算费。

费用证书须通过直接可行性和求解轨迹检查。若求解过程中报告的下界高于后来核验可行的费用，即使最终求解状态显示最优或 gap 为零，也只保留可行报价，并记录证书冲突。

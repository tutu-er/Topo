# 配电灵活性采购：资源、费用与辨识效果

2026-11-14。原六策略开发与确认均已完成、独立核验通过；另有确认前锁定的调用预算修正。当前证据支持保留少量关键节点的无功调用，**不支持为了名称强制增加有功，也不支持单靠容量费改善辨识**。

## 结论与模型解释

无功可以作为配电灵活性服务单独采购。若本研究主要调用可控补偿器，具体名称用“面向拓扑辨识的无功服务采购”更清楚。官方Power Potential和Q-Flex资料支持独立无功服务；面向拓扑辨识是本研究的用途。原文、阅读范围与市场适用边界见 [LITERATURE.md](LITERATURE.md)。

模型允许P/Q按量采购，采用给定示例报价，并非已实现了完整市场竞价或价格弹性估计。增加P变量、容量计费或ADMM名称本身不会增加论文的核心贡献。作为RNJ＋WZZT后续增强环节，直接求解QCQP、核验真实执行收益，是清楚的技术路线；独立优化算法的新意需要另有方法与证据。

当前15个Q供应点可提供36 kvar，但开发批32条方案记录（18组不同动作）全部精确只调用301、302、303、304，P为零。删去其他Q及P后，数组、费用、原证据均不变，32/32通过原验收。四点单侧能力为2＋2＋5＋5＝14 kvar。这说明已完成动作可以由少数节点实现，不需要把所有供应候选点解释为已新建补偿器。设备安装和控制权限仍是声明的工程情景，PV登记kW不能替代逆变器kVA。配置与纯P不可达上界见 [RESOURCE_NOTES.md](RESOURCE_NOTES.md)。

使用Pengwah18测试网，源数据四日窗口从2024-10-14当地08:00开始；采购执行窗口实际为2024-10-17 08:00至10月18日08:00（Europe/Berlin，右端不含）。案例ID中的2024-10-14是历史窗口起日，原稿将其称为执行物理日，现更正。

## 确认结果

每格分母256。“正确”指内部拓扑；含公共响应项的完整支持一致数仍为0，单独保留。错误高权重是选错且相对权重至少90%，并非已经校准的真实性概率。

|---|---:|---:|---:|---:|---:|
| 无采购 | 122 | 2 | 122 | 2 | 0／0 |

原资源参考方案相对无采购新增99次正确、丢失2次，恢复率47.66%→85.55%；同时错误高权重由2次增加至18次。扩展资源稳定方案新增102次、丢失3次。稳定方案相对扩展调用费细化新增13次、丢失8次，净增5次，并非每条路径都更好。预先设定的“恢复改善且错误高权重不增加”标准未全面满足。

开发结果方向一致：原资源无采购61/128、参考107/128、容量43/128；扩展资源61/128、参考108/128、调用费细化105/128、容量46/128。稳定规则在两阶段16/16份预测均保留参考方案；原资源细化没有实质改善，扩展资源部分小额降费改变了动作。

追加策略限制调用费不超过同预测参考方案加0.01元，再优化总费。它把无约束容量方案的97/256恢复到216/256，但比原参考219/256少3次：新增1次、丢失4次。总费节省0.546元，错误高权重18→16。这是费用与结果的取舍，未找到全面优于参考方案的经济修正。详见 [追加协议与实现](../flexibility_call_budget_20261114/PROTOCOL.md)。

## 为什么容量方案失败

原资源确认批，调用费方案与容量方案预测距离增量都约6.458；干净AC的真实候选对数赔率增量却分别为5.168和−1.423，实测为5.086和−1.569。多调用并不自动带来更多正确证据。

开发原资源子集的精确分解显示：实际J几乎不变（6.1667→6.1642），但冻结参数偏差投影恶化6.7048。其中参数响应误差恶化7.1091，AC线性化余项反而改善0.4044。新增Q响应误差的二阶投影是主项；303自身不利项扩大，而301相关有利贡献减少。总响应误差能量相近，变化主要在方向。

容量费促使方案减少购买节点、重复使用已购买能力：总购Q峰值约13.6–13.9降至5 kvar，调用时间由3小时延长到12–14小时。303的单次幅度仍约5 kvar，不能把本例概括成“所有动作幅度摊薄”。逐项公式、恒等校验及节点交互见 [MECHANISM.md](MECHANISM.md)。

另一条看似直接的修正——消除逐时公共电压残差——也失败。旧三组优化正确数29、23、24/32降至14、4、13/32；根表计公共误差确已消除，但同时丢掉了有利于正确冻结候选的评分信息。完整正反结果见 [中心化诊断](CENTERED_SCORE_DIAGNOSTIC.md)。本轮保留原评分。

## 费用、电气结果与求解边界

所有策略按同一价表结算：请求峰值容量费＋实际调用费。示例容量价P为0.5元/(kW·服务日)、Q为0.5元/(kvar·服务日)，Q调用价0.05元/kvarh；双向Q按单侧幅度收费一次。

无动作日电量1833.997 kWh；示例夜/日/晚电价0.3/0.5/0.8元/kWh对应日电费1002.458元。开发原参考的容量费6.880元、调用费1.794元，合8.674元，约为日电费0.865%；额外网损电费0.044元。这是短期服务支付，设备投资、补偿器辅助用电尚未计入。几元服务费有其规模原因，不能当成完整部署成本。

两阶段全部执行电压约1.00151–1.02339 pu，未越过0.95–1.05；网损变化、支路电流和根P/Q/S均独立核算。原数据缺热额定值及变压器铭牌，200 kVA是标幺基准，未据此报告热负载率。

原六策略每预测先用150秒生成共享参考，再分别追加300秒优化调用费或总费。单方法实际计入共享准备约450秒。两阶段共48次原生求解均达到时间限制；原资源8次调用费细化全部保留参考费用，扩展资源8次中仅3次实质降费。容量求解费用界未闭合；确认批间隙约72.7%–99.7%。追加4次受调用预算限制的求解也全部限时，间隙79.8%左右，0回退。保留了有效可行报价和对应问题的费用下界，均未证全局最优。受限问题下界不用于未受限问题。

## 实际欧姆下限

当前两网的转换为 $|Z_C|=0.4\sqrt{r_C^2+x_C^2}\ \Omega$。
目前采用的**8天拟合＋2天验证**应单列：

| 全部线路的欧姆下限 | 完整恢复 | 真实遗漏总数 | 多余支路总数 |
|---|---:|---:|---:|
| 0，原参数基线 | 3/8 | 0 | 5 |
| 0.001Ω | 5/8 | 0 | 3 |
| 0.002Ω | 6/8 | 0 | 2 |
| **0.003Ω** | **8/8** | **0** | **0** |
| 0.005Ω | 8/8 | 0 | 0 |
| 0.008Ω | 7/8 | 1 | 0 |

这8组原来全部内部连接正确，5组额外拟合出小于0.003Ω的公共上游项。
0.003Ω逐条收缩清掉这些多余项，并保留真实线路。因此，针对目前8天主设置，
**先采用0.003Ω的全支路下限**较合适；继续增加到0.008Ω已有误删。
这是当前开发数据上的建议，尚未作新的独立确认。

对**全部线路**逐条收缩的历史验证结果为：

| 实际阻抗幅值下限 | 当前40组 | 当前16组 |
|---|---:|---:|
| 0 | 13/40 | 5/16 |
| 0.0005Ω | 16/40 | 7/16 |
| 0.001Ω | 19/40 | 9/16 |
| 0.002Ω | 20/40 | 12/16 |
| 0.003Ω | 20/40 | 14/16 |
| 0.005Ω | 20/40 | 13/16 |
| 0.008Ω | 18/40 | 13/16 |

这两网真实最短支路约0.01337Ω，但拟合误差可使真实支路的估计值远低于真值。
例如0.001Ω已在当前40组中造成2条真实末端遗漏；“门槛低于真最短线”并不保证估计时不误删。
旧压力中弱边×0.1的真内部线约0.002918–0.005134Ω，因此更不能把0.005Ω直接当通用下限。
本批欧姆网格只在当前56组验证；旧400的压力参数量级另有只读来源重构核算。

## 建议和未解决的内容

- **当前8天主设置优先用0.003Ω，对所有支路检查**。已测0.003、0.005两档均完整恢复8/8，
  采用较小值给弱线留余量。较短历史及旧弱线路压力下保留以下更保守的对照。
- 若要求**每条线路**满足同一种相对下限，建议以**0.01为保守起点，0.02作敏感性对照**。
  当前两网专项使用0.04有较高完整恢复，但旧主批会多丢失原正确输出，不作为通用默认。
- 若目的是删除不可靠的内部细分与公共项，复用末端豁免规则时，**0.04–0.08是较稳妥区间**。
  0.08在这批数据上兼顾当前两网和旧压力；该规则不保证末端线路也达到0.08。
- 若必须写成欧姆，当前56组可从0.0005–0.001Ω保守清理；0.002–0.003Ω清理更强，但已有误删。
  不把无量纲门槛与物理欧姆门槛相互替代，也不按每个输入真值挑门槛。
- 下限主要清理弱的多余支路，无法补回任何原候选中都没有的真实连接。逐条删除也没有全局结构最优保证。
- 结构改善没有解决X参数误差。全部线路相对0.04下，历史winner的平均R/X矩阵误差：
  当前40组为5.342%/41.369%→5.247%/41.128%；当前16组为3.581%/24.063%→3.584%/23.745%。
  后续灵活性规划仍需单独检查响应偏差。

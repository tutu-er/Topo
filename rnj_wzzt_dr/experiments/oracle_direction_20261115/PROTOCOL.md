# 真实矩阵的离线方向检查

本轮是带真值的可行方向诊断，不是可部署采购方法。仅使用已完成的三个开发输入：Soumalas噪声×.5、×1，Pengwah噪声×2；冻结原候选、R/X、历史评分、预测、资源、时窗、能量和价格，不新增设备或更改数据。

## 数学问题

目标c为原完整库中内部拓扑正确候选里历史SSE最低的点，真值仅用于本诊断选择c及构造真实一阶矩阵H*。所有与c内部拓扑不同的native点都作为j，不删弱、零或重复响应对。P/Q基准是原冻结forecast，不打开真实新日P/Q/V或新运行AC。

令X(u)=forecast+Bu，Jj(u)=||(Hc−Hj)X(u)||²/(2sigma²)，e(u)=||(H*−Hc)X(u)||²/(2sigma²)，其中norm对新日全96时刻与全部量测节点求和。两问题都在原资源域中最大化共同相对改善z≥0，要求

`Jj(u) >= Jj(0) + z*max(1,Jj(0))`，对全部j。

distance_only只加上述距离约束。protected另加 `e(u) <= (1-z)*e(0)`；本批e(0)>0，故z>0同时证明误差能量下降和全部距离增加，z≤1。原式直接核验阈值1e−6用于称明显正z，所有更小正值仍原样保留。零动作z=0始终为基准。

功率对u仿射、矩阵冻结，均为QCQP。没有增加原概率门槛或原方向保护，以便直接检验用户提出的‘只增距离’框架。结果同时核算真实一阶全库SSE/赔率，不能把误差减小与距离增大直接写成选模保证。

## 预算与信息

3输入×2问题，共6个正式报价，每报价最多600秒，3输入并行，每个Gurobi单线程。原公共LP初值池及原150秒锚方案复用并逐点核验；不增加新初值搜索或跨模式热启动。零点额外明确提供。优化目标是方向改善，不是费用；记录原预约加调用费、P/Q量和幅度，不能称最小费用采购。

先运行2秒、三输入六问题接线检查，独立核验展开、原资源、正z及失败分母后再正式。全部输入、物理CSV、有效源、环境、初值和预算事前封存；不覆盖旧结果。最大化问题的已核验z是下界，原生全局界是上界；冲突或数值问题完整保留，不根据solver status认定全局最优。找不到正z仅称未找到该共同改善方向，不能据此排除其他辨识设计。

## 评价

保存每个候选的J、e、响应误差与距离的比例、真实一阶SSE优势、全库winner、历史与新日累计评分、费用及调用量。无动作和原已封存三方案仅作同一线性oracle下的代数参考，不算新AC结果。

行动封存后，复用原16条整段设备响应eta，以forecast P作为执行器负荷基准，重放资源交付和截断，再用Y=H*X计算线性真值评分；不另采样量测噪声、不跑AC、不打开实际新日数据。这是同一预测背景下的线性执行敏感性，16条不算独立负荷日期，不报实际电网恢复率或新概率校准。

如找到方向，分析历史数据识别它所缺的信息；本轮不以真实矩阵生成的行动训练或调节可部署策略。若未找到，保留原域、全部对手、时限与未决，不为得到正结果移除对手或改资源。

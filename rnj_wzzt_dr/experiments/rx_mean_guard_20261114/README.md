## 模型与实际检验范围

[事前协议](PROTOCOL.md)保留原冻结评分H、完整五参数点最终MSE、原资源与误差法则，只用已知历史192＋96点，在每个固定结构内拟合规划均值K。新增条件检查校正后的预期评分是否足以战胜竞争者；最终H不重拟合。

对目标i和竞争者j，定义候选预测距离J、历史分数差h，采购后的功率为A(u)。预期总分数是

\[
\mu_{ij}(u)=h_{ij}+J_{ij}(u)
+\frac{\langle A(u)(K_i-H_i)^\top,A(u)(H_i-H_j)^\top\rangle}{\sigma_s^2}.
\]

后面的内积表示规划均值偏离评分模型时，实际证据可能增加或减少多少。声明独立同方差正态残差后，要求`mu − z sqrt(2J) >= tie`，并保留全部旧约束；非负辅助变量给出等价QCQP。推导见[响应误差说明](../flexibility_stability_20261114/R_X_UNCERTAINTY.md)。

本批仍为同一个已知物理日，使用新预测、响应和量测随机流。实际执行窗口为当地2024-10-17 08:00至18日08:00；案例ID的10月14日是历史起日。P/Q分别来自含新能源登记的实测净馈线曲线，V由测试网AC产生，数据并非固定P/Q比例。详细来源、日期及拟合诊断见[数据核查](DATA_AND_BIAS_CHECK.md)。

新方案在规划模型中略好，在真实AC中反而较差。即使提供实际P/Q，模型仍高估约1.99个分数单位；因此主要缺口不能仅归于负荷预测误差。正确结构X矩阵误差由21.87%仅降至20.54%，关键303列几乎没有变化；R误差反而从4.45%升至5.47%。原QP已收敛，完整历史没有提供足够的新方向信息。

还对旧确认批做了反例复算：4个原参考和4个较差容量方案全部通过新条件；后者实际恢复97/256，低于无采购122/256。新增均值条件没有排除已知失败动作，见[逐方案核查](DATA_AND_BIAS_CHECK.md)。

新方案声明模型下的代表库成功下界为97.370%–97.505%，实际AC内部恢复为82.8125%。均值和误差法则没有准确描述实际执行，规划下界不能替代实际成功率。规划代表库与最终完整参数库的范围也不同；本批全库检查已确认主要比较4对2控制结果，未将本次损失归因于省略了其他参数点。

# 四类设备资源重配置：预先锁定的配对测试

本轮只改变灵活性资源模型。历史原生候选、R/X、历史赢家、全部异族竞争者、历史评分、概率式、P/Q偏离带、负荷预测及量测误差沿用已完成的 `node_time_pq_execution_20261115_v1`。生产默认不变，不继续SDP或ADMM。

## 输入与比较

- 三个已研究输入：Pengwah18 / 2024-01-04 / s2 / m2；Soumalas11 / 同日 / s2 / m0.5、m1。它们只有两个物理网络日背景。
- 三种原概率式：正态、固定功率指数、含预测误差指数。历史赢家单目标，对比全部异族原生参数点，停止与验收规则沿用原引擎。
- 每输入、每概率式16条原配对路径，共144条新策略记录；主比较144条既有带约束记录，同时引用48条共同零采购路径。相同零采购AC可以复用，不能算新的独立样本。
- 这些输入与执行路径已被研究，本轮称开发配对重放，不称独立确认或首次测试。不得按本轮AC表现更换节点、容量、阈值或误差。

## 资源与信息边界

按历史开始前登记容量乘原节点缩放，分别取前三个PV、前两个EV、前两个热水、前两个电池节点；容量相同时按节点编号。参与比例沿用10%。选址不读取真实拓扑、实际未来、候选响应强度或既有恢复结果。

登记提供聚合有功kW，缺少分项设备曲线、逆变器kVA、电池kWh及SOC。缺失参数作为统一设备场景假设封存，逐项记录依据；不能称实际设备逐台运行。取消旧SVG、Q95取档和重点节点1/5 kvar下限。

- PV：声明冬季gross可用出力曲线，基线发电不超过可用量；不以净反送估算总光伏。PV额定P、逆变器S和Q服务上限分列。小时动作对四个15分钟点分别满足容量限制。
- EV：沿用普通单向充电设备，18–07允许充电，向网放电关闭；22–04的事前充电基线可在连接窗内转移，离站需求保持。减少基线充电不称V2G。
- 电阻热水：实际有功非负且受额定功率限制，满足预定用热、温度缓冲及日末恢复；不设独立Q。
- 家庭电池：独立AC逆变器，E/P=2小时，S=P；SOC范围20%–90%，初末50%，充/放效率各95%。当地10–16只允许充电、18–23只允许放电，其余有功为零。Q合同不超过0.4S，且仅在上述服务窗开放，满足同一逆变器P/Q圆约束。
- PV和电池Q均来自明确声明的可控逆变器情景，不能由存在PV/电池登记直接推出远程控制已经安装。

所有节点使用 `net_new = net_old + sum(device_new-device_baseline)`。不向原实测净负荷重复添加设备基线。零动作必须精确返回原净P/Q且每类设备基线可行。首版忽略小量待机、无功转换损耗和日内电池自放电；保留充放电损耗。

## 求解和执行

先做零采购条件核算。旧初值只按相同物理设备ID和动作单位映射，旧独立SVG不能改名PV-Q/电池。映射初值必须重新检查设备域与历史带，记录被拒绝原因与准备时间；不另造搜索或跨模式使用最终动作。每份正式报价总预算1200秒，保留原生求解日志、可行点来源、费用上下界、间隙、失败和超时。资源域因预锁充放方向为凸域，完整证据QCQP仍可非凸。

先运行每输入每模式一条路径、短预算的接线检查，独立审计通过后执行16条正式重放。正式运行前封存协议、输入、源代码、环境、预测、设备基线、带宽和随机流；所有动作及报价封存后才打开真实新日/AC。

原P/Q/V/root噪声数组逐值复用。原设备整段响应倍率按物理ID映射；新增电池另用预锁随机流，倍率仍服从原U[0.9,1]。同一设备的P/Q使用同一整段倍率，使交付位于基线与可行计划的连线上；不让独立P/Q倍率破坏逆变器或终端状态约束。新增设备响应与旧SVG不能逐个对应，该差别须说明。

无已验证可行报价时执行零采购，保留失败报价与回退状态。资源约束和SOC必须在交付后复核；历史P/Q带作为规划可靠性限制，实际交付超出另列，不暗中裁剪设备响应以修饰结果。

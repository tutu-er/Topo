# 弱历史证据下的配网灵活性测试

目标是寻找已有方法选对拓扑、历史后验优势较小的条件，再检查有限客户侧灵活性能否提高独立新日的平均证据与后验。保留库缺真拓扑、求解失败和后验下降的结果。

基础网架、线路与原 AC 程序保持原版本。使用上一阶段 10 项 PV、EV、热资源配置；高接入场景增加节点104的4.5 kWp / 3.75 kVA PV与节点107的3.68 kW EV，共12项。历史与新日都包含各场景固定设备基线。它是项目合成 paper15 算例，不作为实测网络或外部标准网架。

第一批36个条件：高接入场景下，48/96/192历史点 × 0.05%/0.1%/0.2%电压表计标准差 × 常规/更同步/晚高峰负荷；另有当前接入水平96点的9个对照。P/Q表计标准差0.5%，规划预测相对标准差5%。48点是完整一天均匀30分钟采样，96点是一天15分钟采样，192点是两天15分钟采样；前2/3训练、后1/3验证。

历史调用原101辨识器，每次90秒总预算、单个MILP30秒、QP10秒、最终输出预留10秒；参数、候选库、误差尺度和历史SSE在新日之前冻结。90秒是本轮有限搜索预算，保留提前停止与超时，结果不称全局辨识最优。

规划沿用原费用最小化QCQP：对所有竞争者要求名义期望对数赔率增量至少log(1.5)，另设log(1.1)较小目标，同时保留现有历史残差校正下的双向非下降条件。总求解时间3秒，包含支持LP初值与QCQP；记录初值可行性、实际改进、可行费用与原问题有效下界。

每个新日先生成实际负荷，加入独立5%预测误差供规划；方案封存后，打开各资源整日0.9—1随机执行系数，运行原AC及表计误差。无服务、优化服务、同预算轮换共用实际日、执行系数与表计随机流。轮换满足相同线性设备域，按计划费用缩放，实际结算另列。两档增量均为模型中的证据要求，实际后验由AC观测评价。

最多12个合格弱证据条件、2个易例与2个缺真候选对照做每例2日开发检查。若弱证据合格历史少于4个或开发正例少于2个，按预先锁定规则再开第二个36条件历史种子。最多4个开发正例及2个弱/负对照锁定后，每例32个独立新日确认。针对性选例与确认分开，结果仅用于所选条件；不同策略不重复计作独立日。

运行入口：`python -m rnj_wzzt_dr.experiments.flexibility_sweep_20261113.study <action> --out <private-output>`。顺序为prepare、fit、qualify、select-development、development、extension（必要时重复fit/select-development/development）、select-confirmation、confirmation。每次只处理尚未运行的任务，既有完成标记、失败与未完成锁均保留。

输入哈希、源码快照、环境、预算和随机流在私有输出protocol.json及lock.json中事前记录。原始P/Q/V、拟合矩阵、逐日报价轨迹不进入Git。

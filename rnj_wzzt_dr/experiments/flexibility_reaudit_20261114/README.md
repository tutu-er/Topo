# 从参数拟合到灵活性执行的重新核查

2026-11-14。本轮按预先记录的 [协议](PROTOCOL.md) 扩大资源覆盖、延长求解，并检查参数与判据的关系。已完成18次参数拟合诊断、原16输入响应核算、三个资源配置的480条策略执行和独立核验。主要发现：更广的控制入口可以改善本难例，但其作用是改变误差对辨识证据的投影，并未修复冻结X参数。原批次不覆盖。

## 无功预测不准是否说明X估计不准

在当前平方电压降表示中，令 `Y=Vroot²−V²`，`A=[P,Q]`，候选预测为 `A Hᵀ`。H的前半列是有功响应，后半列是无功响应。纯Q动作的预测变化由后半列决定。因此，在同一个动作、同一基准状态下，无功电压变化存在系统偏差，首先说明该无功响应矩阵不准。

这些系数包含电压平方的系数2和标幺基准，不能直接当成线路欧姆数。各条R/X在历史上共同拟合，相关的P/Q及支路贡献可以相互补偿，所以Q响应失准也要求检查R和X的分离能力。它本身不证明每条线路的R都错。

此前已完成的Pengwah诊断给出了进一步证据：冻结候选对采购动作的电压平方变化有约25%的相对误差；使用真实线路构造的线性响应与AC变化差约0.4%～0.45%。这一输入中，主要问题在冻结响应参数，AC非线性贡献较小。正确内部结构H4将两条真实非零X响应拟合到零，同时把贡献分配到其他支路。

本轮两个固定族原参数逐系数复现；换另一种凸求解方法，最大差约1.1×10⁻¹³。H4的R响应矩阵相对误差4.45%，X响应矩阵21.87%。其设计矩阵满列秩52，原条件数约1840、列归一后48.4；说明需要检查Q幅值、量测误差和支路贡献分离，而非把它说成严格不可辨识或求解没收敛。放开非负产生9个负X，训练误差仅降约0.38%，两类已有Q动作误差却从约25%升至约78%～85%。增加简单平方参数惩罚也没有修复：H4取λ=0.1时验证MSE稍降，动作误差稍升；λ=1明显恶化。完整结果见 [PARAMETER_AUDIT.md](PARAMETER_AUDIT.md)，正式候选未据此修改。

进一步对原16个历史胜出模型全部核算，R响应相对误差中位3.77%（2.60%～5.51%），X响应中位21.82%（10.77%～34.78%）。15个内部拓扑正确输入的X误差中位仍为21.60%。240个Q输入方向的列误差中位17.18%，最大118.97%。因此无功响应误差并非只有这个困难输入存在；结构恢复好与响应参数准需要分别验收。这些数值由真实参数在离线诊断中计算，未进入采购规则。入口为 [population_response_audit.py](population_response_audit.py)。

## 为什么增加预测距离仍可能降低辨识准确率

给定功率A，对候选t和j，记 `d=A(Ht−Hj)ᵀ`，`b=E[Y|A]−A Htᵀ`。历史对数赔率为h，统一误差尺度为σ²。直接展开两者残差平方差可得

\[
E[L_{tj}\mid A]=h+\underbrace{\frac{\|d\|_F^2}{2\sigma^2}}_{J}
             +\underbrace{\frac{\langle b,d\rangle}{\sigma^2}}_{B}.
\]

J表示两套冻结参数预测得多不一样；B表示参考模型的电压偏差是否抵消了这种区分。执行前后的平均证据变化是 `ΔJ+ΔB`。因此，增量约束只要求 `ΔJ≥2` 时，模型偏差项可以更负，实际证据反而下降。绝对恢复约束改变了J的要求，但它仍需要正确的响应模型；它不能自行消除B。

已有历史方向保护用每个电压输出的一个倍率共同调整P与Q响应。该修正既没有分别辨识R/X，也没有给新增Q方向提供误差保证。在旧确认批，正确结构的偏差方向部分可预测，但偏差幅度明显低估；错误结构的预测偏差方向也有错误。增加资源与求解时间分别解决动作选择范围和数值优化问题，不应被解释为参数校准。

执行接口还有一个独立差别：当前报价按名义完整动作规划，实际设备整日交付倍率为[0.9,1]，规划负荷还有5%预测误差。原绝对约束的条件可靠度并未覆盖这些随机量。本轮实际ΔJ仍约为规划值的九成，与此前相近；这与参数偏差抵消证据是不同的损失来源。对期望方案，可把已设定的交付均值0.95和方差直接计入二次期望距离，仍保留QCQP；直接把期望距离代入正态概率门槛则不构成原概率保证。

## 更合理的下一步顺序

优先处理响应误差，并统一规划与最终评分的候选参数范围。范围核查发现，已有3360条策略记录中，代表点选择与全部原参数点选择的结果均相同；本难例H2/H4也都在代表库中。因此范围不一致应修正，但它没有解释本批无功收益下降。

对历史数据覆盖不足的Q方向，单纯加大采购量会放大外推。可执行的下一步是小幅正负Q试探，通过动作前后电压差估计局部响应；将这部分观测用于重新校准后冻结参数，再用另一段观测评价辨识。这样区分校准数据与评价数据，避免在看到最终结果后回拟参数。

若希望继续保持QCQP，可用若干历史分块拟合得到的响应模型分别构造二次证据约束，而不只信一个输出倍率。有限模型组能否覆盖实际动作方向仍需独立验证，不能直接把组内最坏结果解释为真实可靠度。本轮不修改冻结候选以混合这些影响。

更直接的约束修正是把偏差放进绝对要求本身：如果独立校准后得到冻结响应K，令 `B(u)=〈A(u)(K−Ht)ᵀ,A(u)(Ht−Hj)ᵀ〉/σ²`，则在给定功率及独立同方差正态电压误差下，比较对的条件要求为

\[
h+J(u)+B(u)-z\sqrt{2J(u)}\ge\delta.
\]

δ为最终比较所需的门槛，z为指定可靠度的正态分位数。A(u)随线性资源动作变化，所以J和B均为二次式。引入非负变量s，写成 `J(u)≤s²` 和 `h+J(u)+B(u)−δ≥z√2 s`，仍是QCQP。这个推导说明修正偏差不必放弃当前形式；能否得到可靠的K才是待验证部分。当前实现的方向保护只约束预测增量非负，还没有完成这种独立校准后的绝对约束。

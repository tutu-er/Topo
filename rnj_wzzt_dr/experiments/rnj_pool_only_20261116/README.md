## E具体做什么

E先汇总RNJ连接池、W/T路径中出现的连接和两节点组合。池中每个集合表示某条线路下游有哪些观测用户，
例如`{1,2}`；E可组合嵌套或互不相交的集合，禁止同时选择`{1,2}`和`{2,3}`这种交叉集合。
池列出的是可用连接，整棵树由混合整数二次规划联合选择，并非逐棵枚举RNJ树后取最好者。

对池中内部连接C，a_C是0/1选择变量，r_C、x_C是非负响应系数。训练目标是

\[
\min\ \frac{\|Y-\widehat Y(r,x)\|_F^2}{N_{cell}M_{ref}}+0.003\sum_C a_C.
\]

第一项是归一化训练MSE，第二项限制无意义加线。约束包括`0≤r_C,x_C≤2a_C`、交叉集合不能同时选择、
每个集合W内严格包含的内部连接数不超过`|W|−2`。单节点和全节点基础支持固定在表示中，系数0到2且不计条数罚项。
E可删除W/T已经加入的内部连接，重新组合池中其他连接。给定集合后，预测对系数线性，
所以其连续目标是凸二次；离散连接选择由Gurobi处理。源码见
[`StructuralSolver.select`](../../identification/optimization.py)和[`_reconstruct`](../../identification/algorithm.py)。

热启动向求解器提供一个已知可行点，帮助较早获得好上界。模型无需初值也能求解，
限时性能却可能明显依赖初值。当前E只比较当前W/T点与一个固定RNJ参考点的训练目标，取较好者初始化。
参考点固定为距离配比.75、容差.16，复用`prepare_common`已拟合参数，按当前M_ref重算目标；无新增QP或验证集筛初值。
R关闭时不注入。预算不足或求解器未返回可行点时，仍保留当前点。

若求解器原样返回参考初值，E可以相对当前点改善，但改善来自初值；日志明确分开以下三段：

1. 当前点到实际初值；
2. 实际初值到求解器返回点；
3. 返回点到固定支持QP收尾点。

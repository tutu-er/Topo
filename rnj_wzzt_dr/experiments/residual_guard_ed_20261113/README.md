# 残差方向检查、延长QCQP求解与配网灵活性核算

任务范围：保持候选与后验评分冻结，用历史残差减少新调节方向上的偏差；对原费用界未闭合的问题延长求解；另核固定启停的经济调度和示例电价。生产默认不变。

已完成[结果与失败汇报](results/REPORT.md)、[公式及模型边界](MODEL.md)。独立物理测试704个背景，另4个接口预跑；12个原费用问题延时并做可行凸QP改进；固定ED/价格544条核算，8个联合ED示例。全部原约束与费用独立复算见[验证记录](results/VALIDATION.json)。

## 事前锁定的主测试

原400库中，150库含真候选，28库历史真候选权重低于99%，122库已至少99%。选择全部28个证据不足输入，加每网络一个已清楚输入和一个缺真候选对照，共36个。真值只作离线资格和评价，实际目标沿用历史最高权重候选；不把目标自动换成真拓扑。

每输入16个新日，主增量gamma=2，容量30%/50%，比较原名义规划与增加历史残差检查的规划。四组共享真实背景、5%预测噪声和原表计流；每组含无动作、优化及逐日同费轮换。另预锁Paper121、Soumalas195、Pengwah026、Soumalas039各32日、gamma=4作独立复验。新种子2026111313。每计划0.8秒、原生费用界容差1e-5、四进程。

历史32点残差为每个候选、每个电压输出估计一个比例修正c：

`c=1+sum(mu*(Y-mu))/(sum(mu²)+32*sigma²)`。

这里mu是原冻结候选的历史预测。修正只用于规划，原H、历史SSE、sigma²和完整库后验保持不变。除原名义证据增量至少gamma外，对每一对规划候选，分别把两端的修正均值作为评价均值，要求各自的平均对数赔率增量不为负。新约束仍是二次函数，不增加协方差模型，也没有重写辨识器。这是历史残差的工作近似，准确性由独立AC测试评价。

## 延长求解

在旧冻结预测和报价上选12个费用界未闭合的问题，包含三正例的最大/中等间隙和保留初值、下降例及多竞争者问题。原样复用已核可行报价和原问题下界，依次给2秒、10秒；最多三个剩余间隙大于10%的问题再给30秒。记录实际费用下降、下界变化、初值是否原样保留和全时长。重规划同一预测不是新的独立物理样本。

## 经济解释

名称采用“面向拓扑辨识的配网灵活性调度”；涉及报价采购时称“配网灵活性服务采购”。发电再调度、负荷时移、储能均可提供资源。日前购售电和灵活性服务是不同费用分量；资源启停固定后，出力、爬坡、购售电、负荷时移及切负荷可用连续ED核算。加上辨识二次约束后仍是QCQP。

电价先使用明确标注的示例元/MWh。费用分别列能量购售电、发电报价、负荷转移补偿及切负荷损失，并与同一资源条件下的基线作差。参数是合成报价，不称实证校准。若负荷转供改变供电路径，就改变待辨识拓扑；本轮只做固定拓扑下的连续功率调节。

原始P/Q/V、拟合校正和动作留在忽略的outputs。每批锁协议、源码、输入和随机流；已有完成数据不重跑。

# 分布概率约束的多日期验证

本目录提供同一入口，对比正态约束、固定功率指数约束、含预测误差指数约束。沿用已有辨识器、非凸二次规划和交流潮流桥，不改变生产默认。执行规则见 [PROTOCOL.md](PROTOCOL.md)。

## 文件与顺序

|文件|作用|
|---|---|
|`data.py`|检查预定的112个数据窗口，准备16个开发输入的观测、候选和完整交流潮流缓存|
|`resources.py`|仅按历史登记、训练负荷和冻结候选配置有功与无功合同|
|`run.py`|统一规划、先封存后执行，保存全部策略、随机流、费用及失败|
|`audit.py`|独立复算评分、原约束、资源、费用和全网电气状态|
|`report.py`|保留失败分母，汇总新增/丢失恢复、模型偏差、费用及求解状态|
|`probability_panel.py`|方案封存后，核对声明高斯模型的解析界与2048条独立模拟路径|
|`confirm_data.py`|读取开发审查凭据，再准备原名单的96个确认输入|
|`continuation.py`|在原协议下继续尚未启动的预测，并逐方案保存动作|
|`recover_partial.py`|按已用预算恢复中断预测，核验全部身份后写最终完成标记|

从仓库根目录运行 `python -m rnj_wzzt_dr.experiments.distribution_panel_20261115.<模块> --help` 查看入口。主运行必须指定输入索引和新的输出目录。已经完成的运行保留；恢复运行使用原协议及源码哈希，不重置已用预算。

各输入包含192点训练、96点验证、96点次日观测。开发每输入2份预测、每预测16条执行路径；确认每输入2份预测、每预测32条执行路径。八个策略共享同一条实际路径，包含无采购、旧方案、三个分布方案及各自的同计划账单轮换。

## 结果口径

- 日历窗口缺测单列；数据完整但后续拟合、资源或执行失败的输入仍进入全流程失败统计。不得用成功输入代替原计划分母。
- 完整内部拓扑恢复与全部响应支持项一致分别报告。共同响应项多余，也属于后者的失败。
- 声明模型的概率下界、模型内模拟比例、实际交流潮流恢复率分开报告。概率下界的松紧不能当作精确概率预测误差。
- 预测证据、完整请求动作下的交流潮流证据、实际交付和量测证据分开核算；零增量不计算0/0实现率。
- 零动作已充分时，非负费用直接给出最优值0。非零报价另报初值、生成时间、求解时限、可行值与有效费用界，不将超时可行点写成全局最优。
- 优化目标为调用费；总账单另加请求峰值容量费。对应的求解下界仅用于调用费，不能挪作总账单下界。
- 全母线电压以0.95–1.05 pu筛查。网络缺少设备热额定值，保存电流、根功率和损耗，热安全状态保留未核验。

原始时序、拟合参数、报价及逐时动作保存在忽略目录 `outputs/`。本目录只提交代码、协议和汇总。

开发结果见 [DEVELOPMENT_RESULTS.md](DEVELOPMENT_RESULTS.md)，确认结果见 [CONFIRMATION_RESULTS.md](CONFIRMATION_RESULTS.md)，中断及续跑规则见 [CONTINUATION.md](CONTINUATION.md)。确认保持原96个计划窗口，46个数据完整、50个缺测；有效输入的92份预测全部执行，4份受中断影响的结果单列。

# 有幅度边界的双向灵活性价格响应

本轮允许发电、储能、可调负荷的聚合资源双向改变节点净功率，不把净注入判为违规。基线可理解为日前已经安排的净功率；价格只调用事先签约的可用偏移量。市场主体的接入关系不自动赋予运营商任意调度权，调用权来自合同、市场成交、自有资源或相应调度安排。

政策依据使用原文：[中国虚拟电厂指导意见2025](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202504/t20250411_1397162_ext.html)、[需求侧管理办法2023](https://zfxxgk.ndrc.gov.cn/web/iteminfo.jsp?id=20274)、[欧盟电力市场指令第32条](https://eur-lex.europa.eu/eli/dir/2019/944/)。这些来源支持聚合和采购分布式电源、储能、负荷等灵活性，不代表所有地区或所有资源均由DSO无条件控制。

## 模型与价格含义

沿用`deltaP=m_i*x_hour`、`deltaQ=.35deltaP`，m_i取历史节点功率峰值。x为基线附近的有符号归一化激励／请求。假设资源具有二次机会成本，边际补偿价格随请求线性增长，因而请求对价格呈线性响应。现有`mean(x²)`是归一化二次调节代价；尚未校准成货币结算，也不把机会成本与市场统一结算支付混为一谈。

新增唯一设备边界为`|x|<=alpha`，alpha为.1/.3/.5；另有无界对照。它表示事前声明的双向资源可用容量为节点历史峰值的10%/30%/50%，只是数值容量场景，未声称这些比例来自真实资源统计。保留净注入，仍不恢复SOC、充放电整数或单设备时序模型。

## QCQP如何求

完整问题仍为最小二次代价、每个预定竞争者的期望对数赔率增量达到gamma。先求无界单对问题的标量乘子方程，保留有效原问题下界。如果无界最优点满足容量，直接验证全部比较并核费用界；否则用有界方向／一次充分条件QP产生初值，再调用原生带边界非凸QCQP，计划总预算0.4秒。无界对照沿用0.15秒。

不可行只由有效外界或原生全局状态支持：二次增量在盒上的上界低于要求，或无界问题费用下界超过盒内最大费用，均可证明名义规划问题不可行。一次充分条件QP不可行只表示该内域失败。超时未得报价单列，不能称无解。规划失败执行显式零动作兜底并计失败，不把它报为零费最优。

# 分布概率约束：配对测试与初值迭代

2026-11-14。已实现并完成两轮配对执行、独立概率核验与电气审计。新正态方案内部拓扑恢复121/128，两种指数方案均128/128，旧参考108/128；简单连线搜索虽然满足同一正态门槛，实际只有92/128。这组正反例同时保留，ADMM尚未接入。

## 本批具体做了什么

复用一个已知Pengwah18背景日（Europe/Berlin，2024-10-17 08:00起24小时）、4份预测、每份32条原配对交付/量测路径。每轮6策略、768条执行；两轮共1536条策略执行，仍是同一批128个配对背景，不是1536个独立算例。预测沿原流程由真实新日P/Q加入5%误差形成，规划封存后再打开实际网络执行AC、加入表计误差，并用模拟表计的P/Q/V选模。

P/Q沿用FeederBW v1.1的不同馈线净功率记录，映射到Pengwah18终端，含新能源登记且P/Q并非按固定比例生成；本网络电压来自AC仿真。设备登记、可用合同与实际设备出力的区别见前一轮[数据核查](../rx_mean_guard_20261114/DATA_AND_BIAS_CHECK.md)。

训练192点、历史评分96点、新日96点；5个原生冻结参数点、原最终全库MSE、原36 kvar供给池及7项P资源不变。报价仅使用历史观测、预测、资源合同和冻结候选。均值K仍为原历史逐行幅度校正，未用实际新日调整。错误候选也作为条件目标，目标族按历史累计权重0.99选取。

固定功率版本中，分数均值为μ(u)，方差为v(u)。电压误差包含公共根表和独立终端表两个标量方差。三个新条件为：

- 正态：`μ(u)−z₁₋α√v(u)≥τ`，辅助标准差变量使其保持QCQP。
- 固定功率指数界：`μ(u)−(λ/2)v(u)≥τ+log(1/α)/λ`，直接是二次约束。
- 含预测误差指数界：对独立5%高斯P/Q误差解析积分；固定误差尺度和λ后仍为QCQP。

本批λ=.5，主要单对α=.025。完整推导见 [METHOD.md](METHOD.md)，执行前协议见 [PROTOCOL.md](PROTOCOL.md)。这些门槛控制目标在最终选模中胜出的条件概率；“相对权重达到90%”另外统计。

## 预测概率和实际恢复为什么仍有差别

独立程序从完整SSE和联合高斯积分重建概率，并对每预测、每条件目标生成2048条声明模型路径。两轮各96组检查全部完成，未发现积分、二次展开或模拟概率不一致。下表针对实际正确的原生候选4；8192为4份预测各2048条的合计，仍按预测保留单独区间。

|策略|声明模型下正确族胜出|实际AC恢复|声明充分下界|
|---|---:|---:|---:|
|旧参考，按新固定功率法则重算|7312/8192＝89.26%|84.38%|87.36%–89.50%|
|正态，600秒|7981/8192＝97.42%|94.53%|约97.50%|
|固定功率指数|8186/8192＝99.93%|100%|约97.50%|
|含预测误差指数|8184/8192＝99.90%|100%|约97.50%|
|正态，简单连线缩减|7987/8192＝97.50%|71.88%|约97.50%|

指数界比模型中的实际尾概率更保守。名义总风险预算是10%，但只有一个竞争者接近，固定逐对分配0.025后，实际联合充分下界达到约97.5%；远竞争者的概率贡献接近零。保守性与均值失配要分别处理。

均值偏差的方向随动作改变。下面是正确候选4相对错误候选2的累计对数分数，四份预测取均值：

|---|---:|---:|---:|---:|
|旧参考|6.063|5.526|4.776|−0.750|
|正态，600秒|13.040|11.865|10.961|−0.903|

旧参考的分数方差，原独立误差公式约13.46，计入公共根表后约24.59，实际约23.55；方差量级明显改善。连线方案实际均值只略高于旧参考，实际方差却升至约66.54，因而恢复下降、错误高权重增加。指数方案的参数偏差投影这次有利，真实均值反而高于预测。128/128的成功与“均值模型已经校准”是不同结论，后续必须继续核查该方向偏差。

连线和指数方案交付Q约277、283 kvarh，数量相近，效果却相差很大；动作的节点、符号和时段决定了参数误差如何投影到选模分数。含5%预测误差与固定功率指数版本效果近似，本批没有证明解析预测误差扩展带来额外收益。

## 求解、失败与初值

12个原生QCQP报价全部找到经原式核验的可行点，均到600秒时限；没有报价异常、执行失败或回退。

|模式|原生初值情况|调用费可行上界，元|有效下界，元|费用间隙|
|---|---|---:|---:|---:|
|正态|4次均改进原37.25–37.67元可行LP初值|4.107–4.716|0|100%|
|固定功率指数|4次均无可行初值，求解器找到新解|14.882–14.964|13.606–13.727|8.10%–8.74%|
|含预测误差指数|4次均无可行初值，求解器找到新解|14.903–14.955|13.620–13.728|8.20%–8.63%|

求解器接收了同一原共享池中的暖启动点；“无可行初值”不等于没有提供任何起点。全部未证全局最优；下界仅属于实际编码的固定分布充分QCQP、调用费目标，不属于原概率问题、总账单或实际AC成功率。新门槛替换了旧门槛，所以没有继承旧门槛的费用下界。

每次新报价约600.12秒；计入已发生的共享准备约150秒后，单方法总计算约750.3秒。复用准备是沉没成本，本批没有重新运行这150秒；整批并行墙钟和单方法计费时间分别记录。

连线迭代遵循 [LINE_PROTOCOL.md](LINE_PROTOCOL.md)：扫描原参考到原LP种子的线段，再按费用固定顺序删减一次资源列。13项测试和原式核验通过，约1秒找到17.90–18.37元的正态可行点；计入旧共享准备约151秒。两个指数版本各4次在这些线段中未找到可行点，8次明确回退旧参考，不能把回退的108/128记作新约束成功，也没有据此宣称问题不可行。

全部两轮执行均通过资源、费用、全原生评分和全网AC独立核验。原生批电压1.001447–1.023504 pu，连线批也无0.95–1.05越限；原生批最大KCL误差2.87e−12 pu、全网功率平衡误差2.06e−9 kVA。缺少热额定值，未给热负载率。代数/求解/连线共29项测试通过。

## 后续判断与文件入口

根据当前决定，保留三个实现：正态版本是较低费用基线，固定功率指数和含预测误差指数分别作为两个对照方案。暂不把初值连线方法作为部署方案。分别校准P/Q的两种简单历史修正也已试算：部分旧参考改善，但大采购动作的方向误差没有改善，逐行版本反而更差，故未接入规划，见 [PQ_CALIBRATION_CHECK.md](PQ_CALIBRATION_CHECK.md)。

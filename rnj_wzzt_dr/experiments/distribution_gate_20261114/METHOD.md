# 分布概率约束与原方案的关系

本模块保持原候选、参数、历史评分和最终选模规则，改变灵活性采购的约束。完整执行协议见 `PROTOCOL.md`。ADMM尚未接入。

## 要控制什么

设目标候选为 i，竞争者为 j。历史平方误差为 Sᵢʰ、Sⱼʰ，原评分尺度为 σₛ²。定义历史分数差

`hᵢⱼ = (Sⱼʰ − Sᵢʰ)/(2σₛ²)`。

新日观测加入后，目标相对于竞争者的累计对数权重比为

`Lᵢⱼ = hᵢⱼ + [‖y−Hⱼx‖² − ‖y−Hᵢx‖²]/(2σₛ²)`。

要求 `Pr(Lᵢⱼ ≥ τ) ≥ 1−αᵢⱼ`，其中 τ对应原最终选择的数值容差。每个目标对全部异族原生参数点分配总失败预算0.1；概率相加即可得到目标代表战胜所有异族点的充分下界，不要求竞争者之间独立。只保护目标代表已经足以保证其拓扑族胜出；同族其他参数点仍参与最终评分。

这一要求控制的是“目标能否在最终选模中胜出”。它与“目标归一化权重达到90%”是两个不同事件。后者需要另设对数赔率门槛，本批没有混用。

## 均值和误差如何进入

使用规划模型 `y=Kᵢx+e`。Hᵢ是冻结的评分矩阵；Kᵢ只在历史验证数据上按已有方法做逐行幅度校正。定义

`D=Hᵢ−Hⱼ`，`E=Kᵢ−Hᵢ`，

`B=(DᵀD+EᵀD+DᵀE)/(2σₛ²)`，

`V=DᵀΣₑD/σₛ⁴`。

则单时刻的新分数为 `xᵀBx + eᵀDx/σₛ²`。B保留参数偏差的有符号作用，因此可以是不定矩阵；代码没有删除其负特征值。

电压误差协方差采用一个公共根节点误差加独立终端误差：`Σₑ=σᵣ²11ᵀ+σᵥ²I`。两方差由历史观测电压及原表计误差幅值确定，时间之间独立。这保留了平方电压差共享根量测的事实，没有改变最终MSE，也没有从评分中减去公共响应。

## 给定功率时：精确正态约束

规划功率为 `m(u)=预测功率+线性资源响应`。在独立高斯电压误差下，累计分数为正态变量，其均值和方差是

`μ(u)=hᵢⱼ+Σₜ mₜ(u)ᵀB mₜ(u)`，

`v(u)=Σₜ mₜ(u)ᵀV mₜ(u)`。

因此单对概率要求等价于 `μ(u)−z₁₋α√v(u)≥τ`。引入非负s，写成

`v(u)≤s²`，`μ(u)−τ≥z₁₋α s`。

μ和v均为动作u的二次式，所以这是QCQP。约束通常非凸，求解器可从无可行初值开始，但限时结果可能只保留已有可行点。

原方案的 `h+J−z√(2J)≥τ` 是其特殊情形：`Kᵢ=Hᵢ` 且 `Σₑ=σₛ²I`。当前共享根误差会使方差依赖激励方向，不能再统一写成2J。

## 功率也有预测误差时：固定指数参数的上界

令 `x=m(u)+ξ`、`ξ~N(0,Σₚ)`，与e独立。Σₚ固定为各预测通道幅值5%的方差，不随u变化。取固定λ>0，令

`A=λB−λ²V/2`，`Σₚ=FFᵀ`，`G=I+2FᵀAF`。

当G正定时，积分给出

`Q=A−2AFG⁻¹FᵀA`，

`T(u)=Σₜ[mₜ(u)ᵀQₜmₜ(u)+½log det Gₜ]`。

指数不等式得到 `Pr(Lᵢⱼ<τ) ≤ exp[λ(τ−hᵢⱼ)−T(u)]`。因此使用充分约束

`T(u) ≥ λ(τ−hᵢⱼ)+log(1/αᵢⱼ)`。

Σₚ和λ固定时仍为QCQP。本批λ从0.5开始，只在积分矩阵未正定时减半。这个选法保证积分可计算，不保证概率界紧；同一真实概率可以对应很松的指数上界。因此同时测试Σₚ=0的指数版本，用来单独识别指数界带来的保守性。

## 怎样判断实现和效果

先用独立完整SSE和联合高斯积分核对代数，再在声明分布下抽样检查概率；实际网络另外执行AC潮流、交付误差和原量测误差。三个层次分别报告。声明模型中概率算准，仍可能因Kᵢ响应方向偏差而高估实际恢复率。

采购费用仍是原调用费目标；容量加调用的实际账单另报。保留原历史方向保护，替换原名义绝对门槛。新约束失败时执行已核验旧参考，明确标记回退；该动作不充当新QCQP的可行解。旧门槛已被替换，其费用下界也不转用于新问题。

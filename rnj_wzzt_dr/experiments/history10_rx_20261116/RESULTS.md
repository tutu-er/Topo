# Ten-day history: measured P/Q and R/X estimation

2026-11-16. The locked 8-day fitting + 2-day validation + day11 evaluation
experiment is complete. All 16 native identification attempts and 240 unique
offline fixed-support fits passed independent audit. No flexibility procurement
or coefficient regularization was introduced. Production defaults are unchanged.

## Data and comparison

P/Q comes from the synchronized FeederBW v1.1 measured feeder archive, with one
distinct source feeder per test terminal. The original positive node scale is
applied equally to P and Q; no power-factor synthesis or extra device baseline
is used. Voltage is generated by the original Soumalas/Pengwah AC networks.
See [SOURCE_AUDIT.md](SOURCE_AUDIT.md) for exact lineage, scaling and limitations.

January4 cannot be extended continuously because of source gaps. A predeclared
finite/count-only search retained all31 tested starts and selected the first
common complete11-day window: January21 08:00 Europe/Berlin. Short fitting uses
January27--29 (192 points); long fitting January21--29 (768 points). Both validate
January29--31 (192 points) and evaluate January31--February1 (96 points). Old
January4 scaling is frozen and known before the new interval.

Four paired meter-noise draws per network use SD(P,Q)=0.5% and SD(V,root)=0.05%.
The same physical data, time-aligned noise, validation, evaluation, algorithm,
and 120s+60s budget are used in each pair. This is two known physical networks
and one common time interval, not16 independent field networks or dates.

"Internal topology" checks supports containing2 to N-1 observed terminals:
the branching/grouping relationships among observed endpoints. Complete support
also checks singleton terminal branches and any branch common to all endpoints.
These are separate structure metrics; R/X coefficient accuracy is a third issue.
Internal recovery must not be reported as complete physical-tree recovery.

offline diagnostic. They never enter the native candidate bank or selection.

|Pengwah|AC + V/root meter error only|28.97%|15.98%|
|Pengwah|AC + all locked meter errors|28.95%|15.75%|

The current bounded fixed-support QP can recover R/X to numerical precision
when its exact linear model generates the observations. Clean AC leaves a
small model mismatch, which does not vanish monotonically with more days.
The large X error appears when the declared voltage/root meter error is added;
0.5% additional P/Q error changes it little in this batch. More history reduces
this noise-amplification effect substantially, but X error remains about15--19%.

Thus there is evidence for voltage measurement error amplified along weakly
excited Q directions, rather than a fixed-support numerical failure or an
excessive coefficient-ridge penalty. There is no coefficient ridge/L1 in the
current fitter; structural alpha=.003 penalizes internal support count only.
The source meter's own error is unknown: "clean" means no added simulated error.

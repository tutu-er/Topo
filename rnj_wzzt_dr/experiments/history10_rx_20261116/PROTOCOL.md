# Ten-day identification and R/X sample-length check

Locked before new AC generation or fitting, 2026-11-16. User confirmed eight
days fitting, two days validation, and day eleven evaluation. No flexibility
procurement, regularizer change, impedance change, or production-default change.

## Source and chronological information

Use the existing, hashed FeederBW v1.1 15-minute archive, original terminal to
numbered feeder mapping, and the per-node P/Q scales sealed for 2024-01-04.
These scales are known before the new window and identical in every comparison.
Do not construct Q from P, change signs, duplicate days, fill missing values, or
add a new device baseline. Voltage is generated by the original balanced AC
test networks, not treated as a measured field voltage.

Cases are Soumalas11 and Pengwah18. Check every candidate start from January 4
through February 3, 2024, inclusive (31 starts), using only synchronized finite
P/Q, >=12 valid minutes per 15-minute bin, and no daylight-saving transition.
Retain all qualification rows. January 4 fails during the extended window;
the first common complete eleven-day start is January 21 at 08:00
Europe/Berlin. Lock this first qualified start; never select on fitting results.
Completeness qualification includes validation/evaluation availability, so this
is a complete-window study rather than a prospective missing-data deployment.

The eleven-day physical window has 1056 rows. Validation is rows 768:960 and
evaluation is 960:1056 for every method. Main training lengths are:

- 2 days: rows 576:768, the most recent two days before validation;
- 8 days: rows 0:768, with exactly the same training cutoff.

A four-day nested training slice, rows 384:768, is used only for cheap offline
fixed-support diagnostics. Main comparisons therefore isolate adding earlier
training observations, with the same scales, cutoff, validation, and evaluation.
They do not directly estimate an iid sample-size law or reuse the old January 4
results as the matched short-data baseline.

## Physical data and errors

Keep original branches, R/X, 200-kW power base, and root physical variation
formula (amplitude parameter .003). Prepare clean AC once per network. Separate
root physical variation from meter noise. Four history noise repetitions use
full-window paired standard Gaussian arrays: the same row has the same noise
under the 2-, 4-, and 8-day slices. Seed 2026111601, independent components and
network/repetition coordinates, are saved before fitting. Add P/Q relative SD
.005 and terminal/root voltage relative SD .0005, exactly as in the current
192-point run. Keep source meter error unknown rather than calling it calibrated.

The clean physical source, true response matrix and network are private
evaluation inputs. True parameters must not enter identifier inputs, penalties,
candidate construction, stopping, or validation selection.

## Main identification experiment

2 networks x 2 training lengths x 4 noise repetitions = 16 identifier attempts.
Use the unchanged observed-data 101 RNJ/WZZT entry point, 120 seconds per call,
plus the same additional 60-second search in its own recorded original E pool.
Use one native solver thread and at most three independent workers. Save the
original and enriched banks separately, all native statuses/bounds/times, and
candidate seals before evaluation reads physical truth. No complete RNJ final
tree fallback is introduced. Fixed-support QP remains unregularized bounded LS.

Report both validation selection and validation-plus-evaluation selection.
Training loss is not added again. Two validation days versus one evaluation
day means a 2:1 row-count ratio; this ratio is identical across matched methods
and differs from the former 96+96 experiment. Separate internal topology,
complete active support, candidate coverage, and R/X parameter error.

## Offline diagnostics, never injected into the candidate bank

For each network/repetition, refit fixed supports on nested 2/4/8-day training:
the exact physical support, the old internally correct candidate support, and
the old historical-winner support (deduplicate identical support sets). Use
four diagnostic observation laws:

1. exact linear Y=H* [P,Q], no simulated meter error;
2. clean AC P/Q/V, no simulated meter error;
3. clean P/Q with the locked voltage/root meter error;
4. all locked meter errors.

True-support fits are oracle diagnostics, not deployable identification or
candidate-coverage improvements. Report matrix and current-device-column R/X
errors, validation/evaluation voltage response errors, parameter-design rank
and singular values, conditional Q feature energy, Q signal versus meter noise,
active bounds, convex-QP certificate gaps, and all failed fits. No data or truth
is used to tune a regularizer in this batch.

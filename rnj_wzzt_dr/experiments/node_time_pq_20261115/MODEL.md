# 历史单目标采购的逐节点、逐小时P/Q带

候选H、R/X、历史评分、均值校正K、误差法则、资源与价格沿用[单目标模型](../single_target_20261115/MODEL.md)；本模块不重新辨识、不修改生产默认。原三种概率约束见[原式推导](../distribution_gate_20261114/METHOD.md)。本轮只增加历史动作带，并尝试SDP初值。

## 1. 带宽的来源和含义

节点i的训练量测为(P_ki,Q_ki)，用公共基准转换为kW/kvar。以训练样本的中心化OLS得到

\[
\kappa_i=\frac{\sum_k(P_{ki}-\bar P_i)(Q_{ki}-\bar Q_i)}{\sum_k(P_{ki}-\bar P_i)^2},\qquad
a_i=\bar Q_i-\kappa_i\bar P_i,\qquad
r_{ki}=Q_{ki}-a_i-\kappa_iP_{ki}.
\]

训练时间戳从原observations_sealed.json的sampling.train.timestamps取得，不加载真实P/Q或未来时间序列。UTC转换为Europe/Berlin的当地时钟。对当地小时h，带宽为

\[
b_{hi}=\max_{k:\,\operatorname{hour}(k)=h}r_{ki}-\min_{k:\,\operatorname{hour}(k)=h}r_{ki}.
\]

该宽度是历史同小时残差变化的最大范围；没有按新日恢复率选倍率，没有隐式下限。每小时至少两点，当前三例均为四点，来自两训练日。它是经验外推范围，不是校准的预测区间。负净Q或净P过零不需要除法或特殊符号处理。

## 2. 完整优化

u_h为原设备每小时增量，原节点映射给出deltaP_hi和deltaQ_hi。仅新增线性约束

\[
\boxed{-b_{hi}\le\Delta Q_{hi}-\kappa_i\Delta P_{hi}\le b_{hi}\quad\forall h,i.}
\]

原物理资源域U保留PV上限/时窗、EV能量恢复、热水衰减状态、独立双向无功盒。引入线性绝对值辅助变量处理调用费，目标仍为最小调用费。预约容量费及实际交付调用费另列结算总费，不宣称总费最小。

令原概率约束的二次式为g_j(u)>=0，原目标出发的代表库增量保护为d_j(u)>=0。新问题为

\[
\begin{aligned}
\min_u\quad&C_{\rm activation}(u)\\
\text{s.t.}\quad&u\in\mathcal U,\\
&g_j(u)\ge0\quad\text{全部异族原生参数点},\\
&d_j(u)\ge0\quad\text{目标出发的其他代表点},\\
&-b_{hi}\le\Delta Q_{hi}-\kappa_i\Delta P_{hi}\le b_{hi}\quad\forall h,i.
\end{aligned}
\]

新增行全部线性，整体仍为连续非凸QCQP。零动作总满足新带；若同时通过原概率式，非负费用给出最小调用费0。否则求解原QCQP。无可行报价时执行零动作并标记失败/回退，不能把回退时辨识正确计为新概率约束成功。

求解编码对正带宽归一化后留1e-7相对余量；原kvar带直接审计只容许算术舍入。编码域与原带域分别保存；编码域的原生费用下界不当成未缩紧域的下界。设备交付保留原随机响应和截断，不为了满足规划带而修改真实执行；实际交付越带单列。

## 3. SDP只用于产生初值

两个指数门槛与前向保护均为按小时求和的二次式：

\[
g_j(u)=\sum_h[u_h^TQ_{jh}u_h+2a_{jh}^Tu_h]+c_j.
\]

为每小时引入二阶矩W_h，把u_h u_h^T替换为W_h，保留

\[
\begin{bmatrix}1&u_h^T\\u_h&W_h\end{bmatrix}\succeq0,
\qquad
\sum_h[\operatorname{tr}(Q_{jh}W_h)+2a_{jh}^Tu_h]+c_j\ge0.
\]

不施加秩为1条件，原资源/时序/带约束作用于u；盒边界的四组McCormick包络进一步限制W。原问题的任何动作都可用W_h=u_hu_h^T嵌入，因此这是实际编码QCQP的松弛。跨时段能量约束仍保留；未另外构造跨时段矩块，故不声称这是最强SDP松弛。零固定动作先消除。

使用现有poweropt环境的CVXPY/SCS独立worker，只传封存数值系数。提取均值动作和16条固定高斯舍入动作，必要时投影到原线性资源和带约束域；再用原概率式逐点核验。概率不可行但资源/带可行的点仅作热启动，是否可行仍由原QCQP判断。两个指数SDP产生的候选取并集，同原公共池一起提供两个指数QCQP；两份SDP成本是共同额外准备时间。

高阶矩允许表面上增加预测证据而均值动作无足够证据，所以松弛解可能无法恢复为原问题可行点。保存PSD残差、数值秩、原生残差、目标、舍入、投影和拒绝原因。未经独立验证的数值SDP目标不计有效费用下界；未采用对偶证书修复。无新候选时复用已审同带动作，原费用界统一退回0，避免恢复旧已撤回的界。

## 4. 结果的适用范围

同一物理日的原16条执行路径用于配对比较，冻结原P/Q/V/root噪声、预测和设备整段响应。先封存规划再打开真实新日AC。全部竞争者均参与最终native MSE选模。报告区分预测K优势、实际交付输入K优势、干净AC和含量测优势，另报内部恢复、完整响应支持、费用和电气量。

带约束控制历史方向的外推幅度，不直接限制(H_true-H_fit)delta x，也不保证真实区分证据增加。即使使某些原可行采购不再可行，也不能通过放大噪声、改变候选或按未来效果扩带来掩盖。正式原生QCQP每报价600秒；SDP每模式额外120秒，额外预算单列，不用于宣称等时间加速。

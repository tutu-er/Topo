# 保持历史P/Q关系：先度量，再约束

2026-11-15。沿用两个Soumalas负例的全部封存数据；P/Q关系只由训练量测估计，先保存系数再读取未来观测。没有新拟合拓扑、重新采购、AC模拟或更改正式算法。逐节点拟合系数与原始运行数据留在本地忽略目录。

**建议采用“限制偏离历史关系的动作量”，保留有界的独立无功空间。直接强制固定P/Q比例，会禁止绝大部分现有Q资源；维持原大Q动作再补P，所查两例的响应误差反而增大。**

## 1. 水平比例与变化方向需要分开

比较两种训练关系：

\[
q_i\simeq \kappa_i p_i,
\qquad
q_i\simeq a_i+k_i p_i.
\]

第一种强制经过原点，描述净P/Q的水平比例；第二种保留固定无功偏置，其斜率描述历史共同变化。中噪声格有9/11个过原点比例为负，但10/11个带截距斜率为正。将前者直接用于\(u^Q=\kappa u^P\)，会在多数节点约束到与历史变化相反的方向。

因此若约束新增动作，优先用带截距关系的斜率\(k_i\)，截距在取增量后消去。该斜率表示历史统计关系，不是设备的因果响应规律。独立无功补偿器本来可以只调Q；新增关系约束用于限制模型外推。

训练关系跨日仍有变化，验证及无采购新日也不完全落在训练带内。以带截距残差为例，零采购新日已有6.82%的节点时刻超出训练min–max，14.49%超出训练中央95%范围。因此直接强制“调度后总P/Q必须回到训练带内”，可能排除零采购。

## 2. 偏离关系的动作造成多少响应误差

将动作分成

\[
u^Q=K_pu^P+v,\qquad K_p=\operatorname{diag}(k_i),
\]

其中\(v\)为偏离历史变化方向的无功增量。令\(E_R=R_*-\widehat R\)、\(E_X=X_*-\widehat X\)，则新增响应误差准确分为

\[
E_Ru^P+E_Xu^Q
=\underbrace{(E_R+E_XK_p)u^P}_{\text{沿历史关系部分}}
+\underbrace{E_Xv}_{\text{偏离关系部分}}.
\]

动作先换到原共同标幺基准。真实响应只用于选后诊断，不用于估计\(k_i\)、定价或约束参数。

中噪声格的结果如下，单位是平方电压差的标幺RMS，汇总16条路径、96时刻与11测点：

|方案|全部新增响应误差|沿历史关系部分|偏离部分|两部分交叉项\(2\operatorname{mean}(e_1e_2)\)|
|---|---:|---:|---:|---:|
|正态|9.4713e−4|2.2487e−5|9.4863e−4|−3.3654e−9|
|固定指数|4.5259e−4|0|4.5259e−4|0|

两部分不是正交的，RMS不能直接相加；其平方加上交叉项才等于总平方误差。这里偏离部分主导新增误差，与大量独立Q调用一致。

但把偏离部分直接删除，也会删除大部分激励。仅保留正态的沿关系部分，其原关键对的新动作距离二次项只剩约0.197%；纯Q的固定指数和有效旧参考都变成零动作。这不能报告为“保留收益同时消除误差”。

另一种做法是保留原Q、强加\(u^P=u^Q/k_i\)。只用已知矩阵核算，这会使正态和固定指数的新增响应误差分别增至原来的2.24倍、2.43倍。所需P在全节点全时段的RMS约39.36、30.06 kW；小斜率导致巨大P，连原本较小的R误差也被放大。这些是离线算子比较，不是资源可行报价或AC执行结果。

Soumalas的9个Q供给节点中，6个全天没有可用P合同。关键102/103也没有P资源。中噪声固定指数和预测误差指数的Q请求中，90.82%和93.41%发生在同节点/时段没有P可用的位置；旧参考这一比例为100%。

|严格增量关系|剩余Q静态同时峰值上界|全天绝对Q盒上界|相对原504 kvarh|
|---|---:|---:|---:|
|过原点比例\(u^Q=\kappa u^P\)|0.401 kvar|6.725 kvarh|1.334%|

## 4. 一个简单且保留QCQP的模型

从训练数据固定带截距斜率\(k_i\)，以及残差\(q_i-a_i-k_ip_i\)的标准差\(s_i>0\)。此处\(u^P\)用kW，\(u^Q,s_i\)用kvar；也可全部换到同一功率标幺基准，不能混用。已有资源幅度、时窗、能量与费用规则保留。建议额外限制

\[
\boxed{
\frac{1}{nH}\sum_{i=1}^n\sum_{h=1}^{H}
\left(\frac{u^Q_{ih}-k_i u^P_{ih}}{s_i}\right)^2
\le \rho^2 .}
\]

这里\(n\)为可测终端数，\(H=24\)为每小时一个动作的全天时段数。\(\rho\)控制整日偏离历史变化关系的强度，零动作始终可行。该左侧是已知线性表达式的平方和，是凸二次约束，加入当前非凸采购问题后仍为QCQP，不增加新的非凸部分。零残差或估计不稳定的节点需要事先声明尺度下限或单独处理，不能在优化后调尺度。

相比逐时强制相同P/Q比例，这种预算允许少量、短时间的独立Q调用。若确实需要逐时限制，也可采用两条线性不等式

\[
-\rho s_i\le u^Q_{ih}-k_i u^P_{ih}\le\rho s_i.
\]

两者是不同控制要求：整日预算允许集中调用，逐时带宽限制每一次动作的外推。先比较其中一个即可，暂不叠加多个可调参数。

\(s_i\)是历史P/Q关系的描述尺度，\(\rho\)是控制范围参数；此式本身不是90%响应误差保证，也不修正冻结矩阵。各P/Q设备独立随机交付，计划中的关系并不自动成为实际交付硬约束，执行端仍需核算。

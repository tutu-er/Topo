## 1. 一个指标贯通辨识、拒绝与DR

保持现有RNJ＋WZZT候选生成及训练正则。每种活动拓扑保留训练阶段确定的一组冻结参数，初始先验均匀；只用原32点评价残差估计一次共同方差：

\[
\hat\sigma_h^2=\min_j\mathrm{MSE}_{j,h}>0,\qquad
w_j=\frac{\exp[-S_j/(2\hat\sigma_h^2)]}{\sum_k\exp[-S_k/(2\hat\sigma_h^2)]}.
\]

S是历史验证及随后新观测的物理SSE。训练64点用于拟合和历史功率预测，不重复计入验证证据。**DR报价前冻结方差、候选、代表参数和先验规则，新日只累加SSE。** 原回溯函数`scoring.weights`会随输入重估方差，不能直接拿来作冻结方差的跨日更新。

这里沿用简单的独立、零均值、同方差高斯残差假设；历史`S_j=N_h*MSE_j`，N_h为实际节点×验证时槽的残差个数。得到的是给定冻结候选库、代入共同方差的相对后验权重；库外真拓扑和实际频率校准由全量覆盖／误拒统计另外检查。共同方差为零、非有限或缺失时记为未决，不临时加温度或极小常数。

统一比较输出门槛`beta in {.80,.90,.95,.99}`。所有门槛复用同一组后验权重，调整beta只改变拒绝与达标判定，不改变后验数值或MSE首选。对每个beta：

- w_max>=beta：输出单一拓扑。
- 否则输出累计质量达到beta的最短排序前缀C_beta，边界同权全部保留；首选以外成员为当前主要竞争者。
- C_beta以外的拓扑称为本轮暂拒。完整原库始终保留，后续新证据允许其重新进入，不做不可逆删除。
- 错误拓扑拒绝与DR都使用同一个w、同一个beta和同一个C_beta；不另加训练E门槛或MSE差阈值。

历史全量扫描及零DR规划核算属于开发阶段。结合争议结构、原资源作用和剩余缺口选择展示门槛beta_star，同一组策略／方法对比采用同一个beta_star；保存选择理由与其余门槛结果。beta_star、案例和策略在实际独立新日生成前锁定，确认阶段完整报告登记的四个门槛与连续后验数值，不再根据实际DR效果改展示门槛。真值只用于离线样本资格和评价，不进入门槛选择或报价规则。

对给定目标t，整库过线条件为

\[
w_t\ge\beta\quad\Longleftrightarrow\quad
\sum_{j\ne t}\exp[-(S_j-S_t)/(2\hat\sigma_h^2)]\le(1-\beta)/\beta.
\]

只有两个模型时，要求总SSE差`S_j-S_t >= 2*sigma_h²*log(beta/(1-beta))`。这正是新的辨识证据门槛，后续DR补足它；最小费用问题为

\[
\min_{u\in U}C(u),\qquad
\Pr_t\{w_t(O_h,O_n(u))\ge\beta\}\ge\eta,\quad\eta=.90.
\]

beta表示可选的后验决策门槛，eta表示条件于目标正确、执行后达到该门槛的概率，两者分开报告。本轮优先调整beta，eta统一保持.90，使策略可靠度要求可比。报价使用`Y=H_tP+e`的条件模型，沿用明确冻结的功率预测／误差和设备法则；实际AC、P/Q/V量测及随机交付另做检验。评分的简单高斯假设不自动覆盖实际执行偏差。

## 3. 怎样找“合理且数值合适”的算例

先按观测量筛出全部候选输入，之后才做离线真族资格检查。以下规则用于开发阶段选择清楚的机制演示；实际新日仍留作冻结方案后的确认：

- 以101为定向规划主方法，111作同观测的冻结库对照；生产默认不变，也不按结果临时选方法。
- 主机制候选：存在登记的beta使`w_max < beta`且C_beta至少有两个拓扑。优先同时包含单主要竞争者与多主要竞争者的自然案例；若没有合格多竞争者例，明确该部分缺少AC验证，不修改候选来制造。近乎并列可作主演示，重点是结构差异实质、原资源可区分、零DR仍有缺口。已过线和库缺真保留为对照。
- 必须由原合法库生成；候选、拟合参数和共同方差保持原值。beta按登记范围比较；不通过删除弱真线、改变噪声、阻抗、历史长度或资源制造差距。
- 报告双方争议支持的冻结r/x、相对强度及结构差异。优先检查争议支持较强、结构差异实质的候选，不只展示额外极弱块。排序使用各非零争议支持`max(r,x)`相对于所在候选活动内部支持中位数的比例，取这些比例的最小值降序；分母为空或为零的记为不可排序、排最后。此比例仅作检查次序，不是新阻抗下界或真实性保证。
- 并列时按预先固定的批次、case、input ID排序。每网络先检查至多4个候选输入，合计最多16个；保存未检查清单，未检出结论限定于实际检查分母。
- 每输入最多2个目标，固定为历史权重最高的两个拓扑，边界并列按代表原序；无须保证它们覆盖整个C_beta_star。主条件演示要求离线确认真族在完整库、在C_beta_star内且属于这两个事前指定目标。库含真但不满足此资格的输入保留在全量台账或失败对照中。

资格检查只决定研究样本是否适合该条件问题。报价器接收历史、资源和事前指定的目标ID，不接收真族标签或真实线路参数。对最多两个目标均尝试条件报价，失败／未决也保留；完整竞争者仍为整个冻结代表库。随后按目标是否正确分层评价，避免只把oracle选中的目标交给规划器。

“结果好看”落实为：争议结构能解释、连续后验在DR前后有清楚变化、原资源下费用合理、配对差异容易读懂。展示前后后验及增量、对数赔率、费用和四个门槛的结果；连续权重即使只小幅跨线也照实呈现。最强候选仍只有极弱争议时，如实标为弱块例。定向子集用于机制展示，总体表现仍由全量台账给出。

## 4. 必须先核未来零DR，而不只看历史后验

对最多16个候选输入、每个最多2个目标，按登记的四个后验门槛核算完整历史＋新日的零动作条件，支持展示门槛选择。原每目标4096条规划模型路径预算拆成2048开发路径＋2048锁定方案后的独立确认路径；未入选目标仅使用开发部分，不增加原路径上限。各门槛及策略共享各自阶段的基础随机数。即使历史已选对或已过线，也保留零动作检查；历史低置信也不自动意味着需要付费。

- 复用现有指数矩与设备代码，按新整库后验事件重新构造充分界。先统一代表候选、尺度和合法指数参数，并替换旧严格MSE的并列处理；不能只换一个delta。原40组严格MSE零费结果不直接迁移成新后验门槛结果。
- 解析充分界过eta且原零设备重放可行、费用非负时，按声明规划模型得到最小费用0。
- 充分界未过只称“证书未过”。再用事前固定2048条开发阶段**规划模型**路径核算门槛事件及95%二项区间；与确认阶段和最终AC使用不同流。
- 区间上限低于eta，才作为存在剩余概率缺口的数值证据；区间跨eta的保留为未决；区间下限过eta只作给定置信水平的零动作支持，区别于解析可行证书。
- 仅当零DR有剩余概率缺口的证据、且原资源确实能影响争议响应时，才进入非零报价。精确响应相同／资源作用为零的对象保留为给定模型下的不可改善对照。

选例阶段不打开真实新日，不用实际未来响应或AC结果决定哪个案例更“好”。若没有合格缺口，交付全量后验／拒绝统计和实际筛查分母，不扩批、改噪声或缩短历史求收益。

### 4.1 多竞争者的第一版处理

优先采用一个总失败额度的指数界。简单共同方差高斯残差模型下取公共lambda=1/2，令`c_j=sqrt(beta/(1-beta)*w_j^h/w_t^h)`，T_j为新日对数赔率增量的负对数指数矩，则`F_full(u)=sum_j c_j exp(-T_j(u))`给出整库失败概率上界，且T_j>=0。随机功率使用既有解析指数矩或有效矩界，不要求数值积分。若沿用旧DR的另一误差尺度／异方差法则，须先重新核对公共lambda及T_j>=0，未核对不得套用尾部公式。

先全库检查零动作。非零时按c_j降序纳入主要集合A，直到`R_tail=sum_{j outside A} c_j <= .1*(1-eta)`；始终用对数权重计算，不把浮点下溢当作零。尾部项对全部可行动作均有统一上界R_tail，因此约束`sum_{j in A} c_j exp(-T_j(u)) <= 1-eta-R_tail`足够。

第一版均分剩余额度：`epsilon_j=(1-eta-R_tail)/|A|`，在同一设备图中联立`T_j(u)>=log(c_j/epsilon_j)`。A只有一个成员时复用单对形式；多个成员时资源坐标取各竞争者非零作用集合的并集。完整代表库始终保留。保存每项c_j、T_j、额度、尾部统一界及完整界，不能把历史原始尾部概率之和代替R_tail。

保留二次形式还要求控制均值映射仿射、声明随机误差法则的协方差不随控制改变；若这些条件不满足，应重新说明问题形式，不能自动称QCQP。固定额度及尾部界定义的是保守充分域，其求解下界仅属于该域。

### 4.2 锁定方案后的模型核验

入选输入的报价、beta_star及三个策略冻结后，打开独立2048条规划模型确认路径；以目标冻结响应为生成模型，计算完整历史＋新日后验。记录理论成功下界、模型经验达标率及95%区间，并核对`F_full <= F_active+R_tail`。这些结果用于核验声明模型和界的实现，不能与AC达成率合并，也不再用于换例或调门槛。若确认结果提示界／实现不一致，保留失败记录并先排查，不以AC展示替代。

轮换按冻结的节点／设备类型／时段顺序分配请求，经过原设备投影，再只用名义费用调节整体幅度；费用可匹配时相对差以1%为验收目标。无法匹配则记录费用比及原因，不读取实际未来来补齐费用。

报价、目标、候选库、共同方差、源码／输入哈希、实际Python／依赖／求解器环境、原资源、预算和随机流先冻结，再生成独立完整新日。原64/32点历史不改；新日明确增加96点，最终证据是原32验证点＋新96点，训练64点不重复评分、不重拟合。

未来轨迹保持所选案例原物理网络／压力因子／噪声参数。三策略共享背景、P/Q/V量测随机流和设备整段响应流；按原因果设备执行器处理相关响应、状态、截止和饱和。规划器不读取这些实际未来流。

主要结果：**连续后验及配对增量、正确唯一输出率、错误唯一输出率、真族保留／误拒率、最终首选完整错漏／恢复、后验过线频率、实际交付和费用。** 同一冻结策略产生的观测统一计算四个门槛；仅在beta_star下优化的策略，不能称为各门槛分别最优。历史已选对时，DR可能只提高正确唯一输出率；不能把它改称首选恢复率的增益。单个候选库的错误覆盖问题单列。

每目标32条路径均保留，不按成功率追加样本或替换失败种子。报告配对差与实际达标率区间，不把29/32简单写成“已证明达到90%”。无DR物理轨迹可以复用，但所有策略评价和独立样本数分别记账。

| 原设备＋AC桥对新96点数据 | 待核网络哈希、基值、节点序、噪声及生成器一致性。large96用本地径向AC生成器，旧桥用另一冻结物理生产源；不默认等价。压力case尤其须保持修改后的物理版本 |

接入验收须包括：同响应的两候选在均匀先验下单个权重最多1/2；两名竞争者分别给出90%单对权重时整库仅9/11；固定功率小例的正态精确概率与保守界方向一致；主项＋尾部统一界覆盖完整界。它们是后续实现的必要检查，本轮尚未执行。

报价原型可先处理主要一对，但整库后验和条件达标核验通过后才是本问题可行报价。单对可行／最优状态不能代替整库；充分约束内域的求解下界也不自动成为原机会约束下界。费用为0的原域可行点和非负费用能证明零费最优；其他报价保留上界、界的适用域、gap、超时和未决。

## 7. 预算与停止条件

- 全量后验扫描：最多800库、四个门槛复用同一权重，单进程、15分钟，不调用优化或新AC。
- 模型路径：最多16输入×2目标×4096，其中2048用于开发、入选者另2048用于锁定后确认；四个门槛与三策略复用各阶段路径。单进程总预算60分钟；超预算保留已检查分母与未决。
- 非零报价：每目标最多1800秒、每输入最多3600秒，单求解器线程；最多12目标，名义总求解上限6小时。实际是否可报价取决于接口验收和合格缺口。
- 实际确认：每目标32条配对路径、三策略，总策略评价上限6×2×32×3=1152；不新做结构辨识。跨方法评分复用同一观测。
- 未来实际流命名空间固定为`posterior_dr_confirm_20261112`，study_seed=2026111201，replicate=20000..20031；模型开发／确认分别使用`posterior_dr_model_development_20261112`及`posterior_dr_model_confirm_20261112`，各2048条。具体源适配确定后记录到实施协议再生成。

失败、预算不足、物理适配不一致、多候选优化未就绪和无合格例均是可交付结果，不能绕过。阶段输出依次为：完成核验 → 全量后验与拒绝台账 → 资格／零动作清单 → 冻结报价 → 配对实际结果。

## 8. 到底量测与记录什么

每条实际路径为独立完整新日，24小时、15分钟一次、96时槽；同一时刻同步记录。历史仍为原64训练＋32验证。辨识器仅接收已有终端及根的量测，不新增隐藏节点传感器。

| 字段 | 最小记录粒度与单位 | 用途／可见性 |
|---|---|---|
| 终端P、Q | 每终端×96，保留带噪量测，kW/kvar与原pu基值 | 新日辨识输入；价格只使用历史预测，不读未来量测 |
| 终端电压V及根电压V0 | 每终端×96及根×96，pu | 形成`Y_it=V0_t^2-V_it^2`；使用带噪V0，不能偷换真根电压 |
| 时间戳、节点顺序、基值、噪声版本 | 每个观测文件 | 保证P/Q/Y同步、单位及原网络版本一致 |
| DR请求、名义交付、实际交付 | 每设备×96，kW；按原qratio汇总Q | 执行器日志与交付评价，不作为额外辨识特征 |
| 设备状态、投影／饱和及截止违约 | 每设备×时槽；原有功率／能量口径 | 检验原执行域；记录最大违规、饱和比例、交付偏差 |
| 名义费用、实际费用、绝对／净DR电量 | 每路径及设备汇总，原费用单位、kWh | 分开报价与支付；移峰净电量可能为零，不能只报净电量 |
| 每候选历史／新日SSE、权重及对数权重 | 每候选，最终及新日累计前缀 | 核对统一尺度更新，展示竞争者消退或重新进入 |
| 真族、真实背景与物理AC状态 | 仅模拟生成器及事后评价 | 完整错漏／恢复、覆盖、AC收敛；规划和选模不得读取 |

原始量测是P/Q/V/V0，不额外要求预测真实电压。后验使用平方电压响应残差，SSE与sigma²采用对应平方单位；不得与原电压V的噪声方差混用。全部候选评价使用原32点验证＋新96点；新日累计曲线只增加已到达前缀，训练64点不重复计分。

设备行为和费用沿用原合成设定，费用单位及合同规则如实记录，不称实证校准价格。

三策略共享背景、量测和设备响应的基础随机数；功率、电压及实际噪声幅度仍按各策略改变后的物理量和原噪声规则生成。101/111在同一策略下复用完全相同的观测。无DR路径可跨目标复用，但不能据此增加独立样本数。

## 9. 要哪些结果，以及怎样判断

### 9.1 三张主表

| 主表 | 必须包含的结果 |
|---|---|
| 历史算法与概率表 | 原方法完整恢复／覆盖／耗时；101/111各beta下有效分母、正确唯一输出、错误唯一输出、真族误拒、错误候选暂拒数、剩余候选数、w_max分布 |
| 资格与规划表 | 原候选数、目标及历史权重、结构差异／响应强弱、零DR界与开发达标率、A的大小、尾部界、优化后完整界／充分界、模型确认达标率、名义费用、适用域内上下界／gap及停止状态 |
| 配对AC比较表 | 每输入／目标／方法／策略／beta的32路径分母、物理有效数、正确唯一输出、错误唯一输出、真族保留、MAP完整恢复及错漏、后验变化、实际交付／饱和／费用、配对胜负及失败原因 |

主终点为正确唯一输出：`C_beta={H_true}`。错误唯一输出为`|C_beta|=1且不含H_true`；完整恢复另按原完整活动内部支持族相等评价MAP。真族误拒率在库含真的分母内报告，库缺真同时列入全量覆盖失败；错误候选暂拒数须与真族保留一起看。真族在库外时，其权重写不适用，不能伪造成可计算的真拓扑后验。

每条路径另记录目标权重w_t、最高权重、竞争者总质量、C_beta大小及真正的结构错漏。最高竞争者的单对权重`w_t/(w_t+max_{j!=t}w_j)`与完整w_t并列，统计“单对过线但整库未过线”的次数；此诊断复用同一观测，不新增策略或物理路径。

所有比例给分子／分母；同一冻结输入／目标／策略的独立随机路径比例给95%精确二项区间。历史全量结果是相关的描述性计数，不按800次独立试验给二项区间。策略差给同路径的改善／变差／相同计数及连续权重差。以目标正确为条件的结果与目标错误分支分开，后者需报告是否强化错误结论；不同输入、方法、噪声档和复用路径不混当独立样本。失效／AC不收敛保留在计划32路径分母，另报有效路径条件结果，不只展示成功路径。

### 9.3 希望检验的结论与合法的负结果

- 算法层：原结构搜索是否增加真族覆盖或完整恢复；概率规则是否以保留竞争者减少错误的唯一结论。两种收益分开归因。
- 规划层：有合格缺口时，报价是否在完整库和原设备域满足声明充分界；独立模型路径是否与该界一致。有限路径是核验，不替代概率不等式的证明。
- 实际层：优化DR相对无DR及同费轮换，是否增加正确唯一输出／恢复；目标权重提高但错误结论更多时照实记为失败。
- 若无合格非零例、零动作已足够、尾部界过松、报价未决或AC改善不成立，分别交付对应结论；不预设必须得到正收益。

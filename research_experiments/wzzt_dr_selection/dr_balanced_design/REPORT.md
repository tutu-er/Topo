lie inside the original3% validation band. In114 of them, validation selects
an incomplete raw family. Final complete recovery remains11/217. This is a
selection-stage loss, not lack of fitted candidate information.

Across186 distinct observed WZZT fits there are400 paths,459 accepted steps,
including12 actual crossing deletions. All those12 cross-accepting fits finally
select native RNJ points rather than the crossing paths. Crossing acceptance
therefore is not counted as retained final recovery.

For example r1/strong_12/rotation_1_0_p2 accepts a crossing replacement01->12:
the saved full-error count falls2->0, but final selection returns to native01
and has3 errors. Removing all accepted-cross points and their successors from
the saved candidate tables, without refitting, leaves all12 final outputs
unchanged. This is a saved-point deletion diagnostic, not a no-cross rerun.

Of the14 mappings where W beats augmented RNJ,8 select native points,2 select
path starting points, and4 select accepted path points that only add the common
root. No retained proper-pair correction explains a W-specific gain. In the
one W-full/augmented-not-full example, the augmented method also has the correct
full candidate but selects a simpler one; W had fitted and rejected that
competitor. This is candidate admission and selection behavior, not a successful
B price design or evidence that RNJ never found the right structure.

Raw and final WZZT total errors happen to match. Contraction still has effects:
one true root deletion adds an error and one false pair deletion removes an
error. The two offset. For RNJ plus root, contraction adds net20 errors and
reduces complete recovery57 to49. Neither outcome supports a uniform threshold
change, and no threshold was changed.

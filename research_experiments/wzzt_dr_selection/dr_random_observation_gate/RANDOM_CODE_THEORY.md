# 随机方向DR：可用观测、候选生成及未闭合项

本模块只操作给定数组与控制记录，不导入仿真器、LP或AC。价格0/1/2和参与概率0/.5/.75为既有声明模型，非实证校准。所有控制仍每节点峰值增量.2kW/.07kvar、减/补各.2kWh、19-21h任务总电量.4kWh、非V2G、P在0至.4kW；四事件最坏支付1.6。

## 时序与随机矩

先给定价格并得到接受状态Z，再独立随机整个合同的正反方向S。两种方向都必须在用户预先认可的范围内；若方向揭示后仍存在方向相关拒绝或跟踪误差，应如实记录，不把指令当实测执行。

接受状态可依赖私人自然负荷，不把Z当作外生工具。随机S的总体关系在明确的物理/测量条件下为：

    E[w Y] = R E[w P] + X E[w Q]，条件为E[w e]=0。

w由记录的S和固定时间波形产生，不由电压Y选择。observation_moments对全部未来训练样本形成这些矩行，包括单方和无人参与。四事件仍仅是四个整段随机化单位，不是96或384个独立实验。

有限事件中，sum(S*g*自然波动)一般不等于0。一个独立自然/误差码T恰好与S一致的实现可产生完美的假块符号。因此raw矩仅为可观测估计量，默认没有统计覆盖或证书。它也是原P/Q/Y的左乘，没有凭空增加原数据的信息；公平基线须获得同一控制记录和矩。

## 观测输入消去：有条件的部分回归

候选生成默认另外检查一个数据内可计算条件。给目标平衡控制分量U（仅选双方已接受的事件，其余部分响应及其费用仍完整保留），定义：

    NP = P_observed - U；NQ = Q_observed - .35 U。

投影已知码向量到NP、NQ及已知事件常数列的正交补，得权重h，使h'NP=h'NQ=0且h'U=ea-eb。h只取决于P/Q和执行记录，不由Y挑选；代码检查信号是否被nuisance span吸收以及数值闭合残差。

如果P/Q可信、控制增量精确执行且Y/模型残差有事前给定绝对带epsilon，则

    Y'h = (R+.35X)(ea-eb) + e'h，|e'h| <= |h|'epsilon。

代码据这个条件数值带生成所有可能符号支撑。带内仍可正可负的节点保持未决；超过候选数量上限不截取前若干当覆盖。无显著效应、弱效应、没有双方接受或码落在剩余输入列空间时都允许未决。

这是一种部分回归，并非新的物理可辨识性。默认不会宣称统计证书；甚至可信输入下，浮点投影加上无界未知权重也不是全参数机器证书。numeric_readout_band只是读出数值不确定性，非正线路权重下界。

## 为什么当前带噪声场景仍未闭合

若Pm=P+etaP、Qm=Q+etaQ，则上述观测消去后仍有：

    Y'h = (R+.35X)(ea-eb) - R etaP'h - X etaQ'h + e'h。

P/Q噪声非零而R/X允许无上界时，不能从输入误差幅度直接得到统一电压带。数据依赖h也不能沿用外生S的零均值论证。模块因此对未知P/Q误差、未验证执行或未给定事前Y/AC误差带，默认不产生候选证书；可显式请求启发式提案，但必须标记模型未闭合并由独立实际选择评价。

原电压噪声零均值也不自动消除Y=Vroot^2-Vi^2的二阶偏差；AC损耗随控制变化，可使E[w e]非零。模块没有假设随机化会自动修复这些问题。

## 分块性质与边界

K=sum cT zT zT'、cT=rT+.35xT>=0，块族层状。对v=ea-eb，含a不含b的块构成正链，含b不含a的块构成负链，两侧支撑互不相交。总体正/负集合分别显露两侧最大的正有效块；共同祖先及不含a/b的块不响应。

零权块不会被该性质证明存在；任意弱正效应没有统一有限预算恢复保证。平衡码矩本身不直接激励全节点共同块，侧支也可能未受激励。固定Q/P增量只直接针对R+.35X，不分别证明R与X；结合原历史是否能分开需另验。

这类树性质不能直接宣称新颖。若只增加候选来源、最终仍用原raw L1，它的价值是搜索/初值，不是增加全族原始拟合的信息。WZZT并非唯一可使用这些矩或提案的结构估计器；全族参照、RNJ/直接读出基线应获得相同码信息、观测及预算。

## 接口与验证

- sample_controls(price_rows,pair_rows,seed,dependence)：先Z后S，保留单方响应。输出committed_payment，issued阶段actual_payment=None；执行完成后由运行层结算。
- controls_as_samples(draw,event_indices)：生成逐时delta_P_known_kw/delta_Q_known_kvar及独立码记录。
- observation_moments(observed,controls)：只读future_train P/Q/Y，输出全部响应状态矩行。
- discover_candidates(observed,controls,config)：只读history_train/future_train与控制，不读validation、true K、true baseline或true block。返回candidate_supports、可能未决的direct_family与逐条件诊断，certificate恒为False。

可信输入条件正例仅用于验证该条件模型，不能替代原P/Q=.005带噪场景。单元测试不是算法恢复或工程有效性实验。

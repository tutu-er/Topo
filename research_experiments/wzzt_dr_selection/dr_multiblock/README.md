# 随机DR与多块辨识：冻结的小机制测试

2026-10-29。目的：在相同边际响应概率、总预算、事件轮次和观测长度下，检验不同空间相关性及分轮投放是否形成有用输入差异，并由当前实际RNJ/WZZT转化为最终选线改善。此处的“鲁棒”是随机性进入规划；不是最坏情形优化。

## 冻结模型

- 五末端101–105、根1。S={101,102,103,104}包含A={101,102}、B={103,104}；105在S外。叶r=.08、S的r=.10、A/B的r=.06，x=.5r。弱/零B只作另列控制，分别r_B=.006/0；全部实际拟合仍使用原[0,2]域，允许零权，不添加正下界。
- 历史三天、每事件六个小时：公共基线[.9,1,1.1,1.1,1,.9] kW，历史日倍率[.95,1,1.05]。未来规划用该形状均值；四个实际事件用固定倍率[.98,1.02,1.03,.97]。基准功率100 kW，Q=.35P。线性Y=PR+QX，V=sqrt(1-Y)，无量测噪声；不称AC或iFlex实证算例。
- 每节点每事件的价为0/1/2货币单位每kWh，参与概率分别0/.5/.75。参与后整段执行.2×[0,-1,+1,0,0,0] kW，价格仅改变参与概率。每事件抽一次，不逐小时抽签。无参与时不改变该节点负荷；反弹不奖励。
- local：节点间独立U；common：同事件共用U。两种规律每节点的边际概率完全相同，事件之间独立。它们是声明的相关性对照，不是校准出的用户行为。
- 训练两事件，验证另两事件重复预定价格表、独立执行响应。历史另18点，训练30点、验证12点。所有方法用同一事件数和时长。验证参与初值/最终选模，不是未用预测测试集。
- 总约束为两轮价格矩阵元素和≤4。每次削减.2 kWh，只按实际参与支付，四事件最坏总支付≤1.6货币单位；另报告实际支付。结算假定本合成控制中削减量可核实，并非原iFlex日结算复现。每节点功率[0,1.5] kW、每事件净能量为零，线性电压筛查[.9,1.1]pu；没有AC、热限或行为效用验证。

## 规划与比较

枚举41个单点计划、21个同步计划（两轮同价向量）、891个自由分轮计划（包括前两类）。所有类均允许不激励；同步/自由类允许退化为单点。无“至少两个节点”条件。

规划复用普通D-opt定义：历史列RMS固定尺度、[P,Q]十列、ridge=1e-6。对完整两事件参与模式精确求E[logdet]，每计划最多16个local模式，common最多9个模式；另列均值响应logdet消融。不是logdet(E[信息矩阵])，不调用identifier、真拓扑或测试随机流。相同值1e-6容差内优先较小最坏支付，再按round-major价格元组字典序。对称历史/预测会造成位置并列；保存所有得分与并列数量，不按真块换选址。这是随机输入设计基线，不包装成新的WZZT耦合价格算法。

测试每种相关性下的全部41单点计划，外加随机规划的同步最优、自由最优和均值规划自由最优，共44策略×2规律×8条DR路径=704格。随机种子2026102907；训练和验证用独立事件行，策略共享随机流。实际自然负荷、日期和零量测误差固定，因此独立的是DR参与路径，不是整套观测。完整相同输入按哈希复用，主批最多124个不同拟合；加9个控制最多133，硬上限160。

9个完全参与控制：normal/weak/zero三案例各执行三个冻结local规划方案single/sync/full；分母独立，不混入随机恢复频率。三种方案即便价格相同仍保留比较记录，拟合复用。

“最好单点”分两种：规划最优是在41计划中按事前D-opt选出；测试样本内最好固定单点先对8路径平均，再在41计划中择优，只作事后参照，不作可部署成绩，也不用逐路径oracle。

## 实际辨识与评价

调用dr_pool_v2.adapter.fit_observed，不改任何默认规则：训练观测重建60棵RNJ/NJ树的候选池，15个raw RNJ完整族选模；主路径及最多两个收缩重拟合的额外起点；每路径25秒、每LP15秒、连续系数[0,2]；真实交叉删除、共同调权、1e-10+.001J接受门槛、3%验证选模与.16收缩全部保留。准确名称为冻结的有限候选池RNJ→WZZT多初值策略，不是A2参照或自由支撑MILP。

主指标为完整有效块族的漏检数+误检数、完整恢复、逐块A/B/S恢复；另报内部F1、价格支付、三种模型和路径来源。真值只用于模拟观测和拟合后评价，不创建/筛选算法候选。零B按有效真块评价，同时保留未收缩的全部配置参数。

不通过增加预算、修改阻抗/响应概率/并列规则或选择性丢弃失败改善结果。若输入设计得分增加而选线无改善，保留该否定结果，定位候选池、更新还是选模阻断，不扩大实验。

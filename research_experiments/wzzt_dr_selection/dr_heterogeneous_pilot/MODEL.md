# 异质连续DR与冻结候选的验证排除

本实现复用原条件积分、原含损耗AC、原表计噪声和原冻结候选选模器。新代码只处理资源、能量控制、连续请求和相应梯度。候选来自已完成的RNJ＋WZZT历史路径，所有R/X和原.16收缩输出预先固定；新日不重新拟合，也不重新搜索结构。

## 1. 与实际选模相同的激励条件

C为历史最终选择，F为历史3%带内的另一个不同输出。它们是历史竞争关系，不以测试真拓扑命名正确/错误。H_C,H_F是完整288时段历史验证的平均L1；L_C,L_F是新96时段平均L1。新日权重2，统一3%带给出

    S_k = 0.6 H_k + 0.4 L_k,
    D = L_C - 1.03 L_F,
    h = 1.5(1.03 H_F - H_C) + 2.5 epsilon,
    D > h  <=>  S_C > 1.03 S_F + epsilon.

epsilon=1e-12，为原验证浮点容差。此事件使C退出两族的验证带。它不预设F真实；最终仍按原支持数、损失和固定次序选模，并调用已冻结输出。报告D/h使用微pu²，规划不改变原L1单位。

## 2. 可调用资源与价格

每个节点含可转移用户负荷、可削减用户负荷、EV和家庭储能，库存沿用已冻结library.json/case_allocations.json。本批使用全库存域，三网络总功率分别21.5964、19.4048、22.9033kW；旧2kW受限域未使用。优化和探索共享同一库存、设备/时段/能量规则。

连续决策x_{r,h}为每资源每小时归一化请求，[-1,1]；纯削减资源[-1,0]。展开成15分钟请求并经设备控制T形成名义可行计划u=T(x)。全部节点开放，无最少启用节点、强制分散或费用上界。

令A^+_{r,t},A^-_{r,t}为相对基线的增/减功率裕量，c_{r,t}为该时段全激活补偿单价，则计划可还原为带方向报价

    pi_{r,t} = c_{r,t}|u_{r,t}| / A^{direction}_{r,t},
    C(u) = dt sum_{r,t} c_{r,t} u_{r,t}² / A^{direction}_{r,t}.

A=0要求u=0，dt=.25小时。每台资源同槽一个方向；不同资源相反调节分别核量、计费。价格单位采用合成人民币服务费假设，尚无行为弹性校准。它是预付全天服务合同，包含约定的自动回补；实际磨损费用代理另报，不重复收费。

## 3. 连续相关随机响应与因果执行

名义u不是状态截断后实际响应的精确数学期望。意向执行为

    U_raw(r,t) = u(r,t)[m + nu(r,t) Z(r,t)],
    U = T(U_raw).

Z由共同日偏差、节点日偏差、共同AR(1)与资源AR(1)组成。主模型方差份额(.15,.25,.20,.40)、phi=.8、m=1；失配测试为(.30,.30,.25,.15)、phi=.9、m=.9，基本标准差和原随机创新不变。用户/EV/储能基础相对SD .15/.08/.03，再乘冻结的节点与时段倍率。整段相关误差连续取值，没有枚举二元参与状态。

T每槽仅使用当前请求、当前能量及已声明的未来功率窗口。对下一时刻状态，同时要求物理上下界及剩余时间可回到服务目标；将它映射成当前功率区间后限幅。它不预知未来随机误差、不重抽失败样本。

- 用户移位：前缀能量偏移不超过±2A kWh，24时归零；削减只减不增，日量≤2A kWh。
- EV：00–08与18–24分别完成固定充电量，08–18不可用，无V2G；充电效率.9，50kWh/7kW模板按合同份额缩放，实际SOC核验20–90%。
- 储能：E/P=2.5h，充放效率各sqrt(.85)，SOC20–80%，首末50%。补回损耗所需电量计入实际调节和合同计划。

因此本模型代表具备约定自动控制的聚合资源，尚未包含临时离站、断网或用户取消服务。纯逐槽截断不具有上述能量性质。设备映射分段可微，反向累积其当前活动约束导数；有限差分核验只覆盖常规点，求解仍为局部非光滑问题。

## 4. 预测残差、条件积分与求解

预测器沿用历史非树raw R0/X0，背景和参考残差由三个完整训练日构造联合高斯，秩至多2。本批保留此旧预测器以隔离资源模型改变；资源库中另记的5–10%逐时预测方差尚未接入，不能写成已校准。

某个固定候选k的新日预测残差为

    r_k = mu_k + L_k z + sum_r [(R0-Rk)[:,i(r)]
              + qratio_r (X0-Xk)[:,i(r)]] U_r / base_kW.

实际评估另用原含损耗AC、真实P/Q记录及根/终端电压量测误差构造L_k。价格计算不读取该实际未来。

对响应路径及背景高斯的正交分量作外层积分，剩余一个标量zeta~N(0,1)使D(zeta)成为带符号的绝对值之和。原conditional_probability精确找每段D>h的区间，累加正态CDF。区间根对截距的导数经R/X差、执行T和名义T反传到x。无需固定历史残差符号，也不对整数拓扑求梯度。

期望问题为

    minimize_x C(T(x))
    subject to Pr_working[D(T(T(x)*(m+nu Z)),z)>h] >= .95,
               x in the declared resource request box.

状态可行性由T保证。32固定外层积分点近似概率并做局部搜索；128独立点仅诊断。内层精确积分不使有限外层或局部解成为全局/统计保证。

v1两次小随机SLSQP启动均未达95%。v2只追加一次有界计算修正：先用同一D的条件期望生成初值，再最大化原事件概率，找到可行点才做硬概率约束降费。条件均值用E|a+bzeta|的解析式，未替代最终事件或恢复评价。无可行点时只保存最好概率诊断报价。本批三例均未找到95%可行价，论文不能把这些报价写成该约束的最优解。

## 5. 比较及结论边界

每例6个新背景，四策略为zero、rotation、cost_first、optimized，主/失配共用背景和基础随机创新。轮换与优化同费；成本顺序方案满额仍较便宜，按便宜探索对照报告。参数、完整历史、资源和验证规则一致。

选模冻结后才核对真实块。144记录包含90份不同观察，共18个独立背景；零报价重复不增加样本。主结果是最终完整错漏、恢复和费用，D只是解释通过或未通过验证门槛的中间量。WZZT的本批作用是提供原路径中可用于回选的候选及参数；未证明完整新日搜索优势，也未完成全候选池推广。

# 冻结预测距离DR：执行前模型核对

本核对只阅读源码，不运行旧实验，不读取新日观测或真实结构。v1的60秒零报价incumbent及其上界应保持；v2仅增加经过原域核验的计算起点和源/报价绑定，不改变目标、64个场景或物理预算。

## 已对齐

- 基线差分使用历史P/Q标幺值及冻结R/X。增量列由物理kW/kvar合同波形乘冻结矩阵差，再且仅再除一次200kW基准。价格列乘lambda*(1+D*z)，单位一致。
- q严格是同背景两个预测器L1距离之差，除96*n。不是DR增量响应距离||A*u||，也不是观测损失差或3%排除裕量。
- 原1.6硬预算、价格2上限、实际幅值上限、互斥合同、共享因子设备约束保留。N=5同时扩展弹性、基线、功率及能量库存，明确为合成声明；没有把额外基线加入自然负荷。
- 六个完整历史P/Q模板均参与工作分布。64个规划场景与1000个独立同律场景分开，后者不支持真实现场概率或拓扑恢复概率。
- 只有历史选点及其下一接受竞争点进入冻结二模型池；R/X、顺序、支持数、校准和.16输出映射固定。主选模保留288历史验证行，再加96新行；没有新参数拟合。
- 实际物理生产与计量在报价冻结后执行。所有固定模型的预测/选模文件生成后才读取真实支持评价；失效和费用保留。

## 解释和决策边界

1. prepare的feasible_incumbent仅证明原约束可行。若gamma没有超过1e-6微单位，应称阶段I未找到正的90%分位激励，不能称90%达标报价。超时上界不能被写成不可行证明。
2. 引导时形与轮换共用按历史矩阵差选定的节点；比较隔离的是这些共同节点上的时形/类型/报价策略。新history_contrast合同仅用于优化策略，正结果应归于联合时形—报价设计，不能单归连续价格优化或选址。
3. 实际new_distance使用测得P/Q。乘性P/Q误差会随DR后的功率幅值变化，即使零奖励和DR共用随机数，测得距离增量仍含计量变化。应称观测输入上的配对增量；若另算物理输入增量，应在预测冻结后作为独立诊断，不能混称交付功率达标。
4. 新日q与累计验证裕量分母不同。因为历史预测不变，累计域的配对预测距离增量恰为96/384*q_new=.25*q_new；这不是损失差或3%裕量换算。
5. 零能量移峰在预测差分符号恒定且不跨零时可以使q严格为零。历史contrast合同依据均值处的时间导数改变正负槽位，凸次梯度不等式支持均值处的局部/全局下界；它不提供64场景或独立新日的90%保证。
6. 独立模型留出低于90%时保留失败，不根据该留出重设gamma、节点、N或合同再将同一数据称独立。四个物理新日也不足以认证总体90%。

# 冻结历史争议模型的连续随机DR

## 本轮边界

历史完整288训练＋288验证保留。调用已存在的历史RNJ＋WZZT结果，按原历史选模结果与同路径下一接受点选择两个完整争议族；不读真拓扑选择它们。每个族的R/X、原raw输出校准、.16收缩映射和排序均固定。新一天仅作验证，主评分为原288验证＋96新观测，按原3%带、支撑数及原顺序回选。没有新拟合、W搜索或候选生成。故本轮检验的是RNJ＋WZZT生成的固定模型的辨别能力，完整联合算法新日重拟合另属旧试验。

## 模型

节点i的类型j以全天能量中性形状h_j(t)调节自然负荷，报价c_j产生均值幅值a_j=λ_j c_j，实际幅值A_j=a_j(1+d_j^T z)。z的两个分量独立均匀分布于[-1,1]，两节点因子行为(.15,.05)和(.15,-.05)，相对响应相关.8。每节点最多选一个类型，报价与类型可同时为零。无Bernoulli参与；这是连续、相关、整段幅值随机模型，非实证用户校准。

U_P(t)=Σ_j h_j(t)A_j e_i，U_Q=.35 U_P。自然负荷不加新baseline；假定原负荷内已有可移时柔性分量。实际日若不支持该分量，保留失败，不裁剪或重抽。

每节点是5份原.2kW资源的合成聚合：baseline1kW、功率上界2kW、实际调节幅值上界1kW、累计移时能量±2kWh，λ=.5kW/价格单位，价格上界2并受最坏幅值约束收紧。两节点201/213由历史争议支撑、共同包含区域、历史P/Q最低值与冻结差分列大小确定。没有强制两点均购买。四种原时形为early、late、spread、opposedlate；第五种用历史均值预测差的L1次梯度，选8个最低边际时段削减、8个最高边际时段回补。其重排解只保证该线性方向最优，最终用下式精确评价。

记两个冻结预测器差为ΔR、ΔX。对历史自然全天模板s，b_s=vec(ΔR P_s+ΔX Q_s)，C_s c为随机响应带来的同量差分。N=96×16，直接目标为

q_s(c)=(||b_s+C_s c||_1-||b_s||_1)/N。

它不同于仅计算||C_s c||_1；能量中性的变化可能使后者正而q=0。目标最大化γ，使64个预锁场景中至少58个满足q_s(c)≥γ。64场景为6个完整历史日模板的均匀抽样与独立z抽样。固定连续场景后，使用绝对值等式、场景二元变量和有界大M精确表示，预算为凸二次约束，组成混合整数二次约束问题。求解60秒，保留可行解、界和超时；只有相应状态才称有限样本最优。主目标允许γ=0及零报价，主目标达到数值最优后，在规定容差内最小期望支付。

支付B(z)=Σ_j τ_j c_j A_j。因λ>0且乘子对称，E B=Στ_j λ_j c_j²；硬约束Στ_j λ_j(1+||d_j||_1)c_j²≤1.6。原资源接口的全天功率、可用窗、累计能量和终端能量约束对因子盒所有顶点核验。类型互斥，原总预算、3%规则、网络阻抗、.0005电压/.005P/Q误差保持。

这里90%只指工作分布下预测距离增量达到γ。有限64场景约束由1000个独立同工作分布场景核验；均不称总体概率保证、错误模型90%排除或拓扑90%恢复。

## 距离与最终排除

冻结模型k的累计验证平均L1为v_k(c)，用历史绝对误差总和加新日实际绝对误差，再除以384×16。当前粗族退出条件是v_coarse>1.03 min_k v_k+1e-12。最终仍在3%带内则优先少支撑，.16输出图固定。距离增大不充分保证退出：预测分离的方向、真实观测落在哪一侧、表计/模型误差和历史权重均有影响。真结构只在全部评分文件冻结后用于评价该对中哪族正确及完整错漏。

# 简化版方法说明

最新[PDF](method.pdf)与[LaTeX源](main.tex)。IEEE双栏两页，正文一页，证明放第二页附录。

正文用模型0表示当前模型、模型1表示备选模型，不预设增线或粗细关系。直接说明预测、平方损失、改善条件、所需电压差和最小费用优化；不展开Q/g/c等额外系数。

不需要新增矩估计。功率预测的均值和协方差可由预测器提供，也可在数值研究中直接假设；正态分布下的期望计算是附录证明的一步，不是额外参数估计。分布假设和误差输入仍是概率保证的前提。

损失差中的1/2来自正态密度exp(−S/2)。若改用J=S/2可吸收这个系数，但算法容差也须同步除2。本文保留S口径，避免与已给门槛混用。

主约束只写“两个模型的预测电压差d(u)，按固定W加权后达到门槛h”。W与h由给定误差协方差和改善规则预计算，正文不再使用白化、指数矩、粗/细候选等名称；计算细节在附录完整保留。新的写法与原Tκ条件精确等价，没有删掉协方差或门槛中的常数。

当前适配器仍用MAE；此文说明拟议的平方损失版本。相对门槛尚未接入优化代码或新增测试，本次仅修改文档。

编译命令：`latexmk -xelatex -jobname=method main.tex`。本次本地与桌面编译均通过，完整两页检查见BUILD.json。原main.pdf被阅读器占用，未关闭阅读器或删除本地文件；它是旧版，已由method.pdf替代，旧源仍可从Git提交2f96fc23恢复。

# 简化版方法说明

最新[PDF](method_appendix.pdf)与[LaTeX源](main.tex)。IEEE双栏三页：正文一页不变，附录两页按推导顺序解释计算。

正文用模型0表示当前模型、模型1表示备选模型，不预设增线或粗细关系。直接说明预测、平方损失、改善条件、所需电压差和最小费用优化；不展开Q/g/c等额外系数。

不需要新增矩估计。功率预测的均值和协方差可由预测器提供，也可在数值研究中直接假设；正态分布下的期望计算是附录证明的一步，不是额外参数估计。分布假设和误差输入仍是概率保证的前提。

损失差中的1/2来自正态密度exp(−S/2)。若改用J=S/2可吸收这个系数，但算法容差也须同步除2。本文保留S口径，避免与已给门槛混用。

主约束只写“两个模型的预测电压差d(u)，按固定W加权后达到门槛h”。W与h由给定误差协方差和改善规则预计算，正文不再使用白化、指数矩、粗/细候选等名称；附录依次解释整理损失差、选择概率上界、选择参数、两次正态积分、回代W/h。明确说明该不等式是一种为保留二次形式而作的选择，λ的区间是充分而非必要范围，固定λ不保证最紧。

积分细节说明：每次积分都将函数乘以对应正态密度；先固定模型预测差，只对电压误差平均，再对功率误差引起的预测差平均。两次配方后给出明确换元、体积变化因子和正态密度归一化，解释b的幂次及行列式从何而来。正文与W/h逐字保持不变，源代码比对已核验。

对应实现已集中为[exponential_dr.py](../exponential_dr.py)一个文件，代码内附符号、公式、假设、输入输出、原设备接口及直接运行示例。固定指数参数和本文W/h一致，含概率下界、实际冻结模型损失及连续QCQP。25项数学、解析最优值、原设备接入和独立迁移检查通过。原辨识适配器仍用MAE；新增平方损失概率条件未改变原默认选模，也尚无新paper15/AC最终恢复结果。

编译命令：`latexmk -xelatex -jobname=method_appendix main.tex`。本次本地与桌面编译均通过，完整三页检查见BUILD.json。原main.pdf和method.pdf被阅读器占用，未关闭阅读器或删除本地文件；新版使用method_appendix.pdf，旧源仍可从Git历史恢复。

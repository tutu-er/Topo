# 条件于目标候选正确的零DR检查

本阶段回答：已有候选库包含真拓扑时，条件于目标候选正确，完整历史和一整天自然新增是否已经足以达到原90%激励要求？只计算零动作，不拟合、求解报价、抽样或运行AC。

## 固定模型

每个输入保留96行训练、288行历史验证、原.24收缩后训练QP输出库和原参数。目标是历史严格MSE选中的参数点。只用既存离线真值清单确认其结构正确，规划工作请求不含真结构、测试文件或物理网络路径。合格40组均历史已选对；这本身不用于断言新日概率足够，而是继续计算条件概率充分界。

令P为节点P/Q拼接的功率向量，H_t为目标响应矩阵，H_j为竞争者。新观测的条件模型是Y=H_t P+e。对同一观测比较物理平方和，令d=(H_t-H_j)P，则

\[
L_j=\|Y-H_jP\|^2-\|Y-H_tP\|^2
=\|d\|^2+2e^\top d.
\]

历史平方和分别为S_j^h和S_t^h，历史与新日总标量残差数为N，原MSE并列容差为epsilon=1e-12/K。严格击败竞争者的充分事件为

\[
L_j>\delta_j,\qquad \delta_j=N\epsilon-S_j^h+S_t^h.
\]

目标历史已胜出使delta通常为负，表示新增观测只要不耗尽历史优势，原合并选模仍保留目标。历史只计一次，新日权重1。

原工作误差法则保留：功率均值为4个已观测完整日的逐时均值；每通道标准差为预测最大绝对值的5%；同节点P/Q共用因素、不同节点独立、时间AR(.7)。剩余电压误差独立，逐节点标准差为目标历史验证残差RMS与2sqrt(2)*sigma_V的较大值。没有改成上一替代分支的历史功率RMS。实际P/Q/V噪声与AC偏差的校准不由本条件模型证明。

## 精确积分与谱计算

用s=max(sd_e)统一归一化电压响应，保留不加权物理MSE，令E_i=(sd_e,i/s)^2。固定lambda=1/4，t_i=lambda*(1-2lambda*E_i)。两次高斯积分给每个竞争者的失败上界

\[
p_j^{\rm upper}=\min\{1,\exp(\lambda\delta_j/s^2-T_j)\}.
\]

其中T_j=q_j+0.5logdet(G_j)，与已有core.build_gate完全相同。为避免重复形成96n维稠密矩阵，零动作使用Kronecker结构的精确谱分解。记R为96时段AR相关矩阵，F为归一化节点功率差因素，B=diag(sqrt(t))*F*F'*diag(sqrt(t))，则G=I+2R⊗B。

若R=U diag(r) U'、B=V diag(b) V'，W=(forecast*(H_t-H_j)'/s)diag(sqrt(t))，则

\[
q_j=\sum_{a,i}\frac{(U^\top WV)_{ai}^2}{1+2r_ab_i},\qquad
\log\det G_j=\sum_{a,i}\log(1+2r_ab_i).
\]

空间特征值直接由diag(sqrt(t))*F的奇异值平方取得，没有删弱方向或裁剪负特征值。该变换改变计算表示，不改变误差模型或概率上界。

对所有不同支撑的竞争者求失败上界之和。和不超过0.1，便充分保证目标拓扑在声明条件模型下以至少90%概率严格击败这些竞争者。所有比较共享同一P/e，union上界不要求比较事件独立。另报固定参数点击败全部其他点的口径。本批188比较均为不同支撑，两个口径相同。

严格击败是原选模胜出的充分条件，可能比其并列规则保守；完全相同的响应矩阵按原固定并列顺序处理。本批没有此类不同支撑精确等价对。

## 结果与解释

40/40完成、0失败，共188个竞争比较。四个网络分别paper15 12/12、Soumalas 11/11、Flynn 8/8、Pengwah 9/9，全部零动作已满足整库90%充分条件。

最弱输入为pengwah18/b1001/v0010：整库条件成功下界0.99999971548。其最难竞争者的归一化delta=-54.195、T=1.52371；完整历史使要求T达到的门槛为-11.2462。因而本批不是只看新日有多少差异，已有历史优势是零动作足够的重要来源。

原费用非负且零交付可行，因此本批声明条件规划问题的最小费用均为0，无需再启动非零报价求解。该结论不等于实际AC成功率已经验证，也不是40组新的恢复实验。浮点数显示下界1的输入仍保留log失败上界，不能解释为绝对无失败。

不为制造付费空间提高门槛、删历史、改变噪声或线路。这40组作为含真候选的零费用对照保留；后续正效应例仍需同样满足候选覆盖，并在原要求下存在可核验的剩余缺口。

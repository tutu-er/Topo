# MIQP门槛核对及一次非零DR诊断

## 查到的实际指标

隔壁`mse_exit_tuning_20261111/gate.py:61–79`的研究版最终E接受条件是

\[
M_0-M_1>10^{-10}/K+\tau M_0,\qquad\tau=0.001.
\]

$M_k$为物理电压响应残差的**不加权MSE**，$K$为已有训练损失尺度。等价地，$(1-\tau)M_0-M_1>10^{-10}/K$。写成指数模块的$S_0-\kappa S_1>\delta$时，必须用$\kappa=1/(1-\tau)$。它不是此前逐单元标准化平方和的1.03门槛。

隔壁MIQP的结构提议目标仍含计数罚；纯MSE门槛仅用于研究版最终E的raw训练提议，生产默认未切换。最终主选模仍是**严格验证MAE**，输出采用.24收缩。当前DR原对照是3% MAE与冻结.16输出，二者没有自动统一。

本轮借用其MSE门槛形式比较两个冻结候选，完整保留原288训练、288验证及资源，不称为重跑隔壁完整MIQP。历史评分用全部288验证槽加96新日，训练288槽用于已有拟合及本诊断的K。固定模型0的训练MAE/MSE给K=539.4260611；它是本输入的尺度，不冒称隔壁另一批输入保存的K。

## 原门槛和临时诊断分开

原τ=.001问题仍以零DR满足，费用全局最小0。该结论保留。

按用户允许的临时数值调整，另在新实际数据打开前锁定**τ=.05**，要求备选相对当前候选的物理MSE改善超过5%。这只是更强证据要求的诊断，未将其写成WZZT推荐参数。预测、历史、线路、噪声、全部60资源的能力/成本及原最终选模均未调整，不再提高τ寻找正结果。

## 指数条件和求解

为保持物理MSE，所有残差仅除以同一标量s=max(sd)。原异方差仍保留为$E=\operatorname{diag}((sd/s)^2)$，不是把每个残差除以其sd后改变损失。原功率背景误差给标准化候选差协方差C；价格规划中的误差协方差固定。

模型1为参考时，$z\sim N(d(u),C)$、$e\sim N(0,E)$独立，新日差为$L=\|z\|^2+2e^\top z-(\kappa-1)\|e\|^2$。令

\[
\lambda=\frac1{4\kappa\max_i E_{ii}},\quad
a_i=1-2\lambda(\kappa-1)E_{ii},\quad
t_i=\lambda\frac{1-2\lambda\kappa E_{ii}}{a_i},
\]

\[
G=I+2\operatorname{diag}(\sqrt t)C\operatorname{diag}(\sqrt t),\quad
q(u)=\|\operatorname{chol}(G)^{-1}\operatorname{diag}(\sqrt t)d(u)\|^2.
\]

两次高斯积分给固定门槛

\[
q(u)\ge h=\lambda\delta+\log\frac1{1-\beta}
-\frac12\sum_i\log a_i-\frac12\log|G|,\qquad\beta=.9.
\]

$\delta$含原数值MSE容差和完整288验证槽的既有差值。代码`miqp_mse.py`逐步给出单位、K与容差换算；原`pure_mse_gate`逐字保存在`vendor/miqp_gate.py`。背景功率误差与剩余电压误差在规划中独立；实际P/Q表计、相关乘性交付、饱和及AC偏差保留在独立执行核验，不将工作模型概率宣称为全部实际误差的保证。

最小费用仍用原小时请求与因果设备控制图。直接非凸全局求解120秒只保留初始可行报价，费用24.95880、下界0、gap100%。随后事前单列一次60秒计算修正：用凸q在已可行交付$u_k$处的切平面

\[
q(u_k)+\nabla q(u_k)^\top(u-u_k)\ge h.
\]

该线性下界蕴含原二次条件，保持可行性；内问题仍调用原设备图。它找出费用24.35105的可行方案，比初始低2.435%。319个小时请求改变，24个资源有非零交付。内问题也超时，下界9.09855只属于内问题；原非凸全局下界仍为0。因此本轮得到**有效可行DR**，未证明最小费用。

## 指标确实产生了增量

规划分数q从无DR的11.23698升至21.50747，增加10.27050；门槛h=20.03144。同费轮换q=11.16094。优化方案的指数充分成功下界为97.7146%，高于规划90%；它是工作模型下的下界。

独立工作模型32768条共享随机路径，5%门槛过线：优化32762/32768、无DR27827/32768、同费轮换27619/32768。未用这些结果调整报价。

冻结后，新32条配对执行/量测路径、三策略共96次原AC观察：

| 方案 | 平均相对MSE改善 | 5%门槛过线 | 原3% MAE完整恢复 | 总漏块/假块 | 合同费用 | 实际绝对调节均值kWh |
|---|---:|---:|---:|---:|---:|---:|
| 无DR | 5.0445% | 16/32 | 0/32 | 32/0 | 0 | 0 |
| 同费轮换 | 5.0362% | 16/32 | 0/32 | 32/0 | 24.3510 | 112.5455 |

这里“相对MSE改善”定义为$(M_0-M_1)/M_0$，表示两个候选解释同一观测的差别，**不是同一个模型执行DR前后的MSE下降**。优化后错误候选M0均值由2.24393×10⁻⁶升为2.27318×10⁻⁶，备选M1约为2.1308×10⁻⁶，主要增强了两个候选的区分。

优化相对无DR的平均增量为**1.2163个百分点**，相对轮换为1.2246个百分点；32条配对路径均增加。原MAE最终选模相对两对照均17好、15同、0差。0.1%原门槛在三策略下均32/32，本轮新增效果属于明确标注的5%诊断。

另直接计算两候选在实际新日P/Q下的预测电压差平方均值，不使用量测电压V：无DR为1.35346×10⁻⁷，优化为2.54171×10⁻⁷，同费轮换为1.35026×10⁻⁷（单位p.u.⁴）。优化相对无DR增加87.79%，支持本次变化确实拉开了两个冻结模型的预测。

进一步按隔壁的strict MAE形式在**同一旧冻结.16输出库**上回放，三策略均32/32恢复，已有零费天花板。这个对照不是隔壁完整MIQP/.24输出结果，也不计DR收益。平方门槛32/32而原3%最终仅17/32，仍说明激励事件的90%目标不等于最终恢复概率。

## 范围和复现

分母为一个此前已见自然日、32条新的配对随机路径；96是策略×路径观察数。完整历史保留，H/R/X和原输出冻结，0新参数拟合、0新W搜索。合同费用为原合成合同单位。模型和结果源、所有时限/上下界及随机种子保存在恢复目录，不删除未收敛求解记录。

新增入口为`miqp_mse.py`（精确指数MSE条件及一次全局尝试）和`miqp_mse_refine.py`（一次有可行性保证的计算修正）。本机`miqp_case/`包含额外训练电压输入与声明的起点，只作为独立文件夹的本地数值接口，不上传轨迹。

```text
python -B miqp_mse.py --case miqp_case --tau 0.001 --out runs/native
python -B miqp_mse.py --case miqp_case --tau 0.05 --warm miqp_case/inputs/warm.npz --out runs/diagnostic
python -B miqp_mse_refine.py --case miqp_case --parent runs/diagnostic --out runs/refined
python -B run.py ac --case miqp_case --plan runs/refined --out runs/actual
python -B miqp_mse_score.py --case miqp_case --actual runs/actual --out runs/mse_scores --tau 0.05
```

`run.py`原AC汇总中的`squared_successes`仍属于旧标准化平方事件；新物理MSE的5%过线必须使用`miqp_mse_score.py`输出，避免混用。完整标量结果见`MIQP_RESULTS.json`。独立公式74项、保存结果718项核对及原物理交付/噪声审计均通过；96观察/9216时点全部收敛，设备检查96/96、电压越限0，热限未核。

本轮证明在该有限冻结争议中，非零、定向DR能够增大物理MSE差别并改善原最终回选；5%门槛选择、全局费用最优性、以及完整MIQP重新搜索的收益仍需分别处理，不能合并成已验证结论。

# 已有错误算例的MSE与DR小测试

本目录复用历史QP候选、原异质资源控制器及原AC/量测函数。参数在历史拟合后冻结；没有重写或重新运行拓扑辨识器。`core.py`负责历史输入和概率约束，`run.py`负责报价、冻结、实际AC和全候选选模。数值输入与轨迹放在外部`--out`目录，不能提交到Git。

## 要检验什么

先在已有结果中寻找最终有错漏且候选库仍有改善空间的情况，再检验DR是否改变最终选择。案例选择是明确的事后诊断；报价只使用完整历史观测与冻结候选，不使用真实支撑或新日数据。它检验一个局部机制，不估计随机抽取配网的平均收益。

主测试保留原输出收缩`.24`、原训练QP参数、原噪声和完整96训练/288验证。所有合法输出候选保留，候选数量与各来源写入准备清单。新日与历史验证的每个观测等权。价格不按新日实际结果重调。

## 与最终选模相同的门槛

设`c`为历史严格MSE选中的输出，`f`为历史MSE最近的另一支撑族，参数均已冻结。旧验证平方和为`S_c^h,S_f^h`，新日平方和为`S_c^n,S_f^n`。`m_h,m_n`是相应残差元素数，`K>0`沿用原输入的公共归一化常数。

最终选模直接比较

\[
 M_k=(S_k^h+S_k^n)/(m_h+m_n).
\]

严格数值并列容差为`K*MSE`单位的`1e-12`，并列先选proper内部块更少者，再按分数和原次序。因此让`c`退出数值并列集合的充分条件为

\[
 S_c^n-S_f^n>\delta,
 \qquad\delta=(m_h+m_n)10^{-12}/K-S_c^h+S_f^h.
\]

这个条件不调用训练E的0.1%门槛，也不使用3%验证带。最终仍在全部冻结输出之间选择，不把成功排除一个候选称为完整恢复。

## 规划的概率条件

功率预测为四个已观测完整历史日的逐时均值。给定参考候选`f`，新日电压响应假设为`H_f p+e`。预测功率误差为固定高斯过程：每节点P/Q共享一个随机因子，不同节点独立，时间AR系数`.7`，各通道标准差为最大绝对预测值的`5%`。剩余电压误差逐节点取历史验证残差RMS与`2*sqrt(2)*电压表相对标准差`的较大值，规划暂假设其零均值、独立高斯且与功率误差独立。这是工作假设，不是实证校准。

令`z=(H_f-H_c)p`。新日损失差为

\[
 L=\|z\|^2+2e^\top z.
\]

对`e`和预测功率高斯因素做两次解析积分，计算现有指数上界

\[
 \Pr(L\le\delta)\le
 \exp\{\lambda\delta\}\mathbb E\exp(-\lambda L),\qquad
 \lambda=1/(4\lambda_{\max}(\operatorname{Cov}(e))).
\]

统一标量归一后，右侧不超过`.1`等价于`||b+F u||^2>=h`。`b,F,h`由冻结候选、历史缺口和固定协方差预先计算；全部非零影响资源都保留。原高斯积分与`MSEGate`直接复用。最终概率只条件于所选参考模型和上述分布。

本次规划使用原设备映射的名义交付`u`；实际响应则沿用已有节点、时间相关随机倍率，再由原控制器按功率、能量和截止时刻截断。实际随机交付、AC非线性及P/Q/V量测误差是独立执行核验。因此90%是工作模型中的规划条件，不能当作实际达成率的保证。

## 价格、求解与评价

每资源每小时有一个有符号请求，展开为96个15分钟动作。原控制器实现用户移峰/削减、EV到离站段能量约束及储能状态约束。报价与名义交付的映射、费用和能力均沿用原资源库；费用为按资源和时段变化的凸二次补偿，不增加硬费用上限。

主问题最小化原费用，约束为原设备可行域及上述反向二次约束。先检查全域零费解，再以两个事前指定锚点的线性下界构造内近似MIQP，每次45秒；另给原非凸模型60秒。内近似的下界只用于该内问题。保存所有求解状态、可行上界与原问题界，不宣称限时可行解是全局最优。未达到概率约束时，保留最佳事前方向为**未达标诊断**，如实评价，不改阈值。

冻结报价后，每case运行六条独立完整新日路径，比较无DR、规划DR及同费轮换。自然日、响应抽样和量测随机流在三策略间配对。保留未收敛、越限和未决，最终指标为全支撑错漏、完整恢复、实际调节量、合同费用；另报告指定候选的排除率、真实观测损失差和候选预测差平方均值。

## 运行

在仓库环境中执行，`OUT`指向私有空目录：

```powershell
python -B research_experiments/wzzt_dr_selection/dr_pricing/mse_existing_cases/run.py prepare --out OUT
python -B research_experiments/wzzt_dr_selection/dr_pricing/mse_existing_cases/run.py plan --out OUT
python -B research_experiments/wzzt_dr_selection/dr_pricing/mse_existing_cases/run.py actual --out OUT
```

依赖原Python环境中的NumPy、SciPy、Pandas、NetworkX及Gurobi；读取已有结果位置在`run.py`顶部声明。程序保留断点与报价哈希；同一路径不重复求解已冻结报价，不重复完成的实际观察。此处为研究测试入口，不改变生产默认。

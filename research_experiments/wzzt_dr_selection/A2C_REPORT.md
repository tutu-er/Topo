# A2c：完整补全检查与可观测通道

2026-10-27。当前仍在 A2。已完成 17 个历史数据集、96 次块检查，以及另列的 4 次事后通道对照。

**可以保留“排除某块后，所有完整解释是否都无法拟合”的判断方向。矩阵 LP 下界在本批次没有出现数值越界，但存在明确的判别缺口，也没有计算优势。尚未据此构造或验证新的价格方法。**

## 1. 与 WZZT 的直接联系

本目录使用独立的小系统参照，不是生产 WZZT 的复现。WZZT 的共享块表示为

\[
Y=RP+XQ,\qquad R=\sum_{C\in\mathcal T}r_Cz_Cz_C^\top,\qquad
X=\sum_{C\in\mathcal T}x_Cz_Cz_C^\top,\quad r_C,x_C\ge0.
\]

\(\mathcal T\) 是相容的层状块族，\(z_C\) 表示块包含哪些观测终端。旧、新块的全部权重共同优化，零权重始终允许。

先让历史数据下的逐块算法运行到停止，再检查所有非单终端候选。已有贪心块只影响检查顺序，不限制后续完整解释，也不按真实标签删除误选。候选生成、停止和补全检查均不读取真块标签。

对候选 \(C\)，完整参照为

\[
J_{\neg C}=\min_{\mathcal T:C\notin\mathcal T}\ \min_{r,x\ge0}
\|Y-RP-XQ\|_1.
\]

这里“排除 C”指排除共享支撑：不能仍允许 \(x_C>0\) 而称 C 已删除。三节点枚举 8 个块族，四节点枚举 52 个块族；每个块族优化全部连续权重，随后复用结果检查各个 C。这解决的是完整参数补全，未采用每族一个固定参数代表代替参数集合。

先确认至少有一个完整模型的损失不超过声明的误差预算 \(\epsilon\)。在此基础上，\(J_{\neg C}>\epsilon\) 才表示 C 对该模型与误差预算是必要的。若整个模型集合都不相容，应报告模型/预算失配，不能把空集合变成所有块都必要。

## 2. 可计算下界及其限制

取非负组合 \(K=aR+bX\)，其中 \(a,b\ge0\)。在共享层状模型中，若没有 C，对任意固定 \(j\in C\)，至少存在 \(i\in C,k\notin C\)，使

\[
K_{ij}\le K_{kj}.
\]

理由是：若 C 内所有节点与 j 的公共路径权重都严格大于 C 外节点，则在 j 的祖先链上必有一个恰好包含 C 的块，与“没有 C”矛盾。零权重会把严格差变成相等，但不会破坏这个必要条件。C 为全部终端时，外侧使用已观测根，\(K_{kj}=0\)。

每个 \((i,j,k)\) 分支对 R、X 只保留对称、逐项非负、对角元不小于对应非对角元，并加入上式，最小化同一 L1 误差。这个集合包含合法树，也包含不合法矩阵；它不是替代树生成器。若该分支的有效对偶下界记为 \(d_{ijk}\)，则

\[
\underline J_C=\max_{j\in C}\ \min_{\substack{i\in C\\k\notin C}}d_{ijk}
\ \le J_{\neg C}.
\]

内层必须检查所有分支，不能挑最有利的节点对。分支求解失败时保留失败并标记未决。代码检查数值原始/对偶残差和间隙，并阻止超过合法补全可行上界的结果进入“必要”分类；这些是浮点检查，不是精确算术或统计覆盖证书。

本批次不施加“已确认块”的外部列相等约束。只有该块确已成立时，这类约束才合法；加约束后的界应与同样受限的补全参照比较。错误地把早期贪心块当已确认块，可能删掉真实解释。

## 3. 锁定批次和结果

协议为 protocol_a2c.json。13 个三节点数据集各检查 4 块，4 个四节点数据集各检查 11 块，共 96 次。包含多遗漏线路、弱线、共同输入、错误早期块、三种历史前缀、平衡/嵌套结构、零权重、\(10^{-6}\) 弱权重、P/Q 混同、仅 Q 输入、整体模型失配。

主批次 \(\epsilon=0\)，数值比较容差 \(10^{-7}\)。这是无噪声模型检查，尚未校准工程误差预算。

| 结果 | 次数 | 含义 |
| --- | ---: | --- |
| 找到不含 C 的合法补全 | 69 | 至少一个完整解释在预算内 |
| 矩阵下界确认 C 必要 | 18 | 下界已超过预算，且完整模型集合非空 |
| 完整参照要求 C，但下界未能确认 | 5 | 松弛缺少判别力 |
| 整体模型与预算不相容 | 4 | 同一个失配数据集上的四块检查 |
| 失败、超时或未完成 | 0 | 本批次全部求解完成 |

96/96 次没有发现下界超过合法补全可行上界加 \(10^{-7}\)；18 次必要判断中，离线真值核对发现 0 次错误。重复历史、不同通道方向和不同块检查不是独立统计样本，这些分母不表示泛化误报率。

主要数值：

| 历史和块 | 完整无 C 最小损失 | 矩阵下界 |
| --- | ---: | ---: |
| 三节点独立输入，C={0,1} | 2 | 2 |
| 同一输入，C=全部终端 | 4 | 2 |
| 四节点平衡部分输入，C={0,1} | 0.6 | 0.6 |
| 四节点完整输入，权重 \(10^{-6}\) 的 C={0,1} | 约 \(4\times10^{-6}\) | 约 \(3\times10^{-6}\) |
| P=Q，检查 R 方向的 C={0,1} | 0.4 | 0 |
| P=Q，检查 R+X 方向的 C={0,1} | 0.4 | 0.4 |
| P=0，仅 Q 输入，检查 R+X 的 C={0,1} | 0.4 | 0 |

三节点根块例直接给出判别缺口：忽略数值容差，当 \(2\le\epsilon<4\) 时完整参照要求该块，而这个下界无法确认。不能把下界为零或不超过预算写成“结构不可辨识”。

故意加入错误已确认块 {0,2} 的独立诊断，使一个原本损失为 0 的历史拟合损失升至 2。主批次没有使用这个错误反馈。

## 4. 仅 Q 输入揭示的问题

P=0 时，未知 R 不受数据约束。R+X 方向的下界可能为零，因为矩阵松弛没有要求 R、X 共享同一个层状结构。松弛中的 R 可以包含与 X 的块交叉的支撑，从而掩盖列差。这不是合法共享树中出现了线路抵消。

事后对同一历史增加 \(K=X\) 对照，不固定未知 R，也不增加任何观测。方向选择只用已知的 P=0 和 Q 满行秩：

- C={0,1} 的下界从 0 升至约 0.4，与完整参照一致；
- 根块下界仍为 0.8，完整参照为 1.6；
- 另外两个块仍有合法替代解释。

这 4 次检查单独记录于 x_only_followup.json，不并入锁定的 96 次。复用 8 个完整块族拟合，新增 18 次分支 LP。

可预先使用 R、X、R+X 的少量非负组合并取下界最大值，其有效性保留，但计算成本也增加。任意带负系数的输入奇异向量不满足上述排序论证。下一步应先检查哪些非负方向实际受历史 P/Q 约束。

## 6. 下一步与停止条件

“存在不含 C 的解释”尚不足以将 C 选为值得付费的未决目标：C 可能已经只能取零，或只存在不可观测的参数差异。下一批仍在三/四节点做一次有界审查：

1. 在完整历史相容集合上，区分 C 必要、C 可有非零可观测效应、仅零效应、无界或数值未决。最大可能权重与可观测效应分别记录，不加人为正下界或上界。
2. 对算法生成、确有正效应可能的未决块，查找价格可实现的节点相对输入。使用完整参数补全与少量有效非负 R/X 方向；保留零效应与共同输入导致的无收益情形。
3. 若使用“未来仍无法区分的两个完整解释的差异宽度”，它只评价歧义缩小，不能据此宣布该块存在。先验证它是否能区分 A2b 中完整恢复 0.82 与 0.18 的菜单，再考虑新价格优化。
4. 同预算 D-opt、随机菜单、无奖励保持同一停止规则；评价完整有效块恢复、弱块恢复、无需新数据比例与 LP/时间成本。设计只读历史和预测整段响应，实际模拟用于评价。
5. 若该诊断不能改善价格排序或降低成本，就停止将它作为价格指标推进，不增加工程算例包装收益。小系统通过后才考虑 B1。

当前可报告的是 WZZT 共享块结构对应的完整补全判断及其有限数值核验。新的概率价格设计、恢复优势、噪声下统计覆盖和实测需求响应仍未完成。

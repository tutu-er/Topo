# v4：先解决规划提高、实际分离下降的原因

本轮主张：统一已观测信息和完整AC评分，在父点校正代理值/梯度，并保护每个参考拓扑，可减少动作收益误排。是否减少实际误排由新历史检验；移动本身不设改善要求。旧v2/v3科学源码和评价记录不改。

## 已确定的数学模型

D=H∪V为规划前已到达的全部计量。对每候选a，仅估一组θ_a,D=(R_a,X_a)，用于所有未来参考响应。P/Q直接输入，根电压/独立校准偏差固定；EV只加到末端总P一次。竞争者b对D与预测未来联合拟合，线路跨时共享，源逐时但固定同一物理接口。

S_ab(u)为这一完整AC拟合的半SSE，d_ab=S_ab−S_aa，m_a=min_{b≠a}d_ab，Φ=mean_a m_a。实际评价使用相同D和候选/物理域/拟合目标，仅未来计量换为实际数据。局部数值拟合保留收敛状态，不称全局MLE。

围绕父计划p，用完整AC白化残差与导数构造有域QP：q_ab(u)=.5 min_{z∈Z_b}||c_ab+B_ab(u−p)+J_bz||²。Z_b由原R/X盒、X/R比例和逐时源界平移得到。每对的局部规划模型为

    s_ab(u)=q_ab(u)+α_ab+β_abᵀ(u−p),
    α_ab=d_ab(p)−q_ab(p),
    β_ab=∇d_ab(p)−∇q_ab(p).

这使值和一阶导数与完整AC父评分一致；数值QP使用primal替代q(p)时保留对应primal/dual间隙，父值对齐至该误差。α、β只改变仿射项，保留共享平方分段MILP结构。合法z给上界，支持LP给下界，界只属于本次冻结校正代理。

每个较大域先按同一Φ选最佳直接父p。完整AC接受新动作的条件：Φ(u)>Φ(p)+容差，且对全部a有m_a(u)≥m_a(p)−容差。失败、未完整评分或未通过保护时保留p及完整路线x。该规则保证取得的规划目标不退步，每参考预测间隙不受损；未知均值和未来噪声仍需独立评价。

## 四组域及公平比较

FC=固定纯充，FD=固定双向，MC=允许移动纯充，MD=允许移动双向。FC⊂FD、FC⊂MC、FD∪MC⊂MD；FD与MC不排序。移动为可选，0次合法。跨域通过完整弧映射复制父计划，禁止按功率重求路线。MD继承最高Φ父；不能拼接不同父的逐参考最大值作为下限。

每域比较平方功率MILP、对齐平均指标、对齐平均指标+逐参考保护。平方方法按自己的Q目标优化；其完整AC评分只作同域对照和判别方法初值。开发1的180秒使最高域无提案预算，开发2改为每策略四域300秒软总预算、各域75秒软配额，包含父依赖及所用平方初值成本；同一策略缓存父评分，策略间独立engine/cache。参数估计和预测作为共同准备单列。主MILP每次3秒，解释交换至多2轮，每域先一轮提案。失败/超时保留父计划且计分母。

## 顺序及验收

1. 数学与物理域：保存本方案和详细推导；验证四域包含、路线保真、QP支持下界、平方弦上界、活动边界、仿射校正。极小离散穷举仅作审计。
2. 开发4条独立历史：n3/n4×regular/shift，T12，H96+已观测4。普通负荷时变、功率因数适度独立变化；shift仅未来有未预测变化。保持原资产范围、不抬高Rmin。核验父继承、完整Φ单调和每参考保护；代理/AC收益分开。
3. 冻结科学源码/配置/种子后评价8条新独立历史，真结构事前规定且覆盖两库四结构。每历史规划一次，以相同历史/资产/未来噪声回放regular和shift两种未来，计96计划槽、192方法—未来槽；16未来情景不算16独立历史。开发与评价不混用，不按评价调参数。
4. 对预定评价序号0与6，固定已取得动作离线替换线路、负荷、源作2³归因；完整评分与真实参数只进入诊断。另存实际噪声影响，避免把同一历史的未来重复视作独立历史。
5. 分别报告：代理对完整AC排序偏差、平均指标牺牲参考、预测/噪声误差、QP/MILP计算界及AC局部非收敛。冻结后失败保留，不用删难候选提高分数。
6. 每个已验证阶段commit/普通push原codex/ev-train-validation-design分支，保护原PDF/pyproject。原报告本轮不改。若预算不足，保存进程/配置/检查点并如实保留未完成状态。

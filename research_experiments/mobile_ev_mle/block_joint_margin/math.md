# 局部争议块的联合拟合优势：数学与边界

2026-10-17。新阶段，原冻结记录不修改。强对照为平方功率 MILP，最终判断统一采用历史与新增计量共享 R/X 的完整 AC 条件拟合。本阶段先验收指标和梯度，再运行小型独立验证；不预设新规划优于平方基线。

## 1. 先明确模型

H 是已经观测的历史。u[t,j] 是 EV 净充电功率，单位 kW；正为充电，负为放电。末端表计 P/Q 已含 EV，拟合时不再加一次。根电压和仪表固定偏差沿用已知校准条件。与目前 4.69% 流程一致，校正后的末端 P/Q 读数直接作 AC 输入；误差目标包含末端电压、总表 P 和总表 Q，未传播 P/Q 输入误差。

每个候选 k 的变量 xi_k 包含全时段共享的逐边 R/X，以及同一个物理接口上逐时变化的源 P/Q。Omega_k 是既有的物理 R、X、X/R 及源范围，不依动作改变。历史代价 L_H,k 是上述输出通道的标准化平方误差总和。

WZZT/RNJ 提供可修正候选及候选支持集的分歧。共同支持集为各候选 supports 的交集，争议支持集为其并集减交集。块用于定位争议、组织节点与候选比较，不新增一份似然；WZZT 默认 source_inputs=None，不视为已估计源。三末端完整四候选中，块适配通常不会增加信息，必须保留这个零额外信息情况。

## 2. 规划分数与最终判断对齐

对可能的参考候选 a，场景 s 只从 H 构造：一组合法历史线路和源解释，以及未来负荷和源预测。参考候选通过完整 AC 产生假想未来均值 y_as(u)。它不是实际未来真值，场景编号不携带真实拓扑。

对所有候选 k 采用与最终评价相同的拟合：

    J_k^(a,s)(u) = min_{xi_k in Omega_k}
        { L_H,k(xi_k) + ||y_as(u) - mu_k(u,xi_k)||_W^2 }.

W 是未来输出计量误差的逆协方差。每个候选，包括 a 自己，都重新拟合；线路解释历史和未来，源仍在同一接口。定义

    M_ab^s(u) = [J_b^(a,s)(u) - J_a^(a,s)(u)] / 2.

M 是预计联合对数似然优势（按声明的条件高斯模型），正值有利于 a，负值有利于 b。它不等于正确概率。旧的“新增竞争距离” J_b-L_H,b 忽略参考候选的历史代价和自身重拟合；两者可能产生不同动作排序。

历史响应不确定性首先用合法解释场景表达：保留主历史拟合，再沿消去源后的弱线路方向，以物理 R/X 坐标扰动，并重新拟合历史源；仅保留完整 AC 历史 SSE 不超过主拟合加预声明容差 h 的点。h 是工程支持预算，不称置信覆盖。未来源预测随该历史解释一起改变，不能独立打乱线路与源补偿。若未能得到另一合法解释，记录未覆盖，不伪造不确定性。

设计目标取争议有向候选对的等权、截顶平均：

    m_ab(u) = min_{s in S_a} M_ab^s(u),
    S(u) = mean_{a != b} min{m_ab(u), tau}.

tau 限制容易任务的贡献；不作零截断，负优势任务仍保留方向。等权是预声明设计取舍，不解释为拓扑概率。最终分数保留全部电压与总表，不因块内对比而删除块外源约束。

## 3. 价格导数

记 e_k = y_as(u)-mu_k(u,hat_xi_k)。在相同内层局部解分支、满足约束驻点及包络定理条件时，

    d M_ab^s / d u_l
      = e_b' W (d y_as/d u_l - d mu_b/d u_l)
        - e_a' W (d y_as/d u_l - d mu_a/d u_l).

mu 的导数在各候选重新拟合后的 R/X 和源处用完整 AC 隐式导数计算。因此允许 R/X 补偿造成的混合影响进入价格；不把起始点的灵敏度永久冻结。无需对优化器迭代过程求导，但局部解跳转、未收敛、活动边界不规则时必须报告，价格由可行有限差分核查。

这表示“该时段增加 1 kW，预计使 a 对 b 的联合拟合优势增加多少”。若该时段持续 dt 小时，单位 kWh 的价格为该导数除以 dt。多个最坏场景并列时保留全部仿射约束，不任意挑一个梯度。噪声均值处的 M 不等于含噪期望 M；不同模型拟合自由度会影响后者，必须用独立带噪评价检验。

## 4. 首版 MILP 是明确的局部代理

在当前父计划 u0 处，每个场景计算 M0 和 g，主问题为

    max mean_{a != b} z_ab
    s.t. z_ab <= tau,
         z_ab <= M_ab^s(u0) + g_ab^s'(u-u0), for every s,
         (u, route, SOC, modes) in original EV operation domain,
         |u-u0| <= radius.

路线、接入、充放电互斥为二进制，功率和电量连续；不枚举整条路线或功率库。线性价格可以产生连续曲线，但它仅是局部代理，不是非凸原目标的全局界。非零梯度、正确梯度均不保证全局最优。零梯度的二次激励由继承的平方计划提供；若所有任务截顶，报告分数饱和。

每次提案重新进行完整 AC 双方联合拟合，只有原 S 真实增加且 EV 运行可行才接受。继承平方父计划保证同一模型规划分数不退步；不保证实际未知网络上的误判率不退步。有限求解时间、内层局部解及 AC 调用全部单列。

## 5. 必须通过的检查

1. 解析例显示“竞争新增距离”与双方拟合优势可排序相反；噪声自由度项单列。
2. 补偿例、零梯度例、活动边界例核对价格符号和局部范围。
3. 完整 AC 目标对功率的有限差分与包络价格一致；若不一致，停止部署该价格。
4. 同历史、同计划、同计量比较固定 R/X 和联合拟合，隔离推断贡献。
5. 新策略与平方基线使用相同 EV 域、终端电量、未来计量预算和实际噪声；只更换规划目标。
6. 历史/未来真值隔离；失败、未决和漏真不删除。WZZT 块若由同候选确定，报告零独立信息，不声称新证据。

该构造与旧对称历史 QP、乘积 MILP 和多场景框架有联系。新阶段要检验的是“双方最终拟合优势与最终决策一致”及其真实排序，不能把旧工具重新命名当成新效果。若价格或排序检查不过关，交付失败原因并停止扩展 MILP。

# 固定有限先验的历史适合度诊断

设有限 atom 库在读取历史 H 前已固定；给定已知根电压后，各 atom 的历史均值为 μ_a，共同已知正定计量协方差为 Σ，WΣWᵀ=I，计量维数为 d。
这一假设必须由 atom 构建、固定偏差/根电压和白化实现核对；仅有 EIG summary 无法证实它。
令 S_min=min_a ||W(y−μ_a)||²，只对固定均值取最小值，不重新估计线路或逐时状态。

若任一库内 atom a₀ 正确，则 y=μ_a₀+ε，Wε∼N(0,I_d)，故逐样本有

S_min ≤ ||Wε||² ∼ χ²_d。

取 τ=χ²_d 的 (1−α) 分位数，严格条件 S_min>τ 拒绝整个声明固定均值族；对任意正确 atom，拒绝概率至多 α。均值库大小无需另作 Bonferroni，因为一个库内真 atom 已提供此逐样本上界。
这不是“最小残差服从 χ²_d”：最小残差通常更小，χ² 只给保守上尾界。不能把 d 自行减去拟合参数数目后将本结论用于自由 β/历史状态的 MLE 或局部拟合损失。

对 X∼χ²_d，矩母函数 E exp(tX)=(1−2t)^(−d/2)，0<t<1/2。
Markov 不等式给 Pr(X≥x)≤exp(−tx)(1−2t)^(−d/2)。当 x>d，取 t=(1−d/x)/2 得

log Pr(X≥x) ≤ −[x−d−d log(x/d)]/2。

当 x≤d 用上界 1。代码保留这一有限对数上界；χ² sf 的浮点输出为 0 时明确标记 underflow，不声称尾概率严格为零。
每个有限 x、非退化 Gaussian 观测密度仍有完整支撑。严重拒绝表明该固定参数/过程先验库不能充分代表这条历史，不能解释成观测具有零密度支撑，也不能由极低 posterior 拓扑熵推导真实拓扑已确定。
α=.01 是每条历史的诊断水平，多个历史不自动获得同一整体水平；该工具不改变选择器或主策略校准。
`audit_saved_eig(summary, out, fixed_mean_scope=...)` 只提取历史标签、`best_history_loss` 与 `history_dimension`；显式 scope 和可选先验配置哈希作为调用方声明保存，标明 summary 未验证假设。
实际 atom 固定性、共同协方差、已知条件根电压及原损失定义须另以源代码/构建证据确认；若 atom 依同一历史自由拟合，该诊断应标为不适用。

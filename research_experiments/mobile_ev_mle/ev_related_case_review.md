## 主要结论

没有现场线路资料时，可以先采用有来源的标准网络和公开负荷数据研究方法。此次核查的5篇论文也主要这样做。但它们的有效条件往往比当前“单台6kW EV、4个15分钟时段、R/X自由重拟合”更强：叶节点逆变器容量达到当地全负荷、按秒多点激励、较高电压精度，或已知拓扑且累计600个时刻。

最小电阻在Cavraro–Kekatos图算法中是标准算例的已知最小线路电阻，用于选择探测次数和分组阈值；它不是通过MLE人为抬高的参数下界。其他已读论文未提供可直接用于我们现场的统一R/X最小值。

“真实数据”也需按数据类型说明：Bhela把Pecan Street住宅负荷放入标准IEEE34馈线；Kapoor把NextGen消费者负荷放入IEEE37网络进行AC仿真再加噪。这些实验提供了真实负荷行为，未提供我们待辨识线路的现场参数下界。

## 1. Bhela：负荷估计设计，线路与拓扑已经给定

[Smart Inverter Grid Probing for Learning Loads: Part II—Probing Injection Design](https://arxiv.org/pdf/1806.08836v2)，DOI `10.1109/TPWRS.2019.2906306`。

§II-A式(3)–(5)允许PV或储能逆变器有功及独立无功，受视在功率圆约束；短动作下忽略SOC。§IV-B用IEEE34单相等效及Pecan Street住宅有功，统一模拟.9功率因数；先形成100个候选注入，过滤电压，再选多样性大的T个。线路不是竞争模型中的未知参数。

有功.2pu与报告峰值.5pu的数值比是.4，但峰值口径及具体节点负荷比未列出，不能把.4直接当每节点激励比例。式(18)下80/60dB对应乘性标准差1e−4/1e−3。本地PDF第2页忽略SOC、第7页100次MC、第8页20次MC与T=4/6验证均已核对。

## 2. Cavraro–Kekatos图算法：rmin是已知算例信息

[Graph Algorithms for Topology Identification using Power Grid Probing](https://arxiv.org/pdf/1803.04506v2)，采用arXiv v2，稳定DOI `10.48550/arXiv.1803.04506`；期刊DOI本次未核实。

PDF第5页§VI给出探测量条件

\[
\boxed{\delta_m\sqrt{T_m}\ge\frac{16\sigma}{r_{\min}}.}
\]

\(\delta_m\)是节点m有功扰动(pu)，\(T_m\)是该节点探测次数，\(r_{\min}\)为最小正线路电阻(pu)，\(\sigma\)是包括负荷与电压误差的有效界，非单独仪表σv。条件还用到独立零均值误差及已知R/X谱半径界。§VII采用rmin=.0014pu、部分观测有效电阻.0021pu，据此选90/39次动作。10,000次MC中Table I最终整体拓扑错误率为.2%/.1%，同时保留短动作高失败率。

该rmin来自IEEE37模型并作为设计先验；Sbase及逐线路Ω表在本次已读部分未列出，不能把.0014pu不换基准地搬到case33。

## 3. Cavraro–Kekatos拓扑处理：辨识与已知线路验证条件不同

[Inverter Probing for Power Distribution Network Topology Processing](https://arxiv.org/pdf/1802.06027v3)，DOI `10.1109/TCNS.2019.2901714`，正文采用arXiv v3。

§V（PDF9–10页）IEEE13/37标准网络加入附加线，分别有7/21个径向状态。IEEE37用200次MC、3σ=.01%电压精度、当地全负荷额定逆变器。未知连接与电阻的辨识在630个可能边中选择；已知线路及参数的验证在38个候选边中选择。

Table I的T=10列平均线路错误数分别2.69和.01，两者信息条件明显不同。文中约16–160个1秒动作也不同于仅4个15分钟慢观测。当前没有报告可用于现场的R/X数值下界。P和Q可先后用于电阻/电抗恢复；本文数值主流程为有功扰动，未列EV能量、SOC或旅行约束。

## 4. Taheri：MILP用于选择拓扑，功率动作事先给定

[An MILP Approach for Distribution Grid Topology Identification using Inverter Probing](https://engineering.purdue.edu/~kekatos/papers/PowerTech2019.pdf)，DOI `10.1109/PTC.2019.8810900`。

PDF第4页§V采用IEEE13，真12条线全在24条候选边中。每叶点逆变器能承担当地全负荷，有功先关断再恢复，无功不变；电压由MATPOWER完整AC生成，线性近似用于逆向恢复。6个逆变器每点2/10/50动作，总数12/60/300。

它将观测后的拓扑/阻抗选择变成MILP，未优化EV地点、功率曲线或电量服务。§IV用于McCormick的辅助变量盒 \(\|z\|_\infty\le\|\bar p\|_\infty\) 是经验上有效的计算界，作者未解析证明；它不是物理Rmin。电压×1000并反向缩放逆电阻只是数值调节，未改变物理激励。

## 5. Kapoor：真实负荷驱动标准网络，较长记录的参数估计

[Maximum Likelihood Estimation for Line Parameters in Distribution Grids Based on Expectation Maximization Algorithm](https://doi.org/10.35833/MPCE.2024.000910)，正式刊载MPCE 13(6)，PDF2111–2119页。已有Zotero全文复用，DOI线上入口工具不可达，正文结论依据本地正式PDF。

式(7)以根电压和下游总P/Q近似电流平方，再保留损耗；式(19)–(22)明确计量噪声及潜在P/Q的高斯模型，M步式(50)用fmincon。§IV已知IEEE37拓扑且每节点计量，T=600；§V将NextGen真实消费负荷送入IEEE37完整AC后加噪。初值按真线路参数4–20倍设置，属于报告的benchmark初始化，实务不能直接使用未知真值。

未见线路最小R/X与拟合上下界数值、独立MC分母或主动EV约束。原文σ=.001与“10%相对误差”的通道功率基准未明确列出，不能据此把所有P/Q/V误差统一视为10%。5小时估参结果也不能直接表示短轮EV规划中的快速拟合速度。

## 对本研究的下一步建议

1. 继续使用公开标准线路，逐项保存Ω、kV、kW基准及裁剪变化。没有现场资料时明确研究对象是这一公开算例族。
2. 把已知线路参数、给定参数范围、仅数值正下界三个信息条件分开。若声明参数取自公开线路库，库的最小正值可用于该模拟族的域；现场覆盖另待资产资料，弱边和域外条件继续保留。
3. 比较激励/当地负荷比例和有效电压信号，而非仅比较pu功率。上述拓扑论文使用当地全负荷额定逆变器，当前6kW只是三个MV接入点负荷的5%–6.67%。
4. 在同电池服务下比较短时密集观测、延长观测、可行P/Q能力及接入窗口。按秒的快探测更容易近似固定背景，15分钟过程则需要预测负荷/源变化；SOC、追踪与人员成本仍由我们的操作模型处理。
5. 先做少量公开算例对照，保持完整AC竞争重拟合和全部失败分母。文献表明输入幅度、持续次数和精度共同决定效果，不要求每个现实功率尺度都能成功。

# 含拓扑灵敏度g的精度平方MILP：首轮独立测试

2026-10-18。命名、数学、实现、2份开发与8份独立评价均完成。G-SQ的含噪联合拟合误判为1/16个配对任务，P-SQ为2/16，G-AQ为2/16。G-SQ少错的一个任务来自一份历史；当前证据支持继续研究，尚不足以认定稳定优势。

## 1. 名称和作用

完整旧名称映射见[统一方法表](../METHOD_NAMES.md)。本轮使用以下名称，不再使用A/B指代整套流程。

|名称|中文名|优化内容|
|---|---|---|
|OBS|同长度被动观测|不注入EV；只匹配计量预算|
|CC|恒充|初始位置均匀充电|
|HL|预设高低充电|前半高功率、后半零功率|
|P-SQ|精度平方MILP|按量测精度加权功率平方；强对照|

动作后缀F+、F±、M+、M±依次表示固定纯充电、固定双向、允许移动纯充电、允许移动双向。移动始终可选。推断后缀FIX表示固定历史训练R/X，只调整当期源；JNT表示历史与新增计量共享R/X并联合重拟合逐时源P/Q。主比较为三个MILP的M±域，分别评价FIX和JNT。

## 2. g如何进入目标与MILP

令u[t,j]为时段t、节点j的EV净有功，单位kW，正充负放。mu[a,t]是候选a预测的所有末端电压幅值及总表P/Q；Sigma[t]为这些量测误差的协方差。每候选的一组训练R/X和预测源在规划中固定。

对候选a、b，定义

    g[ab,t,j] = ∂mu[a,t]/∂u[t,j] - ∂mu[b,t]/∂u[t,j],
    w[ab,t,j] = g[ab,t,j]' Sigma[t]^-1 g[ab,t,j] / 2.

g由已有历史拟合模型的完整AC导数得到。w的含义是单位功率平方能产生多少标准化响应差；本批独立误差下，w就是各输出(g/标准差)²之和的一半。与歧义无关且g=0的位置得不到奖励。

G-SQ求

    max eta,
    eta <= sum_tj w[ab,t,j] u[t,j]²,  对全部a<b,
    (位置、路线、功率、SOC、充放电模式) ∈ U.

保留四候选全部六对，没有按真标签挑选竞争对。每对的注入导数为2*w*u；零功率处导数为零，但二次项仍在目标中，MILP保留了这部分曲率。

G-AQ从mu[a]-mu[b] ≈ d + g*u展开，保留D0 + sum(b*u+w*u²)，其中D0=sum(d' Sigma^-1 d)/2、b=g' Sigma^-1 d；其导数为b+2*w*u。常数D0不能逐对删除，否则最弱竞争对会改变。每任务为凸二次；六任务取最小后的整体目标一般既非凸也非凹。

单EV每时段最多接一处，且各时段误差独立，因此同一时段不同节点的u乘积为零，跨时段也不产生平方交叉项。对u²建立共享分段弦图s，目标成为对u、s线性的约束，加上原有路线和电池整数约束，得到MILP，不枚举完整曲线或路线。弦图是上近似，可行计划按原二次式回算给下值；求解器界只覆盖冻结代理。

本批功率界与分段数使节点包含0；通用不对称功率界需要另行核查零节点。更详细推导见[math.md](math.md)，代码见[coefficients.py](coefficients.py)、[milp.py](milp.py)。

## 3. 实验如何运行

采用既有三、四末端合成低压局部网络，普通或相关时变负荷、同接口有功和无功源，无光伏/风电。每库四个真结构均进入评价。候选库事前固定且含真候选，本轮没有重新运行WZZT或检验候选漏真。

训练段32或96点，另有20点已收到的证据段，二者共同训练当前每候选的一组参数。未来8×15分钟，即2小时；计量精度逐时相同，总有效精度30。负荷与源的逐时预测只用已获得的历史。该窗口不是三小时滚动控制。

电池60kWh，初始能量24kWh、终端26.85kWh，充放效率均0.95，功率上限5.714kW，吞吐上限7.5kWh；最多移动一次，移动和接线各占15分钟，各消耗15工作人员分钟；驾驶耗能0.2kWh。三个MILP共用这些约束。CC为1.5kW恒充，HL前四段3kW；相同终端电池任务并不要求包含驾驶和损耗的电网净电量完全相等。EV为单位功率因数，Q_EV=0；背景负荷及源均含Q。末端P/Q直接作为条件输入，输入P/Q噪声未传播到概率模型。

三个MILP每域最多2轮、每次求解2秒、每域总12秒，平方初始4段、最多16段。四个嵌套域继承合法父计划，新G方法还继承同域P-SQ。并列保留先遇到的计划，次序为CC、HL、同域P-SQ及较小域父计划；继承保证各自代理分数不降低。

计划封存后，评价器才读取真网络和未来扰动：先运行真网络完整AC、加入末端P/Q/V及总表P/Q计量噪声，再对所有候选分别做FIX、JNT。JNT的线路参数同时解释历史与新增计量。不同方法共用配对噪声，所有拟合采用相同初值与预算；局部取得值不称全局MLE。

开发2份与评价8份使用独立种子，全部科学源码和配置事前冻结。每份评价历史有regular和shift两个未来情景，故表中有16任务，但独立历史只有8份。clean仅去掉新增计量噪声，历史仍含噪、预测误差仍保留；clean没有参与规划或接受步骤。配置、种子和冻结口径见[protocol.md](protocol.md)、[config.py](config.py)。

## 4. 独立评价结果

下表均为误判数/全部可用任务。全部16任务可用，最终拟合/操作失败及数值并列均为0。这里按最小拟合损失选标签，没有新建统计置信集；“未决0”仅指本次数值并列或失败为0。

|方法|FIX含噪|JNT含噪|JNT新增无噪声诊断|
|---|---:|---:|---:|
|OBS|6/16|4/16|4/16|
|CC|5/16|4/16|4/16|
|HL|4/16|4/16|4/16|
|P-SQ/M±|6/16|2/16（12.50%）|2/16|
|G-SQ/M±|2/16|1/16（6.25%）|0/16|
|G-AQ/M±|6/16|2/16（12.50%）|0/16|

G-SQ相对P-SQ的JNT净改善仅来自历史0（三末端star、32点训练）的shift任务，该历史regular仍错。G-AQ也纠正这一个shift任务，但在历史5（四末端clade_01）的shift新增一次错误，所以含噪净变化为0。两份开发历史上P-SQ、G-SQ、G-AQ的JNT含噪分别2/4、0/4、0/4，仅作开发诊断。

若按“一份历史的两个情景是否至少错一次”计数，P-SQ和G-SQ均为1/8，G-AQ为2/8。因此6.25%对12.50%的任务误判差不能解释为独立历史失败数减半。

**规划增分与实际收益仍有差距。** G-SQ和G-AQ均在8/8历史改变实际功率计划，且各自代理和相应的固定模型完整AC预测分数均优于P-SQ计划。但JNT含噪真实裕量提高的任务分别为8/16和7/16，下降分别为8/16和9/16。真实裕量定义为“最强错误候选SSE减真候选SSE”的一半，仅在评价中使用。固定模型的完整AC增分通过，尚未消除竞争参数重拟合和未来预测带来的排序变化。

G-SQ在FIX下含噪裕量提高16/16，误判减少4个；切换JNT后净少错仅1个。这说明联合重拟合会改变规划增量的大小，应将规划和最终参数恢复分开评价。该配对结果没有单独分离源预测、负荷预测及R/X补偿各自的因果贡献。

真实结构下逐边平均绝对相对误差，按历史等权：

|方法|FIX的R/X误差|JNT含噪的R/X误差|
|---|---:|---:|
|P-SQ|25.30% / 34.69%|3.37% / 26.06%|
|G-SQ|25.30% / 34.69%|4.76% / 28.75%|
|G-AQ|25.30% / 34.69%|3.17% / 25.17%|

G-SQ少一次拓扑误判并没有带来更小的平均线路误差；X仍较难恢复。

## 5. 移动、求解界与成本

P-SQ在4/8历史移动，两个G方法均在8/8历史移动一次，每次占用30工作人员分钟、耗电0.2kWh。移动由优化选择，未强制。当前目标未给工作人员成本设置收益价格，只把它作为预算约束，因此此结果表示“在预算允许时选择了移动”，不是成本效益最优的证明。

例如事前编号为0的评价历史中，P-SQ留在节点0；G-SQ先花一段移动到节点1、再花一段接线，随后六段功率约为[4.718,-5.714,5.714,5.714,5.714,-2.425]kW。两者都满足终端任务；G-SQ从同域P-SQ改选了地点及充放电顺序。

|方法|F+达到间隙|F±达到间隙|M+达到间隙|M±达到间隙|
|---|---:|---:|---:|---:|
|P-SQ|8/8|8/8|8/8|0/8|
|G-SQ|8/8|1/8|8/8|6/8|
|G-AQ|8/8|6/8|8/8|3/8|

未达间隙的计划和原始失败均保留。P-SQ的四个三末端M±条件出现master_without_valid_operation：底层求解器报告OPTIMAL，但主问题返回动作未通过原运行域回验，程序保留合法父计划。这属于数值/实现问题，不能解释成物理信息不足或单纯超时。当前精简求解日志缺少具体违约分量，尚不能定位到哪条运行约束。G-SQ另有4个、G-AQ另有1个条件保留原始提案失败，均有可行计划。最终计划失败0与原始提案失败不是同一计数。

上述P-SQ三末端记录的gap约626来自退出后保留的宽控制盒上界；同记录主问题best-bound约161.653，返回原分数157.238。626不是已证实的实际最优差。四末端P-SQ则两轮后因时间/轮数用尽而未达gap，记录间隙约9.21–9.72。

关键历史0中，G计划的P-SQ原目标也从157.238提高到158.751，约0.96%；地点、曲线及驾驶补电同时改变，无法把一次分类改善全归因于空间权重。历史1的G-SQ反而把P-SQ分数降至67.304，却改善FIX判别，说明全部收益也不能只用幅值解释。

每策略规划依赖闭包的平均耗时：P-SQ约4.60–4.66秒，G-SQ约8.75–8.81秒，G-AQ约9.79–9.86秒。包括历史拟合、基线补全、父计划以及G方法所需AC响应预计算；范围是共同剩余开销的分摊，不是置信区间。各策略含噪FIX+JNT推断流水线再需约1.33、1.33、1.35秒。clean诊断和其他策略不计入单策略费用。

因此本轮是同域、同计量和同单次MILP预算比较，总成本不相等，也未获得全部策略的代理最优证书。G-SQ的小幅排错增量仍可能受基线M±求解不足影响。

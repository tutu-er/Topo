# WZZT—AC—EV完整拓扑辨识：事前实验方案

2026-10-18。授权：完整实现和系统测试，使用更复杂负荷、严格信息边界和并行运算。原研究分支codex/ev-train-validation-design，起点6d57f155。新模块独立于旧冻结记录，原PDF和pyproject不改。

## 研究问题和范围

研究WZZT/RNJ给出的可修正候选，经历史AC拟合、因果预测、EV优化、真实AC量测及最终共享线路重拟合后，能否恢复整棵约化径向拓扑。主网络为6个实测住宅轨迹；扩展网络为上述6住宅加2个真实工业建筑轨迹，共8末端。所有非平凡子树均计入拓扑正确与F1，不仅评分一个局部模糊块。未计量串联二度节点在约化表示中合并；本批不声称恢复这些不可观测节点。

主问题：G-SQ相对同域P-SQ，是否在真实形状负荷、参数补偿和候选漏真均保留时提高最终辨识？G-AQ作背景项对照；不预设EV或移动获益。旧贝叶斯/联合梯度属于不同指标版本，本批主比较采用目前可部署的CC、HL、P-SQ、G-SQ、G-AQ，以及OBS和随机合法计划参考，不把未重新测试的旧结果混入主表。

## A 数据与信息边界

1. 公开源：Open Power System Data, Household Data, version2020-04-15，https://data.open-power-system-data.org/household_data/2020-04-15/ ，原数据CoSSMic，CC BY归属。使用官方15分钟累计grid_import电量；相邻读数差除以0.25h得kW。下载原CSV SHA256为eca7dee5ac6e53373cd0209bc05ba3383cd860bfa5d5e995f74fa78db8857c58。
2. grid_import是建筑进口电量，非完整室内总耗电。本批把它作为合成馈线非负末端负荷轨迹；线路、Q、未计量源、仪表及电网AC量测另外合成，明确区别实测形状驱动与实测台区辨识。没有实测Q或实测线路表。
3. 剔除两个端点有对应列插值标记、缺失、反向累计或非连续15分钟的差分。仅按预先选定列、时间和有效性选窗，不按未来功率、拓扑效果或误判选样。原发布者可能使用未来数据插值，相关标记区间全部排除。不能跨未来填补缺口。
4. 日期按开发、校准、评价分离，完整历史+未来窗口不重叠。预定6开发、12校准、16评价日期簇；每簇同时评价n6/n8×无额外源/单接口DER源四条件。它们是同一日期簇的配对条件，不能把4倍条件数当独立实测历史。最终以实际有效窗清单冻结；不足则减小并明确报告，不改数据有效性规则凑数。
5. 主历史H=96个15分钟点，未来T=12点（3小时）；H=192仅作预注册开发或少量历史长度敏感性，运行成本通过后决定是否独立冻结实施。不同策略同一物理历史、未来背景和标准化计量噪声。
6. 仿真器单独持有真实拓扑、逐边R/X、真实未来P/Q、源P/Q和未来噪声。selector只接收已到达的P/Q/V、总表P/Q、已知仪表校准、时间戳、公共功率单位、运行约束和种子；不接完整case、真标签或未来数组。未来量测到达后才可用于候选更新和联合拟合。
7. 实测P尺度若需统一，缩放因子仅由当前历史计算，并固定作用于该窗未来；保留原单位、缩放规则和因子。Q由时变功率因数合成，包含独立扰动；DER有功和无功固定同一个物理接口，不随候选逐节点自由补偿。EV按单位功率因数、准确跟踪执行，已包含在末端总P中，不能重复添加。
8. 固定仪表偏差已独立校准、根电压已知。末端P/Q直接作条件输入，AC似然只计V及总表P/Q误差；本批不传播输入P/Q误差。分清这种条件模型与潜在P/Q联合计量模型。

## B 预测、候选和AC

1. 预测仅用历史，比较持久和因果岭回归AR/日历特征。H96的内部滚动起点不足96槽，故日周期naive未纳入本批模型选择；不能把回退成持久预测的结果称为独立日周期对照。模型选择仅在开发历史内部的滚动起点完成；调参时点全部早于计划时点。没有生成器的真实周期系数、未来相位或未来突变标签。冻结后不按评价误差选预测器。
2. 候选源先由历史AC估计，再从该历史源序列预测；一候选一组R/X，规划时不连续重拟合线路或源。报告P/Q及源预测RMSE、MAE、区间未实现项，不将点预测说成已校准分布。
3. 实际调用既有约束灵敏度→RNJ、WZZT与循环块bootstrap，保留原生拓扑和求解失败。WZZT可选源输入为空，不能宣称WZZT估计了源；AC阶段再以V和总表估计单接口源P/Q。
4. 候选包含原RNJ/WZZT、bootstrap分歧和少量局部删除/替换/合并，不锁死所谓可信块。上限8、来源/排序/截断全记录，不按真值补候选；所有候选参与AC与G指标。候选漏真是主要失败指标。
5. 收到实际EV计量后，再运行同样WZZT流程，向原池增添最多4个新候选，最多12个；不删除原困难竞争者。新候选同样先拟合历史，再联合解释历史+EV。分别报告旧池与更新池的覆盖、辨识和耗时。
6. 线路边界取公开低压电缆电阻/电抗范围与显式合成长度域，不为了增加拓扑距离提高下界。保留短弱支路。未知源可逐时变，但固定同接口。每次局部拟合记录线路、源、SSE、最大取得对数似然、迭代/停止/物理残差，不能称全局MLE。

## C EV策略和公平性

1. 主策略OBS、CC、HL、RAND（仅参考）、P-SQ、G-SQ、G-AQ。三个MILP的固定双向F±与移动双向M±都实际执行和评价（原无后缀名代表M±），因此共10个主策略。三种MILP同一运行域、采样预算和求解条件。使用固定充电、固定双向、可移动充电、可移动双向四嵌套域，保存合法父计划；G方法继承同域P-SQ。预先编号评价日期簇0..3、n6、无额外源条件还执行P-SQ及G-SQ的F+/M+，仅作充放电和空间消融，不增加独立簇数，也不纳入其他条件的缺失分母。
2. G-SQ最大化全部候选对的最小标准差加权响应差平方；G-AQ另保留背景常数和线性项。完整AC回代只使用历史估计和预测，区分代理分数、固定预测完整AC分数及事后真实辨识收益。
3. 修复旧P-SQ主问题容忍度1e-6与原域回验1e-7不一致：新共享平方MILP均用Gurobi可行/整数容忍度1e-9；所有返回动作原域回验。失败可固定整数模式、在原全部约束下解最近可行LP，原失败/违约项仍保留。不可直接截断后声称可行。
4. 各域最多2轮、每轮2秒、总12秒，初始4段最多16段；正式预算根据仅开发成本检查可一次性冻结修改。记录incumbent、best-bound、原二次可行下值、平方分段误差和unfinished。代理界不作为完整AC或误判率的界。
5. 电池、SOC、终端任务、效率、吞吐上限、移动和接线时间、驾驶耗能及人员预算统一；移动可选，不强制。CC/HL满足相同电池服务任务，驾驶与循环损耗造成电网净电量差另报，避免混称同电量。

## D 评价与校准

1. 在真实网络完整AC执行各合法计划，再添加配对的P/Q/V及总表噪声；所有策略相同初值和拟合预算。报告历史AC、旧池FIX、旧池JNT、更新池JNT；联合线路同时解释历史和新增计量。
2. 主要终点：所有完整拓扑的精确恢复、非平凡子树F1、候选漏真、错误唯一判定、未决、物理失败、优化失败、总耗时、AC调用和求解界。R/X误差只在真结构可用时统计，并给该条件分母。逐对难竞争者结果保留。
3. 在独立校准日期上，事前规则以真候选相对最优候选的半SSE差为候选内保留阈值。源类别仅供分层诊断；实际阈值对每个方法、末端数和推断路线取全部预定源条件阈值的最大值，任一为无穷则统一无穷，避免根据未知真实源类别选择规则。校准的候选漏真和失败另计；不能声称该阈值保证全拓扑空间覆盖。真实候选不在池时，不补真、不删除样本，不把最小拟合损失当正确概率。
4. 主表同时给无阈值最小SSE标签和校准后保留集合。失败保留全池并标未决；候选漏真单列为结构覆盖失败。来源日期是统计簇；置信区间/配对差按完整日期簇计算，网络/源条件和重复噪声不增加独立簇数。
5. clean只允许开发或预定诊断，不用于规划、选模型、阈值或接受计划。正式评价不据真值改预测器、候选上限、G权重或求解预算。主动返回的量测可用于后续推断，这是已发生数据，不属于提前访问未来。

## 阶段验收和执行

S0：方案、数学和数据边界保存并commit；确认已授权远端与分支。

S1：预测/数据因果单测、WZZT实际调用/候选不锁死单测、MILP解析界/运行域修复回归通过；只用开发日期测H96成本、完整AC与漏真情况，不要求提高准确率。

S2：冻结实际窗口清单、方法、参数、源码/数据hash及统计规则；校准与评价原始任务可并行计算，评价规则只能用校准数据生成。主配置约24开发、48校准、64评价条件运行，独立日期簇为6/12/16。若开发出现具体计算瓶颈，修改方案和版本后重新冻结，不能用评价调预算。

S3：32逻辑核机器初始8–12个独立worker，每worker BLAS/Gurobi单线程；根据开发内存/吞吐选固定并发数，避免线程过量竞争。任务级断点续接、PID/源码hash/日志、原始结果原子保存；禁止同输出重复启动，保留任务异常和失败。计算未结束就保存可续接检查点，不声称测试已完成。

S4：独立回放AC平衡/残差/物理约束、候选来源、完整分母、成本依赖和校准统计，精简证据恢复后复算一致；分阶段commit并普通push已批准origin/codex/ev-train-validation-design。交付简明报告与复现文件，不扩写旧长LaTeX。

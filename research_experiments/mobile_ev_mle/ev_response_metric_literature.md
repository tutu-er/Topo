# EV 配置指标：预测误差、检测裕量与可接入的 MILP 结构

核查日期：2026-10-15。范围：固定每拓扑一组训练 R/X 后，如何把 EV 设计分数与实际排错衔接。采用 `research-literature-review`、`hku-library` 的全文与归档要求。已有本地文件及合法开放全文足够，本轮未访问订阅服务、未新增 PDF。以下是相关章节阅读，不是穷尽式综述。

## 1. 先说判断

目前最值得接入的结构是：**保留 AC 作为物理评价；先固定一个可解释的有符号对比方向，再由 MILP 最大化扣除预测误差后的对比裕量。** 与不断增大两预测曲线的平方距离相比，它把“分得远”与“分在正确方向、且大于预测误差”分开。

第二个结构是短间隔的前后对比。它有望削弱固定基线误差，但会损失部分绝对电压信息，并增加差分噪声。它应与原始数据联合使用、明确协方差，先做独立模拟，不直接替换当前 AC 评分。

第三个结构是仿射模型的输出集合分离及内层 LP 最优性。文献已给出 MILP 方法；接入时必须由历史预测误差和有效局部余项构造集合。它是设计代理，最终证据仍由新增计量及完整 AC 评分给出。

## 3. 为什么距离变大，实际排错却可能变差

以下为本项目自行推导。先用最简单的两模型说明：观测向量为 \(y\)，预测均值为 \(\mu_1(u),\mu_2(u)\)，共同噪声协方差为 \(\Sigma\succ0\)。令

\[
d(u)=\mu_1(u)-\mu_2(u),\qquad
L(y,u)=\log\frac{p_1(y\mid u)}{p_2(y\mid u)}
=d(u)^T\Sigma^{-1}\left[y-\frac{\mu_1(u)+\mu_2(u)}2\right].
\]

若第一模型均值准确，\(E_1 L=\tfrac12d^T\Sigma^{-1}d\)，\(\operatorname{Var}_1 L=d^T\Sigma^{-1}d\)。等先验、零阈值时的单向错误率为 \(\Phi(-\|d\|_{\Sigma^{-1}}/2)\)。这说明在模型准确且协方差固定时，增大白化距离有直接的检测意义。这里 \(\Phi\) 为标准正态分布函数，结论是条件错误率，不是拓扑正确概率。

若真实均值为 \(\mu_1(u)+e(u)\)，其中 \(e\) 是训练线路、未来负荷或源预测带来的均值误差，则

\[
\boxed{E_1 L=\frac12\|d(u)\|_{\Sigma^{-1}}^2
+d(u)^T\Sigma^{-1}e(u).}
\]

第二项可以为负，且随动作变化。增大预测距离，同时放大反方向预测偏差，会降低实际证据。因此应同时检查距离、偏差在判别方向上的投影及实际新增计量下的损失差。

当前程序还允许源重新拟合。将计量白化后，用局部仿射源模型 \(\mu_k+G_kz\)，并暂设源无活动边界。记 \(P_k=I-G_kG_k^\dagger\)，则半平方 profile 损失为 \(J_k=\tfrac12\|P_k(y-\mu_k)\|^2\)。在第一均值为 \(\mu_1+e\)、白噪声协方差为 \(I\) 时，直接展开得

\[
\boxed{
E(J_2-J_1)=\frac12\|P_2d\|^2
+e^TP_2d+\frac12e^T(P_2-P_1)e
+\frac12\operatorname{tr}(P_2-P_1).
}
\]

因此源补偿方向不同后，分数还包括误差二次项和残差维数项。源活动边界、非线性及局部拟合会进一步改变该式的适用区域。不能把简单高斯 LLR 公式无条件套到当前 nonlinear source profile；该展开适合做可核查的小型解析对照。

## 4. 最简可试的 MILP：固定方向、优化稳健裕量

仍用两个预测均值。先从训练数据或基线动作确定对比方向 \(w\)，并归一化使 \(w^T\Sigma w=1\)。\(w\) 在本次 MILP 内固定。将局部预测写为

\[
\mu_k(u)=a_k+B_ku+e_k,\qquad e_k\in\mathcal E_k.
\]

其中 \(a_k,B_k\) 来自同一训练参数的 AC 响应；\(\mathcal E_k\) 用训练滚动预测残差和明确局部余项建立，不读取未来数据。定义支持函数 \(h_{\mathcal E}(w)=\sup_{e\in\mathcal E}w^Te\)。两个模型在该方向的最小间隔为

\[
g(u)=w^T[(a_1-a_2)+(B_1-B_2)u]
-h_{\mathcal E_1}(-w)-h_{\mathcal E_2}(w).
\]

它表示第一模型最不利输出仍超过第二模型最不利输出多少。取这两个最不利端点的中点为阈值，高斯共同噪声下，若 \(g>0\)，两类错误率均不超过 \(\Phi(-g/2)\)。这是标量高斯尾界的直接结果：每类均值与阈值至少相隔 \(g/2\)，噪声标准差已归一化为1。该界要求实际均值误差落在所给集合；若集合只在某种模拟分布下校准，应报告该模拟口径的经验覆盖。

因为 \(w\) 固定、均值仿射，固定误差集合下 \(g(u)\) 是仿射函数。多个历史预测情景 \(s\) 可直接写成

\[
\boxed{
\max_{u\in\mathcal U,\ t}\ t,
\quad t\le w^T[(a_{1s}-a_{2s})+(B_{1s}-B_{2s})u]-b_s,\quad\forall s,
}
\]

\(b_s\) 为该情景两侧偏差支持量之和，\(\mathcal U\) 为现有 EV 接入、充放电、SOC、移动和任务约束。它是线性目标、线性约束加整数变量的 MILP，不需要枚举完整路线和功率曲线。误差半径若随 \(|u|\) 增大，可在有依据的逐坐标上界下加绝对值辅助变量；因其系数为负并最大化 \(t\)，最优解会取真实绝对值。若半径是一般椭球范数则成为 MISOCP；分段近似必须另给误差方向。

该结构有三个明确取舍。

1. 固定 \(w\) 使每次主问题清楚可解，但会舍弃其他方向的差异；需要记录在 AC 中保留了多少对比信息。若同时优化 \(w\) 与 \(u\)，会再次出现双线性项。
2. 让 \(w^TG_1=w^TG_2=0\) 可以消除两模型允许的局部源变化，但也可能删掉有效信号。应同时利用电压与实际可用的上游计量，先检查投影后的差异是否接近零。
3. 该检测器可作设计代理或额外诊断。若最终仍用完整 AC profile 损失排错，应检验其动作排序与最终排错一致性，并对完整流程重新校准。

这里的协方差也应与实际 P/Q 输入误差传播一致。若它明显随动作变化，固定 \(\Sigma\) 只是局部代理；需要纳入情景或保守上界，并检查完整 AC。已有历史的检测证据可作为相应模型一侧的固定分数加入规划约束；它在固定候选对、对称平均目标中可能抵消，但在不对称排错阈值或多竞争者中应保留。不要仅为了保留一个常数项就重复计算历史似然。

方向不应从未来真值挑选。可先从历史白化均值差、稳定空间对比或基线 AC 源拟合残差构造一个方向；若该方向没有稳定区分能力，则记录失败。后续可以比较少量由训练数据生成的方向，数量和总计算成本固定；这与预先列举全部 EV 动作不同。

## 5. 前后对比：减少基线误差，但保留真实噪声代价

设相邻两次量测满足 \(y_t=b_t+K_ku_t+\epsilon_t\)，其中 \(b_t\) 是非 EV 基线。取 \(\Delta y_t=y_t-y_{t-1}\)，则

\[
\Delta y_t=K_k\Delta u_t+\Delta b_t+\Delta\epsilon_t.
\]

固定偏差会消去，缓慢基线变化进入 \(\Delta b_t\)。若两次计量噪声独立且协方差均为 \(\Sigma\)，差分噪声协方差为 \(2\Sigma\)；若共用一次基线量测，多个差分之间还相关。普通负荷 P/Q 已有读数，应先输入实际测得的变化，不把它们假装成零；未计量源的变化仍需估计或保守保留。

EV 可围绕任务充电功率 \(u_0\) 安排成对变化 \(u_0+a,u_0-a\)，在同电量及 SOC 条件下优化幅值、时段与接入点；放电是否需要由可行域及实际收益决定。Cavraro–Kekatos 的秒级逆变器实验仅支持对比原理，EV 功率跟踪速度、接线时间和计量频率应先声明为仿真假设，再按目标设备能力验证。

若将绝对量测和差分同时纳入拟合，必须使用联合协方差或可逆变换，避免把同一数据计两次信息。作为首版消融，可以固定总样本数，分别比较原始量测评分与合理白化后的对比评分；不能把额外增加的基线样本当作免费收益。

## 6. 建议接入顺序与验收

1. 先对已有4份开发历史进行排序诊断。对相同动作分别使用训练 R/X、真实 R/X（仅诊断）、训练负荷预测/真实负荷、训练源预测/真实源，逐项替换；独立记录交叉作用。真值只进入诊断，不能进入选择器。另用无未来噪声的 AC 检查区分预测排序错误与纯计量噪声。
2. 在解析两模型算例验证上面的 LLR、profile 期望和稳健间隔公式，保留源投影把有效信号完全消掉的反例。
3. 固定每拓扑一组 R/X 和一个训练生成方向，实现有符号稳健 MILP；与原距离 MILP、梯度 MILP、同域平方基线在相同任务和总时间下比较。先固定接入点，后开放移动。
4. 若主要误差是固定基线而非增量响应，增加短间隔对比消融；若主要误差是线路灵敏度本身错误，差分也无法解决，应调整训练激励或物理约束，并报告这一条件。
5. 只在开发阶段确定指标、偏差估计和方向规则，冻结后重新使用独立历史校准、评价。必须同时报告实际 AC 裕量、未决/误拒、动作排序相关性、收益差符号正确率、计算成本及失败分母。

以上 MILP、误差分解和试验顺序是本项目根据已读文献提出的迁移方案。文献支持其组成结构与条件性检测解释；当前文档不把尚未实现或尚未验证的方案写成实验结论。

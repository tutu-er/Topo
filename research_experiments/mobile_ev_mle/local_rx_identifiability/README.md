# 小末端：R/X能估多准，错误拓扑能否被拒绝

先读 [结果](results.md)、[数学说明](math.md) 与 [事前方案](protocol.md)。两组都是从现有paper15/soumalas11抽出的5节点、3末端物理子树，保留倍率1线路及完整末端负荷；属于项目合成论文风格数据，不是作者原始馈线或现场数据。

- `cases.py`：观测与真值分离，普通/相关负荷，配对96/288点；K有额外理想入口表，U仅原末端P/Q/V。
- `fitting.py`：完整P/Q/V误差变量AC拟合，逐时状态消元，多初值、物理与驻点检查；局部结果不称全局MLE。
- `rejection.py`：原始高斯球与输出残差界，均只接受观测和声明公共域。
- `experiment.py`：先保存推断，再用真实P/Q作诊断；候选自身绝对损失bootstrap。
- `relative_bootstrap.py`：探索性的相对损失bootstrap，不读真值，单独保存成本和失败；见[补充方案](relative_bootstrap_protocol.md)。
- `analysis.py`、`audit.py`、`package.py`：只读统计、独立AC回放及实际归档恢复。

48条件对应12条场景轨迹、6个独立的网络/种子随机族；普通/相关负荷、长度与边界均配对，每网仅3个种子。原事前方案和配置中的“12条独立”表述已在[口径纠正](errata.md)中更正，原记录保留。保留全部候选、数值失败与未决，不把拟合损失、p值或理想两均值误判率称作拓扑后验概率。

源码和新证据都在本目录，原长报告/PDF、旧冻结策略及主目录无关修改保持不动。复算见 [REPRODUCE.md](REPRODUCE.md)。

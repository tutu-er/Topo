# 补充：比较相对损失，而不只比较总噪声能量

2026-10-19。主48条件已封存，本文件追加一个探索性统计量，不修改原主批、原两个严格界或原绝对SSE bootstrap。它不增加新的真实历史，不用真标签设阈值；因此结果只作同一开发证据上的方法对照，尚非独立校准。

对每个候选k，计算

\[
T_k=S_k-\min_j S_j.
\]

S_k是完整P/Q/V误差变量AC拟合取得的局部平方损失。所有候选用同一观测和物理域；小T表示该候选的拟合损失接近当前最好解释。比较差值有机会消除各模型共享的计量噪声项。由于未知R/X、非嵌套结构、正下界和活动约束，其分布不直接设为卡方。

对每个候选分别暂作生成模型，使用其观测拟合得到的合法P/Q/R/X及已知边界生成39份原始P/Q/V计量，再重拟合全部4候选，计算同一个T_k。使用

\[
p_k=(1+\#\{T_k^{(b)}\ge T_k\})/(39+1).
\]

原候选的39次拟合与绝对SSE bootstrap使用完全相同的模拟计量和算法，直接复用，其他三候选增加拟合。RNG种子和顺序必须逐项核对。任一必要拟合未达到同一驻点/物理标准，该重复保守计入上尾；原观测候选若有未达标则不拒绝。

样本固定为两网×普通/相关、seed31001、N96、K边界的4条件；每条件4个null候选。alpha固定0.05，不按结果改动。K使用额外理想边界表，不能据此宣称原U条件已经有效。16个null槽及624个模拟重复不是624条独立现场历史。

# 至少三天普通量测下的局部AC梯度拟合

先读[结果](results.md)、[数学](math.md)和[事前方案](protocol.md)。本轮在上一轮两组原始阻抗小子树上，用3/7天普通负荷、8个新独立网络/种子族比较局部末端信息与入口参考。三种入口条件为U末端only、R增加带噪入口表、K理想已知入口；R/K增加量测信息，不与U称同预算。

拟合本身已经使用完整AC解析梯度、阻尼Gauss–Newton与逐时状态消元，P/Q/V都作为带噪量测处理。分叉以下线路、公共主干和末端响应分别评价。精确局部平方压降关系只作诊断，不再重复计入似然。

- `solver.py`：完整AC梯度拟合，可选带噪入口表，接受步下降与物理检查。
- `diagnostics.py`：观测侧局部压降、信息秩、激励与有限差分核查。
- `experiment.py`：生成观测，封存推断后才计算真参数误差和响应诊断。
- `audit.py`：独立回放保存的物理状态与原始SSE，核查来源与完整分母。
- `analysis.py`：只读保存数据生成配对统计，不重新拟合。

这是项目合成paper-style网络与负荷，不称现场数据或作者原始算例。来源、种子、求解预算和复算命令见[复算说明](REPRODUCE.md)。

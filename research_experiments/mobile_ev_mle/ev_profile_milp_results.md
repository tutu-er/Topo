# 连续EV曲线MILP与阻抗阈值：本轮结果

2026-10-14。已完成单节点四时段开发试验，并定位到竞争重拟合代理省略参数与功率交叉项的问题。连续曲线的分段平方MILP可以求解；本轮有若干实际AC改善，但现有局部代理的分数明显高估部分竞争距离，下一步先修正这一点。

## 1. 实际实现与验证范围

固定地点0，四个15分钟时段，连续功率0--6 kW，网侧电量3 kWh，效率0.95，电池由24增至26.85 kWh。主问题没有预先枚举功率曲线。对历史排名前两名的候选构造双向完整计量局部模型，竞争者所有R/X、历史与未来P/Q及同一接口的源均可调整；历史与未来共享线路。先消去不受界约束的参数调整，再对剩余平方项作分段弦MILP；另外独立求有界竞争QP和完整AC重拟合。

保留四个对照：同长度无EV、同服务3 kW恒充、竞争参数可重拟合的profile MILP、固定MLE参数的MILP。最终全部四个star/cherry候选都参加完整AC联合拟合。MILP的界针对本次冻结局部二次目标；自由参数投影、有界QP和非线性AC分开记录。

试验使用3个独立基础种子：cherry01、cherry02、star各1个。两种cherry的真实内部R取0.0003、0.003、0.012 pu，X=(2/3)R；拟合内部R下界取1e-6、0.001、0.004 pu。star没有内部边，只改变竞争cherry的下界。共21个重复条件，其中真值仍在拟合域内15个、被先验排除6个。每种子各条件共享背景、源、偏差、未来白噪声和历史P/Q。21个条件仍只有3个独立基础样本。

84/84最终方法条件完成AC拟合；选择器回退0/21，历史模糊启动门满足18/21。此批为了诊断，也计算了另外3个已分开历史的动作。没有新的正式校准或独立策略评价，没有复用旧拒绝阈值。

独立复核通过528份保存拟合状态、84份实际未来物理响应、全部保存局部矩阵/分数与MILP可行解分数、参数域和54组预测均值竞争拟合。25份科学源码与试验冻结哈希一致。原试验记录保持不变。

## 2. 实际AC结果

令J为完整AC取得的白化残差平方和，定义

    M = 最优错误候选的J - 真候选的J。

M越大，取得的拟合结果越有利于真候选；M>0表示真候选取得最低损失。本批未校准拒绝门槛，以下“正确第一名”只是最低损失排名。

|方法|域内正确第一名 / 15|域内平均M|域外正确第一名 / 6|域外平均M|
|---|---:|---:|---:|---:|
|无EV|5|2.347|0|-4.367|
|恒充|12|343.398|3|-2.249|
|profile MILP|14|1204.533|2|-34.673|
|固定MLE MILP|13|1405.237|3|-23.056|

域内profile相对恒充的M在14/15条件上升、1/15下降，平均差861.135；域外为2/6上升、4/6下降，平均差-32.424。这些是重复开发条件的描述结果。平均M也会被强信号条件放大，不能据此认定独立总体优势。

保持原拟合下界1e-6，下面每行是两种cherry底样本的平均M，直接考察增强真实内部线路信号的作用：

|真实内部R / pu|无EV|恒充|profile MILP|固定MLE MILP|
|---:|---:|---:|---:|---:|
|0.0003|-3.479|1.260|3.914|3.849|
|0.003|-2.893|53.969|168.047|206.703|
|0.012|8.527|822.445|2889.771|3369.882|

真实信号增强后，本批激励收益增大。单独提高拟合下界则可能排除真实弱支路：域外条件中的明显退化已保留，不能作为先验改善辨识的证据。star在原下界下四方法均给错误第一名；弱cherry01原下界下，profile的M=2.407，低于恒充3.357。这些负例保留。

固定MLE曲线21/21都达到简单“公开电压重复计量次数×充电功率”线性指标的最优值；profile曲线0/21达到该值。因此固定MLE的改善也可由已知高精度时段解释。下一批应直接把这个便宜的质量LP作为对照，而不是将相同曲线包装为模型优化的额外收益。

历史排名前两名在6/21条件未包含真拓扑，最终四候选仍完整保留。只设计一对候选可能把激励用在错误争议上。当前truth只覆盖cherry01、cherry02和star，下一批必须加入cherry12真值。

224项同数据、嵌套下界比较发现1项取得局部损失违反数学最小值应有的单调性：种子986102、真实R=.003、固定MLE曲线、竞争clade12，从下界1e-6变为.001后，J反而下降1.15545。它提示较宽域的局部优化遗漏了更好解释；原记录没有改写。历史拟合部分没有同类违例。

另有一次8段细化，耗时0.623秒，原目标间隙从7.957降到3.039（相对4.31%降到1.69%），返回曲线和实际原目标值未变。总计43次MILP、耗时16.752秒。更细分段改善求解界，但不会修复局部竞争模型。

21条件总运行382.936秒，平均18.235秒，最长33.031秒。保存计数为历史拟合AC调用2637、实际未来联合拟合9779、预测均值审计2788、代理构造84，共15288次；生成真值计量及独立重放不计入该算法调用数。多方法共用相同动作的拟合缓存，这个总时间不是一条策略的部署耗时。

固定参数的前向响应Taylor相对误差仅0.267%--0.554%，但竞争模型重新调整线路后，局部距离可能明显偏大。首弱cherry条件的一条方向上，有界线性QP成本376.641，保存完整AC竞争解释成本25.443；把同一AC参数见证放回线性模型，成本为390.699。问题已经存在于这个可行见证处，继续精确求解原冻结MILP无法消除。

新增事后四角分解审计9个条件54行，0次新拟合/选择、432次AC前向。残差恒等式最大闭合误差1.82e-12。profile曲线未来交叉项范数中位数17.386，纯线路余项0.0392、纯状态余项4.5811；44/54行交叉项范数大于两个单独余项。线路调整幅度中位数14.46%，最大97.58%。这些向量可能抵消，范数不能当可加的贡献百分比。

该证据支持具体机制：冻结补偿矩阵省略了线路调整与大幅功率变化的乘积；同时存在历史候选对漏真和未来均值预测误差，不能把所有排名变化都归于一个因素。完整分解见ev_profile_cross_term_diagnostic.md。

## 4. 已做与下一步

已实现并验证：完整AC局部双向模型、连续平方分段MILP、21条件阈值/信号试验、独立保存状态重放、竞争交叉项诊断。对应针对性测试分别为proxy 11项、平方MILP 26项、review 5项、交叉诊断9项。

另已实现独立双线性解析原型r=c+Bu+(A0+sum u_t A_t)z及有限方向下界MILP，11项解析测试通过。它保留参数与动作乘积，但还没有接入AC或形成新的辨识性能结果。其下界主问题的求解器best-bound只属于有限方向下界问题；真实局部距离全域上界需要另外的可行竞争见证。


进一步实现了竞争解释交换原型 `ev_bilinear_exchange.py`：固定合法参数解释给距离上界，平方弦MILP在连续操作域上优化；返回动作处的全部竞争QP给取得下界并补充解释。保留历次最大下界与最小上界，细化分段或按预算保存未完成状态。新增10项测试通过；历史强度h=.2/1/3的解析例分别在3/3/2轮达到数值间隙，最大8.21e-13。该模块尚未接AC，且当前只处理距离平方，自身profile扣减须另定有效界。

根代理独立运行前述62项测试（9.15秒）及新增交换10项（1.27秒），共72项通过。21条件独立复核在25份源码字节快照保存后再次通过。详细下一阶段步骤与验收条件已保存为 `ev_profile_next_protocol.md`。

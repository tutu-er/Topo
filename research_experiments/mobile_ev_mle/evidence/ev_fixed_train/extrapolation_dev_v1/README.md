# 固定训练参数为何外推失败：四历史开发诊断

本目录只消费 `development_v2` 已保存的实际动作。没有重新选动作、模拟未来数据、使用旧阈值或改变冻结策略。源仍固定从物理接口1进入；P/Q保持同一组校准后读数；拟合只比较 V 与根表 P/Q。所有值均为局部取得的拟合损失。

运行：

```powershell
python -m research_experiments.mobile_ev_mle.ev_fixed_train_extrapolation --input research_experiments/mobile_ev_mle/evidence/ev_fixed_train/development_v2 --output research_experiments/mobile_ev_mle/evidence/ev_fixed_train/extrapolation_dev_v1
```

原始输入哈希、诊断源哈希和求解配置在 `protocol.json`。4个 `trial_*_diagnostic.json.gz` 保存几何、全部新增拟合、独立AC重算和逐方法结果。`summary.json` 汇总44方法条件，随机990103的原失败保留；成功的相同曲线缓存后有26条。训练/验证/未来各段精度均按原记录保留。

## 固定模型失败来自训练参数外推失准

所有历史真实 P/Q 的第一主方向解释99.9596%–99.9756%的变化。8个训练点主要沿同一个负荷方向变化。R/X 在这个方向上可以相互补偿，又能由源部分补偿；独立读取更多相似点对新方向的约束有限。

真候选的线路导数先对逐时源导数作正交投影，再按线路参数盒宽度缩放。训练条件数为1.33万–4.67万，最小奇异值为.0049–.0165；数值秩完整，但弱方向几乎不改变训练输出。真候选线路参数有5–7个触及盒边界，R相对误差20.6%–86.8%、X相对误差57.1%–65.3%。这些边界值是训练拟合取得值，不是电缆物理参数已得到证实。

训练真候选四初值的SSE差只有9.2e−14–6.3e−12，全部正常停止。增加同类局部初值没有显示出新的参数信息。用离线真参数替换后，训练SSE仅增加.13–4.18，却显著改善大激励下的预测。

上限目标动作的未来输入相对训练中心的RMS为训练变化的18.3–20.2倍；离开训练99%能量主空间的RMS为171–222倍。99%仅用于描述输入方向，没有置信覆盖含义。

局部线路误差的源投影响应RMS：训练为.031–.312个标准差，未来为2.00–12.37个标准差。此导数乘有限参数误差只是放大诊断，下面的完整AC替换检验给出实际误差变化。

## A：仅替换真候选线路，重新估计源

错误候选保留各自原训练线路；只有真候选使用模拟真R/X。该操作发生在动作保存之后，用于定位参数误差。定义

    M_hold = min_wrong(J_val+J_future) − (J_true,val+J_true,future).

与原固定策略相同，表中只用验证和未来损失。

| 开发历史 | 真结构 | 固定训练参数 M_hold | 替换真参数 M_hold | 真候选原验证+未来SSE | 真候选替换后SSE |
|---|---|---:|---:|---:|---:|
| 990101 | star | −80.81 | 11.41 | 120.55 | 28.32 |
| 990102 | clade01 | −2530.97 | 1631.62 | 4190.02 | 27.43 |
| 990103 | clade02 | −3760.04 | 805.53 | 4598.29 | 32.72 |
| 990104 | clade12 | 488.30 | 752.16 | 312.91 | 49.05 |

这项不对称的oracle诊断不能直接当作可部署排错表现。它说明固定真候选的训练参数误差足以改变原判断；原结论中把大负裕量归于EV无信息是不合适的。

## B：相同实际动作，开放所有候选的R/X

每个候选在训练+验证+实际未来上共享一组线路参数，P/Q仍按同一读数固定，源逐时重估。初值使用原训练线路及各段保存的源状态。每候选2初值、最多350步；所有104个联合拟合正常完成，并独立重算物理方程和目标。

这一目标包含训练段，故对照为同样包含训练段的固定参数分数：

    M_all = min_wrong(J_train+J_val+J_future) − (J_true,train+J_true,val+J_true,future).

| 开发历史 | 固定原训练参数 M_all | 所有候选开放线路 M_all |
|---|---:|---:|
| 990101 | −80.80 | 6.44 |
| 990102 | −2530.99 | 127.29 |
| 990103 | −3759.87 | 136.11 |
| 990104 | 488.38 | 15.42 |

四个上限目标动作均留下正的联合拟合裕量；全部26曲线的开放拟合，每候选损失均没有高于对应固定参数的全记录损失。这里使用已保存动作诊断其电气信息，尚未校准这一“固定参数规划、事后开放线路评价”的新完整流程。

B的上限动作真候选R相对误差为4.61%、3.83%、6.86%、19.83%，X仍为60.8%、65.7%、46.6%、79.6%。新增单一P激励主要改善R，X仍弱，需要独立Q方向、已知功率因数变化或物理先验来增加约束。

## 建议先改变训练信息，再考虑正则

优先增加训练输入的独立方向：寻找负荷不同步的历史块，或在参数训练阶段安排小剂量、不同末端的预激励，再冻结参数。当前合成训练族把各端负荷设计得近乎同步，单纯增加类似时间点不能稳定约束全部R/X。

只增加训练正则会选中弱方向中的某个参数解释，但不能由现有数据确认该方向。若有线路长度、导线型号或厂家范围，可作明确物理先验并检查敏感性；以真参数附近为中心的正则会引入离线真值。

若必须维持当前8点、无预激励条件，建议保留多组训练支持的固定参数解释，按每组解释规划并检查动作排序稳定性，或者在部署评估中恢复共享R/X重拟合。多模型可表达尚未确定的灵敏度；它也可能使可保证分离很小，这是训练信息不足的结果。

这些建议的证据强弱：A证明本批真候选训练参数误差对外推有实质影响；B说明这些实际曲线仍含可供共同重拟合利用的结构信息；训练导数与输入几何说明增加独立方向比增加同方向点数更有针对性。四个开发历史不支持通用最优性、现场误拒率或拓扑正确概率。

## 验证与成本

- 4独立开发历史、44方法条件，1个原选择失败原样保留；26条实际曲线共享缓存。
- A共34拟合、68求解器调用、345 AC调用；B共104拟合、208求解器调用、3249 AC调用；只读几何额外42 AC调用。
- 全部138个新增状态独立 `review_fixed_fit` 重算通过，固定P/Q、固定oracle线路及输出SSE/loglik均核对；没有拟合全局最优证书。
- 原4历史字节和冻结源未变化；未来真实参数仅用于事后oracle/误差诊断，选择器调用0，新增未来物理执行0，阈值调用0。

# EV响应与动作排序：八种解释的诊断

本诊断使用既有开发历史和已执行曲线。真实线路、真实未来负荷与真实源仅用于事后分解，不向选择器提供，不产生或修改EV计划。

对每份历史最多保留恒充、固定平方、固定AC梯度、固定判别MILP、移动判别MILP五法的不同曲线。相同曲线只计算一次，保留方法别名。排序主表只比较固定点双向操作域中的不同曲线；移动动作和恒充另列，不能混作同操作域比较。零功率只用于计算响应增量。

## 1. 八种参考响应

记a为仿真真候选，u为一条已执行净功率曲线；负值为放电。θ为线路R/X，x为末端基础P/Q，s为同接口源，h为末端电压幅值和根表P/Q的完整AC响应。对三个因素分别取训练/预测值或真实值：

    y_ijk(u)=h_a(θ_i,x_j+u/20,s_k), i,j,k∈{0,1}。

0表示拟合线路、预测负荷、预测源；1表示真实值。20是当前功率基准kW。根电压和计量精度保持原公开设置。比较绝对响应误差y_ijk(u)−y_111(u)，以及EV增量误差

    [y_ijk(u)−y_ijk(0)]−[y_111(u)−y_111(0)]。

每个通道分别给出pu均方根误差和按计量精度标准化的误差平方和。线路、负荷、源之间可能相互补偿，因此既保留单因素替换，也保留二阶和三阶交互。

## 2. 与实际损失裕量对齐

每个竞争者b始终固定自己的训练θ̂_b，只重新拟合原物理接口的逐时源：

    L_b,ijk(u)=min_s ||W[h_b(θ̂_b,x_j+u/20,s)−y_ijk(u)]||²。

这里包含b=a：真实参考响应使用真实线路时，真结构的训练线路也会产生误差。若i=0，b=a可以使用参考源得到零误差，此时零是严格可行上界与平方和下界，直接记录0。

分别记录最近竞争模型距离½min_(b≠a)L_b，以及可与原实际无噪未来指标对齐的裕量

    M_ijk(u)=min_(b≠a){H_b+L_b,ijk(u)}−{H_a+L_a,ijk(u)}。

H_b是原验证段完整SSE，始终不变。原clean_future_M保留有噪验证损失，但未来P/Q/V/根表的随机误差全为0；因此111端点应复现原clean_future_M。该核对先用原源拟合程序、同配置、同初值均值和同重启种子完成；若不一致，保留差异并先检查数据与定义，不靠放宽容差通过。

## 3. 分解和排序

对任一标量f（例如M或EV增量误差），单因素线路替换为f100−f000；线路与负荷交互为f110−f100−f010+f000，其他交互同理。三阶交互由八个角点的交替和给出。七项之和严格等于f111−f000。

另报告平均替换贡献：每个单因素效应加上与其有关二阶交互的一半、三阶交互的三分之一。这等于对六种替换顺序平均，三项之和仍是总体改变量；它只是此诊断路径的归因，不是因果识别结论。

固定点同域动作内报告Spearman排序相关、严格顺序正确/错误/预测并列，以及每种解释下最近竞争者是否改变。分母按独立历史保存；模型对和动作对不增加独立历史数。物理或局部优化失败均保留，未取得的数值不进入成功均值。

运行与结果见outputs/response_ranking_diagnostics_v1；配置、输入文件哈希、源码哈希、原冻结策略ID、次数与耗时全部保存。本文件的结果段由完成的开发诊断补充。

## 4. 完成的诊断结果

原4份开发历史共13条不同曲线、364次源拟合；原16份评价共59条不同曲线、1,652次源拟合。后16份在本轮被用于解释和形成新方案，因此本轮作为开发证据；新方法需另用994xxx历史评价。两批均无源拟合失败；72条曲线的111端点与原clean_future_M差值均为0。最初运行耗时分别3.51和14.68秒，最终配置下的精确耗时保存在各summary。

固定双向域的不同曲线在4开发中仅形成4个严格动作对，原16评价中形成29个严格动作对，分别来自4份、15份有至少两条不同曲线的独立历史。第16份历史所有固定域方法执行相同曲线，仍计入历史分母。以下表中的“正确/错误”是动作顺序，而不是拓扑判断。

在原16评价的固定域曲线中，单独替换真实线路后，EV增量的标准化响应误差仅剩原来的0.006%--2.83%（先每历史内对不同曲线平均）。然而线路替换并未改善动作排序。绝对响应的误差大小与微小动作差的排序是两个问题；前者由线路估计主导，后者明显受到负荷预测及其交互影响。

对同域动作差M(u)−M(v)做完整分解，先每历史内平均效应绝对值，再对15份有可比动作的历史等权平均，得到：负荷主效应16.378，线路×负荷交互12.767，线路主效应2.826，源主效应0.280，线路×源交互0.150，负荷×源0.00110，三阶交互0.01392。单位为SSE裕量；它们是该诊断替换路径的效应大小，没有解释为独立随机贡献率。

最近竞争者也会变化：原16评价有20条不同曲线、涉及6份历史，在000与111之间更换最近竞争者。4开发的993101移动方案从clade_02切换到clade_12，其M从预测37.45降至实际去噪8.74。失败没有归为计算未收敛。

## 5. 对下一步MILP的含义

共同源通过同一物理接口进入时，其主要影响接近共同电压变化。用固定方向w消去两个模型的局部源导数，或扣除原源盒在该方向上的最大泄漏，可以降低源补偿带来的代理误判；仍需完整AC检验以覆盖非线性和活动源界。

本批更直接的改进是同时保护逐时基础P/Q预测。建议保留每拓扑一组线路参数，使用仅由训练数据给出的负荷情景或价格区间，优化同一EV计划在这些情景下的平均值与保守值；不让某一个点预测中的微小增分单独触发换时段或移动。情景或区间的宽度应从训练残差或独立预测校准得到，不读取这批真实未来值。

源投影保护、负荷预测保护和线路响应误差分别验证。联合源投影可能同时移除有辨识力的电压方向；平均源投影加盒泄漏保留更多信号，但对源导数误差及线路误差仍敏感。上述诊断没有证实只做源投影就能解决主要排序问题。

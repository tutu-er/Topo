# 自参考预测拟合何时可以省去

本注只核查数学与现有源码，不读取正式结果、不重解AC。当前冻结B仍计算全部K²组合；下面是尚未实现的后续优化建议。

## 1. 全局训练最优时的恒等式

固定候选a。θ是逐边R/X，s_H与s_E分别是训练、未来逐时源。记训练SSE为H_a(θ,s_H)，未来无噪参考均值为

\[
\mu_a(u)=f_a(\hat\theta_a,\bar s_a;\bar P+u,\bar Q).
\]

u是已给定的EV动作。假设：

1. `(θ̂_a,ŝ_H,a)`真正达到原训练问题的全局最小值`H_a*`。
2. 联合问题中的历史损失、权重、线路/源参数域和训练问题相同；联合可行点投影到训练变量后仍训练可行。
3. 原训练解与预测源`s̄_a`能共同成为联合问题的可行解释。未来输出/输入、偏差、根电压、AC解和源接口一致，因此该点未来残差恰为0。

定义

\[
L_{aa}(u)=\min_{\theta,s_H,s_E}
\{H_a(\theta,s_H)+\|W_E[f_a(\theta,s_E;\bar P+u,\bar Q)-\mu_a(u)]\|^2\}.
\]

每个联合可行点的历史损失至少是`H_a*`，未来项非负，所以`L_aa(u)≥H_a*`。另一方面，代入`(θ̂_a,ŝ_H,a,s̄_a)`即可得到`H_a*+0`，故

\[
\boxed{L_{aa}(u)=H_a^*}\quad
\text{对所有满足上述可行条件的动作成立。}
\]

因此理想自参考值与动作无关，其导数为0。理论上无需对每个动作重新优化自参考；已计算的训练SSE和可行零残差见证足够。

## 2. 只有局部训练最优时

若训练点仅是实际意义上的局部最小，且第3条成立，那么原训练点加预测源仍是联合问题的一个局部最小：在其训练变量邻域内，历史项不会下降，未来项处处非负，当前未来项为0。求解器的成功状态或小梯度本身不证明已达到这样的局部最小。

全局联合最小值仍可能低于该训练取得值，并随动作变化。一个完整平方和反例是θ∈[−2,2]，令

\[
H(\theta)=(\theta^2-1)^2+
\left(\frac{2-3\theta+\theta^3}{4}\right)^2.
\]

`θ̂=−1`处`H=1`、一阶导数为0、二阶导数为5，是严格局部最小；`θ=1`处`H=0`，才是全局最小。用`f(θ;u)=uθ`生成自身均值`μ(u)=−u`，则

\[
L_{aa}(u)=\min_\theta\{H(\theta)+u^2(\theta+1)^2\}.
\]

`L_aa(0)=0`；任何`u≠0`时，两项无法同时为0，在紧区间上的最小值严格大于0，同时不超过1。因此自参考全局值随u变化，尽管生成均值的原训练点始终是一个局部最小。另一次局部拟合找到较低历史分支时，保存的自参考取得值也会变化。

## 3. 当前源码的对应条件

`build_fixed_contexts`保存每拓扑唯一训练线路，检查预测源处于同一P/Q源盒。`JointPredictiveEngine`核对预测与联合拟合源盒相同，检查训练状态在联合R/X域和X/R约束内可用；源仍在接口1。未来P/Q、V的已知偏差按同一计量模型添加并由拟合校正，根电压相同；参考AC电压还需通过物理范围检查。这些条件支持构造零未来残差见证。

训练和联合拟合的损失/参数域应逐项对应；目前都来自同一case配置。若以后收紧未来源域、更换接口或AC分支、改变训练权重，或加入跨时段源约束，必须重新检查第2、3条。预测源在域外时，即使训练已全局最优，未来残差也可能无法取0。

当前训练与联合计算均返回局部取得值，没有全局训练证书。程序自参考先执行固定线路未来源拟合，再以该返回状态作为联合初值；它没有直接把原预测源的精确零残差状态单列为见证。因此数值取得值可能受收敛精度、边界起点和新发现的历史分支影响；正负差异应分别核查，不能都归因于物理信息。现有小结果投影未单独保存每个L_aa，本注不读取大raw来量化该差异。

## 4. 可研究的计算简化

在已证明全局训练最优且零残差见证可行时，自参考`L_aa`可替换为训练最小值；K=4时共享线路拟合调用从16减到12，固定线路源见证调用也可分别减少4次。参考均值与其AC导数仍需计算。

**这是调用数的条件减少，不是25%耗时下降。** 自参考若从准确训练点和预测源开始，原优化本来就可能很快结束；实际节省需单独计时。

没有全局训练证书时，可以另定义固定自参考工作评分

\[
\tilde d_{ab}(u)=\tfrac12[L_{ab}(u)-H_a(\hat\theta_a,\hat s_{H,a})].
\]

若竞争者profile也精确求解，且零残差见证可行，则`L_aa≤H_a(θ̂_a,ŝ_H,a)`，所以`d̃_ab≤d_ab`。这说明固定较高的可行自参考基线会压低同一竞争者的差值。当前竞争者也只是局部取得，其误差方向会影响整个分数，因此该替代工作评分不自动成为真实MLE拟合差的下界，应作为新方法重新冻结、校准并比较。

本结论仅针对规划中由模型自身生成的无噪均值。收到真实有噪EV计量后的最终联合辨识，仍需拟合全部候选；不能据此省去某个候选的最终计量拟合。当前formal算法、K²计算和统计规则均保持不变。

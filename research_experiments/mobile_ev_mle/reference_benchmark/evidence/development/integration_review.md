## 当前可确认的执行逻辑

1. `profiles.prepare` 仅从六条官方 LV 聚合 P/Q 曲线按日历时标选 204 点窗；H=192、T=12，开发 Q1、校准 Q2/Q3、评价 Q4。P、Q 预测模型分别只用开发历史内部的 96/120/144/168 前缀验证。保存文件包含模拟器未来，但 `planning_inputs` 不传完整 prepared 或 case。来源数据本身允许复用，不按节点数宣称独立住户。
2. `cases.make_case` 按标准额定 `P0_i*profileP`、`Q0_i*profileQ` 生成 kW/kvar，除以各网三相总功率基准。原线路 Ω 和额定电压保持。case33 保持 12.66 kV；CIGRE 居民子网包含原 R1 内点负荷。paper11/15 是明确标注的自建论文风格兼容组，新变压器属于声明扩展，不能称原论文作者数据复现。
3. 额外源在每网固定公共接口，PV 式有功 `sP=-cap*PV1`，无功 `sQ=.2*sP`；正号表示吸收，故此设定表示同时注入有功和无功。cap=min(.3*原额定总P,80kW)，两种源条件使用相同允许域，算法不能根据真实源类别换域。该源未计入末端负荷表，因此在源接口另加一次符合计量边界。
4. EV 在实际执行时仅通过 `p_future + power_kw/base_kw` 加入一次；Q_EV=0。之后用原真线路完整 AC 生成 P/Q/V 和根 P/Q，再加同一套配对白噪声。终端计量已经包含 EV；推断没有再次添加。独立一般树求解只作物理等价审计，不回传选择器。
5. `selector._validate_observed` 只允许历史、表计、时间、单位和公共站点元数据；不接真拓扑、真 R/X、真实未来数组或源标签。预测 P/Q、源 P/Q 均 `nonnegative=False`，没有把负 Q、反向功率或负源裁成零；源预测只裁到已声明的共同容量域并记录次数。
6. 历史/未来终端 P/Q 标准差均由原额定通道确定，V 标准差固定 0.0005 pu；fm 深复制 hm，没有 T 个点额外放大精度。同策略和不同源条件共用物理种子；每个实际动作共用未来噪声。输入 P/Q 含噪但在 AC 损失中固定，是已声明的条件输出模型，尚未传播输入误差。
7. 规划始终使用每候选同一组历史 R/X。未来源由该候选历史拟合源预测；G 分数没有在规划内连续重拟合线路/源。执行后 FIX 固定历史线并拟合当期源，JNT 让线路同时解释 H+E。历史缓存只在候选、历史、表计和约束指纹一致且线路完全相等时复用，未用未来解释替代过去。任何必要失败都保留，不能删除竞争者抬高分数。

## 需在正式统计前修复的适配问题

### A. 新配置与旧统计入口不一致：会直接中断

`analysis.finish` 读取 `config['calibration_clusters']`、`config['terminal_counts']`；`_load_phase` 读取 `config[phase+'_clusters']`。新 CONFIG 使用 `phase_counts`、`network_names`，上述旧键不存在。应从冻结配置构造 `(cluster_index,network,source_mode)` 清单，并核对每网冻结 n；缺失记录需带 network 名保留。不得根据已完成文件反推预定分母。

目前四个网络的 n=32、6、11、15 各异，所以按 n 分层暂可唯一映射到网络；但应至少加入 `n -> network` 单射检查，并输出按网络的结果。长期建议键中显式含 network，防止以后同末端数不同馈线被混合校准或配对。

### B. 零虚拟边会令旧 R/X 统计整体失效

`analysis.rx_error` 要求全部真 R/X 严格正。原网精确保留内部表计时存在 0 Ω 虚拟叶，这会使原本合法的真结构误差整项 unavailable。建议分别报告：

- 所有编码边的绝对误差和 RMSE，包括零边；
- 正阻抗物理/合并边的相对误差，同时给正边分母；
- 零虚拟边上的估计阻抗绝对值及其数量，不除以零。

同样，`_replay_state` 不能用 `x/r` 审查锥约束。应核查 `lo*r <= x <= hi*r`，使合法 `(r,x)=(0,0)` 通过。科学拟合的 `_RxMap.contains` 已按锥处理；这里主要是审计适配问题。

### C. 旧空间消融并未在本轮执行

`small_spatial_ablation` 仍硬编码“前四评价日期、n6、none、主64条件”，且尝试读取 F+/M+ 的额外动作。本轮主选择器只实际执行 F±/M±，虽然内部求解了四个嵌套域，但没有为 F+/M+ 保存真实新计量和完整联合拟合。正式统计应明确标为未执行，不把缺失动作当作未决或零收益。若要新增实际空间消融，应在正式冻结前明确配置和预算；不能临时从评价效果好的日期抽取。

### D. 最终预测树的 F1 尚未进入旧主汇总

当前 `clade_metrics` 仅用于 native RNJ/WZZT。`report_text` 却声称 summary 包含最终 clade F1。应对每个方法和推断路线，用最终 predicted candidate 的非平凡支持集合计算 precision/recall/F1；优化或物理失败无可用标签时单列分母，不随意赋 0 或从精确恢复率反推 F1。按网络和日期簇输出。

### E. 结果说明需切换到当前数据事实

旧 `report_text` 写“6/8末端”，limits 写“synthetic Q/source/lines; real imported-load shapes only”，均不适用本轮。现在是公开标准原线路、官方聚合 P/Q 曲线、声明额外源及合成表计；真实测量和构造时序部分应按来源区分。评价分母应从冻结清单计算为 12 日期 × 4 网络 × 2 源 = 96 条件（若正式冻结仍采用本配置），不得沿用旧 64。

## 小型配置问题与解释边界

1. CONFIG 使用 `ev={...}`，`selector.operations_config` 仅读取 `ev_operations`。当前默认数值恰好相同，开发 pilot 动作参数未因此偏离；但随后修改 CONFIG['ev'] 会静默无效。建议统一键，或者遇双键冲突直接报错，并核对 record.domain_config 与冻结 EV 配置。
2. P-SQ 权重只用 V 标准差。本轮该值所有地点/时段相同，因此权重全为 1，目标实质为 `sum u²`；它不包含本轮额外的时间精度信息。G-SQ/G-AQ 的时空系数变化来自历史拟合后的 AC 导数与预测运行点。应以此解释对照，而非把 P-SQ 收益说成按高精度时段择时。
3. 运行装置约束是 11 kW、60 kWh、初始24 kWh、末端30 kWh、效率0.95、吞吐15 kWh、至多一次可选移动，旅行/接线各15分钟、耗电0.2 kWh。恒充为约2.105 kW、高低前半段约4.211 kW，两者都补充6 kWh电池服务。移动和循环损耗可能增加电网电量，不应声称各方案电网净电量严格相同。
4. 所有量测节点都可接入、任意站点旅行15分钟，是公开情景约束而非真实道路与充电桩普查。中压母线处11 kW为下游接入功率的等值；没有给单车安装中压插头，也未模拟未建模低压支线。现实空间价值仍受接入点和交通条件限制。
5. 拟合/预测 AC 允许电压域为[0.8,1.2]，另记录[0.9,1.1]服务电压是否满足。必须分别报告：能否数值/物理解释量测，以及执行是否满足声明服务电压。不能把宽计算域内的成功一概称为运行约束合格。
6. 线路上界来自公开的整网资产阻抗总量，未使用真实下游路径排序；这种库存先验已经声明，应说明它在真实应用需要独立资产资料。本轮不是无任何线路先验的辨识。
7. 16份校准/12份评价日期只是有限时间样本；跨季度时序会分布变化。源盲最大阈值、候选漏真和失败分母应保留，经验误拒率与日期簇bootstrap不能写成普适拓扑置信概率。

## 本批异质性的适用范围

六聚合 profile 在更多节点复用，使本批大网中心化 P/Q 的历史设计秩固定为 12：case33 为12/64列、paper11为12/22列、paper15为12/30列；CIGRE六负荷为12/12列。这样能够检验实际公共波动与弱独立激励下的失败，但它偏向相关聚合负荷，不能单独代表大量住户具有各自开关负荷的异质性，也不足以覆盖全部真实运行方式。EV是否补足了缺失方向应作为本批结果，不通过临时增加独立扰动让它成功。

下一独立数据组可把 SINTEF 小时 P/Q 的逐列历史参考值消去单位后迁移为无量纲形状，保留对应消费类、同母线聚合及小时采样，再乘标准额定P/Q；这能避免猜原始MW/pu，但需明确是跨网形状移植及历史尺度设定，不能称原SINTEF馈线AC复现。本批不因开发/评价表现临时加入它，也不按效果挑曲线。

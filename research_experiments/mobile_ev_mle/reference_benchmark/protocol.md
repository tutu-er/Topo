# 原生线路与公开时序的EV完整拓扑测试

2026-10-18。承接已完成的full_pipeline批次，旧记录不改。本轮研究源码仍提交到codex/ev-train-validation-design；执行副本为D:/0-github_workspace/Topo/outputs/ev_reference_stage_20261018。

## 要解决的问题

检验P-SQ、G-SQ和G-AQ在有来源的完整馈线、原生线路/负荷量级、合理时变P/Q及单接口源下的端到端效果。保留无EV、恒充、高低曲线及固定/可选移动对照。目标是辨别哪些收益能够兑现，不能通过放大阻抗、缩小馈线负荷或增大EV为全节点额定负荷来预设优势。

“符合论文要求”落实为可追溯来源、清楚的扩展假设、明确的测量与信息边界、公平对照和完整失败分母；并非存在一个适用于所有论文的统一数据合格证。

## 1. 算例来源及改造

主网络预定为：

|网络|原生数据|本轮处理|
|---|---|---|
|MATPOWER case33bw|12.66kV、33母线、32闭合线、全部32节点P/Q及Ω线路|保留内点负荷和原线路，EV为经下游接入设施折算到负荷节点的净功率；不把MV改为LV|
|CIGRE居民LV子网|pandapower固定版本的完整居民子网、6个负荷、17条线路及原500kVA变压器|保留R1内点负荷和物理变压器；不删除大负荷使EV显得强|
|旧paper11、paper15兼容组|项目自建论文风格LV树，并非作者原始算例|去掉原4.5–5.2倍阻抗放大，恢复倍率1；任何新变压器和源都单列为扩展|

另核对之前所引论文的原始IEEE13/34/37单相参数与作者数据可得性。拿不到作者等效参数时保留具体缺口，不用自建树冒充论文复现。真实匿名馈线SINTEF/CINELDI已纳入来源审查；只有单位、时标、负荷母线映射核实后才能进入正式科学批次，不能按拟合效果猜单位。

对负荷位于内点的原网络采用精确零阻抗计量叶表示。相同下游量测集合、且中间无注入的串联边合并阻抗；不人为添加正阻抗服务线。用独立一般物理树AC回放证明P/Q/V与根功率等价。目标是所有量测点的非平凡子树层级，同时记录虚拟零边和不可恢复的串联分段，不声称识别这些虚拟线路的物理身份。

## 2. 时序和负荷数据

优先用SimBench官方全年15分钟P/Q曲线，固定版本/文件哈希与原论文构造说明。P_i(t)=P_i^0×l_i^P(t)，Q_i(t)=Q_i^0×l_i^Q(t)，保持标准网络原生P/Q额定量级，不按评价历史/未来的效果归一化或筛选曲线。给新网络分配profile的规则在运行前按客户类型及固定种子登记；不把公开生成曲线当成多个独立现场住户。

来源核查后主选择为官方六种LV聚合曲线lv_rural1/2/3、lv_semiurb4/5、lv_urban6，按固定种子映射节点并记录复用和P/Q设计秩。CIGRE的190kW内点和case33的45–420kW节点本身代表聚合负荷，这比把一户尖峰放大更符合口径。HS0–27在官方表中属于EHV聚合，不能当作住宅曲线来凑32个独立住户。相关性和秩不足属于本轮要检验的条件，不人为增加独立激励。

OPSD仅作实测进口形状来源对照。grid_import为单向进口累计电量；需要有符号净进口时须减grid_export，不能直接叫完整消费，也不能把原有PV重复加入。

SINTEF/CINELDI的小时曲线保持小时，不插值出额外15分钟独立量测。重复一天、同母线多用户、由固定功率因数生成的Q均如实记录。缺失和单位不明确时保留失败/来源缺口，不能用全数据插值或看未来幅值选择容易样本。

主15分钟实验计划历史H=192点（两天），未来T=12点（三小时）。开发滚动起点≥96，使日滞后预测能被真实验证；候选为持久、日滞后和因果岭回归。P与Q可分别选择配置，仅由开发历史内部前缀误差决定，标准化只读该前缀。源预测只用各候选历史拟合的同接口P/Q序列。时序是公开基准构造的年轴或实际测量时钟，不能无依据宣称日期独立同分布。

开发、校准、评价使用不重叠的完整历史+未来窗，并按时间分开。目标为每网络4个开发、16个校准、12个评价日期簇、两种源条件。最终网络集合、样本数、求解预算和并发只可按来源是否核实及开发成本确定，正式校准/评价前冻结，不按评价表现修改。

## 3. 源、计量和单位

每网固定一个明确物理接口作为共同源。源P、Q可以逐时变，所有候选使用同一接口身份和公开容量域。主对照为无额外源、PV式有功及声明无功控制；源曲线来自独立公开PV profile，容量按预定额定负荷比例及工程上限设置，未来路径不提供给规划器。末端已计量的PV反送电应保留在总P/Q，不能又作为共同源加一次。

统一管理kV、kW/kvar、Ω与标幺换算，Zbase=Vbase²/Sbase。计量精度以物理额定通道或固定电压单位定义，再换到标幺；不沿用20kW旧例的固定标幺功率噪声。各方法同通道/时段采样预算，主实验各时段同精度。P/Q作为含噪直接输入的条件输出似然仍是简化；如未传播输入误差须明确报告。

逐边R/X在历史和新增数据中共享。公开线路域覆盖原生X/R和精确零虚拟边，不复用旧LV窄锥，不按真值每条边给不同初始化或拟合界。电压/仪表偏差先固定独立校准值。源容量域、线路域和EV额定值只通过公开规划配置进入算法。

## 4. 推断、规划和执行

WZZT/RNJ只产生可修正候选，不重复计AC似然。WZZT源输入仍为空，不能称已估源。开发中检查短预算下的有效incumbent、best-bound和停止原因；未证最优结构可作为明确标记的可修正提案，不能当无增益证明。候选上限和更新规则须记录截断，真候选不得由模拟器补入。

每拓扑在训练中可比较多初值，保留一组取得的最佳R/X用于全部规划；规划时不连续重拟合线路。执行后保留FIX和JNT两条路线：固定训练线路并拟合当期源；共享线路同时解释历史和新增计量。对每个竞争者保留合法解释及优化失败。

MILP仍使用共享功率平方分段：P-SQ按公开电压逆方差加权；G-SQ加入全部候选AC响应导数差平方；G-AQ再加入背景响应项。四个嵌套域F+、F±、M+、M±和父计划继承不变，不预先枚举全部路线和曲线。严格回验功率、SOC、充放电互斥、接入、移动/接线及服务任务。主EV功率为声明的11kW接入容量；其他功率若做敏感性必须另行事前冻结，不因效果弱临时放大。

计划以真实物理网络完整AC执行，再加配对计量噪声。只在新增数据到达后更新候选和联合拟合。选择器API不接受真拓扑、真线路、真实未来曲线、源类别或未来噪声。

## 5. 统计、成本和验收

主要终点：完整量测子树层级恢复、F1、漏真/截断、校准唯一正确/错误/未决、真候选误拒、物理和优化失败。保留全部分母；同一历史的网络/源/策略/重复噪声不增加独立日期样本。各网络分别给结果，不把不同电压等级和测量精度混成一个漂亮平均数。

独立校准只针对已经生成且可用的候选池；源类别不用于选择评价阈值。样本不足则保留无穷阈值及未决，不把低误拒称可靠性已解决。评价后不改预测、g、候选上限、求解时间或阈值。

记录原目标可行下值、代理best-bound、分段误差、停止原因、单策略完整部署成本和共享缓存费用。稀疏AC优化只改变数值线性代数，须与旧完整AC残差/导数及小例解交叉核验；没有全局最优证明时报告取得的局部值。

阶段验收：S0来源与方案保存；S1单位/内点等价/预测边界/稀疏优化测试通过；S2仅开发pilot决定成本并冻结；S3多进程执行正式校准和评价；S4独立AC与统计回放、证据打包、报告和正常commit/push。所有新实现位于reference_benchmark，不改旧冻结结果、原PDF或pyproject。

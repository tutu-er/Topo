# wzzT 后续路线：结构邻域启发式与动态规划适用性

日期：2026-09-22。用户已决定后续不使用 Benders。本轮是代码核对、原始文献调研与数学推导；尚未实现或测评下述新方法，原核心保持不变。

## 1. 推荐结论

**首选：多起点、按兄弟子块操作的 VNS/ILS，配合固定支撑的联合 L1 线性规划。** 后续再加已学习支撑的删除—替换或局部重建，以纠正前向路径的早期选择。若已有层级分叉数较小，可改用全合法域的子块并集枚举；这是一种有条件实用的精确单步方法。

普通树形动态规划不能直接等价替换当前联合 L1 模型。DP 可以用于可加替代目标、已知顺序下的区间模型、固定树剪枝或局部低维状态模型；这些适用条件必须明确，不能因为最终结构是树就推断原目标可分解。

| 路线 | 对当前模型的适合程度 | 保持原始 L1 评分？ | 保证与主要风险 |
|---|---|---|---|
| 子块 VNS/ILS + 全参数 LP 重拟合 | 首选 | 是 | 每个被访问结构准确评分，结构搜索近似；无全局最优保证 |
| 小分叉层级的全子块并集枚举 | 分叉度小时优先 | 是 | 全部合法集合和对应 LP 均完成时，得到单步全域最优；初始星形仍指数 |
| 单支撑替换、NNI/SPR 型移动、LNS | 第二阶段，改善整条路径 | 是 | 可撤销早期学习错误；不能删除用户指定的硬初始块 |
| 小宽度 beam search | 可作路径对照 | 是 | 保留多条未来路径；宽度截断会漏解 |
| Local branching | 保留 MILP 时可作增强器 | 是 | 受限邻域可精确求解；邻域最优不等于全域最优 |
| 子集/区间/剪枝 DP | 有附加条件时有用 | 一般是替代评分或受限域 | 必须证明状态充分和目标可分；不能直接套用原问题 |
| RINS、完整 ALNS 调度、通用遗传算法 | 暂不优先 | 可以，但工程较多 | 前两者需要有效松弛/多算子；任意交叉易破坏 laminar 结构 |

这个排序是适配判断，不是已经验证的速度排名。

## 2. 当前真正需要加速的部分

核心 `rnj_wzzt_core/rnj_wzzt/estimation/laminar_l1_milp.py` 中：

- `is_admissible_extension`（449 行起）检查非空、非重复、位置范围和 laminar 相容性。
- `solve_fixed_support_l1`（743 行起）已提供固定结构后的全参数联合 L1 求解。
- `solve_best_laminar_extension_l1`（982 行起）无候选池时搜索全部合法新增支撑。
- `fit_laminar_l1_sensitivity`（1182 行起）构造前向路径；单步精确不代表整树全局最优，`initial_supports` 是硬保留块，不是热启动。

设旧族为 F、新集合为 S，定义

\[
\Phi_F(S)=\min_{r,x,b}\frac1N\sum_{s,t,i}
\left|D_{sti}-b_{si}-\sum_{A\in F\cup\{S\}}\mathbf1_{i\in A}
\left(r_A\sum_{j\in A}P_{stj}+x_A\sum_{j\in A}Q_{stj}\right)\right|.
\]

R/X 有界非负，全部新旧参数跨场景共享，截距仍按原规则处理。**启发式只决定访问哪些 S；评价每个 S 时继续求解这个原始目标。** 不能冻结旧权重、只拟合新权重后仍声称获得了相同评分。

固定 S 后，用直接支撑特征构造紧凑 LP，不需要 z、y=zzᵀ 和乘积线性化变量。若有 m 个场景，紧凑 LP 变量数为 `2(|F|+1)+mn+N`，显式残差约束为 `2N`。它仍使用 LP 求解器，但避免在每次结构评分中求解整数搜索。当前接口可作为正确性参照，重复调用开销是否需要缓存或持久 LP 应通过后续 profiling 判断。

## 3. 结构感知邻域：为什么按子块搜索

将 F 补上虚拟全集根 U 和所有 singleton，按包含关系建树。补上的虚拟节点仅用于表示，不自动加入回归模型。

独立推导得到：除原族中缺失的 singleton 和全集这两类例外，每个合法新集合 S 都唯一对应某节点 C 的若干直接子块之并：

\[
S=\bigcup_{j\in J}C_j,\qquad 2\le |J|\le d_C-1.
\]

原因是：取包含 S 的最小节点 C；与 S 相交的直接子块必须被整体包含，否则破坏 laminar 性或违反 C 的最小性。因此无需任意翻转终端 bit 再大量修复非法支撑。

**例子。** 某容器的子块为 `{1,2}`、`{3,4}`、`{5}`。新集合可以取 `{1,2,5}`，然后通过交换整个子块变为 `{3,4,5}`。若只从前者删掉终端 1，则 `{2,5}` 与旧块 `{1,2}` 交叉，不合法。

具体搜索步骤建议为：

1. 枚举可搜索容器，明确处理缺失 singleton/全集；每个高分叉容器设置多个初始子块组合。
2. 在同一容器内依次搜索“加一块/删一块”“交换一块”“改变多块”的邻域；保留非空、非重复条件。
3. 候选由原始联合 LP 评分；局部下降接受严格改善。廉价残差分数可用于排序，不能作为未经证明的安全筛选。
4. 局部停滞后使用扰动、重启或容器切换，并始终保存最佳可行解。只在一个容器内部移动不能覆盖其他容器。
5. 达到时间/LP 次数预算即返回最好解及搜索记录；未穷尽的邻域不能标注“局部最优”，更不能标注“全局最优”。

VNS 的多邻域机制与 ILS 的扰动后局部搜索为这一设计提供成熟框架；上述 laminar 子块表示、LP 评分及具体算子是本项目的适配建议，原论文未验证 wzzT 的性能。[VNS 原论文](https://staff.fmi.uvt.ro/~daniela.zaharie/am2016/proiecte/tehnici/VNS/originalVNS.pdf)，[ILS 作者稿](https://arxiv.org/abs/math/0102188)。

一个状态的加/删/交换邻居数为 O(d_C²)，只是单轮评分数量，不是整体时间保证。若大容器只评估 top-k 邻居，运行更可控，但只能报告抽样邻域的搜索结果。RNJ 或观测矩阵可提供初值；不将它们产生的集合永久锁成候选池，也不使用仿真真值初始化。

### 小分叉度时可以精确枚举

对 n≥2，全部合法新增支撑的准确数量为

\[
\#\mathcal A(F)=\#\{i:\{i\}\notin F\}+\mathbf1_{U\notin F}
+\sum_{C\text{ 为内部节点}}(2^{d_C}-d_C-2).
\]

所以，当最大分叉度 Δ 较小时，可以枚举所有节点的子块并集并逐一解 LP，LP 次数有 O(n·2^Δ) 上界。**只要完整枚举并精确评分，这与原完整域单步问题等价，不是候选池近似。** n=1 需把根和 singleton 的同一个集合只计一次。

但是从全部 singleton 出发时，虚根分叉度为 n，数量仍为 `2^n-n-1`；这一性质主要有利于已有层级较丰富的后期步骤。可能采用“高分叉处启发式、低分叉处完整枚举”的混合路线；只要任何合法区域未完成搜索，整个单步结果仍应标为启发式。

完整证明和边界情况见 `docs/wzzt_laminar_dp_structure_notes_20260922.md`。

## 4. 比单纯加快下一步更值得做的整树纠错

目前前向加入的支撑会约束后续所有选择。即使每次新增都解得精确，早期错误合并也可能阻止后来正确的交叉替换。因此可以加入：

- 同复杂度的单支撑替换：先删除一个已学习支撑 A，再为 `F\{A}` 搜索新的 B，最后对整个新族联合 LP 重拟合。
- 局部破坏—修复：释放少数相关支撑，再重建该区域；保留其余已知硬块。
- NNI/SPR 型树移动：借鉴树搜索中的局部交换或子树重新连接，再转换为支撑族评分。根、标签、已有硬约束和多叉结构必须显式检查。
- 小宽度 beam：按相同支撑数保留若干不同前向路径，避免每层只保留一个选择；它不是精确 DP，截断后也没有全局保证。

纯删除一个可取零权重的回归原子，不可能降低最优训练损失；删除会缩小可行域。纠错应使用“删后换入”的整体移动，或者明确允许中间恶化；若加入复杂度惩罚，则应承认模型选择目标发生变化。必须区分硬 `initial_supports` 与算法后来学到的支撑。

FoBa 文献支持前向选择与后向纠错结合的思路，但其最小二乘理论不能直接套到本项目的非光滑 L1、成对 R/X 原子和 laminar 约束。[Tong Zhang, NIPS 2008](https://papers.nips.cc/paper_files/paper/2008/hash/7380ad8a673226ae47fce7bff88e9c33-Abstract.html)。破坏—修复可参考 [Pisinger–Ropke 的 LNS 作者稿](https://backend.orbit.dtu.dk/ws/files/5293785/Pisinger.pdf)；树移动可参考 [FastTree 2 原论文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0009490)，仅借鉴算子，不搬用其生物似然、复杂度或恢复保证。

### 若仍允许短预算 MILP：Local branching

围绕已得到的支撑 z̄，加约束

\[
\sum_{i:\bar z_i=1}(1-z_i)+\sum_{i:\bar z_i=0}z_i\le k.
\]

这样只搜索距离当前支撑至多 k 次端点变化的区域；也可对子块选择向量定义距离。原框架可以通过补集分支保持精确性，但仅做限时邻域搜索就是启发式。邻域下界不是原完整域的全局下界。[Fischetti–Lodi, Local branching, 2003](https://link.springer.com/article/10.1007/s10107-003-0395-5)。

它适合作为 VNS 停滞后的对照增强器，不必作为首版必需组件。Hamming 距离应定义在真正的结构变量上，不同时对派生的 y 和辅助关系变量计数。

## 5. 动态规划为什么有条件，具体能做哪些

### 原目标存在共享祖先耦合

原始观测的绝对残差包含多个祖先支撑贡献之和。不同子树共用祖先 r/x，通常有

\[
\min_a[f_L(a)+f_R(a)]\ne \min_a f_L(a)+\min_a f_R(a).
\]

**含 singleton 的极小反例。** 两个终端，T=2，s∈{-1,+1}，取 `P_s=(s,s)`、`Q_s=0`、`D_s=(0,3s)`；支撑含两 singleton 与全集。共同根系数 r 和两叶系数均在 [0,1]，每叶允许自由截距。优化叶权重及截距后，两叶时间平均损失为 `f_1(r)=2r`、`f_2(r)=2-2r`。使用共同 r 的整体 MAE 恒为 1；若错误地让两子树各自选择祖先 r，则两边分别取 0/1，虚假地得到整体误差 0。

因此只存一个“该子树最小损失”的标量状态不充分。条件化所有祖先作用后可以写函数值 DP，但状态一般要保留跨时间样本的进入信号，而不只是父边两个系数。连续、高维的分段线性值函数并未带来已知的低复杂度实现；固定结构时，原 LP 已直接处理这个耦合。

### 可加目标的子集 DP

若另外定义了局部拆分代价 c(A,B)，整树目标满足 `J(T)=Σ c(A,B)`，才可使用

\[
D(U)=\min_{\varnothing\ne A\subsetneq U}
\{D(A)+D(U\setminus A)+c(A,U\setminus A)\}.
\]

Cluster Trellis 的精确层次推断建立在局部势函数分解上，完整子集递推时间为 O(3^n)。实现只缓存子集最优值/回溯而按需枚举拆分时，状态数 O(2^n)；显式保存所有拆分连接会需要更大空间。稀疏 trellis 则只搜索部分结构。该原论文提供了非常相关的 DP 框架，但没有证明原始电压 L1 拟合能如此分解。[Cluster Trellis, AISTATS 2021](https://proceedings.mlr.press/v130/macaluso21a.html)。

同组 A* 层次搜索也明确要求兄弟子块代价相加；它可研究高质量替代目标搜索，不能绕开当前共享参数问题。[Exact and approximate hierarchical clustering using A*, UAI 2021](https://proceedings.mlr.press/v161/greenberg21a.html)。

| DP 类型 | 何时成立 | 对当前任务的用途与限制 |
|---|---|---|
| 全子集 DP | 分裂代价对子树可加 | 小 n 的替代目标精确解；O(3^n) 仍指数 |
| 区间 DP | 可加目标，且只允许给定顺序的连续区间 | 常见递推 O(n³)；数据估计的顺序属于限制，可能排除原最优树 |
| 固定树剪枝 DP | 每个块有独立代价，只选叶块分区 | 能优化参考树的剪枝，不能产生树外结构；也不同于祖先与后代原子同时存在 |
| 条件化祖先信号的函数值 DP | 保存足够的连续边界状态 | 理论递推可写，状态复杂；固定结构通常直接 LP 更实际 |
| 小树宽的局部打分 DP | 代理二次交互图确实具有小树宽等结构 | 可以产生候选，再由原 LP 验证；代理最优不代表原目标最优 |

把损失换成 R/X 矩阵拟合或可加层次相似度，会形成另一条研究路线。但矩阵条目共享祖先深度，仍需证明具体分解；不能只换成矩阵误差便假定普通 DP 已适用。

## 6. 建议的首版实现与验证范围

首版宜只做独立文件中的三个组件：合法子块域生成、紧凑固定支撑 LP 评分、多起点 VNS/ILS。小分叉容器完整枚举；高分叉容器使用预算搜索。第二版再加入非硬支撑的替换，避免同时引入太多机制而无法解释收益。

建议比较原完整域单步 MILP、等预算随机采样、单起点块局部搜索、多起点 VNS，以及后续同复杂度替换。使用相同输入、边界、训练/验证划分和计算预算，保留所有种子、失败和缺解。

评价分开：

1. 小规模全合法域枚举/认证 MILP 给出的目标 gap；较大例只有最好已知可行值时，不称其为全局最优。
2. 最好训练目标随时间的曲线、固定目标阈值的到达时间、LP 次数、合法率、重启成本。
3. 完整前向路径上的终端约化树/clade 精度、留出误差和复杂度选择；训练误差改善不等于真拓扑改善。
4. 候选池 baseline 与开放结构搜索分别报告；多起点反复得到同一解不是最优性证书。

本轮没有新的速度实测，因此目前能给出的结论是“结构和接口上最值得先试”，而不是“已经比原 MILP 更快”。

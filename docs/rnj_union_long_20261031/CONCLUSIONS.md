# 同120输入：候选连接并集联合重构的结果与判断

本轮完成四种新方法各120次，共480次运行。另在查看主结果后，补做120次固定参数的候选生成器消融，以及一次不增加求解的验证选择诊断；二者单独标为探索结果。原四方法与原NJ整树组合的代码、报告和结果均保留，55个父报告文件的哈希核对通过。没有更改生产默认方案。

主要结论：联合模型确实允许不同来源的连接重组、撤销旧连接，但当前目标下的拓扑恢复收益不足。它比无惩罚并集好，仍低于原完整RNJ修正版和原严格验证整树组合。延长求解时限已消除本轮新模型的超时影响；主要瓶颈是候选覆盖和有限样本下的结构排序。

## 口径与全部120输入

四个网络为paper15、soumalas11、flynn16、pengwah18。主测试108个输入：4网络×3种终端聚合×3种噪声×3种样本长度；压力测试12个输入覆盖弱激励、根节点噪声和离群点。观测、拆分和真拓扑与父实验相同。F1是非平凡终端后代集合的平均F1；完整恢复要求这些集合全部正确。主响应收缩阈值固定0.24，0.16只作敏感性分析。

## 求解预算与实际完成状态

- 每个新方法、每个输入总预算14,400秒（4小时），包含记账的上游生成成本；纯WZZT每个单步MILP最多3,600秒。联合MILP使用扣除上游与后处理预留后的剩余结构预算。
- 每个固定结构LP最多300秒，同时受总额限制；为连续闭合与固定收缩预留600秒。相对MIP gap为0.0001，单线程求解。8个worker并行，不强迫达到gap后继续耗满时限。
- 四种新方法480个作业全部完成。360次联合／简化MILP，以及纯WZZT的1,130次单候选MILP，均达到所设gap。超时0，总预算超限0。纯WZZT最大单次MILP为111.17秒，最大单输入总时长284.23秒。
- 主实验480作业名义预算上限之和为6,912,000秒。实际新增算法阶段之和11,093.77秒；共享旧候选生成成本只计一次，为33,293.95秒；实际唯一记账组件之和44,387.72秒。并行调度到最后结果的文件时间戳跨度约1,671.48秒（27.86分钟），不包含后续独立审计和补充消融。
- 补充消融另120作业，同样每作业4小时上限；120次MILP均达到gap。新增阶段合计312.58秒，其上游公共几何计算在主实验账中已存在。主实验加消融600作业名义上限之和8,640,000秒，实际唯一组件约44,700.30秒，独立审计不计入算法耗时。

原四方法继续使用原300秒结构预算，原双路径组合600秒结构预算，前后处理另计。这是新方案宽预算、旧方案保留记录的比较，并非所有方法相同预算的重跑。新模型已无超时，故当前退步不能归因于新模型的短时限；这一结果也没有排除旧候选生成器受其历史预算的影响。每步MILP达到gap只约束该步／该候选域，不构成纯WZZT全树全局最优证明。纯WZZT另有1个输入以no_gain_unresolved结束，保留该状态。

## 为什么联合优化没有转化为恢复收益

第一，训练拟合与拓扑目标存在实测冲突。主108中，联合池在81个输入覆盖全部真连接。计数模型未收缩原始解有67个错误，其中59个的正则目标优于真实结构的独立最优LP；只看真结构完全在池中的错误输入，有40个，36个仍严格优于真实结构目标。真实结构LP在相同权重界下独立拟合，只在评分阶段使用，没有进入算法。这些例子说明当前有限样本、噪声和线性响应近似下，原目标会偏好错误结构；延长同一目标的优化不能改变该排序。这不构成物理不可辨识或无限样本不可能恢复的证明。

第二，线路数惩罚有效，但作用有限。无惩罚主108原始解平均有11.52个内部集合，108个原始树全部错误；计数惩罚降至6.29个内部集合。无惩罚原始训练MAE约0.001265，计数模型约0.001270，前者更低却恢复更差。0.24收缩后，主完整恢复从36提升至53，全部120从39提升至59。压力集的无惩罚F1略高而完整恢复更低，故不能声称正则在每种指标和条件下都改善。

第三，候选覆盖仍是限制。主108丰富并集平均27.33个内部候选，81个输入含全真结构；单个RNJ＋NJ平均9.37个候选，只有48个覆盖全真结构，最终完整恢复43个。后者退步的一部分来自候选缺失，不能仅据此认定复杂策略的统计泛化更好。丰富并集的缺失主要仍是小块：主108总计缺53个小块、4个大块（此诊断small指至多5终端）。

第四，纯WZZT的贪心错误会继续限制可行域。主108的已接受错误连接累计351个小块、185个大块；52个输入首次错误就与至少一个真连接交叉。终点保留35个权重为零的错误集合，它们共阻挡38个真连接出现。即使当前权重变零，只要集合仍作为固定层级限制存在，后续单候选步骤仍无法纠正。最终缩掉这些集合也不会自动重开搜索。这支持可撤销修正的必要性，但不保证当前联合目标本身足以正确修正。

第五，本轮联合的实际新增结构价值不大。主108中，只有6个未收缩联合解不同于所有训练热启动结构；0.24收缩后30个输入不同于三个父方法的最终树，但没有新增一个父方案都未恢复的完整正确树。有限候选域的最优正则训练值较好，仍可在固定收缩和验证后的拓扑指标上退步。

## 能否更简单，以及下一步取舍

可把当前最终决策清楚地写成：**训练观测提出候选连接 → 一次带相容约束和线路数惩罚的L1拟合 → 固定收缩并用独立观测检查。** 数学见MODEL.md。RNJ、NJ、WZZT是候选生成器，所有内部候选都可撤销；最终选择无须再描述为反复局部扫描、五块切换和多轮退出。

但丰富并集仍调用了昂贵的旧生成器，描述简短并不等于实现已经简单。为区分候选多样性与WZZT生成器，事后补做了“保留同一训练RNJ候选库＋NJ，只删除WZZT生成连接”的固定参数消融。主108 F1为0.772737、完整50；压力12为0.684193、完整5；全部120为0.763882、完整55，累计475.81秒，单输入中位3.34秒。相比丰富并集，主真结构覆盖从81降至66，完整恢复从53降至50，成本明显下降。它比原普通RNJ＋WZZT的F1略高、完整恢复相同，是值得用独立数据继续检查的轻量方案，尚不据此替换默认方法。

另一项事后诊断把新联合树加入原严格验证候选，同一旧规则不改参数：全120 F1为0.828249、完整70，对照原0.827907、70，只有很小F1变化，没有增加完整恢复。主108为0.843116、63；压力不变。它不能作为联合重构已明显优于原方案的证据。两项追加均在ADDENDUM.md标明时序，未混入事先冻结的主比较。

目前保留原严格组合的恢复质量作为对照，不再叠加救援模块来追同批数据的最高F1。若侧重实现和计算成本，可继续研究固定几何候选库的一次稀疏回归；若侧重恢复质量，下一步应在独立开发集检验结构排序目标和弱边收缩，而非单纯延长求解或不断增加策略。过去多轮设计已看过这120输入，本轮虽未新增参数网格，也不是新盲测；尚无证据证明更复杂方案在新数据上泛化更好。

# 主实验后追加的两项诊断

这两项在读取主480作业结果后才决定执行。它们检验具体替代解释，沿用固定参数；不把它们写成事前确定的主试验，不按此批测试F1选择默认配置。

## 同一旧验证规则下，给新联合树保留竞争机会

主实验的独立联合输出删除了原整树回退。为了检查这一差异，将完整RNJ修正版、少量小块原始WZZT、新联合计数模型三种最终输出送入既有strict验证选择。没有新增拟合、结构MILP、门槛扫描。选择函数只读既有验证统计；真拓扑用于随后评分，不传入选择函数。

结果：主108为F1 0.843116／完整63，原双树组合0.842737／63；压力12不变；全120为0.828249／70，原0.827907／70。改善幅度不足以支持“联合方法提高完整恢复”的判断。这也是一个整树保护诊断，与主实验实际执行的连接联合MILP分开报告。

代码diagnose.py，结果validation_diagnostic_*.csv，时序证据diagnostic_provenance.json。mechanism_*.csv还记录纯WZZT早期错误、零权重约束与联合新结构。

## 删除WZZT生成器，保留训练RNJ库与NJ

主simple_count同时减少了几何候选多样性、删除WZZT生成器。为隔离WZZT生成器的作用，本消融保留原训练RNJ候选库的15种既有配置、common.initial和原始NJ家族，只删除旧WZZT路径／退出产生的候选。该池逐输入都是丰富并集的子集；候选构造只读训练记录。它仍不是“单个RNJ树”的模型。

继续使用主实验冻结的run.py、model.py及其依赖，无源模型变更。λ=0.003 f0、响应界[0,2]、MIPGap=0.0001、4小时总预算、300秒单个LP上限及0.24主收缩均不改变。没有参数网格。另120作业全部完成并达到gap，独立校验见bank_ablation_verification.json。

主108 F1 0.772737／完整50，压力12为0.684193／5，全120为0.763882／55。主候选均值24.83，真结构覆盖66/108；丰富并集为27.33和81/108。全120累计成本475.81秒，其中新阶段312.58秒、公共几何与NJ记录163.23秒。不能把这条低成本方案写成新的未经看过数据的最优策略。

代码bank_ablation.py，额外协议outputs/rnj_union_long_20261031/bank_ablation/protocol.json（added_after_primary_results=true），全部池、求解回执与日志在该目录及records.zip。指标见bank_ablation_*.csv。

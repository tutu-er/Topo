# 用一个模型描述策略，并区分真正的简化

最短描述是：**提出候选连接，再一次性选出相容连接并拟合R/X，最后用独立观测检查。**

“提出候选”与“接受连接”是两件事。RNJ、NJ和已有WZZT只负责提出集合；这些集合不再成为永久限制。最终哪些连接存在，由同一个MILP共同决定。

## 一次层级稀疏回归

训练P、Q、Y按时间×终端排列；Y是观测到的平方压降。令候选终端集合族为C，每个集合的常数指示向量为z_C。单点与全集作为连续响应基B。

\[
R=\sum_{C\in B\cup\mathcal C} r_C z_Cz_C^\top,\quad
X=\sum_{C\in B\cup\mathcal C} x_C z_Cz_C^\top,
\quad\widehat Y=PR^\top+QX^\top.
\]

r、x是当前响应模型中的权重，并非直接把它们当作欧姆值。两个通道共同选择同一连接，权重范围均为[0,2]。

对每个内部候选设a_C∈{0,1}，有

\[
0\le r_C,x_C\le 2a_C.
\]

交叉集合无法同时存在：若C∩D、C\D、D\C均非空，则a_C＋a_D≤1。全部成对交叉限制保证整数选择结果包含或分离。实现另对候选W和全集加入层级计数约束，并加入若干交叉团强化；没有声称枚举全部W的约束，也没有强制完全二叉树。

目标为

\[
\min\quad\frac{1}{nT}\sum_{i,t}e_{it}+\lambda\sum_{C\in\mathcal C}a_C,
\qquad -e_{it}\le Y_{it}-\widehat Y_{it}\le e_{it},\quad e_{it}\ge0.
\]

主模型λ=0.003 f0，f0为同输入原始完整RNJ训练MAE；无惩罚消融固定λ=0。只要候选已确定，所有响应矩阵都是常数，没有未知成员乘积。这里仍需二元变量保证相容，所以是MILP；全部a固定后才是LP。

所有临时内部集合均可删除、增加或替换。没有“先保留大块、再细化小块”的不可撤销顺序，也不要求旧父树保持完整。若父树的所有集合在C中且权重界一致，它就是可行解；因而该候选域的最优训练目标不高于任何父树。有限时间返回只保证已审计可行解及对应上下界；该结论不等于F1不下降。

## 哪些复杂性真的被删除了

union_count的一次最终选择较干净，但候选仍来自复杂旧生成器。把最终决策合并，不等于整个算法已经简单。它在本轮保留为检验“旧方法的块能否重组”的主对照。

simple_count才是端到端的简化：一次训练R/X拟合→单个固定RX75-0.16 RNJ树与NJ树→候选并集→上面的一次MILP→固定响应收缩、LP重拟合。它没有WZZT前缀、局部打开、五块切换和再次退出，也没有公共RNJ整树回退。若其效果较差，要先检查真连接是否根本没有进入候选池；不能只据较低F1认定策略复杂才有效。

pure_wzzt是另一端的基线：从单点／全集开始，每次自由增加一个相容集合，用原始量测L1拟合；不接收NJ/RNJ集合。新集合仍是未知二元成员，其原始单步模型使用既有乘积线性化，不能把它也叫作固定候选的无乘积模型。即使每步解到gap，整条贪心路径也没有全树最优保证。

## 过拟合与验证的边界

更多候选增加结构选择的自由度；线路数惩罚只抑制选择数量，不能自动抵消在许多候选中找噪声模式的偏差。固定收缩参数也可能删掉真实弱边。此次只比较事先冻结的计数惩罚和简化消融，不扫描参数并挑最高测试F1。

一次模型的描述简洁，不保证统计泛化。此前多轮方案设计已看过这120输入，独立验证／测试划分仍保留，但当前结果属于同一固定基准的后续研究，不是新的盲测。判断复杂度是否值得，需同时看候选覆盖、训练／验证／测试误差、拓扑F1、完整恢复和累计计算成本。

新联合模型不再用旧整树择优回退掩盖退步。只有它自身的解进入最终输出；未收缩终点另报。若联合训练目标更低而F1更差，这正是需要保留和解释的实验结果。

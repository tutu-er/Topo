# theft_wzzt 检查与 M7 实施审查

日期：2026-09-19。执行依据：用户要求“思考合理性，并执行”；采用 D1–D4 建议，无子代理、无文件删除。

## 1. 判断

M7 值得实施：外部线损误差直接影响固定偷电幅值，又参与 H0/H1 平衡损失，是现有识别链需要量化的实际不确定性。保留固定幅值和原 MILP，有助于把线损估计问题与整数优化正确性分开。

采用：偏置网格 −50%、−25%、0、+25%、+50%；报告包络 ±25%；L1 单次前向，不做外层迭代；主矩阵仅 null、exp2、exp3。L3/L4 各补充一个 null 和两个事件。

但原方案有以下必须修正的解释。

1. **L1−L0 不是纯参数辨识误差。** L1 使用分表聚合边流和根节点电压，忽略损耗反馈与沿线电压变化；辨识树又是简化区域树。因此差异同时包含树/参数误差、二次潮流近似误差、量测误差。L1 不使用真值通道，只表示其推断输入具备可观测性，不证明其参数等于真实物理支路参数。
2. **原 H0“吸收率”不能度量线损误差吸收。** H0 无偷电源，幅值输入不参与电压预测。记固定量测为 y,p,q，外部线损为 l̂，则

   J₀(r,x;l̂) = V(r,x;y,p,q) + B(l̂)。

   因而 J₀(fixed;l̂)−min J₀(r,x;l̂) = V(fixed)−min V(r,x)，与 l̂ 无关。报告保留此计算为 `h0_refit_benefit`，及除以 L0 的 H0 损失所得比例，同时检查它相对 L0 的增量应近于零。不能把这个比例称为“吞掉了几成线损误差”。另外记录 H1 权重相对 L0 的变化，作为描述性诊断；不同最优解的权重差也不构成因果归因。
3. **包络是条件范围，不是置信区间。** 只有在实际技术线损位于声明误差带且忽略表计误差时，包络才包含对应真实幅值。它不自动覆盖偷电导致的额外技术线损，也不具备 95% 统计覆盖保证。点估计为零时，相对半宽输出 JSON null，避免除零或人为设为零。
4. **5 个 null 不支持 5% 统计校准。** 原方案复制 10–14 已包含在原 20 次校准中。M7 改为独立复制 30–34，以原复制 10–29 的 q95=5.454994777891962 评估固定阈值。每个偏置的 5 次增益仍给出探索性 q95，但其回代误报比例不是独立重校准后的误报率；其秩检验分辨率仅 1/6。一个网格点 0/5 误报不能推出安全误差界。
5. **L3/L4 仍须标注真值依赖。** L3 是裁剪前零均值相对高斯扰动，非负裁剪后并非严格无偏；P/Q 共用扰动。L4 比例在独立历史清洁复制 10 的完整一天用 L0 标定，再固定应用于待测数据，属于理想标定对照，不能声称完全可部署。
6. **沿用已有经验阈值规则。** M5/M6 的实验汇总采用 `gain > q95`，而 `compatibility_report` 使用经验秩 `rank <= alpha`。两者并非对所有观测严格等价。M7 明确沿用前者，不改变现有校准或评价函数。

## 2. 误差传播与单位

正确的总表平衡为 P₀ᵐ−ΣPᵐ = a + ℓ(a) + ε，其中 ε 合并总表与分表误差。固定输入为

â = max(a + ℓ(a) − l̂ + ε, 0)。

L0 取无偷电反事实 ℓ(0)，故即使 L0 理想，â−a 仍包含 ℓ(a)−ℓ(0) 和表计误差。这一差异在结果中分开保存，并检查逐时带符号平衡恒等式。

L1 的权重约定是 wᵣ=2r_pu、wₓ=2x_pu；令 z 为边到观测终端的路径关联矩阵：

Fₚ=P_terminal zᵀ，F_q=Q_terminal zᵀ；
l̂ₚ=Σₑ (wᵣ,ₑ/2)(Fₚ,ₑ²+F_q,ₑ²)/V_root²。

无功损耗同式换为 wₓ。使用观测根电压，按终端标签对齐列，不读取 `P_true`、`root_voltage_true` 或实际/反事实线损。

包络误差与扫参误差的分母应区分：L2 的 β 定义为 l̂/ℓ(0)−1；包络声明的是实际 ℓ 相对估计 l̂ 的范围，即 ℓ∈[0.75l̂,1.25l̂]。这两种“±25%”不是同一假设。若另行假定 |l̂/ℓ−1|≤25%，则应采用 ℓ∈[l̂/1.25,l̂/0.75] 的倒数界。本轮保留原方案的乘法包络，并按前一种条件解释，不把它当成 L2 网格的自动覆盖保证。

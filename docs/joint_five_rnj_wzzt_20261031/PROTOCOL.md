# 五块以内一次联合选择：RNJ预选与WZZT收尾的2×2对照

## 目标与范围

本次实现的是“显式列出全部剩余候选线路，一次MILP联合选择并拟合”，不是此前误解的逐条LP加块。每个参与区域的直属子树块数最多5，候选数最多25，交叉冲突最多195对。各区域共用全部原始终端的量测L1目标，外围R/X权重也一起拟合；区域损失没有被拆开。

沿用近期全面对照的完整RNJ初始层级；RNJ提供预选支撑、暖启动候选及共同最终候选库。本批不等同于生产默认的100次bootstrap、最多两个边界块预选。生产默认参数和代码不修改。

原始输入为paper15、soumalas11、flynn16、pengwah18的108主输入与12压力输入，沿用 `outputs/paper_cases_lp_rebuild_20261031/` 的原始观测和训练前端。主输入：四网络×bundle2/3/4×电压相对噪声0.02%/0.05%/0.1%×总训练样本24/48/96；P/Q噪声0.5%；验证和测试各独立288点。压力条件为弱激励、根噪声、异常点，每网络各一项。它们是既有AC合成数据，不称为新盲测或现场数据。

## 一次联合模型

保留粗骨架集合，列出每个至多五块区域的全部非平凡真并集。每个候选连接有二元选择变量a和连续r/x：0≤r≤2a，0≤x≤2a。交叉候选满足a_C+a_D≤1；另加区域及子集的内部集合数约束。响应矩阵由训练P/Q和固定支撑预计算，没有未知支撑乘积。全部区域一次进入同一个模型。

模型允许多分叉，未预设真实内部节点数。既有树必须能被候选池恢复，作为有效暖启动和可行上界。保留incumbent、bound、gap及原量纲可行性检查。状态2表示相对gap达到0.1%容差，不改写为零gap精确全树最优。

## 两处介入与四个方法

RNJ预选介入：按支撑终端数从小到大，尝试打开≤5终端的临时合并；只有打开后父区域直属块数仍≤5才释放。大于5终端的骨架边界保留，必要的小边界也保留。一次联合重选全部可开放区域。既有大于5分叉的区域明确跳过，留给原WZZT处理，不默称已进入五块域。

WZZT收尾介入：先照原有自由支撑单线路MILP推进；当所有剩余区域的最大直属块数≤5，打开可释放的小合并，执行一次联合MILP，随后结束结构搜索。这里没有逐候选LP扫描或接续多轮联合重构。

四组：baseline（原RNJ+原WZZT）、rnj_pre（只改RNJ预选）、wzzt_tail（只改WZZT收尾）、both（两处都改）。保留所有中间状态与路径，记录两处是否调用和是否接受。

四组共享20秒结构搜索软预算；预选联合最多5秒，原单步MILP每次2秒，联合收尾使用剩余预算；所有构模和暖启动计入实际时间，单个固定家族LP最多5秒。四个单线程工作进程并发，进程硬上限180秒。每个联合位置最多调用一次。参数和矩阵在评分前冻结，无按F1调参。

训练目标均为原量纲MAE，系数范围0..2，不加正下界和稀疏惩罚。接收门槛统一为1e-10+0.001×当前MAE。所有组使用同一公共RNJ候选库、各自路径和相同单点备用候选，按0.16收缩→训练重拟合→严格验证MAE选模。另报仅路径与未收缩终点，防止把公共RNJ回退当作WZZT修复。

## 错误诊断

切换中的“≤5”是直属子树块数；错误统计中的“小线路”指覆盖2..5个终端，“大线路”覆盖超过5个终端，两者分别记录。

逐输入记录RNJ原预选、修改后的预选、收尾前、搜索终点和最终输出，统计大小线路的TP/FP/FN及各自分母。结构上保留但权重为零的初始集合单列，因为它们仍可能排除相交真线路。

对每条真线路检查它是否被当前错误集合交叉排除，按错误集合来自RNJ预选还是后续WZZT、属于大块还是小块分类；多个错误同时阻断时保留重叠，不相加冒充互斥贡献。追踪首次新增错误集合及其阶段。该诊断说明搜索域限制，不把误差计数或残差解释为拓扑概率，也不单凭计数断言全部因果。

真实拓扑和测试观测只在冻结推断后的离线评分中读取，不传给推断工作进程。

## 核验与记录

小例核查一次加入多条线路、交叉排除、与完整小树家族LP枚举的一致性，以及错误小合并的释放与修复。正式结果重算原始损失、层状性、系数界、单调性、切换条件和求解器界，最终家族追加独立HiGHS LP核验。保留全部失败和未决停止原因。

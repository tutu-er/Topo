# 连续一日96点：T端到端对照与DR候选接口

日期：2026-11-10。用户明确采用连续一日96个15分钟时点，区别于旧批次三日各32点的N96。

## 固定主试验

- 网络：paper15、soumalas11、flynn16、pengwah18。
- 每网络4个新随机历史；采用未用于旧批次的replicate命名空间。
- 每个历史共用物理轨迹和标准噪声，实现电压/根表sigma=.0002/.0005/.001三个条件；P/Q相对噪声.005。
- 训练：连续一日96点；验证：独立三日288点；测试：另一独立连续日96点。
- 48个数值输入来自16个网络-历史块。四个网络共用4个随机种子索引，噪声条件配对；主要重采样以4个共同种子组为块，每块保留全部网络和噪声，不把48个输入或96个时点都当成独立重复。
- 三方法：无T；原T(.003f0)；仅T正则改为.01f0。基础WZZT和最终E仍用.003f0，明确这是T的单模块消融。
- RNJ指导、及时清零、最终E、.24收缩后重拟合及严格验证择优相同；最终没有完整RNJ整树备用。
- 每配置输入总预算14400秒，单候选MIP3600秒，LP300秒，单线程，MIPGap=.0001；达到精度即可提前结束。
- 先四网络各一新历史sigma=.0005验证接口和数值口径，再运行余下输入；参数不根据首批结果调整。

生产默认和旧实验保持原样；优化代码从既有full_ablation冻结源复制，仅覆盖T系数入口。所有新观测和代码哈希在运行前保存。失败、超时、未完成、预算超限保留计划分母144。

## 主要指标

完整算法F1、精确率、召回率、完整恢复率、逐输入算法累计耗时，按网络/噪声配对比较。单列前向路径、T提案、E提案及收缩前后的结构。候选评价同时报告真连接并集覆盖和至少一个完整候选恢复真树，二者不混同。

本轮不把六个已知失败输入当测试集，不按真拓扑选择正则或输出。48个新输入用于首次独立端到端比较；跨网络结论仍限于四个固定网络、4个共享种子组及已声明的数值条件。数据生成后的源审查确认了跨网络种子共用，故在完整结果前明确上述统计分组；优化配置和输入不改变。

## DR相容性核验

隔壁“设计WZZT耦合激励判据”最新入口为dr_continuous_independent/full_price.py和full_evaluate.py。该路径冻结两棵历史预测器，只改变新日观测后按原3%规则回选；当前历史候选来自dr_pool_v2有限连接池/多初值LP路径，仍含完整RNJ整树备用，.16收缩且不重拟合。它与本轮研究辨识器不是同一配置。

本轮提供独立候选导出：自身路径及E输出、单点保护候选，保存完整层级和全部历史拟合R/X。按完整参数指纹去重，保留全部来源；原始预测器与输出收缩拓扑分开保存。所有候选在DR报价和新日观测前冻结。

对接至少检查终端顺序、根节点、电压平方降Y=Vroot^2−V^2、P/Q正方向和标幺基准、响应系数界及样本权重。隔壁价格入口目前硬编码paper15的15终端和3日历史；这不是候选矩阵本身的不相容，而是必须显式适配的数据接口。

首先保留隔壁两模型概率问题，导出一个历史首选与一个结构挑战者，记录候选覆盖范围。扩大到多模型后，排除一棵粗树的成对事件不能直接等同于全池最终恢复，需要另推共同选择事件。

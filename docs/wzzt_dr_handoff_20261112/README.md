## 当前主问题

给定正在评估的目标候选，**条件于它正确，计算需要多强的DR及多少费用，才能使它在完整历史＋新日的原选模规则中胜出**。目标不必是历史已经选中的模型。候选和R/X由历史拟合后冻结，90%指声明误差模型下达到激励/选模门槛的条件概率。

额外电压预测器Hbar、候选均值、VAE/copula等是历史替代探索，不是本主线必需项。拓扑辨识器与DR规划分层：先复用RNJ＋WZZT生成候选，再规划新日DR，最后用实际AC含噪观测评价冻结候选。是否重新运行辨识器另列实验，不能在“冻结参数”评价中悄悄重拟合。

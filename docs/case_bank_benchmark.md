# Paper-Style Case Bank Benchmark

This benchmark adds several compact terminal-load-only LV feeders that are
closer to the structures used in topology-identification papers than the long
terminalized case33 backbone.

## Cases

- `paper15`: the previous 15-terminal balanced hidden-node LV feeder.
- `soumalas11`: compact Soumalas-style LV feeder with 11 terminal meters.
- `flynn16`: balanced hidden tree inspired by recursive-grouping/Flynn-style
  examples, with uneven service drops to avoid near-tie terminal MST edges.
- `pengwah18`: unbalanced mixed-lateral LV feeder inspired by smart-meter
  voltage-sensitivity graph-learning tests.

All cases keep the strict terminal-load-only assumptions:

- the root/transformer node is observable;
- internal nodes are hidden, zero-injection, and unmetered;
- all P/Q/V meters are placed at terminal leaves;
- PV, wind, small-generator, and demand components are attached only to terminal
  leaves.

## Data generation

The benchmark uses the same heterogeneous terminal profile generator as the
current AC-flow experiments. It includes default, high-wind, low-wind,
no-solar, cloudy PV, high-load, evening-peak, storm-front, and mixed cloud/wind
days. P/Q noise defaults to 0.5% of instantaneous P/Q. Voltage noise is taken
from the scenario definitions, normally 0.02% of instantaneous terminal voltage
magnitude.

Voltages and branch flows are generated by the nonlinear radial AC
backward-forward sweep solver with the root as slack/reference. LinDistFlow
sensitivities are used only as the reference reduced sensitivity and distance
matrix for topology evaluation.

## Estimator

The benchmark runs the constrained symmetric nonnegative squared-voltage-drop
model:

```text
V0(t)^2 - Vi(t)^2 ~= sum_j Rij Pj(t) + sum_j Xij Qj(t) + gamma_i,scenario
```

It searches a compact preprocessing grid and compares two terminal distance
modes:

```text
dR_ij = R_ii + R_jj - 2 R_ij
dRX_ij = normalize(dR_ij) + normalize(dX_ij)
```

The second mode is useful because these LV cases are constructed with R and X in
the same order of magnitude, so the estimated X matrix contains meaningful
topology information rather than acting as numerical clutter.

```bash
python -m experiments.run_case_bank_filter_search --output outputs/case_bank_filter_search
```

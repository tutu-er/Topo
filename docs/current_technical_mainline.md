# Current Coupled Topology-Identification Mainline

The canonical method uses noisy terminal P/Q/V generated by radial AC power
flow. The linear sensitivity model is used only for estimation and candidate
generation; it is not used to synthesize benchmark voltages.

## Canonical Entry Point

```powershell
python -m experiments.run_unified_topology_pipeline_sweep `
  --cases paper15 soumalas11 flynn16 pengwah18 `
  --data-regimes sparse medium rich `
  --noise-regimes low nominal high `
  --trials 2 --quartet-replicates 12 `
  --nj-bootstrap-replicates 8
```

For a smoke run, use one case, one data regime, one trial, and two quartet and
NJ bootstrap replicates.

## Identification Flow

1. Split complete operating scenarios into training and representative
   held-out validation scenarios.
2. Form the drop target `v_root^2 - V_i^2` (relative to the observed root
   squared voltage) and demean each day. Fit
   symmetric, nonnegative, diagonally ordered reduced R/X matrices.
3. Form additive terminal impedance distances and root depths. Run RNJ with
   the known physical root to obtain the Ordered base candidate.
4. Fit the GTLS/EIV branch and generate a finite OLS/GTLS RNJ candidate pool.
5. Run root-placed NJ and root-augmented RG on the Ordered distance. Circular
   block resampling plus an additional small measurement perturbation estimate
   the persistence of peripheral clades.
6. Confirm NJ-only regions with at least two external sources among Ordered
   RNJ, GTLS marginals, AC-validated clades, and quartet significance.
   NJ/RG-consensus regions need no second structural detector, but a material
   quartet contradiction rejects them.
7. For confirmed regions, sum P/Q and estimate pseudo-parent squared voltage
   from mean terminal voltage plus a descendant-only service-drop correction.
   Re-identify the pseudo backbone and each local subtree with Ordered RNJ.
8. Put the Ordered base, OLS/GTLS RNJ grid, and all accepted aggregate/decompose
   trees into one shared candidate pool, deduplicated by rooted terminal clades.
9. On every fixed candidate tree, refit nonnegative additive branch R/X with
   P/Q-error-aware weights. Accept an AC parameter update only if training AC
   voltage RMSE improves, then rank on held-out scenarios with heteroscedastic
   predictive likelihood and complexity penalties.
10. Contract only hidden edges whose fitted impedance is near zero or whose
    quartet confidence interval materially contradicts the split.

No frequency-domain preprocessing, spectral cutoff selection, or phase-based
clock-offset correction is part of the active code path.

## Method Roles

- Ordered constrained regression supplies the stable deterministic base.
- RNJ reconstructs a rooted hidden tree from additive distances and known root
  depths.
- NJ/RG proposes small peripheral regions without fixing their local topology.
- One-layer aggregation reduces the simultaneous-injection dimension and then
  re-identifies both backbone and local structure.
- GTLS supplies errors-in-variables candidate diversity and clade marginals.
- Quartet gaps test local tree additivity and reject materially inconsistent
  hidden splits.
- Error-aware AC likelihood performs the final comparable physical ranking.

These diagnostics are correlated. Their scores are combined with explicit
gates, not multiplied as independent probabilities.

## Outputs And Interpretation

`UnifiedTopologyResult` exposes `base`, `gtls_posterior`,
`peripheral_proposals`, `detector_aggregations`, the shared AC ranking,
clade-level evidence, and `final_clades`. `selection_source` starts with `ac_`
because no proposal family bypasses physical reranking.

Topology accuracy is evaluated with rooted terminal clades. Hidden-node labels
are algorithm-local and are not compared directly. Degree-2 hidden chains are
not uniquely identifiable from terminal additive distances without additional
meters or line-length assumptions.

## Core Files

- `terminal_case33/estimation/baseline.py`: Ordered constrained R/X and RNJ.
- `terminal_case33/pipeline/peripheral_edge_proposals.py`: NJ/RG proposals and
  perturbation stability.
- `terminal_case33/pipeline/two_level_aggregation.py`: pseudo P/Q/V,
  pseudo-backbone fitting, and local re-identification.
- `terminal_case33/pipeline/gtls_topology_posterior.py`: finite OLS/GTLS
  topology posterior.
- `terminal_case33/pipeline/ac_likelihood.py`: fixed-tree R/X refit and held-out
  AC ranking.
- `terminal_case33/graph/quartet_significance.py`: four-point bootstrap tests.
- `terminal_case33/pipeline/unified_topology_pipeline.py`: orchestration and
  evidence gates.

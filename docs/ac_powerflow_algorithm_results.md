# AC Power-Flow Reproduction Results

This note records the current reproduction run after replacing synthetic
LinDistFlow voltage generation with nonlinear radial AC backward-forward sweep
measurements.

## Data-generation rule

- Network: terminalized IEEE case33, `hybrid_leaf`, LV-style service drops.
- Root: observable slack/reference bus.
- Load convention: positive terminal `P/Q` means consumption.
- Voltage and branch flows: generated by nonlinear radial AC power flow.
- Measurement noise: 0.5 percent relative noise on terminal `P/Q/V`.
- Reference matrices: `R_true/X_true` remain reduced LinDistFlow small-signal
  reference matrices for sensitivity and impedance-distance scoring.

## Output locations

- `outputs/ac_line_flow_case33`: AC voltage, branch current, branch flow, loss,
  and power-balance files.
- `outputs/paper_full_reproduction_ac_noise`: paper-inspired algorithm metrics.
- `outputs/topology_identification_gallery_ac_noise`: topology plots and
  per-case graph-recovery metrics.

## Paper-inspired benchmark summary

| Variant | R relative error | X relative error | terminal MST F1 | R2 |
|---|---:|---:|---:|---:|
| Soumalas 2017 regulated-root proxy | 17.895 | 57.538 | 0.065 | 0.090 |
| Flynn 2023 without transformer mode | 23.723 | 85.550 | 0.097 | 0.085 |
| Flynn 2023 with transformer/root mode | 17.882 | 57.332 | 0.065 | 0.489 |
| Pengwah 2024 mixed-meter proxy | n/a | n/a | 0.095 on smart subgraph | n/a |

The AC plus 0.5 percent noise setting is much harder than the earlier idealized
LinDistFlow-generated data. The main failure mode is that the voltage signal
used to estimate small reduced sensitivities is close to the noise level, while
the nonlinear AC operating point also introduces finite-load deviations from the
linear sensitivity model. The transformer/root mode improves voltage fit under
root variation, but it does not by itself recover the terminal-equivalent graph.

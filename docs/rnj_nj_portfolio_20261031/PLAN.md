# NJ基线与完整树组合：冻结方案

在同一120输入补充NJ，并测试优势能否结合；不重新求解四条结构搜索路径，不改写原结果。

NJ沿用项目已有的已知根锚点经典Q准则实现，使用同一训练RX75几何，固定几何收缩0.16。报告两种口径：NJ_native保留几何拓扑（即使事后L1权重为零），只拟合响应来评价原量测损失；NJ_matched在同一树上使用与四方法一致的训练L1、0.24最终响应收缩及重拟合，另报0.16。后者不回退到公共RNJ库。前者是项目内部经典NJ对照，非某篇完整电网方法的原实现复现。

组合候选仅为完整RNJ修正版与少量小块原始WZZT组合的最终完整预测树，第三候选可加入NJ_matched。不拼接交叉集合，也不平均R/X矩阵。固定两个候选域×两种原有验证规则：严格最小验证MAE为主；已有12时间块配对一标准误差、优先较少线路规则只作敏感性。两种规则都只看验证观测，不使用真拓扑或测试数据。所有阈值与收缩参数冻结，不按这批F1调整。

优化阶段120个NJ及选择作业，无新结构MILP；固定家族LP上限30秒。组合部署需要先运行两条结构搜索路径，顺序结构预算上限为300＋300秒；本次额外选择耗时与两条已记录流程累计耗时分开，不声称组合仍是同一300秒方法。

评分后单列有限候选的逐输入最好F1／任一完整恢复作为事后互补性参照，不将其当成可部署方法或全局拓扑上界。对照保留原四方法、逐网络／噪声／N、F1、完整恢复、选择来源和失败分母，并检查原24与其余84主输入。源码、输入、父结果、原验证块误差和旧交付哈希均核验保存。

四源型为无源、常值源、间歇源、平滑源。有源时算法可见源 P/Q 时序，接入位置未知。NJ/RNJ 通过自由终端响应的 FWL 投影消去源；WZZT 将源响应限制到同一树上的完整路径。比较同时含拟合目标和源模型域的差别。Soumalas11 压力实验另用非比例 P/Q 的秩2源，不能与原 AC96 源型视为同一条件。

完整主线复测的两档预算分别指“单次求解 / 方法总时限”；后续三批 WZZT 均沿用 6000 / 30000 秒。所有计时来自非独占机器；复用基线使用原保存耗时。`compute_seconds` 是当前采用尝试的耗时，AC96 的 `combined_spent_seconds` 只累计已记录的尝试；外部中断前的未知花费仍未知。

## 3. 优先采用的横向结果：AC96 初始化/分组对照

主 F1 为 `resolution_clade_f1`，按批次固定 RX75 尺度处理预测，再对完整物理真簇评分。以下均值严格取六种配置均 complete 的共同 14/16 条件；排除 Pengwah18 常值源、平滑源。两条件仍在逐项表与下一张表中保留。

R/X 误差是平方电压响应矩阵的相对 Frobenius 误差，统一在 CSV 中记为百分数；它评价整体响应矩阵，逐条物理线路阻抗需另评。NJ/RNJ 参数来自前置 ordered L2 回归，WZZT 来自结构化 L1 拟合，因此上述差异包含结构域与损失函数的共同作用。

## 6. 后续系统处理顺序

先固定要评价的 WZZT 版本和拓扑尺度，再做能够解释机制的小对照，最后扩大随机重复与噪声矩阵。下表是待办及验收条件，本次尚未运行这些新增实验。

| 顺序 | 工作与最小范围 | 验收条件 |
|---|---|---|
| P0：协议冻结 | 明确“纯 WZZT / 稳定组 / 普通整树初值”的区别，固定 Source 模型、剪枝、扩界、正权下界、停止和选模规则；实际依赖闭包单独冻结 | 同一方法名能唯一指向配置与源码；含空选组、初始触界及 max_atoms 计数语义。当前工作区有未提交 AC 改动，不能用 HEAD 代替运行源码指纹 |
| P1：六个机制条件 | paper15 AC96 无源；flynn16 AC96 常值源；pengwah18 AC96 无源与常值源；pengwah18 64/32 无源；soumalas11 rep2 秩2源 | 从既有模型先形成逐步表：加入/删除簇、R/X 权重、真实/伪簇、训练/验证误差、认证与耗时。真值只作事后解释 |
| P2：消融归因 | 叶初值、稳定组、同支持不分组、普通整树初值；另加入固定 NJ/RNJ 树的同 L1/Source 重新拟合控制 | 分别回答初值联合重估、binary 共享、后续新增支撑各贡献多少；保存 path0 与最终结果，空组原样保留 |
| P3：扩展稳健性 | 四网络共同协议；先无源，再已知时序/未知位置源；增加随机重复与噪声/样本档位 | 预先固定条件和主指标；所有失败保留分母；每个对比报告共同完成集与计划分母，划清训练/验证/测试用途 |

六个条件同时包含 WZZT 有利、错误初值有害、超时、正权错误路径和“仅重拟合即改善”的结果，用于检查因果解释；它们是诊断集合，性能均值仍用完整预登记条件集。

后续每项至少保留：数据与实际源码哈希、输入信息、初始化家族/不可分组、每轮候选和权重、primal/bound/gap、接受或拒绝原因、全部路径点、训练/验证/测试分工、三种 F1、响应矩阵误差、当前尝试与恢复耗时。以这些字段解释结果后再决定是否扩大预算或修改搜索。

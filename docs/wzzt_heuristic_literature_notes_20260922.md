# wzzT 启发式检索笔记（2026-09-22）

本笔记只调研启发式，不实施算法、不改动核心代码、不开展性能实验。适配判断以当前问题结构为前提：离散变量为层状支撑族；固定支撑后，所有旧、新支撑的 R/X 系数在多场景间共享，并与场景截距一起联合求解 L1 线性规划。下述“建议”是模型分析，不是文献已经验证的 wzzT 结论。

## 推荐顺序

1. **结构感知 VNS/ILS + 固定支撑联合 L1 LP**：最适合首先实现的独立原型。用整块增删交换保持 laminar 性；多起点、扰动和跨父节点跳转用于跳出局部极小。
2. **整树的删除—重建 LNS / NNI、SPR 型移动 + 联合 LP**：若目标是纠正前向贪心早期错误，比只优化下一条支撑更直接。可以先做单支撑替换，再做两条相关支撑一起替换。
3. **Local branching**：作为 VNS 停滞后的短预算强化器或受限邻域最优检查，仍需 MILP 求解器。优点是邻域可数学定义、易控制；缺点是有限预算子 MILP 仍可能难。
4. **RINS / 完整 ALNS 调度**：第二阶段再考虑。RINS 依赖整数可行解与 LP 松弛提供有用共识；当前模型的松弛质量需要实测，不能仅凭“RINS 在通用 MIP 中表现好”就优先引入。ALNS 先要有多个有效算子和足够多运行记录，才有调度价值。

这里的优先级基于结构匹配与实现复杂度；尚无新实验证明哪种方法更快。

## 一、为何首选结构感知邻域

记当前固定的支撑族为 F，对一个合法新支撑 S 定义

\[
J_F(S)=\min_{r,x,b}\; L_1(F\cup\{S\};r,x,b),
\]

其中仍使用原数据、场景权重、参数边界及截距规则，并对 **全部** 旧、新连续参数联合优化。对每个被评估的 S，这一步是原模型的准确固定结构评分；对哪些 S 进行访问则是启发式。

单端点 bit flip 可能遇到结构屏障。例如已有块 C={1,2,3}，当前 S=C∪{4}，删除其中一个端点通常使 S 与 C 部分交叉。直接删除整个 C 才可保持 laminar 关系。因此邻域应当以当前层次的子块为单位。

将 F 加入虚拟全集根和必要单端点叶后，形成包含关系树。非平凡、非重复且与 F 相容的新支撑，可表示为某个父节点的若干直接子块的并集。父节点需要遍历或允许跳转；只在一个预选父节点内搜索仍然会漏解。全集根是否允许选为新增支撑、单端点支撑是否已存在，应按原问题规则处理。

对同一父节点的 d 个子块，用 q∈{0,1}^d 表示选择：

- N1：增加或删除一个完整子块；
- N2：交换一个选中与未选中的子块；
- N3：同时改变两个以上子块，或重新选择父节点；
- 每次过滤空集、重复支撑和不允许的结构，再做联合 LP。

一个父节点的一轮 N1+N2 至多需要 O(d²) 个 LP 评分；这只是单轮候选数量，不是整个算法的多项式运行时间保证。父节点的度数大时，邻域数和多起点次数仍可能成为瓶颈。

可先用便宜残差分数排序邻居，再按顺序做 LP；排序不应被描述为安全剪枝。若只评估前若干个邻居，也不能宣称达到完整 N1/N2 局部最优。

## 二、Local branching 的具体适配

给定可行支撑指示向量 z̄，增加

\[
\sum_{i:\bar z_i=1}(1-z_i)+\sum_{i:\bar z_i=0}z_i\le k.
\]

保留原 laminar、非空、非重复约束，所有连续系数自由重估。也可在一个父节点的子块选择 q 上定义相同距离，避免把一个大子块的移动误算成许多独立端点变化。两种距离定义的邻域不同，实验需注明。

不宜对 y_ij=z_i z_j 和辅助关系变量一起计算 Hamming 距离：它们是结构变量的派生编码，会使同一次结构变化被重复计数，导致邻域半径难解释。

建议用 k=1、2、4 等递增邻域与短时间预算，更新 incumbent 后重新中心化。若要证明局部最优，必须让当前邻域子 MILP 完成认证；若限时未结束，只能说该邻域内找到了当前最好可行解。要证明全局最优，需要补集分支完整搜索及有效全域下界，不能用子问题下界替代全局下界。

## 三、整树纠错与 NNI/SPR/LNS

只对新增 S 做启发式，仍然锁定了旧支撑的结构。若前向步骤早期做错，一条新支撑可能永远无法修复。因此第二个值得做的模块是完整支撑族的局部替换：

1. 从当前估计的层次树选择一个内部区域，删除一条或两条非必需支撑；
2. 用相容的新支撑重建该区域，或者使用树的 NNI/SPR 型重接；
3. 将新树重新转换为支撑族，检查 laminar 性、终端身份和根约束；
4. 对完整支撑族联合求解原 L1 LP，再决定是否接受。

树重接比任意交叉/突变更容易保持合法性。若允许改变支撑数，应保持与原方法一致的复杂度约束/惩罚，并独立验证选择步骤，否则训练误差下降可能仅来自模型变复杂。若比较相同支撑数的替换，复杂度混杂更小。

优化训练目标与正确恢复拓扑是两个指标。等价终端树、近零边权和多解仍可能使不同支撑达到几乎相同目标。这里引用系统发育树方法，只借鉴搜索算子，不据此声称 wzzT 的物理拓扑可识别或具有恢复保证。

## 四、首轮对照实验应怎样设计

保持旧单步 MILP 作为小规模精确参照，独立实现 VNS/ILS；至少比较单起点、等预算随机多起点、VNS、整树替换四组。数据、训练划分、参数边界、终止预算一致。RNJ 等观测驱动方法可作为一种初值，但不能提供真实树或仿真支撑用于搜索。

记录最好目标随时间的轨迹、到达同一目标阈值的时间、LP 评分次数、结构合法率、所有随机种子及失败/超时。小规模用全域 MILP 的有效下界比较 objective gap；大规模报告相对最好已知解，而不是相对未知全局最优。完整恢复再报告终端等价树距离及留出集误差。

只要不加入有效全局下界，这些方法交付的是可行解上界。随机多起点收敛到相同结果、遍历所有一阶邻居或若干邻域子问题精确求解，都不等价于原问题全局最优证书。

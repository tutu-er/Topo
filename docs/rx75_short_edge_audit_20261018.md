# WZZT短边尺度遗漏核查

用户确认沿用既有RX75短边尺度：75%R、25%X，阈值因子0.16。本次核查没有另设欧姆阻抗下界，也没有根据真值调阈值。

## 核实的实现差异

- NJ按`0.16*median(RX75 root depths)`收缩短隐藏内边；RNJ把相同尺度用于同簇判别。RNJ最后的显式边收缩另只有1e-10数值阈值，两者并非完全相同的规则。
- 当前WZZT及已核历史核心的R/X变量下界均为0；`zero_tolerance=1e-9`只做近零剪枝。本轮`active>1e-8`只是数值活跃口径，不能替代图分辨率。
- 早期AC验证管线另有2%相对边强度过滤，但未在本轮WZZT调用链启用。旧优势结果还受有限RNJ候选池与验证1SE选择约束，不能宣称旧WZZT已执行了本次新增短边处理。

因此，此前直接拿WZZT全部非零支撑与有尺度处理的NJ/RNJ比较，混入了图分辨率差异。原分数继续保留，新增同尺度结果单列。

## 已完成pengwah18无源联合方法的诊断

原运行全部288点拟合，2055.45秒，19/19求解认证，零超时、零扩界，停止于`max_atoms`。路径第9点已恢复7/7真簇；后续又加入8个非零伪簇。最终原始family和active F1均0.63636（7真、8假），R/X响应矩阵误差5.7356%/18.2275%。

采用同工况NJ的FWL有序回归矩阵校准固定尺度：

| 量 | 值 |
|---|---:|

| 正X距离均值 | 0.2383088790837734 |
| R权系数a | 3.0497464743710774 |
| X权系数b | 1.0490586878725439 |
| 根深度中位数 | 0.6213656285024758 |

| 最小真内边权（事后检查） | 0.1575658717125141 |
| 最大伪内边权（事后检查） | 0.0553600632294133 |

`a=0.75/mean(dR>0)`、`b=0.25/mean(dX>0)`，每条原子边权为`a*r+b*x`。上述阈值仅由允许的观测输入确定；真假标签只用于事后诊断。固定尺度可把这份原始模型的8条伪内边全部收缩，保留全部7条真内边，拓扑F1为1。收缩后R/X及Source需要实际重拟合，不能沿用未收缩模型并声称参数已对应新拓扑。

## 修复路线

1. 原始模型、16项分母和停止证据保持完整；增加固定RX75尺度收缩与全量重拟合结果。
2. 在新隔离模型的每次固定支持与扩展求解中，旧内边为零或达到tau，新内边必须达到tau；同样保留完整未知Source路径与原严格最优性认证。
3. 在这个搜索域内判断是否还有增益，实现及时停止。不能仅因无下界最优候选的边较短就终止全部搜索。
4. RNJ初值逐项核对筛选、真实完整性、实际支撑与原子分区；selected为空明确标记退化。

新增阈值是图分辨率先验。单步无增益证书仍只覆盖当前分组、系数界和分辨率内的一个新原子；初始支撑的层状兼容约束仍可能限制换边。它不提供整棵树全局最优或所有工况恢复保证。

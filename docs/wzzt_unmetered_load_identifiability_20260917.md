# 基于 wzzᵀ 的漏计负荷识别、联合不确定性与可辨识性

记录日期：2026-09-17。

研究重点已根据用户澄清调整为**隐藏内部节点或未建档接入点的偷电负荷能否被有效辨识**，详见[隐藏节点专题主线](wzzt_hidden_node_theft_identifiability_20260917.md)。本文件保留一般背景；第 4.2 节已有表计用户的比例漏报分析不作为隐藏节点识别的主方案。

原始想法：在现有 wzzᵀ 拓扑辨识中增加偷电识别，同时估计置信度和可信度，综合判断存在偷电时拓扑与异常是否仍可辨识。

状态：研究想法与可行性分析。已核对当前代码；下文公式为本文建模和推导，尚未实施检测器、跑识别实验或建立统计覆盖保证。文献仅作相关工作定位，未完成全面查新或作者实验复现。

**判断：值得研究。适合将问题表述为“结构化拓扑与漏计负荷联合辨识，以及哪些结论能够被数据支持”。** 电气数据可提供未计量负荷、漏报或表计异常的证据；相同电气现象可能来自故障、正常未建模负荷或故意行为，单凭这些数据通常不能确认“偷电”这一原因。

## 2. 物理模型：异常加在注入上

先考虑单相/平衡等效、径向、稳态、负荷为正的模型。令

\[
d_t=V_{0,t}^{2}\mathbf1-V_t^{2},\qquad
R(T,a)=\sum_{e\in T}a_ez_ez_e^\top,\quad
X(T,b)=\sum_{e\in T}b_ez_ez_e^\top,
\]

其中 \(z_e\) 指示边 e 下游的终端，\(a_e=2r_e^{pu},b_e=2x_e^{pu}\)。这里的 R/X 已包含平方电压系数，不再在潮流关系前重复乘 2。

用 \(p_t^m,q_t^m\) 表示报告功率，用 \(u_t,v_t\) 表示实际功率相对报告功率的系统性漏计分量：

\[
p_t^m=p_t^{true}-u_t+\nu_t^p,\qquad
q_t^m=q_t^{true}-v_t+\nu_t^q,
\]

\[
\boxed{d_t=R(T,a)(p_t^m+u_t)+X(T,b)(q_t^m+v_t)
       +\eta_t+\epsilon_t.}
\]

\(\eta_t\) 为明确建模且受到约束的偏置/公共项；\(\epsilon_t\) 包含量测误差和 AC 线性化偏差。功率量测噪声以 \(-R\nu_t^p-X\nu_t^q\) 进入有效误差，因此是解释变量带误差问题，不能自动假设普通回归的独立同分布残差。

关键联系是

\[
Ru_t=\sum_e a_ez_e\underbrace{(z_e^\top u_t)}_{\text{该边下游漏计有功总量}}.
\]

wzzᵀ 因而能表达漏计负荷沿公共路径造成的影响。边权表示阻抗，漏计变量表示注入，二者应分别解释。

需要至少区分以下场景：

- **已有用户漏报：**候选 u 位于已有表计节点。消费漏报可设 \(u\ge0\)，但这是假设，不适用于所有净注入、光伏或储能计量错误。
- **未建档旁路/隐藏节点负荷：**需要扩展隐藏注入位置 H，使用 \(R_{OH}u_H+X_{OH}v_H\)。相应原子为 \(a_ez_{e,O}z_{e,H}^\top\)，不能默认现有终端字典覆盖所有位置。
- **表计坏数据：**电压坏点或量测偏置须另设变量/误差模型。若电压和功率同时受到任意协调篡改、且没有独立可信观测，则不承诺识别。

若增加馈线首端独立总表，可补充

\[
p_{0,t}^{m}-\mathbf1^\top p_t^m
=\mathbf1^\top u_t+\ell_t+p_t^{other}+\epsilon_{0,t}.
\]

\(\ell_t\) 是技术损耗，\(p_t^{other}\) 是合法但未包含在终端表计和中的功率。二者须已知、可估计或有可信界；自由未知的损耗项仍会吞掉漏计量。无功可建立对应约束。单个总表主要增加总量信息，不能自动完成逐户定位。

## 3. 先确认什么不能辨识

以下是理想模型中的反例，不依赖算法能力不足。

**阻抗与漏报的尺度混淆。** 对任意 \(c>1\)，

\[
R(cp^m)+X(cq^m)=(cR)p^m+(cX)q^m.
\]

左侧为真实阻抗与同比例漏报，右侧为放大阻抗与无漏报；二者都满足同一树的 wzzᵀ 结构。因此，仅增加样本数量不能区分这两种解释。可信阻抗、可信历史工况、适当的可信表计/已知注入或独立总表能提供额外锚点，但各自仍有适用条件。

**恒定漏计与截距混淆。** 在线性、固定 R/X 模型中，若每天 \(u_t\equiv u_0,v_t\equiv v_0\)，其电压贡献为日内常量，去均值后消失；自由节点截距也可完全吸收它。AC 下可能残留运行点依赖的高阶影响，但不能把微弱高阶信号当成可靠辨识保证。必须保留绝对数据，并约束或独立标定偏置。

**位置混淆。** 若两个位置 i、j 对所有可信传感器具有相同灵敏度列，则相同波形的负荷分别放在 i 或 j 产生相同观测。只能报告位置等价类或区域总量。相近的列虽未必完全相同，也会导致定位严重不稳定。

**有功、无功与其他误差混淆。** 每时段只有 n 个电压方程时，不能一般性恢复任意变化的 2n 个有功/无功漏计量。尤其 \(X=\rho R\) 时，只能看到 \(u+\rho v\)。未知功率因数、根电压误差、正常未计量负荷、拓扑错误和阻抗漂移都必须进入竞争解释。

**联合估计的混淆。** 同时放开拓扑、阻抗、漏计时，“错误树+漏计修正”可能与“正确树+无漏计”相容；漏计又可能污染 RNJ 的候选池。即使池内所有解都指向某用户，也不能排除池外另一棵树的无漏计解释。

稀疏惩罚、低残差和重复抽样稳定性可以帮助选择解释，但不会自动消除这些等价关系。

## 4. 两个可行的研究起点

### 4.1 已知/已校准灵敏度：先判断漏计负荷是否可观测

假设已有可信 R/X，漏计负荷满足已知共同 \(v_t=\kappa u_t,\kappa\ge0\)，则

\[
y_t=d_t-Rp_t^m-Xq_t^m=Au_t+B\gamma_t+\epsilon_t,
\quad A=R+\kappa X.
\]

若全部候选注入节点的电压可测、\(Z=[z_e]\) 满行秩且所有有效边权 \(a_e+\kappa b_e>0\)，则

\[
A=Z\operatorname{diag}(a_e+\kappa b_e)Z^\top\succ0.
\]

在无未知干扰的无噪声情形，\(u_t=A^{-1}y_t\) 唯一。这是 wzzᵀ 直接给出的条件性正面结果；不知道 R/X 或漏计功率因数时不能照搬。

更一般地，以 \(\Pi B=0\) 消去允许的干扰，设 \(\widetilde A=\Pi A\)。对允许漏计集合 \(\mathcal K\)，唯一辨识的条件为

\[
\ker(\widetilde A)\cap(\mathcal K-\mathcal K)=\{0\}.
\]

已知支持 S 时检查 \(\operatorname{rank}(\widetilde A_S)=|S|\)；未知 s 稀疏支持时，任意不超过 2s 列线性独立是充分条件。非负约束可能改善条件，但相同观测列依旧不可区分。

还须报告稳定性。定义

\[
\sigma_{\mathcal K}=\inf_{h\in\mathcal K-\mathcal K,\ h\ne0}\frac{\|\widetilde Ah\|_2}{\|h\|_2}.
\]

若两个解释的投影残差均不超过 \(\delta\)，且 \(\sigma_{\mathcal K}>0\)，它们的距离至多 \(2\delta/\sigma_{\mathcal K}\)。很小的值表示虽可能唯一，实际却无法精确定位。未知 R/X 的误差还须另行传播，不能只计算一个名义矩阵的条件数。

### 4.2 固定比例漏报：利用对称性恢复相对比例

这是本文推导的候选切入点，尚未实验，也未声称文献创新。假设：

- 报告与电压覆盖同一组节点，且没有额外未建模注入；
- \(p_t^{true}=D_gp_t^m\)，\(D_g=\operatorname{diag}(g_i)\)，增益 \(g_i>0\) 跨时间不变；
- 所有用户真实无功满足同一已知 \(q_t^{true}=\kappa p_t^{true}\)；
- 根电压/偏置已处理，功率量测误差暂忽略，处理后的报告功率矩阵满行秩。

于是

\[
d_t=M p_t^m,\quad M=AD_g,\quad A=R+\kappa X=A^\top.
\]

由 \(M_{ij}=A_{ij}g_j\)，在 \(A_{ij}>0\) 时有

\[
\boxed{\frac{M_{ij}}{M_{ji}}=\frac{g_j}{g_i}.}
\]

所以在由非零公共路径耦合组成的每个连通分量内，可以恢复相对漏报增益。每个分量有一个已知 \(g_i=1\) 的可信用户，就能固定该分量的绝对尺度，再得到 \(A=MD_g^{-1}\)。不同根支路可能互不耦合；一个可信用户不能锚定其他不连通分量。

手算例：\(A=\begin{bmatrix}3&1\\1&4\end{bmatrix}\)，\(g=(1,2)\)，则 \(M=\begin{bmatrix}3&2\\1&8\end{bmatrix}\)，\(M_{12}/M_{21}=2\)。无锚点时，\(A/2\) 与 \(2g\) 仍产生同一个 M。

若严格限制所有用户只能少报，即 \(g_i\ge1\)，将相对比例归一化为每分量最小值 1，得到 h，则 \(g=sh,s\ge1\)。此时 \(h_i>1\) 给出条件性下界 \(g_i\ge h_i>1\)；\(h_i=1\) 的节点是否少报仍不确定。若额外确信每个分量至少一户完全诚实，才可令 s=1。存在过报、未知电压增益或模型失配时，这些结论失效。

这一方向提示：应保留约束前的非对称回归诊断，或显式估计 \(A,D_g\)，不能先强制把 M 对称化再寻找增益信息。不对称本身也可能来自噪声、错时和模型误差，不是偷电证据。共同功率因数假设下只能先辨识组合 A，不能分开恢复 R 与 X。

## 5. 置信度与可信度如何同时覆盖拓扑和漏计

建议构造联合兼容集，而不只在选定的一棵树上计算误差条：

\[
\mathcal C_{\alpha}=\{(T,a,b,U,V,\eta,\text{量测/模型误差}):
\text{满足物理、先验和经校准的数据相容约束}\}.
\]

只有证明或在明确数据生成条件下校准了真实配置落入该集合的概率，才能称其具有 \(1-\alpha\) 覆盖率。没有这一步，应称“给定误差界下的兼容集”，不能直接写 95% 置信。

若 u 以 MW 表示、时间以小时表示，漏计电量为 \(E_i=\sum_tu_{it}\Delta t_t\) MWh；若沿用代码中的标幺功率，还须乘功率基值。对漏计电量报告

\[
\underline E_i=\inf_{\mathcal C_\alpha}E_i,\qquad
\overline E_i=\sup_{\mathcal C_\alpha}E_i.
\]

实际使用预先给定的最小实质漏计阈值 \(\tau_i\)，而不是把数值误差量级的正数当成告警。

| 联合分析结果 | 合理解释 |
|---|---|
| \(\underline E_i>\tau_i\) | 在声明的模型、误差与搜索域内，该节点必须有超过阈值的漏计量；原因仍待核查。 |
| 区间覆盖 0 或 \(\tau_i\) | 数据不能支持确定的逐户判断。 |
| 单户区间宽、某区域总量区间窄 | 可以定位区域，不能逐户归因。 |
| 多个拓扑均相容 | 报告共有 clade/边与未决结构，并传播它们对漏计定位的影响。 |
| 兼容集为空 | 模型、误差界或数据不相容，不等于发现了确定的偷电者。 |
| 没有可信上界锚点 | 某些漏计上界可能无穷；如实报告，不用正则化点估计代替可辨识区间。 |

这里应分开三个对象：

1. **统计置信度：**在明确假设下的区间覆盖、误报率、检出率；逐户多重筛查还要考虑多重比较。联合覆盖集的有效投影可保留其同时覆盖意义。
2. **可辨识性：**是否存在无漏计替代解释、位置等价类、受限最小奇异值、最小可检出量；多采样不一定改善结构性不可辨识。
3. **模型与证据可信度：**同步与表计质量、根/总表是否独立可信、损耗模型、对拓扑/阻抗/功率因数扰动的敏感性、候选覆盖和求解完整性。

bootstrap 可报告“重复抽样选择频率”，不自动等于偷电概率或拓扑正确概率。有限候选池上的权重只能解释为池内条件权重；若采用贝叶斯模型，应显式指定完整似然与先验，并区分后验可信区间和频率学覆盖率。不要将复用同一批数据的多个分数相乘。

计算方向也必须正确：要认证 \(\underline E_i>\tau_i\)，需要最小化问题超过阈值的可靠全局下界；局部可行解只提供上界。有限池删掉可行解释会抬高最小漏计量、压低最大漏计量，造成虚假确定性。相反，若找到一个完整满足假设的 \(E_i=0\) 解释，即已足以否定“该用户必须漏计”。限时或候选搜索不完整应明确标记。

## 6. 计算路线与最小验证计划

建议先做两个分层原型，再研究未知拓扑下的联合估计：

1. **已知 R/X + 已知漏计功率因数：**建立可辨识基线、残差字典、区间估计和“不足以定位”的输出。
2. **固定比例漏报 + 相对增益推导：**验证对称结构与可信锚点的价值，分别测试全体同比例漏报和部分用户不同比例漏报。
3. **拓扑/参数不确定：**让多个兼容树与阻抗区间进入诊断，逐步加入隐藏节点、时变漏计、无功不确定与总表；用 AC 数据生成，用线性模型估计，单独量化模型失配。

一般形式可考虑“物理残差损失 + 用户级组稀疏 + 时间变化惩罚”，但稀疏性和光滑性必须对应明确场景。固定 R/X 时可形成凸子问题；同时未知边权和漏计量时出现 \(a_eu_{it}\)、\(b_ev_{it}\) 双线性项，因此现有 L1-MILP 不能直接增加几个连续变量就获得同样的全局保证。交替优化只能先作为候选生成器；是否能认证要另行处理。

实验时将实际负荷、报告负荷、量测噪声分开保存；潮流由实际负荷生成，识别器只能使用被声明为可观测的量。验证集不能用真实漏计标签帮助选择告警阈值。训练、阈值校准、评估按时间块/独立场景划分；时间相关下普通随机拆分和逐点 bootstrap 不足以保证有效校准。

| 必须包含的实验 | 应检验的行为 |
|---|---|
| 已知参数、充分观测、变化漏计 | 在信号强度足够时恢复，报告区间和误差。 |
| 无漏计但有根电压误差、正常负荷变化、无功偏差、技术损耗 | 评估误报，不能只用理想正常样本。 |
| 同比例漏报与阻抗缩放 | 无锚点时保留尺度不确定，加入锚点后再比较。 |
| 日内恒定漏计 | 展示去均值/自由截距为何丢失信息，比较绝对量与总表约束。 |
| 隐藏位置灵敏度相同或接近 | 正确输出区域定位或不可辨识。 |
| 真拓扑缺失于 RNJ 池、错误冻结/收缩 | 不能因池内一致而给出全局高置信结论。 |
| 同时修改 P/Q/V 或传感器故障 | 检查可信观测边界与拒绝判断能力。 |

分别报告：拓扑 precision/recall；漏计检测 precision/recall、误报率和最小检出量；位置分辨率；漏计量误差；区间覆盖与宽度；无法判断比例；候选覆盖；总运行时间与搜索状态。仿真覆盖结果只适用于对应生成机制，不能直接声称现场概率已校准。

主动探测可作为后续补充：可信已知的 P/Q 扰动能帮助标定参数和增加独立激励，但在线性模型下对前后数据作差也会消去恒定隐藏负荷。不能声称“增加探测必能定位所有偷电”；必须同时检查实际量测配置和非线性可观测条件。

## 7. 初步文献定位与贡献边界

- **Gao, Foggo, Yu (2019), _A Physically Inspired Data-Driven Model for Electricity Theft Detection With Smart Meter Data_，DOI 10.1109/TII.2019.2898171。** 本次查看作者托管全文的摘要、框架及建模入口。论文已用表计用电量与电压之间的物理回归关系做异常排序，不要求完整网络参数。因此“使用电压和功率检测偷电”本身不是新贡献。[作者全文](https://intra.ece.ucr.edu/~nyu/papers/2019-Electricity-Theft)
- **Pengwah, Razzaghi, Andrew (2023), _Model-less non-technical loss detection using smart meter data_，IEEE TPWRD 38(5):3469–3479，DOI 10.1109/TPWRD.2023.3280551。** 本次核对作者所在大学的摘要和出版信息，未逐式审查全文。摘要介绍先估计电压灵敏度，再估计真实用电并比较报告值，是很直接的后续对照对象。[大学论文记录](https://research.monash.edu/en/publications/model-less-non-technical-loss-detection-using-smart-meter-data/)
- **Bhela, Kekatos, Veeramachaneni, _Smart Inverter Grid Probing for Learning Loads: Part I—Identifiability Analysis_，arXiv:1806.08834v2，2019。** 本次核对摘要与版本。其研究受控注入、电压观测与未计量负荷的可观测条件，适合后续设计补充量测；未将其条件直接移植到本笔记。[作者预印本](https://arxiv.org/abs/1806.08834v2)

有待进一步查新的贡献方向是：**树原子结构 + 拓扑/漏计的竞争解释 + 条件性辨识定理 + 校准区间/拒绝判断 + 最小补充量测选择**。需先核对相关论文的完整假设与定理，再判断相对增益推导和联合兼容集方案具有多少新增内容。

## 8. 下一步研究问题

优先回答：现有终端 P/Q/V 和根电压数据，在什么条件下足以识别漏报？缺少什么信息时，只能识别比例、区域或总量？最少补充哪一类可信观测，才能将“存在异常”升级为“能定位并估量”？

置信度设计应从这些可辨识边界出发，使模型在证据不足时扩大区间或不作逐户判断，而不是对每个样本都输出一个看似精确的偷电百分比。

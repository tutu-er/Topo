# 局部重构后续核查：F1 下降、RNJ 配合与同域对照

本轮完成了三项工作：解释旧四例的退化；明确 RNJ 与共同 R/X 拟合的接口；在相同候选域、参数界和接收门槛下比较单候选修正与联合重构。结论是：**确实存在单候选停滞、联合重构能纠正拓扑的例子，但 RNJ 起点上的额外收益仍有限。眼下更直接的改进是收缩后重拟合、再按实际输出验证选模。**

## 为什么训练拟合改善、原始 F1 却下降

旧四例中，原有正确集合均未丢失；合计新增 13 个内部集合，其中 **1 个正确、12 个错误**。F1 对每个错误支撑计一次，与其权重大小无关。

| 网络 | 起点 TP/FP/FN | 重构终点 TP/FP/FN |
|---|---:|---:|
| paper15 | 5 / 1 / 1 | 6 / 3 / 0 |
| soumalas11 | 4 / 1 / 0 | 4 / 4 / 0 |
| flynn16 | 5 / 1 / 1 | 5 / 6 / 1 |
| pengwah18 | 7 / 2 / 0 | 7 / 4 / 0 |

这组结果支持三个具体判断：

1. **原始训练 L1 没有惩罚额外连接。** 在完整层级候选中添加一条弱边，只要改善一点残差就可能获益。12 个新增错误集合中，9 个归一化深度低于原有 0.16 收缩阈值，另 3 个约为 0.183、0.226、0.227。提高阈值能清理一部分弱边，但不能把强度直接解释为真实性。
2. **上轮接收门槛不同。** 重构用了 `1e-10 + 1e-8 × 当前MAE`，原单候选修正用了 `1e-10 + 0.001 × 当前MAE`。前者允许非常小的训练改善；本轮统一为后者。上轮比较不能单独归因于联合选择能力。
3. **噪声和病态回归为弱边提供了拟合空间。** 48 个训练快照对应 22–36 列 P/Q，列标准化并去均值后的条件数约 316–1166，虽然都满列秩。观测与无噪声平方压降的 MAE 约为 `1.11e-3–1.14e-3`，是真层级对无噪声 AC 数据最佳线性拟合残差的约 42–176 倍。这些诊断与噪声驱动的微弱结构变化相符；病态性本身不证明某一条边错误。

训练损失与 F1 衡量不同对象。paper15 同时增加了真边和假边，独立预测误差反而下降；其他三例的原始测试 MAE 略升。不能把四例统一解释成“所有预测都变坏”。

四例最大响应系数仅 0.213–0.369，未触及上界 2，因此优先增大阻抗响应系数界缺少依据。

## 发现的选模顺序问题与参数试验

当前正式研究流程的 `finalize` 顺序是：**根据收缩前的验证 MAE 选模型 → 按 0.16 阈值删边 → 直接输出剩余权重**。这些权重是在完整家族中联合拟合的，删边后不再是剩余家族的最优权重；选模使用的预测也与最终输出不同。

隔离对照实现了：

> 每个候选先收缩 → 在训练数据上联合重拟合全部剩余 R/X 权重 → 计算实际输出的验证 MAE → 按原来的 3% 简洁规则选模。

验证集只用于比较模型，没有用于权重拟合。校准深度仍固定使用最初的训练前置 R/X，不随路径点重新校准。

保持 **0.16 收缩阈值和 3% 验证带宽** 不变，得到：

| 对照位置 | 原顺序 F1 | 新顺序 F1 | 原测试 MAE | 新测试 MAE |
|---|---:|---:|---:|---:|
| 旧 paper15，bundle 0，既有重构路径 | 0.8333 | 1.0000 | 0.00120998 | 0.00119095 |
| 本轮 pengwah18，bundle 1，第二个区域的单候选路径 | 0.8000 | 0.9333 | 0.00120146 | 0.00118118 |

前一行是事后诊断；后一行采用相同的固定顺序和参数，在本轮未用于旧四例诊断的重复上评价。后一行收益来自**单候选路径的选模修正**，联合重构没有增加这一收益。这里比较的是所列路径候选，并非重新评估整套正式 pipeline 的全部候选库。

旧四例还检查了验证带宽 `{0,1%,3%}`、收缩阈值 `{0.08,0.16,0.24}`，并保留全部结果。缩小验证带宽不保证 F1 上升：pengwah18 在 0% 带宽下选择预测稍好但 F1 较低的模型。阈值应由独立验证表现及所需分辨率决定，不能用这些已看过的真拓扑挑参数。

六个五终端小例还比较了连接数惩罚 `MAE + λ × 内部集合数`，`λ/初始MAE ∈ {0,0.001,0.005,0.01}`；六例均未改变最优家族。这组结果没有支持该小范围惩罚网格的收益。连接数惩罚也无法区分内部集合数相同的不同二叉层级。

## 目前技术流程，以及与 RNJ 的配合

当前研究入口为 [`wzzt_paper/pipeline.py`](../../research_experiments/wzzt_paper/pipeline.py)，调用 [`wzzt_fine/pipeline.py`](../../research_experiments/wzzt_fine/pipeline.py)、[`wzzt_retune/engine.py`](../../research_experiments/wzzt_retune/engine.py) 和 [`wzzt_refine/core.py`](../../research_experiments/wzzt_refine/core.py)。本轮原型位于 [`local_rebuild/`](../../research_experiments/local_rebuild/)。

1. **观测与目标。** 使用同步终端 P/Q/V 和已观测根电压，构造 `Y = V_root² − V_terminal²`。最终拟合为原始量测上的 `mean |Y − P Rᵀ − Q Xᵀ|`，无截距；本轮无隐藏注入。R/X 是吸收系数 2 的响应系数。
2. **前置 R/X。** 用具有对称、非负、对角序约束的最小二乘估计稠密 R/X。原始/去均值视图用于生成候选；稠密矩阵本身尚未满足共同树结构。
3. **RNJ/NJ 候选库。** 构造 R、X 和归一化 RX75 三种几何。其中 `K = 0.75 R/μ_R + 0.25 X/μ_X`，μ 为对应矩阵的正成对距离均值。两种视图、三种几何、五档分组阈值 `{0,0.04,0.08,0.16,0.24}`、NJ/RNJ 两种建树规则生成初始家族和并集池。RNJ 主搜索从 raw/RX75/0.16 开始；普通 RNJ 展示基线用 raw/RX75/0.24，二者用途不同。
4. **共同 R/X 的 L1 重拟合与修正。** RNJ 给出的是候选支撑和初值，原始 P/Q/Y 决定重新拟合的权重。单候选修正加入一个候选时删除与它交叉的暂时集合，再联合重拟合全部权重。既有流程有多初值，并以强度 0.001/0.01 的前置 ridge 回归扩充候选池；这些 ridge 参数用于造候选，并未改写最终原始 L1 目标。
5. **局部重构的位置。** 应接在已选原始家族后、最终收缩前。选择完整子树区域，打开到最多五个叶块；保留块内和外围结构，释放块之间的暂时集合。五块有 25 个内部候选；二元变量选择相容集合，`r,x ≤ 2a`，另加成对冲突与 A5/A6。所有保留集合和新集合的权重一起拟合。RNJ 暂时结论不自动成为物理硬先验；在一次局部试验中，外围/块内集合固定属于邻域定义。
6. **输出选模。** 新实现提供收缩后重拟合、重新验证的对照入口。正式 pipeline 默认顺序尚未切换。若错误合并仍封装在某个完整块内，本次局部优化仍无法拆它；需要打开对应层级，而不只是增加求解时间。

新数值入口为 [`normalized_solve`](../../research_experiments/local_rebuild/scaling_recheck.py)，返回原量纲的 `physical_point` 和 `physical_dual_bound`；`native` 保留缩放后求解器原始状态和审计。本轮已有 RNJ 管线没有被改为使用这个独立模块。

## 同域、同门槛的小规模对照

共同规则为：系数区间 `[0,2]`，相同支撑域和固定外围，权重均联合优化，接收必须满足 `gain > 1e-10 + 0.001 × 当前MAE`。单候选停止必须完成所有合法单步候选的扫描，超时不记为停滞。

### 五终端完整层级：6 个数据集、每个 236 个初始层级

固定三个种子、两档根/末端电压噪声 0.02%/0.1%，P/Q 噪声 0.5%；训练/验证/测试分别 12/64/128 点。使用共同 R/X 的 LinDistFlow 合成模型和随机完整二叉真层级，所有非空支撑都允许；支撑选择及见证选择只使用训练目标，不按 F1 筛例。

全部 **6/6** 数据集、**1416/1416** 起点完成。一个数据集的 50 个起点汇入同一个坏局部极小；其余五个数据集未出现这种停滞。首先按数据集顺序和训练停滞选中的见证是 `n5_seed2_v0.001`：

- 单候选终点内部支撑：`{0,1}`, `{3,4}`, `{2,3,4}`。
- 22 个替代候选全部重新拟合；最好单步的训练 gain 为 **−4.73573e-6**，也就是最好一步仍变差。这里是严格的单步局部极小，不依赖 0.1% 门槛制造停滞。
- 联合重构选中 `{0,3}`, `{2,4}`, `{0,1,3}`，与真层级一致。MILP 从该停滞点重解，并与全 236 层级的独立 LP 枚举一致。

| 指标 | 单候选停滞点 | 联合重构 |
|---|---:|---:|
| 训练 MAE | 0.001704923 | 0.001656467 |
| 验证 MAE | 0.003164959 | 0.002837046 |
| 测试 MAE | 0.002922413 | 0.002743643 |
| 内部支撑 F1 | 0 | 1 |

训练/验证/测试误差分别下降 2.84%/10.36%/6.12%。这证明了所问机制确实存在；50 个起点是一个数据集上的结构枚举，不是 50 次独立重复。

**从实际 RNJ 初值出发，六例中的单候选修正均已到达联合最优，联合重构没有额外改善。** 因而，本轮没有证明 RNJ 初始化之后经常需要这种联合逃逸。

### AC 数据：四网络 bundle 1、八个五块区域

每个网络使用 N=48、电压噪声 0.05%、P/Q 噪声 0.5%。起点取原流程按既有验证规则选中的**收缩前家族**。每网按“区域较大优先、再按字典序”选两个不同的五块区域，不按真簇或结果挑区域。各区域先将单候选修正运行到同一门槛下的停滞，再求整个相同邻域。

独立枚举 **8 × 236 = 1888** 个 LP，8/8 完成并有原始预测重算及 primal/dual 核验。找到 **2/8** 个超过共同门槛的联合改善：

| 区域 | 最好单步 gain | 接收门槛 | 联合 gain | 原始 F1：单步→联合 | 测试 MAE：单步→联合 |
|---|---:|---:|---:|---:|---:|
| flynn16，第二区域 | 8.45822e-7 | 9.45824e-7 | 1.17037e-6 | 0.7143 → 0.7500 | 0.00120119 → 0.00119765 |
| pengwah18，根区域 | 9.34421e-7 | 9.99024e-7 | 1.09217e-6 | 0.8000 → 0.7059 | 0.00120146 → 0.00119769 |

这两例属于**门槛停滞**：单步仍有正 gain，只是未超过门槛；多个小变化合起来越过门槛。它们与上面的严格单步局部极小应分开解释。一个提高了原始 F1，一个降低了原始 F1；两者独立预测均稍好。

保留原来的 3% 简洁规则后，这两个联合候选均未改变最终选中的输出，新增联合重构的部署收益为零。另一个 pengwah18 子区域的 F1 改善来自收缩后重拟合选模，已在前表单独归因。

## 数值核查与上一轮证书说法的修正

原量纲目标在 `1e-3` 附近时，当前 SciPy/HiGHS 运行环境出现了错误的 MILP 下界：初始 **4/8** 个下界高于同域内已独立核验的可行解；仅关闭 presolve 后仍有 **3/8**。可行解已嵌入完整 MILP，约束违约为约 `1e-17`，排除了“两个比较模型不一致”的解释。内部数值原因尚未定位到具体 HiGHS 算法分支。

因此，上一轮“32/48 满足严格最优性检查”应理解为通过了当时的**求解器 gap 报表检查**，不能继续把报表单独当作已独立核实的最优性证书。原始状态、失败和错误界均保留。

等价地把 P/Q/Y **同时乘 1000**、保持 R/X 系数界和支撑域不变，求解后将目标与界除回 1000，并关闭 presolve，得到：

- **8/8** MILP 状态正常、可行性审计通过并闭合 gap；无超时。
- **8/8** 与独立 236 层级 LP 枚举的最优值及 F1 一致；原量纲目标最大差约 `2.48e-15`。
- 新增“已知可行解嵌入”检查；若求解器下界高于这个经过核验的上界，撤销该次最优性标记。这个检查是必要核验，独立枚举进一步检查了比现有解更好的可行见证。

缩放改变的是求解器数值单位，不是物理系数、候选域或统计目标。这些结果支持本轮数值处理，不能外推为所有网络的求解可靠性保证。

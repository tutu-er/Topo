# 四网络一天96点的额外源项与AC数据

日期：2026-10-18。范围为 paper15、soumalas11、flynn16、pengwah18 的数据准备。此报告记录先行生成与独立核验的 AC 潮流；后续四法比较见[96点辨识实验](source_ac96_benchmark_20261018.md)。

## 数据与信息口径

每个网络生成一个完整24小时、15分钟间隔的96点负荷日，以及无源、常值源、间歇源、平滑时变源四个配对版本，共16个案例、1536个AC时刻。网络为项目自建低压合成网络；采用单相平衡等值径向 AC 后推前推潮流。

后续算法获得终端 P/Q/V、根电压观测和已知的额外 P/Q 时序，接入位置未知。额外源表示未计入终端分表的正负荷；它进入物理潮流，不加入终端 P/Q 观测。源位置、物理线路参数、隐藏节点电压和真实损耗仅保存在评价真值中。

采用 reference 物理配置：线路倍率1，根均值1.02 p.u.、背景波动尺度0.003 p.u.；P/Q相对量测噪声标准差0.5%，终端与根电压0.02%，总表P/Q为0.2%。采用 scenario_index=0、replicate=0 的固定随机路径，不根据算法恢复结果选数据。

同一网络四个版本复用终端真实负荷、根轨迹和标准化量测噪声。由于电压和总表噪声按瞬时幅值缩放，其绝对误差可随源项变化。原始AC真值与含噪量测均保存；不裁剪越限电压。

## 源项设计

记网络终端额定有功负荷之和为 D（kW），令 m=0.05D，t=0,...,95，theta=2*pi*t/96。三种有源版本的日有功电量均为24m kWh、日无功电量均为9.6m kvarh。5%是本轮预先规定的受控幅值，不代表现场源项统计分布。

| 版本 | P（kW） | Q（kvar） | 用途 |
|---|---|---|---|
| no_source | 0 | 0 | 配对基准 |
| constant | m | 0.4m | 全天持续额外负荷 |
| intermittent | 8:00–12:00及16:00–20:00为3m，其余0 | 0.4P | 同电量、较高峰值、间歇激励 |
| smooth | m(1-0.6cos(theta)) | P(0.4+0.15sin(theta)) | 平滑时变、P/Q两通道独立激励 |

接入点按预定规则选择：距根至少两条边的隐藏分叉节点中，下游终端额定有功负荷之和最大者；相同时按母线ID升序。无此候选才退到根的直接隐藏子节点。所有有源版本使用同一个接入点；本轮仅覆盖该固定位置，不据此评价任意位置的恢复能力。

constant与intermittent的源P/Q时序秩为1，直接源响应只能识别R/X响应的一个组合；smooth的秩为2。保存输入设计的秩和条件数，供后续解释辨识难度。

### 使用入口

数据根目录为 `outputs/source_ac96_20261018/`，每个案例目录布局如下：

```text
<case>/network/                   网架和线路参数，仅仿真评价使用
<case>/<variant>/observed/        终端P/Q/V、根电压、平方电压降、总表P/Q
<case>/<variant>/source/          已知的额外P/Q时序，无接入母线
<case>/<variant>/truth/           物理负荷、源接入点、真实根电压及损耗
<case>/<variant>/truth/ac/        全节点电压幅值/相角、支路电流与首末端P/Q/损耗
```

算法只需以下加载器，返回的根电压模式保留为noisy，避免后续误当准确根量测：

```python
from research_experiments.rnj.prepare_source_ac96 import load_algorithm_inputs
scenarios, source_inputs = load_algorithm_inputs(
    "outputs/source_ac96_20261018/paper15/smooth"
)
```

功率采用网络base_mva的标幺值；源表额外提供kW/kvar两列。电压幅值与电流均为标幺值，相角为度。支路首末端功率都按远离根的方向记号，损耗为首端减末端。

复现命令（已有数据目录受保护；重跑应使用新的输出目录）：

```powershell
& D:/apps/miniconda3/envs/Topo/python.exe -B -m research_experiments.rnj.prepare_source_ac96 --output-dir outputs/source_ac96_new
```

独立审查1380项全部通过，逐文件复核624个数据文件与38个源码文件的SHA256。最大复数支路电压式残差为6.67e-16 p.u.；最大非根节点复功率平衡残差为1.03e-11 p.u.；最大馈线总复功率平衡残差为2.43e-11 p.u.。原有源场景测试17项通过，新增独立核验与篡改检测测试6项通过。

# 65037 馈线窃电算例：效果评估与改进顺序

日期：2026-09-20。对象为已有“已知参考点电压”实验；本轮仅重放、分组与误差分解，没有新增拟合、调参或独立测试样本。

## 1. 总体判断

**当前最有支撑的结果是：可信正常历史提供按相 wzzᵀ 模型后，在已有 z 上做离散位置选择，可以较稳定地筛查窃电区域。完整的拓扑—阻抗—窃电联合重估，尚未证明普遍提高准确度。**

两点必须分开：一是区域筛查确有积极结果；二是定位正确不等于检测已校准、物理母线唯一确定或全部线路参数恢复准确。主要困难已经可以具体定位到弱支路参数、位置相关的线损偏差和联合整数求解未完成，单纯再增加同类随机种子不能解决这些问题。

## 2. 实验究竟覆盖了什么

- 数据为公开 65037 馈线参数：53 母线、52 支路、14 个有功率记录的电表节点。真实的是网络及负荷快照来源；负荷时序和窃电标签均由仿真生成，没有现场窃电记录。
- 固定 z 评估使用两个正常历史模型；平衡/不平衡、母线5/10、持续/间歇四个维度组合。每组20个新测试种子、每窗口64点，总计320次评估。实际是160个工况窗口分别交给两个历史模型，并且不同工况复用了配对种子，不能作为320个独立同分布试验计算常规置信区间。
- 每窗口仅一个固定窃电位置，三相均分，已知 Q/P=0.4。持续幅值15 kW；间歇幅值30 kW、半窗口发生。分别约为原始260.925 kW净负荷的5.75%和11.50%，尚非小幅窃电试验。
- 两个测试位置的真实约化支撑均已在候选池内；尚未验证候选遗漏。53节点网络不等于已验证53个窃电位置。
- 正常历史被假定可信，网络参数在训练与测试之间不漂移。这一条件有利于冻结历史参数，不能推及历史受污染或线路漂移情形。
- 参考点电压逐时已知；使用原始绝对压降，没有减均值或自由截距。持续窃电可得到正确结果，但没有“保留参考/未知参考”的配对消融，不能单独量化该设定带来的增益。

完整数据解释和物理假设见同目录 `theft_real_feeder_known_reference_20260920.md`；包括两处缺失负荷设零、长度单位及接地方式假设。

## 3. 定位：区域筛查较好，但精确唯一性有薄弱点

### 3.1 固定历史参数、选择已有 z 的结果

|工况|唯一选对约化区域|最小目标集合包含真值（允许并列）|前三候选包含真值|
|---|---:|---:|---:|
|平衡|160/160，100%|160/160|160/160|
|不平衡|120/160，75%|157/160|160/160|
|合计|280/320，87.5%|317/320，99.06%|320/320|

位置决策为 one-hot 整数选择。固定参数时，逐个计算候选代价并取最小值，等价于精确求解该有限集合上的整数选择；没有采用连续位置混合。所选 z 标识下游电表组成的约化区域，并不天然对应唯一物理母线。

**40次未能唯一选对全部集中在“历史模型0 + 不平衡 + 母线5”**：其中37次为包含真区域的并列最优，另3次真区域未进入最小目标集合、但仍进入前三。其他280次全部唯一选对。3次非覆盖均为持续窃电。

这说明当前失败并非所有位置随机失效，而与特定历史参数估计和相邻区域的微弱差异有关。前三候选覆盖率是固定长度排名指标，既不是95%置信域，也不是窃电检测率；候选还是区域，不是三个物理母线。

### 3.2 为什么母线5困难

历史模型0在不平衡数据上，将通往39号电表的相序电阻、电抗同时估为0，仅保留中性线相关项。三相均分的窃电增量没有中性线电流，于是 `{39}` 与 `{39,41,42}` 两个候选区域的模型窃电响应相同。这里的并列来自**估计参数导致的响应退化**，不能解释为真实线路没有阻抗或物理上必然不可辨识。

历史模型1在这一工况下虽能唯一选对，分离程度仍很弱。将排名第一与第二的平均绝对平方电压代价差按230 V一阶换算，唯一正确窗口的中位差值为：

|位置/工况|持续窃电|间歇窃电|
|---|---:|---:|
|母线5，平衡|0.001827 V|0.002664 V|
|母线5，不平衡|0.000030 V|0.000064 V|
|母线10，不平衡|0.003548 V|0.004968 V|

母线5不平衡一行只统计唯一正确的历史模型1。该数值是**聚合拟合目标的差值**，不是两个物理电压轨迹之差，也不能直接与单次噪声标准差比较后宣称统计显著或不可分辨。它说明“数值上唯一”对模型扰动的稳健性仍需验证。

独立的真值 AC 诊断则显示：在85%原始负荷、15 kW窃电下，母线5与39的最大相电压差约0.0486 V、均方根差约0.0119 V；单次电压噪声标准差约0.046 V。多时刻信息可能提高分辨率，但系统模型偏差不会随样本数简单消失。

## 4. 幅值：绝对误差不大，但有可解释的系统偏差

### 4.1 必须区分整窗误差与窃电发生期间误差

以下均对两个历史模型、各20个测试窗口取平均，单位kW。

|工况/位置|持续15 kW：MAE|间歇30 kW：整窗MAE|间歇：发生期间MAE|间歇：停窃期间平均估计值|
|---|---:|---:|---:|---:|
|平衡/母线5|0.612|0.581|0.920|0.242|
|平衡/母线10|0.516|0.392|0.542|0.242|
|不平衡/母线5|0.724|0.713|1.157|0.268|
|不平衡/母线10|0.586|0.440|0.612|0.268|

持续窃电MAE约为真值的3.44%–4.82%；间歇窃电发生期间约1.81%–3.86%。不能将整窗MAE直接除以30 kW作为发生期间相对误差，因为半个窗口实际没有窃电。

### 4.2 误差主要从哪里来

令未截断估计为 `a_raw = P0_meas − ΣP_meas − loss_hat`，最终幅值 `a_hat = max(a_raw, 0)`。在仅用于评估的真值通道下，可以逐时精确分解：

`a_hat − a_true = (loss_true − loss_hat) + (P0_meas − ΣP_meas − a_true − loss_true) + (a_hat − a_raw)`。

三项分别为线损低估、表计平衡误差、非负截断引入的偏移。本轮320次重放中，该恒等式最大残差为3.55×10⁻¹⁵ kW；真实线损没有参与幅值估计或位置选择。

持续窃电下：

|工况/位置|平均幅值有符号误差|平均线损低估|平均表计平衡误差|
|---|---:|---:|---:|
|平衡/母线5|+0.406|+0.399|+0.0065|
|不平衡/母线5|+0.520|+0.513|+0.0070|
|平衡/母线10|−0.0039|−0.0104|+0.0065|
|不平衡/母线10|−0.0271|−0.0341|+0.0070|

所以母线5的系统高估主要对应线损估计不足，而母线10基本无系统偏差。这一分解证明的是净线损估计误差占主要贡献，尚未把其中的“窃电新增损耗、参数误差、基线线损近似误差”完全分离。

间歇场景停窃时仍有0.242–0.268 kW平均非负估计，其中非负截断会产生正偏移。因此“幅值大于零”不能直接用作窃电告警。此前单个不平衡null窗口从标量版约14.49 kW降至按相版约0.223 kW，是重要的混淆修正例证；它是组合改进前后的个例，不是纯线损因素的独立消融或已校准误报率。

## 5. 联合重估：有正例，但当前主要受求解和可辨识性限制

### 5.1 不能用43/76描述含窃电联合模型的求解成功率

重新逐个检查V3检查点后的计数为：

|子问题类别|数量|求得最优|未完成|
|---|---:|---:|---:|
|正常历史拟合|4|4|0|
|当前窗口忽略窃电的H0模型|36|36|0|
|无窃电窗口上的H1模型|12|3|9|
|真实有窃电窗口上的H1模型|24|0|24|
|总计|76|43|33|

因此43个已完成最优解中，40个来自历史或H0拟合；真正含窃电的24个H1候选树子问题全部达到时限。它们返回的可行解经过校验，但没有最优性保证。8个窃电场景中所选解只有2个定位正确，不能据此将25%归因于联合模型本身的统计性能。

更直接的证据是：8个原窗口中有4个，固定历史参数并选择已有z即可构造一个比联合求解器当前解目标更好的可行点。这明确表明至少部分错误包含求解不足。另一方面，即使将来完全求解，增加R/X自由度仍可能吸收窃电信号；目前还不能排除这个建模层面的问题。

### 5.2 哪个正面例证确实成立

V1平衡间歇工况的相关MILP全部求解完成：两阶段定位到邻近错误区域，联合方法选对区域；独立正常验证集上的电压MAE由0.0352降至0.0242 V，约下降31%。这证明联合解释**可以**纠正某些偏差，但只有一个种子，且同版本持续窃电仍定位错误。

V3两阶段与联合大多选择相同树，尚未形成稳定优势证据。V1与V3同时改变相别建模、历史利用、线损、搜索及正则，且电压指标口径不同，不能把跨版本差异归因于某一因素。

### 5.3 电压拟合好不等于全部阻抗准确

V3平衡正常验证的相电压MAE约0.039 V，不平衡约0.084–0.092 V。但一个平衡历史模型的原始R矩阵相对误差约265%，按独立激励加权的响应误差约1.6%。51号电表平均仅54 W、标准差约11 W，其对应列贡献约99.7%的R矩阵平方误差。

这不是可以删除的异常值：它提示弱激励参数并未可靠辨识，而常见工况的预测仍可能准确。论文应同时报告物理参数误差、预测误差和激励强度，避免用预测表现代替线路恢复结论。

## 6. 更合理的主线和改进顺序

目前适合作为已验证主线的执行逻辑是：

**可信正常历史 → 按相共享z的wzzᵀ辨识 → 相线/中性线线损校准 → 总分表差估幅值 → 枚举已有z的one-hot选择 → 输出并列区域和排名。**

完整联合重估作为增强分支。暂未校准告警时，应把输出明确标为“给定存在窃电条件下的区域排序”。建议按下面顺序补齐证据：

1. **先修复联合求解比较。** 将冻结历史参数的最佳位置构造成初始可行解；由正常数据约束R/X可辨识范围、收紧有效big-M。至少保证最终返回解不劣于已知可行基线，并分别报告每个候选子问题的上下界与缺口。需要据数据论证参数界，不能用真实线路答案收紧。若比较简化实现，可逐个固定离散位置再重估连续参数，最终仍从已有z中选择；不把位置放宽成连续混合。
2. **处理母线5的弱支路与排序脆弱性。** 通过重采样正常历史及参数可辨识区间评估排名稳定性；不能仅靠人为正下界强行打破并列。对于数据不能分开的区域，明确输出合并区域或不确定集合。集合覆盖需要独立校准，不能将前三候选包装成置信域。
3. **把幅值误差与告警分开闭合。** 用估计位置和估计幅值计算窃电增加的线损，做有边界的校正并检查收敛及排序变化；全过程不使用真值通道。对于新三相目标重新校准H0/H1统计量，在独立null窗口评估误报。旧q95≈5.455不能直接移植。
4. **增加有诊断价值的工况，而不是只重复现有种子。** 扩展到其他根出线、近根/远端/弱激励位置和候选遗漏；增加1–5 kW、单相、未知功率因数、正常历史受污染、线路漂移。对照时保持样本、噪声、候选和预算一致，分别消融按相模型、线损、参考电压和参数冻结。再加入至少另一馈线，验证结论是否局限于此网。
5. **最后验证多点窃电。** 使用已有z的多重离散选择及幅值分配，专门测试相邻/远隔位置、同形/异形时序；通过独立验证控制增加自由度带来的假定位。当前单点结果不能作为多点成功证据。

以上为后续改进建议，本轮没有执行新的联合拟合、位置校正或校准实验。

## 7. 论文能写什么，不能写什么

可以有证据地写：已知参考电压下，三相共享拓扑支撑的wzzᵀ模型结合已有z的离散选择，在公开真实馈线参数生成的受控AC算例中实现较好的单源区域筛查；进一步诊断了线损、弱支路和求解证书对结果解释的影响。

目前不足以写：实测窃电检测准确率高、误报率受控、联合重构普遍更准、全部线路阻抗准确恢复、所有物理节点唯一定位、多点窃电已验证或优于现有文献算法。

若论文主张是“区域筛查方法与可辨识性/计算边界”，当前结果可以组成有价值的主体案例；若主张是“联合重构显著提升广泛真实窃电辨识”，还缺公平且充分求解的对照、多工况扩展、独立检测校准及跨馈线验证。关键缺口是证据结构，不是结果表数量。

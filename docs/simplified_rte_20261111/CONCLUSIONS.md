# 简化RTE：结构、实现与四输入核验

已实现隔离研究版，原方案和生产默认完整保留。搜索层采用一个共同线路数系数alpha=.003；bmax=5限制末端枚举的子树块数。没有依据本批F1重新调参。

## 算法结构

1. R只提供RNJ/NJ候选连接和热启动。初值为单点/全集基底，不再固定两个小种子，不做三终端大小筛选或删除损失排名。
2. W保持原始未知支持的单连接扩展，联合拟合全部权重；达到最大直属块数≤5时结束前向。每个提议先QP重拟合、允许范围内清零，再验收。
3. T枚举当前各父节点全部宽度≤5的完整子树切分，汇总其非平凡真并，在共同MIQP中联合重构一次。旧支持若可由这些切分打开则可退出，其余骨架暂时固定。候选连接本身可以包含超过5个终端。
4. E复用同一重构内核，在RNJ候选、自身路径、T候选和全部终端对的并集上联合选择一次；所有临时内部连接包括大块均可退出。仅基底与物理硬先验必选，本批无硬先验。T/E后均不重新启动W。

各阶段共同最小化训练MSE与线路数：J=K*MSE+alpha*f0_MAE*k，等价于MSE/f0_MSE+alpha*k。候选经过QP及允许的零清理闭合后，仅要求J超过数值容差严格下降。取消独立相对改善门槛、纯MSE接收分支、近邻修复窗和输出.24收缩。最终按原有严格验证MAE比较原始自身路径及单点基线，另记录同库MSE视图；没有完整RNJ整树最终备用。

RNJ历史几何、75/25及其前处理.16选择仍沿用，响应界[0,2]、数值容差和求解精度也继续披露。因此“一个统计正则参数”指新增搜索层，并不表示全流程无参数。取消后收缩是独立模型设计变化，不与计数正则数学等价。

数学定义及每项设置见MODEL.md、PARAMETERS.json。源码核心与运行驱动分别提交为b3b674e0、22d7b34f；历史实现未覆盖。

## 小型独立验证

8项合成核验全部通过，最终源码对应记录见toy_verification.json。包括三叶交叉块纠错、四叶全部26个laminar支持族的独立有界最小二乘对照、纯删块MSE上升而J下降、先清零再比较候选、硬先验/基底保护、全部有界切面及旧解恢复、完整W/T/E流程。最终一轮耗时2.29秒，13次固定族QP。

纯删块缩小同界拟合空间，最佳训练MSE不可能下降；共同J允许用少一条连接补偿小幅拟合代价。因此本版的非零块退出不再依赖额外的后收缩门槛。

### pengwah18负例定位

独立事后检查见pengwah_diagnostic.json。漏掉的真实支持为内部索引{2,3,4}，即终端标签{303,304,305}。它存在于父common.pool、旧T候选及旧E池，却不在本版由initial与实际热启动族导出的R域，也未由本次W路径或T候选补回。新版E只有全部终端对作为通用补充，仍缺这个三终端连接；所有自身路径点都未包含完整真树。

这不是E新增错误连接：本例T后为4FP+3FN，E将其修到1FP+1FN，最终保留的错误二终端细分{303,304}已由T引入。最终验证MAE与同库MSE都选同一个E端点，未发生同库验证错选。

只用于诊断的真实支持族经一次独立SciPy有界最小二乘拟合，得到J=0.001185813194681，低于最终错误族J=0.001189931150488，验证MAE/MSE也更好。该oracle没有进入候选库、参数选择或最终输出。因此本例首先是候选域覆盖损失，不能解释为当前数据缺少区分信息，或训练J天然偏爱错误树。

父公共池来自更广的历史RNJ/NJ、预处理及正则几何组合；本版为了缩减候选来源，没有把整个池作为实际搜索域。减少验收超参数与收窄候选来源是两项不同改动。本例揭示后者的代价：在当前冻结E域内，仅调整计数惩罚无法选到一个不存在的连接。后续若评价简化结构，应单独固定候选域做对照，区分取消种子/门槛/后收缩与缩减候选来源的影响；本轮未据此负例补候选或继续调参。

新4/4与旧4/4均独立核验通过，失败、无效及未完成均为0。新24个结构MIQP均status2，相对gap最大6.76723e-5，0超时；4个最终选择族通过独立SciPy有界最小二乘核验，原始预测、训练目标、层级约束、共同J单调性、严格验证选模和源码/数据哈希均通过。

## 预算与解释边界

每输入名义总上限14400秒，四输入合计16方法小时；W单次上限3600秒，固定QP上限300秒，输出预留600秒，剩余结构预算前半供W/T，后半及未用余量供E。实际累计方法时间1217.979988秒，其中新运行1167.282197秒、复用公共预处理记账50.697791秒；四路并行批次墙钟422.604001秒。

旧累计时间3422.510872秒直接来自归档。新旧共用相同历史预处理成本，但初始化、T邻域、验收、输出映射和历史执行负载同时不同。因此这里只报告累计成本，不能将差额解释为单个模块的独立提速，也不是新鲜同机同预算复跑的全面比较。

本轮不扩大到48或120输入，不增加新阈值补偿负例。保持原版作对照，后续若要评价替换主线，应在更多冻结输入上检验F1、完整恢复和耗时。有限T/E域及本批求解gap不构成全网络最优或拓扑唯一可识别性证明。

完整逐输入、求解器、阶段及计时数据随本目录保存；records.zip的哈希、成员与CRC核验见archive_receipt.json、manifest.json。大父归档通过parent_reference.json引用，未嵌套复制原始观测数组或许可文件。

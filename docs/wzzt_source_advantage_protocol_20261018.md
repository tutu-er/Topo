# WZZT有源优势的机制检验（预先固定的探索方案）

本方案在看到pengwah18无源路径“先达到F1=1、随后多加8个伪簇”的诊断后制定。它是针对一个机制的探索，不是对WZZT普遍优越性的确认。既有pengwah18四源型、16项冻结运行继续保留，不改其数据、参数、最后认证点或失败记录。

## 要检验的机制

NJ/RNJ基线已经取得准确源P/Q，用FWL投影消去自由终端源响应；它们没有忽略源。WZZT额外要求两通道响应由同一树、同一阻抗与同一非空源路径产生。在正常负荷辨识较弱、额外源独立波动且模型适用时，这一约束可能提供FWL没有使用的结构信息。

采用项目原始soumalas11网络，不改支路阻抗。源接隐藏母线5，位于相对较弱支路3→5下游；受该段源电流直接影响的末端簇为[106,107,108]。这一位置只用于物理仿真和事后评价，不交给估计器。源接点下方的内部结构不因一个共同源自动可辨。

## 数据（在新算例任何拟合前固定）

- 配对无源与`rank2_source`，共用背景P/Q、根电压及量测噪声抽样。
- replicate固定0、1、2；每个replicate使用reference场景0、1、2，各96点；全部288点拟合，不划验证集或测试集。
- P/Q量测相对噪声0.005；末端及根电压相对噪声0.001；主表P/Q噪声0.002。结论限定该电压噪声压力条件。
- 源平均P为全部终端名牌Pd之和的25%。令`a=2πt/96`：
  `P=meanP*(1+0.65*sin(7a)+0.20*cos(13a))`；
  `Q=0.35*meanP*(1+0.70*cos(11a+0.4))`。
  曲线非负、P/Q不成比例，每场景重复相同曲线、同一物理位置。
- 源均值约19.1kW，相当于该局部簇名牌负荷的约90%；这是较强额外消费的明确压力设置。保存峰值、能量、电压范围、AC收敛与完整潮流，检查强源带来的AC与线性响应失配。
- 不根据F1改变源幅值、位置、噪声、seed或末端簇阈值。保留所有18个物理场景及24项方法结果的分母，包括失败和超时。

## 方法与短边尺度

四方法仍为NJ、RNJ、WZZT、RNJ+WZZT。使用与AC288相同的冻结Source/terminal-group核心、RX75、同簇阈值、bootstrap与严格细分否决、系数界与扩界、剪枝、接受条件、6000秒单次/30000秒方法预算。

主记录继续保留原来的最后认证路径点。用户已明确选择沿用既有RX75短边尺度，不引入新的复杂度惩罚选模。对同一工况的FWL有序回归矩阵，按正终端对距离的均值定义`a=0.75/mean(dR>0)`、`b=0.25/mean(dX>0)`，固定`tau=0.16*median(diag(aR+bX))`。四种方法与整条路径共用这个校准，禁止按真值或最终WZZT矩阵调尺度。它是归一化图分辨率，并非单位为欧姆的物理线路下界。

先对原结果单列固定尺度的短边收缩：叶单例保留，内部支撑达到`a*r+b*x>=tau`才计为有效边；使用并记录固定1e-10归一化边权数值容差。收缩后重新拟合全部R/X及未知Source路径，若重拟合出现新的短内边则再次收缩并重拟合，直到稳定。原模型及分数保持完整，不以删簇而不重拟合的方式交付一个自相矛盾的模型。等于阈值按下界语义视为有效；旧NJ收缩使用小于等于边界，此处明确这一仅在等号处的约定差异，不借此更改实际阈值。

另在隔离的新模型中，把旧内部原子约束为“零，或`a*r+b*x>=tau`”，新内部原子必须达到`tau`。扩展搜索直接在这个域内比较，再使用原严格增益和primal/dual条件停止；不采用“无约束最优新增边较短就立刻停止”的替代规则，因为它可能漏掉其他达到分辨率且仍改善的候选。叶边不按隐藏内边的图收缩阈值处理。源h仍覆盖全部当前原子并保持祖先/互斥条件；零权祖先可对应已收缩节点，不把h错误绑定到边激活变量而阻断有效源路径。证书范围仍是当前有界单原子扩展域，整条路径仍是贪心搜索。

## RNJ初值必须核实的内容

逐工况检查bootstrap高频候选、细分否决、最终selected、标签到原始终端索引、实际initial_supports、requested terminal_groups、完整partition与每步组内不拆分。事后独立检查selected是否为真实完整直接终端子组，不把高频或独立RNJ的F1当作该条件的证明。

若selected为空，明确标为联合方法退化，不能声称RNJ已经提供有效非平凡初值。不从真值补簇，不为使初值非空而降低阈值。普通高置信初始支撑与不可分末端原子组是两个不同用途；若另改这一策略，必须作为新variant并保留本方案原结果。

## 优势的验收与解释

逐次报告family/active拓扑F1、R/X响应矩阵误差、拟合误差、时间、初值及停止原因。主要查看3次有源配对中WZZT/联合方法相对NJ、RNJ的F1差；至少2次胜、平均差为正且没有删失失败，才称在该压力设置下观察到拓扑优势。另报告无源→有源各方法的变化，区分源结构信息与一般结构正则化的收益。

若只有R/X改善，需明确NJ/RNJ原始指标来自树推断前回归矩阵；必要时增加“固定NJ/RNJ树、按相同Source/L1目标重拟合”的控制，不能把不同后处理的差异全部归给拓扑搜索。RX75收缩后重拟合与搜索中加入阈值的结果须分开，后处理不能冒充已执行的在线停止。若没有达到上述条件，直接报告未找到支持该机制的结果，保留不利重复，再据证据制定下一轮。

# RNJ/WZZT 的平方误差对照模型

本实验只替换历史训练损失。原生L1批次、物理网络、观测、参数界、层级约束和最终MAE验证合同保留；不加入ridge、正阻抗下界或新的结构恢复规则。

## 1. 线性提升后可用凸MIQP

原始单连接预测含有 r*z_i*z_j 和 x*z_i*z_j。现有WZZT先引入 y_ij=z_i*z_j，再引入 u_ij=r*y_ij。二元z、非负有界r及线性包络约束使这些等式在整数可行解上精确成立；预测因而对提升后的变量是仿射函数。

记全部观测展平为向量y，预测为A*v+b，m为节点数乘时点数。数据内部乘S=1000，已有绝对残差上图变量满足

\[
e_j\ge S(y_j-\widehat y_j),\qquad
e_j\ge-S(y_j-\widehat y_j),\qquad e_j\ge0.
\]

清除原e的线性目标，使用非负对角平方目标即可精确得到平方损失：最优时e_j=S|y_j-yhat_j|。连续目标的Hessian半正定，约束仍为线性，故结构搜索为凸MIQP；固定结构时是凸QP。整数支持搜索仍需分支定界，其证书只覆盖声明的有限权重/候选域。

固定家族特征矩阵F给出同一个连续问题：

\[
\min_{0\le\theta\le2}\frac1m\|F\theta-y\|_2^2.
\]

F可能秩亏，最优参数未必唯一；独立核查以目标、预测和KKT条件为准，不要求不同求解器返回相同系数。

## 2. 保持参考尺度一致

令f01为已冻结公共RNJ参考家族的最佳训练MAE，f02为同一家族重新QP拟合的最佳训练MSE，取K=f01/f02>0。f02不是f01平方，也不从测试数据估计。K在一个输入的搜索全过程中固定。

原始与平方误差内部目标分别为

\[
J_1=L_1+\alpha f_{01}k(F),\qquad
J_2=K L_2+\alpha f_{01}k(F),
\]

其中L1=MAE，L2=MSE，k(F)为内部连接计数。两者分别除以f01后为MAE/f01+alpha*k和MSE/f02+alpha*k，保持每条连接相对于公共参考误差的惩罚比例。

对应原生目标为

\[
\boxed{\frac{K}{mS}\sum_j e_j^2+S\alpha f_{01}\sum_C a_C.}
\]

因此原生ObjVal/S仍为内部目标，而不是物理MAE。固定keep块的计数成本继续是常数。若参考误差退化到零，归一化不成立，必须显式报告，不能静默更换尺度或利用真值补标定。

## 3. 全链条采用同一训练损失

WZZT扩展、T、E、固定家族闭合、种子删除分数和清零后的重拟合均使用K*MSE。所有热启动家族也重新QP拟合，不能把旧MAE点的objective直接传给新判据；原参数若作为可行起点使用，须重新计算平方目标。

接收条件仍为

\[
J_{\rm old}-J_{\rm new}>10^{-10}+0.001L_{\rm old},
\]

但J和L均为新的内部尺度。这保持相对于f01的数值容差比例，不代表MAE与MSE具有相同的统计误选率。清零系数阈值1e-9沿用，因为r/x单位未改变；删除后必须以QP重拟合并检查内部训练损失不增加。

本对照的RNJ几何、候选池及初始完整家族相同。种子筛选原本依赖删除后的训练损失；替换成平方损失后，预选小块的排名也可能变化。因此对照是整条训练损失链的替换，不宣称已把“种子变化”与“后续WZZT变化”单独分离。

## 4. 验证与DR合同

主输出继续对每个保存路径点进行.24收缩，随后按该方法的训练损失重新拟合，再按严格验证MAE择优。L2组的闭合必须为QP，不能最后回到MAE-LP。

另外在同一批已拟合输出点上计算验证MSE视图，仅改变择优分数，不新增拟合或搜索。主视图保持MAE，因此后续冻结模型DR的绝对值评分合同仍可沿用；若把DR评分也改成MSE，原绝对值概率内核必须另行推导。

候选导出保存实际R/X与历史数据来源，导出副本的objective字段若用于旧MAE接口，应明确写物理MAE，同时另存原始内部目标、MSE和K。导出不能改变原生拟合权重。

## 5. 核查和最小实验矩阵

新组为noT与T003两个结构，每个使用相同48输入，共96次新配置；父L1对应96条结果仅复用已核验字节。完整比较为两种损失乘两种结构乘48输入。试运行四网络、bundle1000、sigma=.0005，为8次新MIQP配置；它不是完整96分母。

48输入包含四个跨网络共享的随机种子块和三档配对噪声。统计区间按四个种子块重采样，不能把16个case-bundle历史当成独立随机流。

独立后分析用NumPy从支持与系数重建预测，重新计算MAE、MSE、SSE和内部K*MSE；用SciPy有界最小二乘核验唯一家族的QP。设f(theta)=MSE，g=gradient f，则对任意可行theta，

\[
f_*\ge f(\theta)+\sum_i\min\{g_i(0-\theta_i),g_i(2-\theta_i)\}.
\]

这个盒上支撑平面下界与可行上界给出独立目标差检查，配合KKT和可行性核验，不调用旧L1-LP判据。冷参考QP、热启动QP及最终输出家族均分别核验。求解时限、失败、未完成和上下界保留原计划分母。

MSE对大残差的权重更高；测量输入误差、公共根表相关误差和AC线性偏差仍然存在。目标是检验实际拓扑收益，不将平方误差直接解释为正确的完整物理似然。

## 6. 独立分析的保存口径

`analyze.py`不导入原生优化器。每个输入的保存核查记录列出观察数据、公共预处理、原生结果、父分析和源文件的SHA链。新MIQP原生计划分母固定96，另复用父L1的noT/T003共96条结果；MAE与MSE验证视图属于同一拟合结果的两种输出，不重复计为求解。

`per_model.csv`保存主MAE视图；`view_inputs.csv`同时保存两种验证视图；`paired_summary.csv`只比较配对已核验输入，并报告配对数量。完整恢复率同时保留计划分母与已完成分母。四网络单种子试运行只覆盖8次新配置，完整标记保持false，重采样区间暂不输出。

固定家族QP核查容差在执行前固定为内部目标绝对差2e-8加参考目标的2e-5倍。记录独立有界最小二乘上界、支撑平面下界、目标差、秩和KKT残差，允许秩亏情况下的不同最优系数。`solver.csv`保留每次原生结构求解的incumbent、bound、状态及gap；`mechanisms.csv`分别统计T调用/接收、E接收、零块释放及直接保存的阶段时间。

总耗时采用成功返回的算法时间，公共预处理在每个逻辑方法中计入一次。父L1基础设施中断的已记账时间单列为operational time；它不会改写该方法的预测或成功返回耗时。

# 96点平方误差MIQP对照

2026-11-11，按用户要求检验“误差平方和替代原L1目标”。原L1实验、冻结源和结果继续保留；本轮单独实现与归档。

固定数据为父实验的48个输入：四个网络、四个共享随机种子组、三档电压/根表噪声。训练连续一天96点，验证独立288点，测试另一天96点。不重新生成观测。四个网络共用随机种子，主统计仍以4个共享种子组为重采样单位。

主对照只替换训练损失及由该损失驱动的步骤：固定族QP拟合、RNJ临时小块删除代价排名、WZZT单步MIQP、T、E、清零重拟合、收缩后的QP重拟合。原RNJ几何、候选池、初始层级和实际提供的热启动支持族保持父实验合同；热启动的系数和目标值必须重新QP拟合。父热启动支持族已经经过其L1预处理，不将其冒称为未裁剪的全部几何层级。

新运行两种结构：无T和T系数.003；每种48输入，共96个计划配置。原L1同结构结果作为配对对照，旧T系数.01结果单独保留，本轮不新增正则网格、阻抗下界或其他搜索策略。RNJ整树最终备用关闭；RNJ仍提供几何候选和热启动指导。

主输出继续使用原来的MAE验证和.24收缩合同，以隔离训练目标变化并保留当前DR的绝对误差评分接口。另在相同QP输出候选库上报告MSE验证视图，不新增拟合或结构搜索。因此主方法明确称为“平方误差训练＋MAE验证”，不能称为全部步骤均改为L2。

对同一个完整RNJ参考家族及相同权重界，分别取得父MAE最优值和新QP的MSE最优值，定义

\[
K=f_{0,\mathrm{MAE}}/f_{0,\mathrm{MSE}}>0,\qquad
L_{\mathrm{int}}=K\,\mathrm{MSE}.
\]

内部目标为 \(L_{\mathrm{int}}+\alpha f_{0,\mathrm{MAE}}k\)，等价于最小化 \(\mathrm{MSE}+\alpha f_{0,\mathrm{MSE}}k\)。这里 \(k\) 为非单点、非全集连接数。这样保留原数值接收门槛和容差在参考损失中的相对尺度；没有把MAE的绝对线路罚直接套到平方误差。SSE与MSE仅相差固定观测单元数，罚项也同步缩放。两参考值均只用训练数据，K在搜索前冻结；零或非有限参考值须显式报告，不暗加分母下限。

保留原线性残差约束，清除误差变量的原线性成本，加入正二次成本。数据放大S=1000时，二次系数为K/(mS)，m为训练残差单元数，使Gurobi目标除以S后仍等于内部目标。所有结构约束与乘积线性化保持原样，所得连续松弛为凸QP，整数问题为MIQP。固定族也用同一平方误差目标，不能只改结构求解器而留下L1重拟合。

每配置仍采用14400秒总预算、原始单步MIQP3600秒、固定族QP300秒、前向最多7200秒且不超过剩余结构预算一半、输出保留600秒、相对gap=.0001、单线程、最多8配置并行。T和E使用其阶段剩余预算。96配置名义预算上限384方法小时。共同父预处理成本每方法计入一次，新参考QP及热启动QP成本另计，队列等待和后分析分别记录。

先跑四网络首种子、中噪声的8配置pilot。先核验手算例、目标单位、二次审计、独立有界最小二乘和导出预测，再扩大到96配置；不根据pilot F1改变参数。参数或实现若需修复，保留原失败和源版本，不在冻结源内无记录改写。

原生点的objective为内部归一化MSE。面向MAE合同的导出只复制系数并计算真实MAE，另存原始MSE/SSE及K，不改原生点或冒充L1最优拟合。实际最终输出必须完整包含在导出库中。

主指标为F1、完整恢复数/48及总算法耗时，并报告预测MAE/MSE、T触发、清零、E、求解gap与超时。独立核验使用NumPy重建响应和SciPy有界最小二乘/KKT，不能复用原HiGHS的L1最优值等式。失败和未完成保留96计划分母。原L1收尾与新MIQP实现隔离，新真实批次在原L1收尾后运行。

# 当前效果评估、实现简化与改进顺序

日期：2026-09-19。依据：已完成的 M7 55 条记录、本轮三个代表场景回归、当前源代码。没有重新执行 M7 全矩阵，也没有引入新模型的性能结论。

## 1. 当前效果应如何评价

**当前是已验证求解正确性的研究原型：L1 幅值估计在这两个事件上表现较好，固定阈值对线损低估敏感，稳定定位与受控误报仍缺少足够证据。** 最值得继续做的是把检测与定位的证据补齐，暂时不宜增加更复杂的联合幅值优化。

|维度|已有证据|判断|
|---|---|---|
|优化正确性|48 组独立 H0/H1 比较均通过原直接可行性、乘积、目标校验；最大 gap 约 1.44e−16|在给定树、候选域、权界及固定幅值的 MILP 内成立；不是物理模型正确性或统计可靠性证明|
|L1 线损|5 个独立 null 上相对 L0 的 MAE 中位数 4.22%|可作为实用候选；误差混合了近似、树/权重与量测误差|
|L1 幅值|exp2/exp3 活动时段相对 MAE 为 2.47%/3.58%|两个 8 kW 事件的幅值量级较好，不能推广到更弱事件或其他馈线|
|正常状态检测|L1 为 0/5 误报|样本太少；不能解释为误报率接近零|
|抗偏置|固定原 q95 下，−50%/−25% 线损偏置分别误报 5/5、1/5|明显低估线损会破坏旧阈值的适用性|
|定位|L1 两个事件的“整窗集合覆盖”均为真；逐活动时刻仅 2/6 命中真值区域或祖先区域|当前输出不足以支持稳定、唯一定位；需要区分最优解选点与近优相容集合|
|幅值区间|L1 exp2/exp3 的 ±25% 线损包络分别覆盖 3/6、2/6 个活动时刻真值|当前只是对线损假设的确定性敏感性范围，不是可靠的真实幅值区间|

若把 5 个评估样本视为同一固定判定规则下的独立 Bernoulli 试验，0/5 误报的单侧 95% 精确上界为

p_upper = 1 − 0.05^(1/5) ≈ 45.07%。

这是小样本证据不足的直观量化，不是对真实误报率为 45% 的估计。同样假设下，即使观察到零误报，也至少需要 59 个独立评估样本，才可使这一单侧上界低于 5%；多个条件分别比较及样本相关性还需另行处理。

## 2. 当前增益的来源与误报机制

令 d_t=P₀ᵐ−ΣPᵐ−l̂，â_t=max(d_t,0)，u_t=Σ_h s_th∈{0,1}。由于幅值固定为正平衡残差，H1 选择 u_t=1 时，可直接消除该时刻正的有功平衡残差：

G = G_voltage + G_balance，
G_balance = Σ_t u_t max(d_t,0) / σ_balance。

这并不使 H0/H1 比较无效，但意味着“幅值来自总表平衡”和“平衡拟合改善”使用的是同一个量测来源，不能相互充当独立验证。需要通过完整流程的 null 校准处理这种选择效应。

|条件|总 gain|电压 gain|平衡 gain|
|---|---:|---:|---:|
|L1 exp2|168.972|67.576|101.396|
|L1 exp3|187.340|84.314|103.025|
|−50% 偏置 null，复制 31|11.659|6.688|4.971|

事件存在明确的电压改善，不能说告警全部来自平衡项。同时，误报案例也有正的电压改善，因此简单增加 `G_voltage > 0` 并不能解决误报。R/X 重估、逐时选点和量测误差也需要被纳入校准。

另一个已查清的问题是 H0 固定/重估 R/X 的差：由于 H0 的平衡损失与 R/X 无关，这个差是电压拟合自由度的收益，不是线损误差吸收率。M7 中它随线损扰动的最大变化仅 5.68e−14；日常入口无需为此额外调用一次求解器。

## 3. 已执行的简化

新增 `theft_wzzt/detect_simple.py`，150 行，提供 `prepare → detect → decision` 的量测入口。原 627 行 `experiments/run_theft.py` 保留用于研究实验及历史复现；本次没有宣称旧框架已被删除或重构瘦身。

|日常流程|原 M7 单条件入口|简化入口|
|---|---|---|
|输入|实验名 → 生成含真值的仿真场景|6 个量测/量测派生通道 + 已缓存辨识树|
|线损|L0–L4 分支|固定 L1；oracle 变体留在实验框架|
|求解|H0、H1、固定 R/X 的 H0|只求 H0、H1|
|其他计算|扫描基线、真值映射、统计报表|仅输出增益分量、幅值、候选位置和必要诊断|
|判定|M7 汇总 q95；可信度函数另用经验秩|统一用经验秩；缺失/不足校准时为“未校准”而非“无偷电”|
|定位输出|整窗位置集合与真值比较|逐时优化器候选；未校准时不发布定位结论，已校准时也不宣称唯一定位|

这次简化的价值是降低日常执行路径的复杂度、阻止真值意外进入输入、明确判定语义。去掉一次固定 R/X 求解不代表整体运行时间下降三分之一，主耗时仍是 H1。

**优化层与决策层的改动须区分：** L1、固定幅值、H0/H1 模型和参数界完全复用原实现；新入口的经验秩判定是有意统一口径。原 M7 的 q95 判定及所有历史输出保持原样。

当前没有足量的 L1 校准集，因此简化入口默认给出 `alarm=null, status=uncalibrated`。即使显式使用现有 5 个 L1 null，5% 经验秩的最小可达值也只有 1/6，返回 `insufficient_calibration`，不会输出“检验通过”。原 20 个 L0 null 不应仅换一个协议签名就冒充 L1 校准集。

## 5. 建议的改进顺序

### P0：先建立匹配 L1 的完整校准与独立评估

冻结线损模型、权界、窗口、噪声设置和评分规则；用同一入口跑清洁 null。建议下一批以 **199 个校准复制 + 100 个独立评估复制** 为目标，先在代表条件上完成再扩展；这只是建议，尚未启动。199 个校准样本的秩分辨率为 1/200，并不自动证明 5% 实际误报控制。

校准集与评估集不得复用；评估需包含线损失配、负荷水平和噪声变化。若想声称在一组偏置条件下稳健，必须校准并独立验证相应规则，不能仅看当前 5 点曲线。协议签名只能检查声明的配置，不能证明样本独立性、清洁性或分布一致。

验收重点：分条件报告误报数、样本数和区间；有偷电场景增加独立复制与幅值档位，报告检出与定位随幅值变化，而非只报 8 kW 强事件。

### P1：先做固定 R/X 与重估 R/X 的公平定位消融

使用完全相同的固定幅值、观测、评分与候选域，比较：

1. H0/H1 都固定为清洁数据得到的 R/X；
2. H0/H1 都在当前界内重估 R/X。

已有 `fixed_rx` 接口即可完成，不必改 MILP。两种流程分别做匹配校准。不能只固定 H1、放松 H0，或用会重新估幅值的扫描基线冒充该消融。

目的是判断逐时 2/6 命中主要来自参数自由度、模型误差还是位置近等价性；不能事先认定收紧 R/X 一定改善效果，也不能未经验证把界任意缩小。

### P2：对位置稳定的短窗，尝试“单位置假设枚举 + 位置剖面”

若应用允许声明“该短窗来源位置不变，但可以间歇活动”，可直接复用现有 `TheftTree` 和 `fit_theft_milp`：保留同一树、观测和边权界，每次把候选集合设为 `(h,)`，允许逐时选择该 h 或不活动；遍历 h，取最优 H1，并保留每个 h 的目标差。

每个子问题仍允许全零选择，因此 H0 保持嵌套。枚举覆盖全部原候选时，得到的是**短窗单位置假设内**的最优值；它不是原始“逐时可切换位置”模型的等价改写。H0 只需拟合一次。

报告 J_h−min_h J_h 的位置剖面，输出近优区域集合与宽度，不再仅拼接每个时刻的一组最优选点。相容容差需要单独论证或模拟校准，不能把任意目标差阈值叫置信区间。exp4 的真实位置切换不满足此假设，应保留原流程、分窗或另做切换建模。

这是比立即扩展复杂联合 MILP 更容易解释的定位试验，**本轮尚未实现或验证改善效果**。

### P3：将线损与表计误差真正纳入不确定性口径

先在模型外做：用 L1 附近的声明误差网格反复生成固定幅值并拟合，报告哪些告警/区域对所有已测网格点一致。它只证明有限网格上的稳定性，不证明连续误差区间的鲁棒性；不要再用不可观测 L0 作为部署时扫参中心。

真实幅值区间应同时包含实际线损 ℓ∈[ℓ_lo,ℓ_hi] 与表计合成误差 ε∈[−e,e]。令 D=P₀ᵐ−ΣPᵐ，则可行幅值集合为

A = [D−ℓ_hi−e, D−ℓ_lo+e] ∩ [0,+∞)。

若上端小于零，表示当前误差假设与量测不相容，应标记为空，而非机械地把两个端点都截断成零。若界是概率界，还必须说明联合覆盖口径。实际线损应包括偷电导致的额外线损，不能默认等于无偷电 L0。

后续如改模型，可在 H0/H1 中同时加入相同的有界平衡误差项 e_t，仍保留固定幅值；有界线性误差变量和 L1 残差可以保持 MILP，H0 仍对应零选择。误差界必须来自独立证据，不宜任意放宽；整个流程要重新校准。该模型改动未实施。

## 6. 暂不建议优先做什么

- 不先把幅值 a、R/X 都变成连续未知量直接联合拟合：会产生 r·a 一类连续乘积，失去当前精确 MILP 的结构；有限幅值网格是另外一种近似，不能冒称连续问题全局精确。
- 不用外层“定位—修正线损—再定位”迭代替代误差校准；它需要另外研究收敛、选择偏差和整个算法的统计行为。
- 不根据 0/5 误报宣布安全，也不根据整窗集合包含真值就宣布定位成功。
- 不把更低目标值、更多可选参数、更多最优解候选自动解释为更高可信度。

下一步最有价值的组合是：**匹配 L1 的独立校准评估 + 固定/重估 R/X 消融 + 短窗位置剖面**。后两项的改善仍是待验证假设。

# 单个大块退出后重启：结果前固定的小规模机制试验

用户指定small3_original_exit为主线，要求考虑更灵活的退出和屏蔽后重拟合。本试验保留主线，只检验退出后一次重新搜索能否增加纠错机会，不扫描惩罚/阈值、不改生产算法。

## 对象和时机

固定使用原120输入中的24个：四个网络，bundle2/3，N48，三档电压噪声。按输入条件选取，不按正确与否或F1筛选。起点为旧small3_original_exit的训练退出终点（尚未最终收缩/验证选择）。本试验只测试该时机，其他提前触发时机仅作数学讨论。

每个输入至多选择一个当前保留的大块C：5<|C|<n，优先终端数最多，同规模按终端位置字典序。包括仍保留的零权重集合，因为它们同样可能限制相容域。没有大块的输入保持分母，退出分支不实施，另报可实施子集。

## 五个对照

1. historical：旧主线记录，逐字节保留，不是新重跑。
2. continue：从同一训练终点恢复原WZZT及五块末端联合，不删除连接；用于检查增加计算时间的影响。
3. drop_refit：删掉C，仅重拟合剩余家族的连续LP。
4. drop_resume：删掉C、重拟合，恢复原WZZT及末端联合；允许C再次入选。
5. mask_resume：同上，但新集合成员加Hamming排除C，末端选择也强制u_C=0；仅禁止这个确切集合，不禁止其子集/超集。

后三个退出提议允许暂时提高训练目标，否则无法跨越删除造成的障碍。重启后的每个新增/末端步骤继续使用原J改善门槛。只重启一次，不再串联第二次全池退出，也不逐块循环。本试验不是完整重新运行RNJ初始化。

## 数学与输出

固定家族LP满足L(F\{C})>=L(F)，所以单独删块不能改善最优原始拟合。重新运行同一个完整可选候选MILP也不扩大域；重新启动自由WZZT才能提出之前被C交叉限制排除的集合。屏蔽是一个受限反事实，不保证训练J下降，也可能删掉真块。

沿用J=训练MAE+.003*f0*K，响应界[0,2]，相同原终端量测，0.24固定收缩，strict验证。每个新分支单独报告：未收缩终点、只在本分支路径选择的提议、加入原主线最终候选后的验证保护结果。保护可拒绝屏蔽提议并返回含C的旧树，不能把保护输出说成全局硬屏蔽。真拓扑和test仅评分时打开。

96个新作业（24×4），8单线程worker。每分支每输入总账14,400秒，计入旧公共前端和主线记录耗时；新单步MILP至多3,600秒，LP至多300秒，预留600秒后处理，MIPGap=.0001。达到gap即可提前结束。历史记录原300秒结构预算保留，新continue对照用于区分延长预算与退出效果。累计记录组件时间不是新测整套端到端时间。

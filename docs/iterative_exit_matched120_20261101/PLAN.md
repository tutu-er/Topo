# 同120输入、等预算的新旧主线对照

本实验执行用户指定的完整比较，不调参、不增加第三种部署策略。输入沿用原四方法矩阵的全部120项：paper15、soumalas11、flynn16、pengwah18各30项，包含主矩阵108项和压力条件12项。保留原训练/验证/测试文件、采样长度、RNJ共同前端和原300秒结果；两种方法均重新求解120次。

## 对照与控制

- before：原冻结版“至多两个不相交RNJ小块＋原始WZZT步骤＋五块末端联合枚举＋最终退出”。算法源码从outputs/rnj_four_methods_20261031/source取得，执行前核验原协议中的全部源码哈希。
- after：当前研究主线，增加迭代零块释放、一次训练排名临时删块，以及允许旧块回来/暂时屏蔽旧块的恢复分支。全部分支共享总预算。
- 两侧使用同一线路数惩罚系数0.003乘原完整RNJ训练MAE、响应界[0,2]、同一RNJ种子规则，无新增物理阻抗下界。
- 所有MILP相对gap统一0.0001，绝对gap 1e-7，单线程。旧前向/退出代码原gap为0.001，仅在隔离源码副本中统一为0.0001，并记录替换前后哈希；没有改写原快照。
- 最终选模统一沿用原方法：0.24收缩、联合重拟合、严格验证MAE、平分少内部集合/固定顺序、相同完整RNJ候选库及单点回退。新版原有native选模结果另外保留，报告统一口径的影响。
- 训练worker的payload只含训练、验证及冻结共同前端；无测试路径、物理真拓扑或按F1选模。真拓扑与测试仅由独立分析入口读取。

新版按max(r,x)<=1e-9识别临时内部零块，删后联合重拟合MAE增量<=1e-10才提交。原加块改善门槛为1e-10+0.001乘当前训练MAE；停滞最多一次训练删块排名，不重新调参。F1沿用原内部集合口径，排除单点和全集；完整恢复指预测的正权重内部集合与真实内部集合完全一致。

## 求解与计时

每方法/每输入总账上限14,400秒（4小时），计入共同RNJ前端的原记录成本、观测准备、训练、恢复分支、退出和输出选模。前缀上限7,200秒，且不超过可用结构时间一半；原WZZT单候选步骤的MILP上限3,600秒，末端联合MILP与最终退出使用所属阶段剩余预算；单LP上限300秒；预留600秒完成输出。实际达到停止条件便结束，无需消耗满上限。

共240次新求解，8个单线程worker，按案例轮换、按输入交替新旧启动顺序。最高方法总预算为960小时，属于各输入上限之和，不是预计耗时或机器并行墙钟。分别报告算法内新增时间之和、加共同前端后的方法耗时之和、中位数/最大值及整批并行墙钟。算法内计时包括数据准备、求解和验证，不包括Python进程启动/模块导入；共同前端未重新生成，累计账不是从头重跑前端的实际时间。

原300秒历史结果另列historical300，作为预算及精度放宽的参照（历史gap为0.001），不将其称为纯时间单因素实验，也不拿它替代等预算before。

## 指标与机制统计

主比较为最终含RNJ保护的F1、完整恢复数/120、方法总耗时；同时报告自身路径结果、分案例、主矩阵/压力条件、采样长度和噪声，以及逐输入胜/平/负、新增完整恢复/丢失完整恢复。

零块统计区分检查事件、成功释放事件、集合释放次数、不同集合数和触发输入数。新增显式清理与旧方法原有最终退出清理分开解释。

停滞恢复区分可操作停滞、选中删块、排名是否遍历完、实际运行恢复/屏蔽、最终采用及被选块真/假、规模和种子来源。屏蔽只在该分支内禁止确切集合，不限制其他分支。

收益逐级比较before→after、before→新版baseline、baseline→加入非屏蔽恢复、再加入屏蔽恢复，分别统计验证改善、F1改善/下降及新增/丢失完整恢复。新版baseline的退出时间来自共享预算，因此该零块路径比较不是额外独立满预算的单因素消融。记录原始终点训练L/J，避免只看训练拟合或把触发数当收益。

## 核验与恢复

每个保存路径/输出验证laminar性、响应界、重算训练MAE，并以独立HiGHS固定家族L1 LP核对最优拟合值。检查屏蔽贯穿恢复路径、零块删除损失容差、每输入至多一次恢复、源/输入/共同前端哈希、时间账和历史归档不变。记录每个MILP状态、可行目标、界与gap；超时或未闭合保留原分母，不报告全局拓扑最优。

入口为research_experiments.iterative_benchmark.run的freeze/run/status，以及research_experiments.iterative_benchmark.analyze。输出目录outputs/iterative_exit_matched120_20261101；state.json实时记录返回数、队列和worker PID；每项独立result/checkpoint/error可恢复。未完成前不发布完整120输入的效果结论。

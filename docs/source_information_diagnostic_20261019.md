# 已知时序、未知位置的 Source：信息机制与 Soumalas11 设计诊断

2026-10-19。对象为已生成的 Soumalas11 三个重复，每个重复采用三段96点、合计288点。本文核查输入设计和条件性信息机制，采用原有观测、保存的无噪声输入及AC物理记录做线性代数和已知参数前向计算。

**同树 Source 约束可以提供额外信息；本批数据支持的是条件性的结构约束收益。** 三个重复中，投影前后的观测设计、无噪声设计均为22列满秩；固定真树的30个边参数设计也均满秩。当前设计没有出现由FWL投影造成的精确秩缺失。源明显增强两条祖先边的P/Q激励，但固定正确树和源路径时，全体边参数最弱方向的信息曲率仅提高约4.3%–4.8%。未知树、未知路径、输入测量误差和AC模型偏差仍影响实际恢复。

本文所有数值来自[完整诊断JSON](D:/0-github_workspace/Topo/tmp/source_advantage_fwl_rank_diagnostic_20261019.json)。计算未读取任何方法的F1或拟合结果，未生成数据、调用估计器或求解器，也未修改正式配置。

设 \(P,Q,Y\in\mathbb R^{288\times11}\)，其中 \(Y\) 为根节点与终端的电压平方差。\(u_P,u_Q\) 是已知源时序，\(U=[u_P\ u_Q]\)。自由终端响应模型为

\[
Y=PR+QX+UG+E=DC+UG+E,
\qquad D=[P\ Q],\quad C=\begin{bmatrix}R\\X\end{bmatrix}.
\]

这里 \(G\in\mathbb R^{2\times11}\) 可独立响应每个终端。令 \(\Pi_U\) 为源时序列空间的正交投影，\(M_U=I-\Pi_U\)。保留相同的 \(C\) 约束时，消去自由 \(G\) 的最小二乘问题精确等价于

\[
\min_C\|M_U(Y-DC)\|_F^2.
\]

因此，FWL同时投影负荷设计和电压目标，是自由 \(G\) 模型的消元步骤。项目的NJ/RNJ前置回归采用这个最小二乘口径，再施加R/X对称、非负及对角顺序约束，未添加独立截距。FWL会去掉终端负荷中落在 \(\operatorname{col}(U)\) 的分量；这些分量在自由 \(G\) 下本就可与源响应互相补偿。此等价关系针对自由响应最小二乘；WZZT采用的L1目标及同树源路径约束属于进一步的模型选择。

同树约束把源响应与边参数联系起来。用 \(z_e\in\{0,1\}^{11}\) 表示边 \(e\) 下游的终端集合，用 \(h_e\) 表示该边是否位于根到源的完整路径。\(r_e,x_e\) 是矩阵分解的原子系数，本诊断由物理线路按 \(2r_{line}/Z_{base},2x_{line}/Z_{base}\) 换算；功率时序均使用标幺值。于是

\[
R=\sum_e r_ez_ez_e^\top,\qquad
g_R=\sum_e r_eh_ez_e,
\]

X通道同理。固定树和路径 \(h\) 后，边 \(e\) 的R通道对观测的贡献为

\[
r_e(Pz_e+h_eu_P)z_e^\top.
\]

把所有终端的时间序列纵向排列，得到边参数设计矩阵 \(B_h\)。其R列是 \(z_e\otimes(Pz_e+h_eu_P)\)，X列相应替换为Q。FWL后的设计 \(B_F\) 将时间部分替换为 \(M_UPz_e,M_UQz_e\)。按终端分别作正交投影，有

\[
B_h^\top B_h=B_F^\top B_F+C_h^\top C_h,
\]

这里 \(B_F=(I_{11}\otimes M_U)B_h\)，\(C_h=(I_{11}\otimes\Pi_U)B_h\)，其中 \(I_{11}\) 为11阶单位矩阵；\(C_h\) 收集被投影掉的时序分量。两投影正交，因而交叉项为零。这表示：**固定正确树和路径时，物理约束能利用自由 \(G\) 模型舍去的信息。** 在正确线性模型、已知设计和同方差高斯输出误差下，除以误差方差后即为条件Fisher信息的增加。当前L1拟合、P/Q带噪声及AC数据的有限样本误差，需要另外评价。

该恒等式在两侧采用相同的固定树，隔离的是Source响应约束带来的增量。WZZT的层叠树结构与NJ的自由矩阵回归还存在参数域差异；这项计算没有把全部结构化降方差都归给源。

精确的条件性秩修复要求 \(B_F\) 有缺失方向，且 \(C_h\) 恰好约束这些方向：

\[
\ker(B_F)\cap\ker(C_h)=\{0\}.
\]

路径未知时，还需排除其他允许的树、路径和边参数产生相同预测。单个正确路径下的满秩，只解决该路径内的参数识别。

一个两叶例子说明条件性识别收益。根连接两个终端，源位置为两叶之一，两个源时序线性独立。令第一叶 \(P_1=u_P,Q_1=u_Q\)，第二叶 \(P_2=v_P,Q_2=v_Q\)，并令四条时序 \(u_P,u_Q,v_P,v_Q\) 线性独立。源实际位于第一叶时，

\[
y_1=2r_1u_P+2x_1u_Q,\qquad y_2=r_2v_P+x_2v_Q.
\]

FWL消去了第一叶的全部P/Q列。同树模型中，若把源改放第二叶，则第二叶必然额外含有正的 \(u_P,u_Q\) 响应；在正边参数和上述独立时序下，无法复现原观测。因此，在这个给定的两叶候选位置域内，源路径及第一叶的R/X可以恢复。

最小反例也只需两叶。令两叶都满足 \(P_i=u_P,Q_i=u_Q\)。源在第一叶时，

\[
y_1=2r_1u_P+2x_1u_Q,\qquad y_2=r_2u_P+x_2u_Q.
\]

把源改放第二叶，并取

\[
(r'_1,x'_1)=(2r_1,2x_1),\qquad
(r'_2,x'_2)=(r_2/2,x_2/2),
\]

预测完全相同。取足够小的正边参数即可同时满足同一个有限上界；叶边也不受本轮非singleton下界约束。即使源P/Q秩为2、拓扑已固定，未知源位置和R/X仍有等价解释。源时序独立、源幅值较大，均不足以单独保证联合识别。

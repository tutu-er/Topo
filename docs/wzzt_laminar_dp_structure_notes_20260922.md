# wzzT 的合法集合参数化、局部邻域与动态规划边界

日期：2026-09-22。本文只读核对当前核心实现，并给出独立数学推导；未修改核心代码，也未运行旧 Benders 实验。

## 1. 对齐当前目标

核心来源：`rnj_wzzt_core/rnj_wzzt/estimation/laminar_l1_milp.py`。

- 第 5–15 行：`R=Σ_A r_A 1_A1_A^T`、`X=Σ_A x_A 1_A1_A^T`；单次扩展精确，整个前向路径仍是贪心。
- 第 391–460 行：非空、非重复、laminar 集合约束。
- 第 525–543 行：一个支撑 A 的特征是 `1{i∈A} Σ_{j∈A}P[t,j]`，Q 同理。
- 第 684–740 行：固定支撑后，旧、新全部系数共同拟合，系数有非负上界，每场景每输出有自由截距。
- 第 1204–1214 行：初始支撑固定保留；候选池只保证池内单次扩展最优。

记当前支撑族为 F，候选新增集合为 S。真正要比较的是

\[
Q(F\cup\{S\})=\min_{r,x,\alpha}\frac1N
\sum_{s,t,i}\left|D_{sti}-\alpha_{si}
-\sum_{A\in F\cup\{S\}:i\in A}
\left(r_A\sum_{j\in A}P_{stj}+x_A\sum_{j\in A}Q_{stj}\right)\right|.
\]

这里所有 r、x 均跨场景共享；因此不能把“固定旧系数时的新原子打分”直接当作上述完全重拟合目标。

## 2. 精确重参数化：一个合法新集合是同一容器的子块之并

令终端全集为 U，n≥2。补全

\[
\bar F=F\cup\{U\}\cup\{\{i\}:i\in U\}.
\]

这只是用于搜索的结构表示：补上的虚拟节点不自动成为回归原子。按包含关系构建根为 U 的树；C 的直接子节点是严格包含于 C 的极大成员，记 `child(C)`，数量为 d(C)。因为补齐了 singleton，直接子节点互不相交并且恰好划分 C；每个非叶节点至少有两个孩子。

**命题。** 任意与 F 相容、非空且不在 F 中的集合 S，恰落入以下一类：

1. F 缺少的 singleton；
2. F 缺少的全集 U；
3. 存在唯一内部节点 C 及唯一子节点子集 J，使
   \[
   S=\bigcup_{B\in J}B,\qquad 2\le |J|\le d(C)-1.
   \]

第三类中的 C 是 \(\bar F\) 中包含 S 的最小容器。反过来，每个这样的子块并都是合法的新集合。

**证明。** 前两类排除后，S 不属于补全族。取最小容器 C。S 是 C 的真子集。若直接子块 B 与 S 相交，laminar 条件只允许 B⊆S 或 S⊆B；后一种情况与 C 最小矛盾。因此每个相交子块均完整包含于 S，且这些子块划分 S。只取一个子块会使 S 已在补全族，取全部子块会使 S=C，因此必须取 2 至 d(C)-1 个。最小容器与不交子块划分给出唯一性。反方向，对任何旧节点 A：A 在 C 之外则与 S 不交或包含 C；A 位于 C 内则包含在某一直接子块内，因此被 S 包含或与 S 不交。故仍 laminar，且不等于任何已存在节点。证毕。

**准确候选数量。** 对 n≥2，合法新增支撑的数量是

\[
\#\mathcal A(F)=\#\{i:\{i\}\notin F\}
+\mathbf1\{U\notin F\}
+\sum_{C\text{ 内部节点}}\left(2^{d(C)}-d(C)-2\right).
\]

n=1 单独处理：唯一可能是尚未存在的 U=singleton，不能重复计数。若 F 已含 U，全集例外项为零；若 F 已包含全部 singleton，singleton 例外项为零。

例子：n=4，F 只有四个 singleton，则根有四个孩子，一共有 `2^4-4-2+1=11` 个合法新集合。若 F 再含 `{1,2}`、`{3,4}`，则仅剩缺失的全集可以新增；再加入全集后无合法新集合。后者说明当前 laminar 族已经饱和，**不说明它在所有其他树结构中最优**。

独立有限核对：枚举 n=1、2、3、4 的全部非空子集族，再筛选 laminar 族，共分别检查 2、8、64、832 个合法族（合计 906 个）。对每个族直接逐个测试所有非空新集合，与上述子块并生成结果逐项比较，并核对计数公式，全部通过。该检查不调用核心求解器，也不替代上面的证明。

这不是候选池截断，而是全合法域的精确枚举方式。其潜在收益取决于最大分叉度 Δ：候选数量可由 O(n·2^Δ) 控制，但 singleton 初始化对应 Δ=n，仍有指数数量；不能据此宣称多项式算法。

## 3. 从表示直接得到合法邻域

### 单次扩展内部的邻域

在固定容器 C 内，用孩子选择向量 b 表示 J：

- **加一块**：把一个未选孩子加入 J；
- **删一块**：从 J 移出一个已选孩子；
- **交换一块**：移出一个已选孩子，再加入一个未选孩子。

只接受 `2≤|J|≤d(C)-1` 的状态，合法性自动保持；缺失 singleton、缺失根需作为显式额外状态。一个状态有 O(d(C)^2) 个上述邻居。交换操作很重要：当 d(C)=3 时，第三类集合只能有两个孩子，单独加/删均无效，而交换仍可遍历三个状态。

同一容器内，加/删/交换在所有第三类状态之间具有组合可达性；但它们不会改变最小容器。实际算法须遍历各容器，或加入容器切换与多起点。只要没有枚举所有集合或有效下界，局部最优不能升级为全域最优。

### 整个支撑族的邻域

- 删除非保护支撑 A 永远保持 laminar；结构上是删除对应内部节点，并将孩子提升到父节点。
- 替换 `A→B`：先从 F 中删除 A，再按上述精确表示为 `F\{A}` 生成 B。这允许 B 与被删除的 A 相交但互不包含，从而改变已有分支划分。
- 大邻域：一次释放少量不确定内部支撑，再对局部多叉节点重组。若只允许新增并永久保留旧集合，错误早期分组无法纠正。

若允许删除所有非保护集合并重新加入，则在共同保护族 F0 的约束下，任意两种合法族之间都有“删至 F0，再构建目标族”的路径；这只是可达性结论。**在无复杂度惩罚的完全重拟合训练损失中，单独删除回归原子不会降低 Q**，因此严格下降算法可能拒绝必要的中间删除。交换、允许暂时恶化的搜索或显式复杂度惩罚才可能利用这些路径。保护初始支撑不应被擅自释放：核心现有契约将它们视作固定拓扑块。

## 4. 原始 L1 目标为何不能直接使用子树标量 DP

不同子树虽然终端集合不交，但同一祖先的 r、x 系数同时进入两边的残差。独立优化各子树会给共享祖先分配不同参数，改变可行域。

**最小反例（保留全部 singleton、自由截距和完全重拟合）。** 两个终端，一个场景，两个时刻 `s=-1,+1`，令

\[
P_s=(s,s),\quad Q_s=(0,0),\quad D_s=(0,3s).
\]

支撑族为 `{ {1}, {2}, U }`。全集原子系数为 r，两个 singleton 系数为 a、b，三者都在 `[0,1]`。对每个输出独立优化自由截距及其 singleton 系数后，分别有 a=0、b=1，因此两子叶按时间平均的损失分别为

\[
f_1(r)=|2r|,\qquad f_2(r)=|2-2r|.
\]

于是

\[
\min_{0\le r\le1}[f_1(r)+f_2(r)]=2,
\qquad \min f_1+\min f_2=0.
\]

第一边使用一个共同 r，第二边分别需要 r=0、r=1，根本不是同一模型。上式 f1、f2 各自已经除以两个时刻；联合 MAE 还需再除以两个终端，因此正确 MAE=1。等价地，两叶的残差和分别为 4r 与 4(1-r)，联合残差和为 4，按当前总观测数 N=4 正规化得到 1。错误拆分会给出 0。Q 为零意味着 x 系数对该例没有影响，允许它们共同重拟合也不改变结论。

因此只有一个“该子树最佳损失”标量的 Bellman 状态不够。即便两子树的局部系数不同，也仍必须保留共同祖先的影响；固定旧系数只是避免其中部分耦合，并不自动使一个新集合内部的损失对子块可加。

## 5. 哪些 DP 有数学依据

### 5.1 固定结构上的函数值 DP：可以写，但一般状态很大

把各场景时序拼接，共 m=Σ_s T_s 个时刻。给子树 C 的进入信号定义为祖先原子累计贡献 `h∈R^m`。令 `p_C,q_C∈R^m` 为 C 内注入求和时序。内部节点的形式递推可以写成

\[
V_C(h)=\min_{0\le r_C\le\bar r,\,0\le x_C\le\bar x}
\sum_{B\in\operatorname{child}(C)}
V_B(h+r_Cp_C+x_Cq_C).
\]

叶节点的终止函数是观测残差对该 singleton 自身 r_i、x_i 及每场景截距共同最小化后的损失；虚拟而非实际回归原子的节点固定 `r_C=x_C=0`，包括未被实际选入的 singleton。这里正确保留了共享祖先。一般只传“父边两个系数”不够，因为更早祖先具有不同的时序向量。

但是 V 是连续状态上的分段线性函数，状态维数可达 m，精确表示的片段数量未获多项式界。把状态离散到每维 L 个值会遇到 L^m 的规模，并产生离散近似误差；有限参数网格也不自动意味着低维状态。对**固定支撑**，现有线性规划已经直接完成同一连续优化，不应仅凭上述递推声称提速。

若所有累计影响确实位于一个固定小维数、有限可达状态的信号空间，可在该特殊模型上构建状态 DP；这需要单独证明状态充分性与网格封闭性，不是当前一般 P/Q 数据已满足的性质。

### 5.2 可加替代目标上的子集 DP

若目标已被定义为二叉层次树的局部代价和 `Σ_C c(C)`，且 c(C) 与祖先/其他子树的参数无关，则

\[
V(S)=c(S)+\min_{\varnothing\ne A\subsetneq S}
[V(A)+V(S\setminus A)]
\]

是合法的子集 DP；规定最小编号终端属于 A 可去掉对称重复。一般时间 O(3^n)、空间 O(2^n)，是小规模精确方法，不是大规模多项式方案。若加入 K 个局部结构的预算，则需要额外计数状态和合并卷积。

如果终端顺序已知且仅允许连续区间，可改为区间递推，常见复杂度 O(n^3) 时间、O(n^2) 空间。但“连续区间”是额外结构约束；数据生成的顺序只能给出受限搜索，不保证保留原问题最优解。

固定参考树上、目标是独立块代价的**剪枝/分区**，可以用 `V(C)=min(c(C),Σ_B V(B))`。它优化的是叶块分区；不能直接等同于允许祖先和后代原子共同出现的当前 wzzT 模型。

### 5.3 局部打分的 DP 与真实损失应分开

固定当前残差次梯度后，新原子的线性化打分仍通常含 `z_i z_j`，即 `z^T H z`。在孩子层面仍有跨子块二次交互，因此一般不是普通背包可加目标。只有交互图具有小 treewidth、链形结构等附加性质时，才可能对该**打分代理问题**使用相应 DP；之后仍需以原始完全重拟合 L1 LP 验证候选。代理 DP 最优不等于原始 Q 最优。

## 6. 给后续原型的建议

优先用精确层级表示生成合法邻域，以多起点的块加/删/交换搜索提出新支撑；先用廉价分数排序，再对候选做真实固定支撑 L1 完全重拟合。加入已有内部支撑的交换或有限大邻域，减少前向冻结错误的影响。对小 n 保留全合法集合枚举作为 oracle，并分别报告目标差距、搜索时间和未找到更优邻居的范围。

DP 适合两类辅助用途：小规模可加代理的精确 oracle，以及有明确低维/树宽/顺序约束的局部代理求解器。目前没有根据把一般联合 L1 wzzT 直接替换为简单、精确且多项式的子树 DP。

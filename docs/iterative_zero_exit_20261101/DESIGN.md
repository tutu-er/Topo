# 当前研究主线：迭代零块释放与一次停滞修复

用户确认三条规则：零权重集合及时释放；前向停滞时允许一次临时删块并恢复搜索；屏蔽只作临时反事实，经验证决定采用。本次将其接入研究主线，不重写历史实验或更改已声明物理硬先验的语义。

## 实际修改范围

- 通用核心fit_laminar_l1_sensitivity本来已在接受扩展后清理非初始零权重集合；其initial_supports仍表示固定先验，本次没有改成可随意删除。
- 补齐研究用joint_five.search普通前向、rnj_count.search、rnj_small_seed.prefix及rnj_union_long.pure_search的清理调用。普通前向默认zero_release=True，复现旧零块保留行为可显式False。纯WZZT仍只从单点/全集基出发，每次接受扩展对应一个已清理的路径点。
- 当前完整策略入口为research_experiments.iterative_exit.engine.fit_mainline；四算例入口检查使用同包run。旧实验脚本的冻结源继续用于复现旧协议，不把旧结果解释成已运行新策略。
- hard显式传递已核实先验；RNJ种子在研究主线中是临时集合。单点和全集响应基保留。

## 每轮清理

在初始状态、接受新连接后、预/末端联合重拟合后清理所有临时内部集合，不仅检查本轮新增项。条件为max(r_C,x_C)<=1e-9。删除后重新拟合；只有新MAE<=旧MAE+1e-10才提交删除。若重拟合又使其他集合归零，继续清理至稳定。拒绝清理时保留原家族并记录原因。

零块释放不要求满足普通加块的相对改善门槛，否则纯结构解锁可能被误拒绝。精确零意味着原预测仍可表示；数值近零只有复核容差范围的保证。释放的集合不被永久禁止，后续若有正响应贡献可重新入选。

末端重拟合清理后若结构改变，重新检查剩余直属块和候选域，不能拿旧层级直接停止。循环仍受3n步和墙钟预算限制。

## 一次停滞修复

只有前缀最后一次前向/末端尝试未接受且未声明墙钟耗尽，才允许一次修复；求解未闭合时只叫操作上的停止，不叫已证明的局部最优。

在当前所有非硬内部集合中计算删块后的训练LP损失增量，选最小者；同分按规模和字典序。它是训练删块成本，不是线路正确概率。最多处理一个集合，不逐块循环，不设新惩罚网格。删除可暂时提高L或J，否则无法跨过结构障碍。

生成两个完整延续：release允许旧块回来；masked仅在本分支用Hamming约束和退出池过滤禁止该确切集合，子集、超集和量测均保留。恢复原WZZT/五块末端后运行该分支的最终结构退出，屏蔽在整个训练延续和输出拟合中持续有效；两条分支都禁止递归触发新的停滞删块。

只有所有训练延续结束后，才比较验证MAE。平分沿用少内部连接和固定顺序，顺序优先baseline、release、masked。最终若选旧主线/RNJ回退，原块仍可能出现；此时记录屏蔽未采用，不能称它成为全局硬约束。

## 输出与数学边界

原始训练目标继续J=MAE+.003*f0*K，响应界[0,2]，主收缩0.24，无新物理阻抗下界。单独输出：

1. zero_only_own：及时清理后的主线自身路径。
2. zero_only_with_rnj：该基线加原有公共RNJ验证保护。
3. new_branch：仅release/masked两条新分支的最佳提议，未触发则明确not_triggered。
4. own_output：基线自身路径与新提议验证择优。
5. with_rnj_fallback：再加入公共RNJ库的输出，明确来源。

F1只在训练/验证选择完成后评分，不参与删块排名或屏蔽接受。较低验证损失仍无F1不下降保证。临时删除后的L/J允许变差；每条延续的新增步骤沿用原训练改善门槛。局部/候选域求解界不变成全树最优证明。

## 预算与验证范围

当前策略默认每输入共享4小时，包含基线和两个反事实分支；前缀上限2小时且不超过剩余结构时间一半，单步MILP上限1小时，单LP300秒，预留600秒输出。剩余时间按待完成延续数分配并记录，基线和分支共享总额，不是每分支再各有4小时。旧前缀/退出native gap=.001，恢复搜索native gap=.0001；未宣称新旧方法统一预算的全面对照。

已进行41项相关研究回归和60项通用核心回归。五个研究入口重新冻结时均携带零块清理依赖，rnj_count同时携带匹配的普通WZZT接口；五份隔离快照导入检查通过。历史快照不改写。

四算例入口检查固定为原数据中bundle2/N48/V噪声.0002，每网络一个，只检查源/数据对应、分支和屏蔽生命周期、独立固定家族LP、损失与验证重算。它不是同120输入的重新全面测算，也不用于选参数或宣称恢复率提升。

# Pengwah18：288点全量拟合，有源与无源对照

本轮按用户要求测试pengwah18的无源、常值源、间歇源和平滑源，分别比较NJ、RNJ、WZZT、RNJ+WZZT，共16项。每项使用三个96点场景的全部288点，不划分验证集或测试集。WZZT按原核心无验证分支返回最后认证路径点，不使用one-SE，不按真实F1选择中间模型。

## 数据与方法

场景0逐文件复用 `outputs/source_ac96_20261018/pengwah18/` 的既有96点；另补现有reference场景1、2，使用相同物理网络、源接入位置、replicate=0、量测噪声和AC求解设置。三个场景的背景负荷不同；同一场景的四个源型共享背景与量测噪声抽样。源P/Q曲线在三个场景中相同，源接入位置仅存于仿真真值，不提供给估计器。

数据目录为 `outputs/source_ac288_20261018/`。共1152个AC点，384点复用、768点新模拟，全部收敛。独立复算1165项检查全部通过，最大馈线P/Q平衡残差约3.64e-11 pu；原AC96文件未改变。

## 本轮实际版本

本轮冻结的是 `72af` 工作树中的原子末端块与Source高层完整实现，区别于前一轮D盘旧主线。原始包完整存入仓库的实验源码归档，并复制到 `outputs/source_ac288_runtime_20261018/`。只在运行副本添加默认关闭的被动检查点，剥离观察接口后整个核心模块AST与原件相同；原工作树和D盘已有用户修改均保持原状。每个worker核对实际模块路径，禁止退回旧库。

RNJ+WZZT若没有选出合格末端块，仍保存筛选记录，明确标为没有有效RNJ先验的退化情况；不降低门槛或从真值补簇。固定支撑、不可分原子组和估计的Source路径分别记录。

## 保存与评价

运行目录为 `outputs/source_ac288_benchmark_20261018/`。每项保存全部288行输入及源曲线、实际配置、初始支撑与分区、bootstrap记录、全部认证路径、原始求解器primal/目标/对偶界/gap、原线性约束与界、停止原因和计算时间。超时与失败保留在16项分母中。只有父进程在worker结束后读取真网评分。

同时报告全部非平凡family和活跃支撑 `max(r,x)>1e-8` 的拓扑F1；R/X为平方电压响应矩阵相对Frobenius误差。全量拟合按用户要求进行，预测误差属于拟合误差，没有独立泛化测试。bootstrap频率表示重采样稳定度；单次MILP证书覆盖当前有界单原子子问题，整个前向路径仍是贪心搜索。
